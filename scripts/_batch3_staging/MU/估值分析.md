# Micron Technology 独立估值

> **目标价$650；合理区间$500–800；当前$869.01已进入乐观区间。** 当前12个月盈利异常强，估值核心不是“FY2026能赚多少”，而是2028年供给恢复后可持续赚多少。

## 1. 基准输入

| 输入 | 数值 | 性质 |
|---|---:|---|
| 当前价 | $869.01（2026-07-17） | 市场事实 |
| 稀释股数 | 约1.15bn（Q4指引） | 公司指引 |
| FY2026前九月GAAP EPS | $41.40 | 已发布 |
| FY2026 Q4 GAAP EPS | $30.73±$1.00 | 公司指引 |
| FY2026全年EPS桥 | $72.13中点 | 推算：41.40+30.73 |
| Q3末净现金 | $24.4bn | 已发布 |
| FY2026净Capex | 约$27bn | 公司指引 |
| FY2026前九月简化净FCF | $29.089bn | 45.702-19.602+2.989 |

Q3毛利84.9%，Q4指引约86%；Q3 DRAM/NAND价格分别环比低60%/中80%上涨。故FY2026 EPS属于短缺峰值，不直接赋高倍数。

## 2. 盈利正常化桥

| 情景 | 可持续收入 | 净利率 | 净利 | 每股盈利 |
|---|---:|---:|---:|---:|
| 保守 | $95bn | 42% | $39.9bn | $34.7 |
| 基准 | $115bn | 52% | $59.8bn | $52.0 |
| 乐观 | $135bn | 59% | $79.7bn | $69.3 |

基准不是FY2026预测，而是跨周期正常化假设。52%净利率仍远高于历史常态，反映HBM、SCA和数据中心组合改善；同时显著低于Q3约68%的净利率。

## 3. PE法

周期硬件的基准倍数取13倍；优质寡头/净现金上调，资本强度和地缘风险下调。

- 保守：`$34.7×11=$382`
- 基准：`$52.0×13=$676`
- 乐观：`$69.3×15=$1,040`

PE法基准 **$676**。

## 4. 正常化FCF收益率

FY2026前九月简化净FCF $29.1bn，Q4若OCF约$30–35bn、净Capex约$10bn，则FY2026简化FCF约$49–54bn；这是短缺峰值估计。

基准正常化FCF取$38bn（净利$59.8bn+D&A约$12bn-净Capex约$32bn-营运资金约$2bn）。

`权益价值=$38bn/5.0%=$760bn`；除以1.15bn股 = **$661/股**。

情景：$28bn/6%= $406/股；$48bn/4.5%= $928/股。

## 5. DCF

显式公式：`EV=ΣFCF_t/(1+WACC)^t + FCF_5×(1+g)/(WACC-g)/(1+WACC)^5`，再加净现金$24.4bn、除以1.15bn股。

基准FCF序列（$bn）：42、40、38、40、43；WACC 10.0%，终值增长3.0%。

- 五年现值：`42/1.1 + 40/1.1² + 38/1.1³ + 40/1.1⁴ + 43/1.1⁵ ≈ $144.4bn`
- 终值：`43×1.03/(10%-3%)=$632.1bn`；现值约`$392.5bn`
- 权益价值：`144.4+392.5+24.4=$561.3bn`
- 每股：`561.3/1.15≈$488`

DCF低于相对估值，核心原因是全额计入增长Capex；这是有价值的警告，不删除。

## 6. EV/EBIT法

基准正常化净利$59.8bn，15%税率、净利息近零，正常化EBIT约`59.8/0.85=$70.4bn`。给予10.5倍EV/EBIT：EV $739bn；加净现金$24.4bn后权益$763bn；每股 **$664**。

再单列净现金、SCA下行保护和HBM产品领先的期权价值。若对约$100bn最低RPO给予10%税后利润率、50%因合同/执行折扣，价值约$5bn，仅$4/股，不能解释大幅溢价。真正溢价来自长期超额利润假设。

最终目标价取 **$650**，仅比机械加权值高约3%，用于反映SCA可能抬高周期谷底，但不把尚未经过完整周期验证的合同保护直接资本化为大额溢价。

## 9. 逆向预期

当前市值约$999bn，扣净现金后EV约$975bn：

- 对FY2026 EPS中点$72.13为12.0倍，表面不贵；
- 对基准正常化EPS$52为16.7倍，已高于给定的13倍；
- 若按10倍EV/EBIT，市场隐含正常化EBIT约$97.5bn，对应税后净利约$82.9bn、EPS约$72，意味着峰值盈利几乎永久化。

因此当前价格已要求SCA显著削弱周期、HBM份额稳定、FY2027+ Capex取得高回报且新增供给不压价。
