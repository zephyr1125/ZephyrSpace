# Boot Barn Holdings（BOOT）

> **裁决**：公司质量 **83/100**、管理层 **78/100**。Boot Barn 已证明全国开店、同店增长和自有品牌扩张可以同时进行，但本质仍是服饰零售商，租赁负债、库存和消费周期决定尾部风险。合理价值 **$170**，确定性 **0.58**，机械买入价 **$130**；Tiger参考价 **$153.80** 低于中枢约10%，可列入 Growth，最大仓位 **2%**。

## 最新经营快照

- FY2026销售额 **$2.254B**，同比增17.9%；同店销售增7.2%，其中线下同店约6.2%，电商同店增15.3%。
- FY2026净利润 **$225.9M**、营业利润率13.3%，高于FY2025的12.5%。
- 门店由FY2024的400家、FY2025的459家增至FY2026的539家；FY2026净开80家，无关店。
- FY2026 OCF **$304.9M**；按净资本开支约$178.8M计算，FCF约 **$126.1M**。高开店资本开支压低当前FCF，但 landlord allowances 已部分抵消投入。
- 库存因扩店增加$97.4M；FY2025曾增加$148.1M。Q3同店口径的单店平均库存仅增4.1%，低于销售增速，暂未见明显积压。
- 经营租赁负债约 **$760.0M**，总租赁负债 **$773.5M**；这是比银行债务更重要的固定承诺。

## 业务构成

FY2026男装约占60%，Western约占75%；靴类46%、服装37%、其他17%。核心商品兼具工作用途、耐用品和西部生活方式属性，时尚过季风险低于一般服饰零售，但牛仔/乡村文化热度仍会影响可选消费。

## 关键跟踪项

1. 新店成熟后是否保持门店级回报，避免以开店掩盖老店放缓。
2. 同店销售能否持续为正，且不是主要靠提价。
3. 库存增长是否长期低于销售增长；折扣和毛利率是否恶化。
4. 租赁负债增速与门店销售密度是否匹配。
5. 新CEO John Hazen能否延续前任Jim Conroy的选址和商品纪律。
