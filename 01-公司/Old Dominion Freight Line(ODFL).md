# Old Dominion Freight Line（ODFL.US）

> Old Dominion Freight Line, Inc. | NASDAQ: ODFL
> 成立：1934 | IPO：1991 | 总部：北卡High Point
> 主营业务：零担货运（LTL）——美国第二大LTL运营商，纯LTL公司

---

## 业务概览

| 指标 | 数据 |
|------|------|
| 服务网络 | 261服务中心，覆盖50州+加拿大+波多黎各 |
| 车队 | 11,284台牵引车+46,714台拖车 |
| 员工 | ~21,895人，**全部非工会** |
| 市场地位 | 美国LTL第2（~12-13%份额），仅次于FedEx Freight |
| 服务品质 | 99%+准时率、0.1%货损率，连续15年+#1品质排名 |

**核心差异**：收益率优先于货量——收取10-15%价格溢价，故意保持25-30%过剩产能。非工会劳动力=15-20%永久性成本优势。
