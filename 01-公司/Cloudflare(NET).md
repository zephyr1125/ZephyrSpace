# Cloudflare (NET)

> **Cloudflare 是全球最大的边缘网络之一，正在将其覆盖 330+ 城市的基础设施从 CDN/安全平台演进为 AI 推理 + Zero Trust + 开发者平台的统一入口，是唯一能在边缘同时提供网络保护、AI 推理和无服务器计算的公司。**

Cloudflare 通过自建的全球边缘网络（330+ PoP，覆盖 12,500+ 网络互联）提供安全、性能和开发者平台服务。其商业模式是订阅制 SaaS，几乎无需客户维护基础设施。核心业务从 CDN/DDoS 防护演进为：
1. **Network Services**（Magic Transit、Magic WAN）
2. **Application Security**（WAF、Bot Management、DDoS、SSL）
3. **Zero Trust**（Access、Gateway、CASB、DLP）
4. **Developer Platform**（Workers、R2、D1、AI Gateway、Workers AI）

## 4. 护城河分析

### 4.1 全球边缘网络规模

Cloudflare 拥有 **330+ 城市、12,500+ 网络互联**的边缘节点，处理约 20% 的全球 Web 流量，**每秒处理 5,800 万 HTTP 请求**（2025 数据）。规模上：
- **vs Akamai（AKAM）**：Akamai PoP 数量更多但老化，盈利导向限制投资；Cloudflare 持续扩张且以软件定义架构为主
- **vs Fastly**：Fastly 专注高端 CDN，体量约为 Cloudflare 的 1/10
- **vs AWS CloudFront**：AWS 依赖已有 AWS 客户，不做独立网络安全平台

**规模护城河质量：高**。边缘网络一旦建成具有自然的规模经济和高切换成本。

### 4.2 Zero Trust 市场地位

Zero Trust 是 Cloudflare 增长最快的模块，与主要竞争对手对比：

| 维度 | Cloudflare | Zscaler（ZS） | Palo Alto（PANW） |
|---|---|---|---|
| 架构 | 边缘原生，统一平台 | 云代理，Zero Trust 专注 | SASE + NGFW 混合 |
| 优势 | 网络层 + 安全层一体化 | ZIA/ZPA 深度整合 | 企业安全生态完整 |
| 劣势 | 大型企业交付复杂 | 无 AI 推理能力 | 架构复杂，成本高 |
| ARR 规模 | ~$2.2B（全平台） | ~$2.7B | ~$9.6B |

Cloudflare Zero Trust 的差异化在于：**流量在边缘层直接完成安全检查，无需回传**，延迟极低，且可与 Workers/R2 等开发者平台无缝集成。这是 Zscaler 和 Palo Alto 无法复制的。

### 4.3 AI Inference 双护城河（新兴）

**Workers AI**（边缘 GPU 推理）是 Cloudflare 的战略性新赌注：
- 2025 年推理请求量 +4,000% YoY，体现爆发式采用
- 开发者可直接在边缘部署 LLM 推理，延迟 <50ms，无需管理服务器
- AI Security（Prompt Protection, Shadow AI Detection）是 Zero Trust 的 AI 延伸

**与 AWS Lambda / Vercel 的差异**：
- Cloudflare Workers 原生集成网络安全（防 DDoS、WAF），竞争对手无此能力
- 数据不离开边缘节点，满足数据主权合规要求（GDPR、欧盟数据法案）

**护城河唯一性判断**：在边缘同时提供 AI 推理 + 网络安全 + CDN 的统一平台，**目前无直接可比竞争对手**，形成"摩擦成本护城河"——切换需要同时迁移安全策略、流量路由和应用逻辑。

### 4.4 护城河总结

| 护城河类型 | 强度 | 备注 |
|---|---|---|
| 规模经济（边缘网络） | ★★★★☆ | 330+ PoP，难以复制 |
| 切换成本（Zero Trust） | ★★★★☆ | 多产品绑定，迁移代价极高 |

## 5. 主要风险与红旗

### 5.1 SBC 稀释风险（★★★★★ 高）

FY2025 SBC $451M，占收入 **20.8%**，且绝对值逐年增长（FY2021: $90M → FY2025: $451M）。若以"真实 FCF = GAAP FCF - SBC"计算，FY2025 真实现金利润为 **-$163M**。Non-GAAP 指标存在系统性美化，投资者需理解这不是"会计调整"而是**真实的股东稀释**。

### 5.2 估值极端（★★★★★ 高）

当前 EV/Revenue = **35x**（LTM），EV/NTM Revenue ≈ **27x**。即便假设 30% 持续增速，达到合理估值仍需：
- 若 5 年后收入达 $7B，FCF margin 20%，FCF = $1.4B；
- 按 50x P/FCF（成长溢价），市值 $70B，与当前持平；
- 意味着当前股价已 Price-in 完美执行。

### 5.3 AI 收入转化不确定（★★★★☆ 中高）

Workers AI +4,000% 的请求量增速亮眼，但 Cloudflare **尚未独立披露 AI 相关收入**。AI 业务可能仍以免费/极低价获取客户，货币化时间线不明。"用增速掩盖质量下滑"风险存在。

### 5.4 毛利率下滑趋势（★★★☆☆ 中）

FY2025 毛利率 74.5%，低于 FY2024 的 77.3%，且 Q4 2025 降至 73.6%。AI 推理（GPU 成本高）和 R2 存储的扩张将持续压低毛利率，需关注是否能企稳在 75%+。

### 5.5 竞争加剧（★★★☆☆ 中）

- Zero Trust：Palo Alto（PANW）Prisma SASE 积极整合；Microsoft 推出 Entra Internet Access 直接竞争
- AI 推理边缘：AWS Lambda@Edge、Vercel、Deno Deploy 等持续改进
- CDN：AWS CloudFront 对 AWS 客户具有天然集成优势

### 5.6 债务再融资压力（★★★☆☆ 中）

FY2025 年末流动负债中含 $1,291M 当期长期债务（可转债），在利率偏高环境下需关注转股/还款对股权稀释的影响。

### 5.7 地缘政治与数据主权（★★★☆☆ 中）

作为全球互联网基础设施，Cloudflare 在欧盟 GDPR、中国防火长城、俄罗斯互联网法规等多重合规要求下运营，部分市场存在强制本地化风险，制约全球扩张速度。
