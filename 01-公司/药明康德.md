# 药明康德（603259.SH）

## 公司简介
药明康德是中国CXO体系中的全球化龙头，核心能力是“药物发现-开发-生产”一体化CRDMO平台。2025年公司总营收 **454.56亿元（实际值，已发布）**，其中化学业务（含TIDES）贡献主增量；但美国收入占比高，地缘与监管不确定性仍是估值与仓位上限的核心约束。

## PreBuy结论（最多3句）
**结论：可持有、回调分批，不宜追高重仓。**  
**一句话判断：公司基本面优质（深度评分79/100、管理层80/100），但"美国收入集中+1260H地缘+融资摊薄"使其更适合 Growth 成长仓而非 Core 底仓。**  
**执行口径：优先等回调进入"较好区90-110"再加仓；当前124.12处于中性区上沿。**

## 地缘监管状态（BIOSECURE / 1260H）

- **BIOSECURE Act（已成法）**：2025-12-18 由特朗普签署成法（FY26 NDAA, P.L. 119-60），药明康德被列名"生物技术关注实体（BCC）"。限制美国联邦政府机构采购/资助使用 BCC 服务的承包商；过渡期预计至约 2027 年。直接政府收入占比小，**核心风险是含 NIH/政府资金的美国客户预防性迁移**；2026Q1 持续经营业务收入仍 +39.4%，短期影响有限，长期取决于细则。
- **DoD 1260H 名单（2026-06-08 更新）**：**已正式纳入**1260H名单（5/22版"不在名单"状态已变，尾部风险兑现）。公司6/11在美国哥特区法院起诉国防部挑战认定（参照小米/中微先例）；智堡测算业务影响<1%（核心客户为跨国药企，非政府机构）。6/9 A股大跌收93.48，后随靴子落地反弹至124.12（7/3）。诉讼进展是后续关键变量。
- **美国营收集中度**：2025 年约 72%，单一市场高度集中，是结构性脆弱点，也是压制其升入 Core 档的主因。

## 催化剂与监控指标

**正向催化**：BIOSECURE 细则宽松（豁免私营 pharma 客户）/ 欧亚收入份额提升 / 多肽产能扩至 13 万升后 TIDES 续高增 / 2026 业绩指引超预期。

**负向风险**：BIOSECURE 细则严苛致大型美客迁移 / 重回 1260H 名单 / TIDES 增速放缓 / 美国子公司被迫剥离 / 国内创新药景气下行拖累 DDSU。

**关键跟踪节点**：2026 半年报（约 8 月）；BIOSECURE 细则颁布（2026 中–2027 初）；DoD 1260H 更新（每年 10–11 月）；TIDES 季度新增订单。
