## A. 公司一句话

**全球最大的铜金复合型矿业集团之一**，依托低成本海内外矿山组合（刚果DRC铜矿、塞尔维亚铜金矿、秘鲁La Arena等），在铜黄金双重商品价格超级上行周期中实现利润指数级扩张；同时凭借**零息可转债负成本融资**，锁定下一个十年最大的单体铜资产（秘鲁La Arena二期斑岩铜矿）。

---

## B. 买入逻辑

1. **PE处于3年历史25%低分位，但利润高速增长**：2025净利润518亿（+61.5%），2026Q1净利201亿（+97.5%，年化约800亿），当前PE 15x在历史偏低区间，铜金双驱力量定价偏保守。
2. **零息可转债：史无前例的负成本融资（详见专项分析）**：2026年2月完成15亿美元零息CB（发行价102.5%，到期还100%，有效成本为负），5年内节省约2亿美元利息；12亿美元定向开发La Arena铜矿，相当于用别人送来的钱建造下一个十年现金奶牛。
3. **管理层大规模增持H股**：2025年12月，创始人陈景河增持H股200万股（均价HK$11.15），多位董事及高管同向增持数百万股——内部人用真金白银表态，可信度极高。
4. **铜黄金结构性需求支撑**：AI数据中心+新能源电网驱动铜需求持续增长，黄金去美元化背景下央行购金维持高位；紫金在两条线上均有产量规模扩张，部分对冲价格周期风险。

## 专项分析：2026年零息可转债——负成本融资的战略意义

### 核心结构

| 要素 | 内容 |
|---|---|
| 发行时间 | 2026年2月 |
| 规模 | 15亿美元 |
| 票面利率 | 0%（零息） |
| 发行价 | 102.5%（投资者溢价购入） |
| 到期还款 | 100%面值 |
| 有效资金成本 | **约-0.5%/年（负息融资）** |
| 初始转股价 | HK$63.30/股（较当时H股约HKD14溢价约4.5倍，深度OTM） |
| 资金用途 | 12亿美元开发La Arena铜金矿二期；3亿美元偿还旧债 |

### 为什么是重大利好

1. **真实融资成本为负**：5年合计节省约2-3亿美元融资成本（相比正常美元债利率3-4%）
2. **转股风险极低**：转股价HK$63.30比当前H股价格高约4.5倍，即期稀释可忽略
3. **La Arena二期是战略级铜资产**：铜资源量277.5万吨@0.36%，按当前铜价资源价值远超15亿美元投资
4. **2026年4月CEO在秘鲁论坛明确表态**：计划投资15亿美元扩建La Arena（华尔街见闻，2026-04-29）

### La Arena二期资产价值

- 资源量：铜277.5万吨@0.36%，金186.2吨@0.23g/t
- 一期（在产）：年产金约1.3-2.0吨，剩余服务年限3年左右
- 二期（研究中）：斑岩型铜金矿床，拟露天开采+浮选工艺，3,300万吨/年处理规模
- 位置：秘鲁拉利伯塔德省，安第斯山脉成熟矿业地带

## H. 周期位置判断

**是否为周期股**：是——有色金属/铜金矿，利润高度依赖商品价格

**周期类型**：商品价格周期（铜+黄金双驱）

| 维度 | 当前信号 | 说明 |
|---|---|---|
| PB历史分位 | 82%（3年高位） | PB=4.69x，接近历史峰值 |
| ROE趋势 | 持续加速 | 26%→33%→年化41%，上行斜率仍在扩大 |
| 产品价格趋势 | 双高 | 黄金突破3,300美元/盎司；铜价9,000-10,000美元/吨 |
| Capex/产能趋势 | 全力扩张 | La Arena二期15亿美元，行业Capex回升 |
| 库存周期 | 被动补库 | 铜库存低位，价格维持，量价分化初现 |

**当前周期阶段：景气高峰**（PB高位+ROE历史高+Capex大扩+价格创新高）

对结论影响：
- 结论口径：景气高峰强制降一档警告，但因产量扩张部分对冲，维持growth（加注高仓位警告）
- 价格区间：追高线下移-15%（保守于标准-20%，因La Arena等产量增长提供Buffer）
- 关键警告：当前PE 15x低是景气顶部典型特征，不等于安全；不建议重仓
