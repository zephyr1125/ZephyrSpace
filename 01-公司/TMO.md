# Thermo Fisher Scientific（赛默飞世尔，TMO）

公司代码：`TMO.US`（NYSE 纽交所）

## 公司简介

Thermo Fisher Scientific 是全球**生命科学工具与服务行业的第一大平台**（FY2025 营收 $44.56B，行业第一），2006 年由 Thermo Electron（1956 年成立）与 Fisher Scientific（1902 年成立）合并而来，2009 年 Marc Casper 接任 CEO 后开启「平台化 + 连续并购」时代。核心业务覆盖四大分部：实验室产品与生物制药服务（LPBS，含 PPD 临床 CRO + Patheon CDMO）、生命科学解决方案、分析仪器、专业诊断。

商业模式为「仪器 + 耗材/试剂/服务」的剃刀-刀片模式，约 80-83% 收入为经常性/重复性，客户留存率约 95%。护城河来自规模 + 一站式采购 + 转换成本锁定，17 年连续并购（Life Tech $13.6B → PPD $17.4B → Olink $3.1B → Clario $8.9B）无一爆雷、$54.8B 商誉多年零减值。当前处生物科技融资回暖（Q2 2026 融资 +133% YoY）的景气回升起点，但有机增速仅 2-3%、中国区结构性下滑是核心隐忧。
