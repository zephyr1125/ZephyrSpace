# 罗珀科技 (Roper Technologies, NYSE: ROP)

## 公司概要

Roper Technologies是一家**利基垂直软件复利机器**。公司通过收购在各自利基市场中排名#1的软件和技术产品公司，以去中心化模式运营（总部仅~130人管理19,400员工和29家子公司），用子公司产生的自由现金流持续并购新标的——形成一个"买好生意→让它们自己赚钱→用FCF再买更多好生意"的复利循环。

- **总部**：Sarasota, Florida, USA
- **成立**：1981年（原名Roper Industries，2015年更名）
- **CEO**：Neil Hunn（2018年8月至今）
- **CFO**：Jason Conley（2023年2月至今）
- **员工**：~19,400人
- **三大业务板块**：Application Software (55%) / Network Software (20%) / Technology Enabled Products (25%)

## 投资亮点

1. **利基垄断组合**：29个市场均为#1，最大TAM<$4B——对手不愿来也打不赢
2. **去中心化复利**：25年$25B并购，增量FCF yield 8%+，Jellison→Hunn传承制度化
3. **高质量经常性收入**：75%来自软件，60%+经常性收入，客户留存>95%
4. **负营运资本**：客户预付年费→应收<递延收入→FCF/净利~1.5x

## 主要风险

1. 商誉$21.3B超过净资产——减值风险是达摩克利斯之剑
2. 内生增长仅6-7%，高度依赖并购
3. Hunn时代并购规模上移（$1.5B+单笔），回报率待验证
4. AI长期可能降低利基软件的切换成本
