# 澳博控股（0880.HK）

## 公司简介

何鸿燊家族控股的澳门博彩运营商，前身为1962-2002年澳门博彩垄断者（STDM）。2008年港交所上市。当前为六家牌主中最小且仍在萎缩的一家（市占率~10%）。旗舰新葡京在半岛，上葡京（路氹，2021年开业，投资HKD 390亿）爬坡极慢，为六家中ROI最低的新物业。FY2025仍为亏损状态。

## 核心业务

- **新葡京（半岛）**：历史旗舰，~25%营收
- **上葡京（路氹）**：投资390亿HKD但EBITDA极低（Q1 2026仅5800万HKD），~20%营收
- **其他自营赌场（半岛）**：~30%营收
- **卫星赌场**：已全部于2025年底关闭（监管要求），永久损失~3-4pp市占率

## 主要红旗

1. 🔴 **唯一无法持续盈利的牌主**：FY2025净亏损4.29亿HKD，FY2026 Q1继续亏损
2. 🔴 **市占率崩塌**：从31%（2008年）→ 13%（2024年）→ ~10%（2026年Q1）
3. 🔴 **债务契约风险**：Moody's 2026年4月警告可能需要寻求契约豁免，杠杆>8x EBITDA
4. 🔴 **上葡京投资失败**：390亿HKD投资，开业4年仅贡献极微薄EBITDA
5. 🟡 **何鸿燊家族治理复杂性**：17子女4房结构，2011年曾有股权争夺
