# Arm Holdings plc

> ARM 是全球领先的 CPU 架构 IP 授权商，总部位于英国剑桥。公司设计 RISC 处理器架构并授权给全球 1000+ 半导体公司，芯片被用于 ~95% 的智能手机和不断增长的数据中心/AI 服务器。

## 业务模式

ARM 通过双引擎模式盈利：
- **Royalty 收入（53%）**：按芯片出货量收取的"技术税"，边际成本接近零
- **License 收入（47%）**：前期授权费 + 年度订阅（ATA/AFA）+ CSS 捆绑授权
- 2026年新增：AGI CPU 自研芯片（从"卖地图"到"也挖矿"）
