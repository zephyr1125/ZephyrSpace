# 安徽合力

公司代码：`600761.SH`

## 公司简介

安徽合力是中国叉车行业的绝对龙头，全国市占率超20%，全球前十大叉车制造商之一，产品覆盖内燃叉车、电动叉车、仓储设备及港口机械。2025年3月首次完成海外合资建厂，全球化布局进入新阶段。公司属于弱周期制造型公司，随工业活动景气度波动，但通过海外扩张和电动化转型增加成长逻辑。PB=1.58处于3年历史20.7%分位（PB偏低），提供净资产安全垫；OCF/净利=133%，现金质量优秀。

## 在相关指数 / ETF 中的角色

- 角色定位：`质量价值`（制造龙头+出口扩张）
- 主要意义：高端制造+物流现代化政策受益方，在叉车赛道具有不可替代的规模地位
- 实战看点：盯叉车月度销量数据（中国工程机械工业协会）+ 毛利率季度趋势

## 价格与时机判断

当前价格：**19.76元**
记录时间：2026-05-15（理杏仁日线数据）

**价格区间计算基础**（PE分位法，TTM EPS=1.379元）：
- TTM NP = 12.25 - 3.34 + 3.26 = 12.17亿
- 总股本 ≈ 176亿/19.76 = 8.908亿股
- TTM EPS = 12.17/8.908 = **1.366元**（与PE=14.33验证：19.76/14.33=1.379元，误差<1%，一致）
- 采用：EPS = **1.379元**（以LX PE=14.33反算，数据一致性更强）

- 3年PE P20 = 11.30 → 对应价格 **15.58元**
- 3年PE P50 = 12.86 → 对应价格 **17.73元**
- 3年PE P80 = 13.94 → 对应价格 **19.22元**
- **当前PE=14.33 > P80=13.94，处于历史85.7%分位（TTM盈利低点导致PE偏高）**

PB分位参考（BV/share=19.76/1.58=12.51元）：
- PB P20=1.57 → 对应价格 **19.64元**（当前PB≈P20，资产估值便宜）
- PB P50=1.76 → 对应价格 **22.02元**
- PB P80=2.16 → 对应价格 **27.02元**

| 价格区间 | 评估 |
|---|---|
| **＞22.02元** | 偏贵区（PB > P50），等待回调 |
| **19.64～22.02元** | 合理区（PB P20~P50，资产安全） |
| **17.73～19.64元** | 价值区（PE P50~P80 + PB接近P20）← **当前19.76元正处于此区间上沿** |
| **＜17.73元** | 优质买入区（PE P50以下 + PB低位），历史高赔率区间 |

**当前口径：当前价格19.76元处于"PE偏高（历史85.7%分位）+ PB偏低（历史20.7%分位）"的分歧格局。PB近P20提供资产安全垫，大股东增持是正面信号，但TTM利润处于低点令PE失真。等半年报确认利润止跌，若利润率改善则PE自然回落至合理区间（约P50），价值区间将转向17.73-19.64元，届时17-20元均为良好买入机会。当前可维持1/4仓小仓位，半年报利润改善后加仓。**
