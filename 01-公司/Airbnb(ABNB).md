# Airbnb, Inc. (ABNB.US)

## 公司简介

Airbnb 是全球**替代住宿第一平台**（约 900 万活跃房源、5.5M+ 房东、累计 25 亿 guest arrivals），双边网络效应 + take rate 长期稳定约 13.4%、毛利率约 83%、**FCF 率约 38%**（报表口径）。2007 年 Chesky/Gebbia（RISD）+ Blecharczyk（哈佛 CS）创立，2020-12 IPO；2026 在"旅行 slowdown"叙事中逆势两度上调 FY26 指引（营收 ≥mid-teens、AdjEBITDA margin ≥35.5%），Q2'26 营收 $3.6B（+16.5%）再加速。**硬伤**：监管结构性封顶核心住宿 TAM（纽约 LL18 -90% 房源、巴塞罗那 2028 全面清退约 10,101 张牌照、欧盟 STR 登记 2026-05、日本拟地方 0 晚权限）+ Booking 替代住宿供给已逼近（约 880 万 vs 900 万）+ 创始人 2025-26 持续大额减持（保留底仓）与约 70-75% 超投票权。

## 商业模式与护城河（简）

- 双边网络效应平台：约 900 万房源流动性 + 全球品牌（Airbnb=替代住宿品类心智）；take rate 稳定约 13.4%、GM 约 83%、FCF 率约 38%
- 增长引擎：住宿再加速 + 酒店（nights 3× 主业增速）+ 体验 + 服务 + AI 客服降本（成本 -16%）
- 主要竞争：Booking.com（alt-accom 房源约 880 万已逼近、整体规模约 2 倍）、Expedia/Vrbo（弱化）、酒店直订/OTA、AI agent 入口（Booking Romie/Priceline Penny/Google）
- 结构约束：监管（巴塞罗那 2028 全面清退为标志）对核心住宿 TAM 逐步封顶

## 风险（Top 3）

1. **监管结构性封顶 TAM**：纽约 LL18 -90%、巴塞罗那 2028-11 全面清退约 10,101 张牌照、欧盟 STR 登记（2026-05 平台守门人）、英国 2026 强制登记、日本拟地方 0 晚权限——直接冲击低个位数 nights，2028 时间点 + 示范效应为最大天花板变量
2. **Booking 供给逼近 + 生态竞争**：Booking alt-accom 约 860-880 万房源逼近 Airbnb 900 万；酒店/OTA/AI agent 分流；替代住宿供给可复制性高、切换成本低
3. **治理/股东回报错配**：创始人约 70-75% 超投票权 + 2025-26 持续大额减持（12 个月约 $1.2B、零增持）+ 平台信任记录（隐藏摄像头应对、幽灵房源）
