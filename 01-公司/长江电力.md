# 长江电力（600900.SH）

## 公司简介

长江电力是全球装机规模最大的水力发电上市公司，实际控制人为中央直管国有企业中国长江三峡集团有限公司（持股约43.2%）。公司管理运营长江干流梯级水电站群，包括白鹤滩、乌东德、三峡、葛洲坝、溪洛渡、向家坝六座巨型水电站，2024年完成对云川公司（原三峡集团云南、四川水电资产）的重大资产重组后，合计装机容量约 71.7 GW。公司以"类债券"高分红稳定性著称，2024 年起对部分分红分期派发（年中+年末），每年稳定分红占当期净利润约 55-56%，是 A 股高股息稳定型价值投资的核心标的之一。

## 波特五力分析

> 用于判断行业竞争强度与公司护城河宽度。灯号：🟢 有利 / 🟡 中性 / 🔴 不利

| 维度 | 灯号 | 判断 |
|---|---|---|
| 供应商议价能力 | 🟢 | "原料"为水，零成本；主要支出为建设期设备（三峡、白鹤滩等已全部建成），运营期采购规模有限，供应商无议价空间 |
| 买方议价能力 | 🟡 | 电力市场化改革推进中，大工业用户（电解铝、数据中心等）的直购电比例上升，有一定压价能力；但水电成本极低（边际成本几乎为零），长协锁定大部分电量，整体可控 |
| 新进入者威胁 | 🟢 | 流域梯级牌照是国家稀缺资源，不可复制；单座巨型水电站建设周期 10-20 年、投资千亿级，事实上无新进入者；长江干流可开发量基本已被长电垄断 |
| 替代品威胁 | 🟡 | 光伏/风电装机快速增长，绿电供给总量上升；但水电兼具调峰价值（光储无法完全替代），且随AI算力基荷需求增加，稳定可调度电源地位更加凸显 |
| 同业竞争强度 | 🟢 | A股水电龙头高度集中：长电装机71.7 GW远超华能水电（41.1 GW）、川投能源等；流域地理分隔，各运营商之间不存在直接价格竞争 |

**综合竞争强度**：🟢 行业竞争结构极为有利——供应商/进入者威胁接近于零，流域地理形成天然垄断，护城河宽且极难被侵蚀，是A股最具防御属性的商业模式之一。

## 杜邦分析

> 基于 2025 年报数据。优先使用年报避免 Q1 ROE 低估陷阱（Q1 单季 ROE = 3.01%，年化约 12%）。

|---|---|---|

**杜邦结论**：ROE 15.9% 的驱动力主要来自**超高净利率（40%）**，这是水电"零燃料成本+固定资产折旧"商业模式的核心优势；资产周转率偏低（重资产）、权益乘数中等偏高（2.3-2.7x），三者共同支撑ROE，且净利率可持续性强，ROE结构健康。

## 周期位置判断

**水电是弱周期 / 非周期行业**，本节不做五步法。

理由：
1. 电力需求与 GDP 挂钩，有经济周期影响，但弹性极小（即便经济低迷，工业和居民用电仍保持基础消费）
2. 水文条件是主要业绩扰动因子，但不与经济周期同步（与厄尔尼诺/大气环流相关）
3. 来水好的年份（如 2023-2024）→ 发电量大增，业绩大幅超预期；来水差年份 → 业绩平稳但不亏损
4. 长电通过流域梯级联合调度和多电站互补，已大幅降低单一水文风险
5. 当前处于 2025-2026 年正常来水恢复期（2026 Q1 归母净利 +30.5% YoY 印证）

**周期位置**：不适用（公用事业弱周期）
