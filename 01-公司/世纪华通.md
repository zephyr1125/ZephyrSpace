# 世纪华通

## 公司简介

浙江世纪华通集团股份有限公司，A股游戏行业龙头之一，旗下核心子公司为**盛趣游戏（上海盛趣科技）**，主营端游和手游运营，代表产品包括《传奇》系列、《热血传奇》等经典IP。2022年因巨额商誉减值和财务信披违规遭证监会行政处罚、被标注ST，2023年开始整改，2025年11月成功摘帽（去除ST标签）。2025年营收暴增至379亿，ROE恢复至20%，但历史合规问题仍是重大隐患。

## 产业链位置

游戏研发（部分自研，部分代理）→ 游戏发行运营（盛趣平台）→ 玩家付费（手游+端游内购）

## 核心业务

- **端游运营**：传奇系列经典IP，用户粘性高但用户群老龄化
- **手游发行**：扩展手游矩阵，2024-2025年新品推动营收爆发
- **海外市场**：出海拓展，东南亚和中东市场

## 已核实的关键事实

- **证监会行政处罚**：2021年虚假记录盛趣游戏2020年度业绩承诺，虚增营收3.3亿元（虚构《千年3》软件著作权交易），被证监会行政处罚（2023年7月）
- 2025年11月成功摘帽，恢复正常上市状态（"世纪华通合规重生"）
- 2025年营收同比增长 +67.5%（226亿→379亿），净利润同比增长 +362%（12亿→56亿）
- 总市值1180亿，属于A股游戏行业前三大市值
- 数据来源：理杏仁 API + Tushare（2026-04-30）+ CSRC公告 + 21经济网

## 主要红旗

1. **⚠️ 重大：财务造假历史**：证监会2023年证实2021年虚假记录业绩承诺，涉及虚增营收3.3亿元，信息披露严重违规，治理可信度存疑
2. **盈利可持续性存疑**：2025年净利润暴增362%，需核实是否有新的一次性收益（游戏IP销售、资产处置等）
3. **商誉风险残存**：即便2022年已大额减值，仍需关注残余商誉规模
4. **游戏版号政策**：游戏新版号审批仍存在不确定性，影响新产品上市
5. **PE历史分位失效**：历史含大亏损期，P50=47x和P80异常（负值），估值参考意义有限
6. **用户结构老化**：传奇IP核心用户年龄偏大，长期增长依赖新IP能否持续成功

## 9种投资陷阱复核

1. **数字游戏**：⚠️ **历史上确认存在虚假记录（证监会处罚）**，此为最大风险；当前2025年数据未见新造假迹象，但信任度已受损
2. **例外主义**：游戏公司复苏故事（"摘帽重生"）是市场常见叙事，需用数据而非故事判断
3. **可持续性**：ROE从-25%→2%→5%→20%，爆发式恢复，但游戏行业产品周期短，2026年是否能维持需关注
4. **管理层**：曾主导或默许虚假信披，管理层诚信有历史污点，换届后可信度需观察
5. **增长诱惑**：379亿营收同比增67%，若主力游戏生命周期结束，营收回落风险大
6. **竞争者**：游戏行业竞争极为激烈，腾讯、网易等巨头持续施压
7. **监管政策**：游戏版号、未成年保护、海外审查均是持续风险
8. **会计质量**：OCF/净利>1（良好），但考虑历史造假背景，建议对会计质量始终保持更高警惕
9. **末日场景**：主力传奇IP流失用户、新游戏失败、再次出现合规问题——任何一项都可能导致股价暴跌

## 当前操作含义

PE=18.78x处于3年历史极低位，若2025年盈利可持续，则存在一定估值修复空间。但**财务造假历史是系统性信任折价因素**，不适合作为核心或成长仓位持有。适合少量跟踪，等待2-3个季度验证盈利持续性后再调整判断。
