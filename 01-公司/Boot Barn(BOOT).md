# Boot Barn Holdings（BOOT）

> **裁决**：公司质量 **83/100**、管理层 **78/100**。Q1 FY2027 继续验证扩张故事——$593.5M 营收（+17.7%）、4.7% SSS、27 家新店、EPS $2.29（剔除关税 ~$1.91 仍大幅超预期）。但 7 月 SSS flat 提醒这是零售而非无周期资产。合理价值 **$175**（↑$5），确定性 **0.60**，机械买入价 **$134**；当前 $150.91 低于中枢 14%，可列入 Growth，最大仓位 **2%**。
