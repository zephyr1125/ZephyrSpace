# 康宁（Corning Incorporated）

公司代码：`GLW (NYSE)`

## 公司简介

康宁公司（Corning Incorporated）成立于1865年，是全球领先的材料科学公司，专注于玻璃科学、陶瓷科学和光学物理三大核心技术。公司通过"品类创造"（Category Creation）模式——发明新材料→等待市场出现→以制造工艺壁垒实现规模化垄断——在过去170年间创造了多个改变世界的玻璃品类。

旗下最著名的产品是Gorilla® Glass（全球70%+智能手机盖板玻璃），以及AI数据中心光通信解决方案。公司当前处于"Springboard"增长计划中——2026年5月目标已三连跳至$20B（2026年底）→$30B（2028年底）→$40B（2030年底），三家hyperscaler（Meta $6B + Amazon multibillion + NVIDIA 10x制造扩张）已签约为Corning的产能扩张买单。
