# 埃斯顿（002747.SZ）

公司代码：`002747.SZ`

## 公司简介

埃斯顿是国内少数同时覆盖运动控制核心部件、工业机器人本体和智能制造系统集成的 A 股公司，本质上是在做“国产替代版的工业机器人整机平台”。它值得研究，不是因为当下利润质量已经很好，而是因为它站在高景气赛道里，理论上具备从核心部件向整机放量的产业位置。问题也同样清晰：行业空间很大，但行业并不天然好赚钱，埃斯顿自己的盈利能力、现金流和商誉质量都还远没到“可以放心重仓”的阶段。

## 杜邦分析

> 拆解 ROE 来源，以下为按期末资产负债表估算的截面口径；与加权平均 ROE 会有轻微差异。

| 指标 | 数值 | 说明 |
|---|---|---|
| ROE（净资产收益率） | 约 `2.25%` | 对应 `2025` 年报，盈利恢复但仍很弱 |
| 净利率（净利润/营收） | `0.93%` | 主业还没有形成足够利润垫 |
| 资产周转率（营收/总资产） | `0.52 次` | 资产利用效率一般 |
| 权益乘数（总资产/净资产） | `4.66` | 杠杆偏高，ROE 不是被高利润撑起来的 |
| 经营现金流/净利润 | `约 11.6x` | `2025` 年度经营现金流明显好于利润，但 `2026Q1` 又转差 |
| 非经常性损益占净利润比 | `约 80%`（`2026Q1`） | 一季报利润质量很弱，不能把表观高增速直接当成经营拐点 |

**杜邦结论**：埃斯顿的问题不是“高杠杆伪装高 ROE”，而是**净利率太薄**。它的 ROE 修复目前还没有经营质量支撑，Q1 甚至主要靠非经常性收益撑住利润表。
