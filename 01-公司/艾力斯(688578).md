# 艾力斯（688578）

**中国科创板原创第三代 EGFR-TKI 肺癌靶向药商业化平台，核心产品伏美替尼已进入稳定商业放量阶段。**

**分析日期**：2026-05-02  **参考股价**：¥92.60（2026-04-30收盘）

---

## 1. 公司简介

上海艾力斯医药科技股份有限公司（Allist Pharmaceuticals），2017年成立，2020年于科创板上市（688578.SH），专注于肿瘤领域创新小分子靶向药物的研发与商业化。

核心产品**甲磺酸伏美替尼片（艾弗沙®，furmonertinib）**是国产第三代 EGFR 酪氨酸激酶抑制剂（EGFR-TKI），已于2021年3月获NMPA批准用于含铂化疗后出现疾病进展的EGFR T790M突变阳性晚期非小细胞肺癌（NSCLC），2022年获批一线 EGFR 突变阳性晚期NSCLC适应症，2024年获批辅助治疗（ADJ）适应症。

艾力斯的商业模式接近纯商业化单产品公司：伏美替尼贡献收入比例超过95%，但管线处于快速扩充阶段，多个适应症及联合方案临床已启动。

**已获批适应症（截至2026Q1）：**
1. **EGFR T790M 突变后线治疗**（2021年3月）
2. **EGFRm 阳性晚期 NSCLC 一线治疗**（2022年）
3. **EGFRm 阳性术后辅助治疗（ADJ）**（2024年）—— 辅助治疗患者数大于晚期，长期口服，扩大市场空间约30-50%

**与竞品核心差异化：**

- 阿美替尼（贝达药业）：国内另一第三代竞品

## 4. 护城河分析

| 护城河类型 | 评级 | 说明 |
|-----------|------|------|
| 临床数据差异化 | **中等** | FURLONG研究数据在某些亚组优于竞品，但全面超越证据尚不充分 |
| 专利保护 | **强** | 化合物专利至2033-2035年，国内医药诉讼体系保护较好 |
| 辅助治疗后发优势 | **中强** | ADJ适应症已获批，长期用药患者黏性强，国内外竞争相对少 |
| 品牌学术推广 | **中等** | 肿瘤领域KOL覆盖良好，但推广网络规模不及AZ |
| 管线多样性（KRAS G12C）| **待证** | 突破性治疗品种候选，若获批将是第二增长曲线 |

**核心护城河结论**：伏美替尼的护城河以**专利+临床数据差异化**为主，绑定特定患者亚群（如脑转移、ADJ）是可持续优势。但面对奥希替尼的全球推广能力，护城河属于"区域性+"而非全球领导者。

## 7. PreBuy 结论

**结论：可以买入，适合作为成长仓/弹性仓，当前价格提供了充分的安全边际。**

**核心依据：**
1. **估值处于历史最低位**：PE 17.26x，3年历史分位仅0.55%，市场过度定价医保续约风险
2. **基本面加速增长**：FY2025收入+45.8%、净利润+53.1%，2026Q1持续+44%/+55%，成长质量高
3. **盈利质量极佳**：毛利率96.8%，OCF > 净利润，无财务水分
4. **护城河尚存**：ADJ适应症扩大患者基础，KRAS G12C管线提供第二增长期权
5. **主要风险已知可控**：单产品风险最大，仲裁事项和出海风险中等；但当前估值折价已相当充分

**建议档位：Growth Tier（不入 Core 的原因：单产品依赖度>95%，出海路径尚不明朗）**

## 8. 催化剂与监控指标

### 近期催化剂（6-12个月）
- **2026H1**：伏美替尼 ADJ 适应症医保续约谈判结果（若续约成功且降价<30%，正面催化）
- **2026H2**：戈来雷塞（KRAS G12C）突破性治疗品种公示结果，若通过则大幅强化管线叙事

## 当前操作含义

- **如果你是成长仓投资者**：当前PE 17.3x处于3年历史最低位，2026Q1增速持续印证，是性价比较高的布局时机。建议分批建仓（第一批30-40%），若跌破¥87（PE 18x以下）可加仓。

- **当前最合理动作**：在¥87-¥100区间分批布局，设置止损参考¥73（PE 15x）；关注ADJ医保续约结果作为加减仓决策节点。
