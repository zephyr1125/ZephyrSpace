# 阳光电源 (300274.SZ)

## 公司概要

阳光电源股份有限公司是全球光伏逆变器出货量第一的企业，1997年由曹仁贤创立于安徽合肥，2011年在深交所创业板上市。公司从逆变器起家，2014年切入储能系统，现已形成"逆变器+储能+电站开发"三大业务板块。

## 公司一句话

**全球光伏逆变器#1（~30%份额）+ 储能系统全球#2，靠技术创新+规模效应构建的双引擎新能源装备龙头，当前市场定价其全球化+储能持续高增长预期。**

### 9B. 绝对估值（补充参考）

**公司类型判断**：近3年FCF波动极大（OCF从-16亿→169亿），不符合"稳定现金流"。营收增速>30%但PE<60x，也不完全符合"高成长/亏损"。按分流表 → **默认：EPV**。

**EPV（归一化盈利）**：

- 归一化经营利润：近5年经营利润均值 = (19.9+41.3+114.6+135.4+162.6)/5 = 94.8亿
  - 2021: 18.9亿, 2022: 41.3亿, 2023: 114.6亿, 2024: 135.4亿, 2025: 162.6亿
- 变异系数 CV = std/mean = 61.9/94.8 = 65% → ⚠️ >30%，标注"低置信度"
- 归一化 NOPAT = 94.8 × (1-0.15) = 80.6亿（高新技术企业实际税负约15%）
- WACC = 8.5%（beta 1.2, Rf 2.5%, ERP 6%）
- **EPV = 80.6 / 0.085 = 948亿**
- + 现金220亿（2025年末货币资金228亿） - 有息负债~150亿（估）
- 权益价值 ≈ 948 + 228 - 150 = **1026亿**
- **每股 EPV ≈ 49.5 元**

> ⚠️ 变异系数 65%→低置信度。EPV 49.5元仅为"零增长地板价"，且基于跨周期均值——公司在2021年前利润微薄，拉低了均值。若仅取近3年（2023-2025）均值：经营利润均值=137.5亿，EPV每股≈73元。**EPV区间：50-73元（低置信度）。**

**反向 DCF**：

- 当前市值≈3047亿，WACC=8.5%
- 基于2025年FCF（OCF 169亿 - Capex~50亿 ≈ 119亿）
- **当前股价隐含未来5年FCF CAGR ≈ 12-15%**
- 判断：公司近3年FCF CAGR远高于此（从12亿→119亿，CAGR>100%），隐含增速相对保守 → **当前估值并非泡沫化，市场定价了明显放缓的增长**
