# 微软（Microsoft Corporation，MSFT）

## 公司简介

Microsoft Corporation（纳斯达克：MSFT）成立于1975年，总部位于美国华盛顿州雷德蒙德，是全球最大的科技公司之一，FY2025市值约$3.1万亿美元（截至分析日2026年5月22日）。公司以Windows操作系统、Office生产力套件起家，在Satya Nadella（2014年上任CEO）领导下完成了"云化+AI化"的历史性转型，目前以Azure云计算、Microsoft 365订阅生态、GitHub/LinkedIn平台和OpenAI战略投资为核心增长引擎。

- **FY2025营收**：$281.7B（同比+14.9%，实际值）
- **FY2025净利润**：$101.8B（同比+15.5%，全球首个软件/云公司净利破千亿美元，实际值）
- **FY2025经营现金流**：$136.2B
- **股息**：$3.32/股/年，连续15年提高（FY2025）

## 产业链位置

微软在AI+云产业链中处于**中游平台层**核心位置：

```
上游: NVIDIA GPU → [微软Azure数据中心] → 下游: 企业客户/开发者/个人用户
                ↑
         OpenAI（持股~27%）提供GPT系列模型
                ↓
    Azure AI Foundry → 企业AI应用开发
    Microsoft 365 Copilot → 企业生产力AI
```

在人形机器人AI推理产业链中，Azure是主要的AI推理云平台之一（OpenAI API全球承载，机器人大脑决策层多依赖云端大模型推理）。

### Azure 与 AI 布局

- **Azure**：全球第二大云平台（市占率约22%），FY2025增速+34%，超越AWS(+17%)和 Google Cloud(+28%)
- **OpenAI 战略关系**：累计投资约$130亿，持股~27%（2025年协议重谈后），OpenAI全部工作负载跑在Azure
- **Microsoft 365 Copilot**：月活超1.4亿（FY2025 Q4），每用户额外$30/月AI订阅
- **GitHub Copilot**：付费用户400万+（FY2025），嵌入全球最大开发者平台

## 与 AI 生态的关系

微软是人形机器人/AI产业链的**L2级AI生态基础设施提供商**：
1. **AI推理云**：OpenAI GPT-4/GPT-4o跑在Azure，全球机器人决策层/感知层大量调用Azure AI API
2. **AI开发工具链**：GitHub Copilot → Azure AI Foundry → Promptflow，形成从模型到部署的完整路径
3. **企业AI Agent平台**：Copilot Studio允许企业构建自定义AI Agent（自动化工作流，潜在延伸至机器人控制）

## 历史反垄断与监管事件

| 时间 | 机构 | 事件 | 金额/处置 | 当前状态 |
|---|---|---|---|---|
| 1998–2001 | 美国司法部 | PC操作系统反垄断（IE捆绑/市场分割）| 最终和解，未被强制拆分 | 历史结案 |
| 2004 | 欧盟 | Windows Media Player捆绑 | €4.97亿罚款 | 结案 |
| 2013 | 欧盟 | 未履行提供浏览器选择承诺 | €5.61亿罚款 | 结案 |

**总体评估**：微软有反垄断历史，但均通过承诺/和解解决，无核心业务结构性拆分；当前FTC调查是最主要的尾风险。

## 研究观察

- **Azure增速连续加速**（FY2025 Q4 +35%）是最重要的领先指标，AI工作负载成为增量驱动主力
- **M365 Copilot月活1.4亿**超预期，证明企业用户愿意为AI支付$30/月溢价，AI变现路径清晰
- **FCF margin从30%降至25%**（capex激增），需持续观察capex是否带来相应AI收入增长（資本效率）
- **OpenAI关系演变**：2025年协议修订赋予OpenAI更多外部采购自由，排他性弱化，是中期风险需跟踪
