# 衛龍美味（09985.HK）

公司代码：`09985.HK`  
全称：衛龍美味全球控股有限公司（Weilong Delicious Global Holdings Ltd.）

---

## 公司简介

卫龙美味是中国休闲食品行业的辣条品类绝对龙头，以"辣条"起家，通过品牌化、规模化运营确立护城河。2022年12月在港交所上市（代码09985），是市场公认的"辣条第一股"。公司目前经营三大品类：调味面制品（辣条、亲嘴烧）、蔬菜制品（魔芋爽）以及豆制品与其他产品。

**战略转型关键节点**：2023年起，魔芋爽成为公司最大增长引擎，至2024年蔬菜制品收入（33.71亿）首次超越辣条（26.67亿），公司已从"辣条专家"实质性升级为"多品类辣味休闲零食平台"。这是理解卫龙估值逻辑的核心。

**单品依赖风险正在减小**：辣条仍具极强品牌壁垒，但业务结构已趋于均衡；最大风险已从"辣条天花板"转向"魔芋赛道竞争白热化"。

---

## 行业位置与壁垒

| 维度 | 情况 |
|---|---|
| 辣条市场地位 | 绝对龙头，中国辣条零售市场份额第一，远超第二名 |
| 魔芋爽市场地位 | 连续多年全国销量第一 |
| 渠道布局 | 全渠道覆盖（商超、电商、便利店），经销商网络下沉至三四线城市 |
| 品牌势能 | "卫龙"品牌在年轻消费者中认知度极高，社交媒体传播自带流量 |
| 生产技术 | 第七代智能生产线，AI异物监测 + X光检测 + 全链路可追溯，护城河有科技支撑 |
| 成本优势 | 漯河基地生产规模全国最大，规模效应显著 |
| 海外扩展 | 已覆盖40+国家地区，占比尚低，处于探索阶段 |

**核心壁垒评估**：卫龙的真正护城河是**品牌心智 + 渠道密度**，而非供应链独家资源（魔芋原料国内广泛种植）。辣条是卫龙的品牌压舱石，魔芋爽是成长引擎，两者叠加形成较宽的消费品护城河。

## PreBuy 结论

**结论：基本面优质、估值合理，可以研究性布局；但管理层近期频繁变动是重大观察项，建议等一季度基本面确认稳健后再重仓。**

- FY2025 营收72.24亿（+15.3%）、净利润14.25亿（+33.4%）、ROE 19.52%，毛利率48%稳健，经营质量有明显提升；
- 当前价格9.39 HKD约对应14.4x FY2025 P/E（按RMB EPS 0.60折算），对于ROE近20%的消费品公司估值偏低，下方安全边际较好；
- 核心风险：2025年内CEO与CFO相继离任（均为家族接班人接管），叠加魔芋赛道涌入30+竞争对手，需持续跟踪。

## 股息率分析

> 港股消费品中，卫龙属于"边成长边分红"模式，适合看重现金回报+资本增值的复合收益投资者。

当前股息率（估算）：**约4.5%**（基于FY2025派息率60%、EPS 0.60 RMB×派息率，当前价9.39 HKD）  
数据日期：2026-05-04

| 维度 | 数据 | 说明 |
|---|---|---|
| 当前股息率 | ~4.5% | 基于FY2025 EPS及60%派息率估算，HKD计价 |
| 派息政策 | 承诺分红率≥50%净利润 | 公司有明确的股东回报政策 |
| 分红稳定性 | 政策承诺 | 每年中期+末期两次派息，历史记录稳定 |
| FY2025派息率 | ~60% | 相较FY2024（59%）基本持平，略有下调 |
| 股息率参考价位 | 8 HKD时约5.2% | 提供较具吸引力的股息安全垫 |

**综合判断**：股息率在港股消费品中属于中等偏高水平，4.5%的收益率加上15-30%的利润增速，为估值提供了双重支撑；股息本身是辅助安全垫，而非核心买入触发器。
