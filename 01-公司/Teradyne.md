# Teradyne（TER）

公司代码：`TER` / `NASDAQ`

---

## 公司简介

Teradyne 是全球领先的自动测试设备（ATE）与工业自动化公司之一，核心收入和利润来自 **Semiconductor Test**，同时通过 **Universal Robots** 与 **Mobile Industrial Robots** 布局协作机器人和 AMR。当前最重要的投资主线不是“普通设备周期”，而是 **AI/HBM/高性能计算带动的测试需求上行**；同时，机器人业务仍处于修复期，尚未成为稳定利润来源。

## 产业链位置

- **上游**：高精度仪器、核心零部件、外包制造、软件与工程能力
- **中游**：半导体测试平台、系统测试、协作机器人、AMR
- **下游**：IDM、Fabless、Foundry、OSAT，以及制造/物流自动化客户
- **角色定位**：处在客户量产良率、测试效率与自动化投入的关键卡口

## 核心业务

1. **Semiconductor Test**：SoC、Memory、Analog/Mixed Signal、System Level Test 等，是集团绝对利润核心。
2. **Product Test**：Defense/Aerospace、Production Board Test 等，承担稳定补充作用。
3. **Robotics**：Universal Robots（协作机器人）+ Mobile Industrial Robots（AMR），当前仍是长期期权而非稳定利润引擎。

## 与相关公司的关系

- 与 [[ASML]] 一样，都处在半导体制造链中“高验证门槛、客户切换成本高”的环节，但 Teradyne 更偏后段测试而非前道设备。
- 与 [[苹果(AAPL)]] 的关系体现在终端复杂芯片、影像与高性能计算器件升级，会持续抬高测试复杂度。
- 与 [[特斯拉]] 的关系更多体现在工业自动化与机器人长期渗透逻辑，但 Teradyne 的 Robotics 当前仍是修复阶段。

## 研究观察

- FY2025 营收 **$3.190B**，净利润 **$554.0M**，OCF **$674.4M**，显示主业质量仍高。
- 2026Q1 营收 **$1.282B**，SoC 与 Memory 测试需求明显加速，体现 AI 周期弹性。
- 最大隐患不是主业，而是 **Robotics 仍亏损且 goodwill 较高**。
