# 天孚通信（300394.SZ）

## 公司简介

苏州天孚光通信股份有限公司，2005年由邹支农、朱国栋联合创立，2015年于深交所创业板上市。公司是国内规模最大的独立光无源器件供应商之一，近年快速切入光有源器件，成为全球AI算力基础设施光器件的核心组件供应商。

**核心定位**：光通信精密器件制造商，服务于数据中心AI基础设施供应链（主要下游：Fabrinet → 英伟达/思科供应链）。

**总部**：苏州工业园区（研发中国总部）；新加坡（国际总部）  
**生产基地**：苏州 / 江西 / 泰国  
**研发节点**：苏州 / 深圳 / 日本  
**实际控制人**：邹支农（通过家族平台天孚仁和持股37.57%）  
**董事长 + CEO**：欧洋（邹支农之妻）

## 核心业务

### 光无源器件（2025年：20.84亿，占营收41.94%，毛利率63.67%）
- 光纤适配器（陶瓷套管为核心壁垒）
- 光纤阵列（FA）
- BOX封装组件
- Mux/Demux模块
- **特征**：技术壁垒极深，20年工艺积累，毛利率高，现金牛

### 光有源器件（2025年：29.98亿，占营收58.06%，毛利率46.63%）
- 光收发接口组件
- 高速光引擎组件（800G/1.6T）
- **特征**：高速增长（+81% YoY），毛利率偏低，仍在产品爬坡

### 前沿布局（尚无营收贡献）
- CPO（共封装光学）技术储备
- 硅光模块相关预研

## 关键产品 / 竞争壁垒

八大技术平台（Mux/Demux耦合、FA光纤阵列、BOX封装、精密陶瓷工艺等），垂直整合制造（从精密陶瓷到完整光器件组件），高定制化产品认证周期长（6-12个月），竞争对手短期难以完全替代。

## 主要红旗

- 🔴 **Fabrinet超高集中度**：2025年Fabrinet占营收63.31%，前五大客户89.73%，单客户依赖是核心系统性风险
- 🟡 **毛利率结构性下滑**：有源器件占比提升，整体毛利率从60%水平下行至54%，趋势延续
- 🟡 **大股东高位减持**：联合创始人朱国栋2025年8月套现8.77亿；控股股东天孚仁和2025年11月套现4.22亿
- 🟡 **家族公司治理**：董事长+总经理（欧洋）兼任，独立监督机制有限
- 🟡 **H股IPO摊薄风险**：2026年3月申请赴港上市，规模及对A股股东的摊薄影响未定

## 研究观察

1. 天孚通信是少数同时具备优秀财务质量（ROE 37-42%，净利率39-41%，OCF/NP>90%）和清晰技术护城河（垂直整合精密制造）的A股制造公司
2. 核心风险不在技术，而在客户结构：Fabrinet单客户63%是全仓逻辑最脆弱的一环
3. 治理结构（F维度）是长期持有中最大的非财务变量
4. 当前PE=130x处于历史高位，价格时机需另行评估（本页不含估值建议）
