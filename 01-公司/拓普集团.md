## 公司简介

宁波拓普集团股份有限公司（601689.SH），成立于1983年，总部位于浙江宁波，是国内领先的汽车零部件综合平台型供应商。2015年在上交所主板上市，实际控制人为邬仁生（通过迈科国际控股香港间接持股）。

公司以汽车底盘系统、NVH减震系统、内外饰件为基本盘，2023年起向人形机器人执行器（一体化关节、旋转关节总成）延伸，定位"Tier 0.5级"汽车+机器人综合供应商，强调系统集成能力和平台化扩展。

```

        ↑
  电机/减速器/传感器/控制器零部件供应商
```

## 核心业务

| 业务板块 | 主要产品 | 核心客户 | 收入占比（估）|
|---|---|---|---|
| 底盘系统 | 铝合金副车架、控制臂、转向节 | 特斯拉、吉利、比亚迪 | ~30% |
| NVH减震系统 | 发动机悬置、排气悬挂、动力总成衬套 | 主流整车厂 | ~25% |
| 内外饰件 | 门板骨架、仪表台骨架、立柱饰板 | 主流整车厂 | ~25% |
| 热管理/其他 | 冷却管路、空调配件 | 特斯拉等新能源 | ~15% |
| 机器人执行器 | 旋转关节总成、一体化关节、直线执行器 | 特斯拉、小米、优必选 | ~5% |

**ROE偏低（12.73%）原因分析：**
1. 资本扩张速度快：机器人电驱事业部2023-2025年大规模建厂，净资产增速快于净利润增速
2. 机器人业务投入期：研发+厂房+设备投入尚未被收入完全覆盖，拉低整体ROE
3. 汽车零部件降价压力：整车厂持续压价，汽零毛利率承压
4. 净利首次下滑（FY2025 -7.4%）：规模效应尚未追上投入增长

**预期修复路径：** 随2026年机器人订单兑现（毛利率>50%），高毛利业务占比提升，ROE有望重新向15%+回升（12-18个月内可验证）。
