# 湖南黄金

## 公司简介

湖南黄金股份有限公司，深交所主板上市的黄金矿业企业，控股股东为辰州矿业集团，主要从事黄金采选冶炼及贸易。公司拥有湖南、甘肃等地多处金矿资源，同时涉及黄金贸易业务（占营收大头）。受2023-2025年黄金价格持续上涨影响，公司营收和净利润大幅改善，ROE从8%→20%。2026年1月披露重组预案，存在重大资产重组不确定性。

## 产业链位置

矿山开采（金矿资源）→ 采选/冶炼（提纯） → 黄金贸易/销售（批发+零售）

## 核心业务

- **黄金采选**：湖南本地矿山（辰州矿业旗下），低成本矿山开采
- **黄金冶炼**：金锭加工及精炼
- **黄金贸易**：高营收低毛利，贡献大部分营收规模（贸易业务性质）

## 已核实的关键事实

- 2026年1月26日披露**重大资产重组预案**（股票曾停牌），重组内容待进一步披露
- 2025年辰州矿业等子公司存在多项矿山安全和用地合规问题（小额行政处罚：10万、8千、75万等，不影响经营）
- 2025年营收同比增长 +80%（278亿→502亿），主要来自黄金贸易量价齐升
- 净利润同比增长 +76%（8.47亿→14.88亿），创历史新高
- 数据来源：理杏仁 API + Tushare（2026-04-30）+ 东方财富公告

## 主要红旗

1. **⚠️ 重组不确定性**：2026年1月披露重大资产重组预案，重组方向、估值、对价均未确定，存在较大不确定性（可能重大利好也可能摊薄）
2. **金价依赖**：业绩高度依赖金价走势，若金价回落30%，净利润可能腰斩，ROE将回落至10%以下
3. **矿山安全合规**：多处矿山存在安全生产和用地违规，虽处罚金额小但反映管理规范性不足
4. **贸易业务占比高**：大量低毛利贸易收入（营收501亿但净利润仅14.9亿）降低分析意义，需关注矿山自产金量
5. **PB偏高**：PB=5.21x对于重资产矿业公司偏贵，意味着市场已充分定价黄金景气

## 9种投资陷阱复核

1. **数字游戏**：OCF/净利>1，现金流健康；矿山处罚属于非财务合规问题，不涉及财报造假
2. **例外主义**：黄金涨价是宏观因素，非公司自身竞争优势的体现；企业本身矿山经营能力为中等水平
3. **可持续性**：**业绩高度依赖金价，金价周期性强**，2022年ROE=7.7%时更能代表中性水平；不宜用2025年高ROE预测未来
4. **管理层**：无重大负面信息，国有企业背景（辰州矿业控股）
5. **增长诱惑**：营收501亿看起来很大，但贸易收入占比高，实质增长是净利润增长，金价驱动不等于经营能力提升
6. **竞争者**：国内黄金矿业竞争格局较稳定（中金黄金、山东黄金等），但主要驱动因素是金价而非竞争格局
7. **监管政策**：重大资产重组需要证监会审批，进度不确定；矿山用地合规存在持续风险
8. **会计质量**：现金流良好，OCF/净利>1，会计质量无明显问题
9. **末日场景**：金价大幅下跌（如回落至2000美元/盎司）将导致净利润降至4-5亿区间，估值重压

## 当前操作含义

当前PE低于历史P20，在金价维持高位的假设下存在估值修复空间。但重大资产重组预案是最大不确定因素——重组完成前不宜重仓，需等待重组方案披露后判断对价是否合理。
