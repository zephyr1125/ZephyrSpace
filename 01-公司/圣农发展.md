# 圣农发展

公司代码：`002299.SZ`

## 公司简介

圣农发展是中国最大的白羽肉鸡一体化养殖企业，覆盖育种、孵化、养殖、屠宰加工到品牌销售全链条，总部位于福建光泽。公司属于典型的农业养殖周期股，盈利高度依赖白羽鸡肉价格景气度与饲料成本（玉米/豆粕）双重驱动。2025年利润暴增93.9%，是近年罕见的景气复苏年。估值处于3年历史低位，适合在价格低点做成长仓布局。

## 在相关指数 / ETF 中的角色

- 角色定位：`周期价值`（农业养殖周期）
- 主要意义：国内白羽鸡肉最大一体化供应商，具备规模成本优势，行业集中度提升受益方
- 实战看点：盯鸡肉出厂价格月度趋势 + 玉米/豆粕期货价格

## PreBuy 结论

**结论：当前价格处于3年PE历史低位（20.3%分位），估值赔率较好，适合中等仓位布局，做复苏周期弹性仓。** 尽管农业周期属性限制了其作为核心底仓的稳定性，但当前景气复苏势头明确（Q1 2026净利+66.6% YoY），估值低位叠加政策顺风，赔率可接受。

## 价格与时机判断

当前价格：**18.60元**
记录时间：2026-05-07（理杏仁日线数据）

**价格区间计算基础**（PE分位法）：
- EPS = 18.60 / 15.57 = **1.195元/股**
- 3年PE P20 = 15.48 → 对应价格 **18.49元**
- 3年PE P50 = 25.95 → 对应价格 **31.00元**
- 3年PE P80 = 45.38 → 对应价格 **54.19元**
- PS=+2 → 追高线调整 ×1.10 → **59.61元**

| 价格区间 | 评估 |
|---|---|
| **＞30元** | 中性偏贵，赔率下降，逐步减仓区 |
| **18.5～30元** | 绿灯区，估值有吸引力，可布局 |
| **＜18.49元** | 最优买入区，PE接近3年历史最低 |
| **（参考追高线）59.61元** | PS+2调整后P80追高区，远超现价，属于未来周期高峰目标区域 |

**当前口径：现价18.60元≈PE 3年P20区域（绿灯区底部），估值赔率良好，可研究性建仓1/3~1/2标准仓；等候鸡价确认继续上行后择机加仓。**
