# 鱼跃医疗

公司代码：`002223.SZ`

## 公司简介

鱼跃医疗是中国家用医疗器械领导品牌，主营雾化器（超声/压缩）、电子血压计、血糖仪、制氧机、呼吸机等家用/院用器械，在家庭慢病管理设备赛道具有较强品牌护城河。公司在2020-2022年COVID期间受益于呼吸机/血氧仪需求暴增，形成利润超高基数；2023年起进入后疫情正常化去库存阶段，利润持续下滑。当前PB处于3年历史最低位（0.3%分位），但PE处于历史最高位（97.7%分位），形成"PB极便宜 / PE极贵"的估值矛盾信号，本质是利润还未找到新增长动力。

## 在相关指数 / ETF 中的角色

- 角色定位：`质量价值`（医疗消费品龙头，历史ROE>20%，但当前处于基本面下行期）
- 主要意义：家用医疗器械行业绝对龙头，老龄化受益标的，但需等利润触底
- 实战看点：盯Q1/半年报净利润降幅是否收窄（利润触底信号）

## PreBuy 结论

**结论：不适合现在积极买入。利润处于持续下滑通道（Q1 2026净利-31.1%），PE在3年历史最高位（97.7%分位），虽PB便宜但仅说明股价已跌至净资产安全垫区域。等候利润出现明确触底/企稳信号（如净利降幅收窄至-10%以内、ROE止跌）再考虑入场。定性为radar档，观察备选。**

## 价格与时机判断

当前价格：**29.73元**
记录时间：2026-05-07（理杏仁日线数据）

**估值信号说明**（PE/PB分位存在矛盾，用PB分位法为主）：
- 当前PE=22.84，PE 3年分位=97.7%（极贵，因为利润大幅下滑导致PE虚高）
- 当前PB=2.15，PB 3年分位=0.3%（历史极低，股价跌幅超过净资产降幅）
- **PE高+PB低 = 利润正在缩水，价格已跌至净资产区域，但利润底尚未确认**

**价格区间计算**（PB分位法，因PE失真）：
- BPS = 29.73 / 2.15 = **13.83元/股**
- 3年PB P20 = 2.786 → 对应价格 **38.52元**
- 3年PB P50 = 2.951 → 对应价格 **40.81元**
- 3年PB P80 = 3.168 → 对应价格 **43.80元**
- PS=+2 → 追高线调整 ×1.10 → **48.18元**

| 价格区间 | 评估 |
|---|---|
| **＞43.80元** | PB P80以上，估值偏贵 |
| **40.81～43.80元** | PB P50~P80，中性区 |
| **38.52～40.81元** | PB P20~P50，较好区 |
| **＜38.52元** | PB P20以下（当前29.73元在此区域）→ 净资产极便宜，但**需利润触底才能成为真正买入信号** |

**当前口径：从PB角度，29.73元已低于历史3年最低PB对应价格（38.52元），净资产安全垫充足。但利润仍在加速下滑，PE极贵，市场在合理定价业绩风险。当前不适合主动建仓，等候2026半年报利润降幅收窄信号。**
