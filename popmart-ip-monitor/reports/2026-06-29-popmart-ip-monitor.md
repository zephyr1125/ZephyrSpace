## 7. 本期核心判断

### 边际转弱

核心理由：

1. **Labubu 首次出现新系列大面积破发**——这不是个别配色或渠道问题，而是"复古理发店"全线常规款跌破发售价 30%+。在 Labubu 历史上这是第一次。
2. **所有 5 个 IP 评级均为 C**——没有 IP 达到 A（80+）或 B（65–79）。在 Labubu 降温的同时，没有任何其他 IP 能撑起健康评级。
3. **公司主动压制二级市场价格**——百万补货 + 月产能扩至 3000 万只 + 管理层明确表态"大众消费品非奢侈品"。这对长期 IP 健康可能是好事，但短期必然冲击二级市场指标。
4. **但是**：Labubu 的世界杯亮相是历史性事件，Wings of Fantasy 仍溢价 700%+，说明 IP 本身并未失效。边际转弱 ≠ 崩盘。
