## 1. 本期结论摘要

- **多个非 Labubu IP 的全球运营动作本周密集落地，但需区分"公司资源投入"与"消费者需求验证"。** MOLLY 20 周年联名潮三箭齐发（星巴克 7/8 + Crocs + Ducati 预热）、SKULLPANDA 登上巴黎高定周（× Robert Wun 7/8）、CRYBABY 全球多点开花（芭提雅巨型装置 + 新加坡 S.E.A. 海洋馆 + 北京特展预热 8/1）——这些事件证明泡泡玛特正主动将运营资源扩散至多个非 Labubu IP，其国际商务拓展和场景运营能力获进一步验证。但它们目前主要兑现的是**运营动作**，而非**销售或财务结果**。
- **DIMOO×皮克斯已于 7/16（线上）和 7/17（线下）正式发售，但首发 2–3 天内的二手溢价/成交量数据尚未进入公开报道。** 皮克斯催化已从"官宣预期"转为"实绩验证期"——DIMOO 边际分维持但方向从「预期驱动」变为「待验证」。
- **Labubu 4.0 二手价格显著走弱。** 公开报道确认新系列多款低于官方价格交易、市场反响弱于预期；隐藏款从峰值 1378 元回落至 879–1200 元区间。德银报告称部分二手价已跌至约 50 元。短线套利活动明显退潮，「投机退潮」已获**较强验证**。
- **Wings of Fantasy 锚点本周无新数据。** 上期发现的跨平台 $550 vs StockX $1,243 口径差异仍未解决——锚点真实状态仍待 StockX 同源验证。
- **段永平持股 7.65% 维持不变**（7/6 增持后无新披露）；股价从上周 ~153 港元反弹至 ~163.6 港元（+7%）；汇丰 7/17 降级（买入→持有，TP 168.9），德银维持沽售/140——**资本市场信号持续分化，独立成章（§4.6），不计入任何 IP 健康度。**
- **本期核心判断：Labubu 投机性需求退潮已获较强验证；多个非 Labubu IP 的联名、展览和新品集中落地，表明公司正主动将运营资源扩散——但当前兑现的主要是运营动作而非销售结果，多 IP 接力应定义为"候选信号显著增强"，尚不能定义为"商业接力成功"。**

## 7. 本期核心判断

**本期泡泡玛特 IP 侧面数据呈现为：【Labubu 新系列二手价格显著走弱，投机性需求退潮已获较强验证；多个非 Labubu IP 的联名、展览和新品集中落地，表明泡泡玛特正主动将全球运营资源扩散——但当前兑现的主要是运营动作，而非销售或财务结果】**

四态区分：
- **投机退潮【较强验证】**：4.0 多款低于发售价交易、套利空间明显压缩、隐藏款从峰值回落。已从「信号出现」升级为「较强验证」。
- **消费需求退潮【未验证】**：缺官方销售数据；破发可由补货+投机退出+公司主动放缓节奏共同解释。德银/汇丰高频数据方向偏弱但非官方，等 2026 年中期业绩。
- **多 IP 接力候选信号【显著增强——运营动作密集落地】**：Molly（星巴克+Crocs+Ducati）、Skullpanda（巴黎高定）、Crybaby（全球特展）、Twinkle（vinyl-faced 定档）同期出现高质量运营事件。这证明泡泡玛特有能力同时推进多个接力候选，但尚未证明接力棒真的交出去了。
- **多 IP 接力成功【未验证】**：六个 IP 仍零个达 A/B 线。关键证据不是更多联名数量，而是 DIMOO×皮克斯首发销售、Molly 联名转化、Crybaby 活动带动的商品销售，以及 2026 年中期业绩中的分 IP 收入结构。

核心理由：
1. **Labubu 投机退潮已获较强验证，但这是"投机需求"而非"消费需求"的信号。** 4.0 二手价格继续走弱，套利空间压缩。但二者可能同时发生："黄牛退出、消费者正常购买"的健康化过程，以及"真实终端需求转弱"——中期业绩是判别关键。
2. **多个非 Labubu IP 的运营动作本周集中落地，合作层级和场景有全球化特征。** 这验证了泡泡玛特的国际商务拓展、品牌联名和展览落地能力——但这些是**供给侧能力**（公司能做什么），不是**需求侧验证**（消费者是否买单）。当前多数 IP 的联名/展览只处于"活动落地"层，尚未进入"销售验证"或"财务验证"层。
3. **需要区分三种不同的组织能力**：① 发现和签约艺术家/IP 的能力（Twinkle Twinkle 更接近此项）；② 把中型 IP 做成全球化 IP 的能力（Molly/Skullpanda 联名潮更接近此项）；③ 在爆款退潮后维持长期收入的能力（所有成熟 IP 待验证）。不能用成熟 IP 的联名活动完全替代对新 IP 原创孵化的验证。
4. **DIMOO 皮克斯催化兑现，从预期驱动转为实绩验证**——首发数据是下一个关键验证点，将决定 DIMOO 能否成为首个冲破 B 线的非 Labubu IP。

**对"泡泡玛特是否具备持续制造全球 IP 的组织能力"的验证程度：【进一步确认了"全球 IP 运营/联名/跨界能力"和"多 IP 同步运营的组织执行力"；但"持续从零创造全球原创 IP 的能力"仍待 Twinkle Twinkle 等新 IP 验证】**

> ⚠️ 措辞精确：
> - Molly 星巴克+Crocs 验证的是**成熟 IP 商业化再运营能力**；
> - Skullpanda×Robert Wun 验证的是**品牌调性升维与跨界背书获取能力**；
> - DIMOO×皮克斯验证的是**外部授权商业化能力**；
> - **以上三者均属「已有 IP 的运营放大」，不能直接证明「从零创造全球原创 IP」。**
> - Twinkle Twinkle（原创 IP、从零孵化）才是更接近后者的证据，但 vinyl-faced 公仔下半年才发售。
> - **这不是"多 IP 接力已经兑现的一周"，而是"泡泡玛特证明自己有能力同时推动多个接力候选，但尚未证明接力棒真的交出去的一周"。**
