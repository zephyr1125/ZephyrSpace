- **消费需求退潮【未验证——等 H1 中报 8/20–25】**：缺官方销售数据。产能扩张意味着即使零售量大幅增长，二手价格仍可能下跌——这使二手价格作为需求代理指标的有效性进一步下降。H1 中报的分 IP 收入是判别关键。
- **多 IP 接力候选信号【增强——DIMOO L3 验证+菲律宾店+CRYBABY 双系列+HACIPUPU 入局】**：DIMOO 皮克斯 L3 流量验证已获确认——预售加购数据是独立于公司官方宣传的第三方可观测信号，其独立性高于联名官宣/展览开幕。但 L4 销售验证（二手溢价+成交量/售罄速度）在首发 10 天后仍缺失，比预期更差——若下期仍无数据，需下调 DIMOO 皮克斯的边际评估。
- **多 IP 接力成功【未验证】**：七个 IP 仍零个达 A/B 线。关键证据：① DIMOO 皮克斯 L4 销售验证；② 2026 年 H1 中报分 IP 收入结构；③ Crybaby 双系列新品二手表现；④ HACIPUPU 是否形成独立粉丝群。

核心理由：
1. **Labubu 产能 100 万→5,000 万/月是本周期最重要的供给侧发现。** 它从根本上改变了 4.0 破发的解读框架：价格下跌至少部分来自公司主动去稀缺化——"让 Labubu 回归消费本质"。对 IP 长期健康而言，产能扩张→扩大真实消费者基数→降低投机依赖，可能是健康化过程。但 Wings 锚点悬空三周是需要警惕的风险——如果连最稀缺的 SKU 也松动，说明需求侧可能确实在转弱。
2. **DIMOO×皮克斯 L3 验证确认——但 L4 验证缺失的时间越长，信号越偏负面。** 预售加购数据（抖音 26,000+/天猫 20,000+）是监控以来最强的非 Labubu IP 需求侧信号。但首发 10 天后二手溢价+成交量仍未进入公开聚合——已超出"时间差"能解释的范围。若下期（首发 17 天后）仍无数据，需认真考虑"未形成爆款级话题"的可能性。菲律宾主题店是独立于皮克斯联名的正向信号——DIMOO IP 独立性获战略级认可。
3. **Crybaby 从"展览驱动"升级为"新品+展览双线驱动"，是五大 IP 中 7 月新品管线最活跃的。** 心动系列+怪兽的眼泪双系列同步发售，品类矩阵在拓宽。北京特展 8/1 开幕是下周最强催化剂——但特展本身仍属"运营动作落地"（L2），需观察是否出现售罄/排队/预约满等 L3 信号。
4. **HACIPUPU 入榜填补了能力①（发现和签约新艺术家/IP）的监控空白。** 此前七个 IP 中，THE MONSTERS/Molly/Skullpanda/DIMOO/Crybaby 主要验证能力②（已有 IP 运营放大），Twinkle Twinkle 是唯一接近能力①的标的。HACIPUPU 提供了第二个能力①的验证窗口——但其历史表现分化（二代强、三代弱）提醒我们：不是每个新 IP 都能成为 Twinkle Twinkle。
5. **段永平「10 年不卖」是极罕见的公开长期承诺，但它是估值信号而非 IP 健康信号。** 段永平的核心论点——"2000 亿市值、去年赚 130 亿利润、商业模式已跑通、未来 10–20 年平均年利润大概率不低于现在"——是典型的长期价值投资逻辑。但即使他是对的，也不能证明 Labubu 不会退潮或多 IP 接力已成功。资本市场信心与 IP 运营现实之间可能存在显著时滞。

**对"泡泡玛特是否具备持续制造全球 IP 的组织能力"的验证程度：【进一步确认了"全球 IP 运营/联名/跨界能力"（DIMOO×皮克斯 L3 验证、菲律宾独立主题店）+ "多 IP 同步运营的组织执行力"（7 个 IP 同期有内容产出）；"持续从零创造全球原创 IP 的能力"获新增验证窗口（HACIPUPU 首发）但尚无结论——Twinkle Twinkle vinyl-faced 和 HACIPUPU 迷路汪汪的二手/销售数据均空白】**

> ⚠️ 措辞精确：
> - DIMOO×皮克斯 L3 验证（预售加购）确认的是**外部授权 IP 的商业化能力和消费者兴趣**——这是能力②的重要子维度（全球 IP 联名运营），但≠原创 IP 制造能力。
> - DIMOO 菲律宾主题快闪店验证的是**公司对单一 IP 独立号召力的信心和渠道执行能力**——这是能力②的另一个子维度（IP 独立运营）。
