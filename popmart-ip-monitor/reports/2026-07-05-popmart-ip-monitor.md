## 7. 本期核心判断

**本期泡泡玛特 IP 侧面数据呈现为：**

**【边际转弱——且核心IP Labubu从C档快速滑入D档】**

核心理由是：

1. **Labubu 4.0首发破发是结构性信号**，不是短期波动。提价60%+月产能5000万+百万补货的组合拳彻底改变了供需。二级市场从"炒稀缺"逻辑向"消费体验"逻辑的切换正在加速，而切换过程必然伴随旧指标全面恶化。
2. **其他IP无接力能力。** Molly稳定但缺乏新品（-4分）；Skullpanda处于产品空窗期（-12分，跌入D档）；Crybaby缺乏存在感；唯有Dimoo有皮克斯联名预期（+3分）。整个矩阵在Labubu降温时没有第二引擎。
3. **社媒热度虽高但尚未转化为二级市场价格支撑。** "发型自由"出圈是真实的产品创新力证明，但3万预约≠3万成交。热度能否持续、能否带动4.0价格修复，需要更多时间验证。
4. **但这不是"崩溃"信号。** 泡泡玛特在主动做一件事：用供给淹没投机，让IP回归消费本质。如果这个战略成功，短期数据恶化就是必要的阵痛。本skill只管IP当前数据，不给长期判断。

**对"泡泡玛特是否具备持续制造全球IP的组织能力"的验证程度：**

**【持平——产品创新能力获验证，但IP矩阵健康度未改善】**

- 美发沙龙系列证明公司有持续的产品创新能力（DIY玩法是真正的品类创新）。
- 但五个IP中零个达A/B线，说明"多IP健康矩阵"的目标还很远。
- Dimoo×皮克斯联名和Twinkle Twinkle新IP是近期最重要的验证窗口。

**下期最重要观察点：**

1. Labubu 4.0美发沙龙系列的价格能否企稳？（首发破发后是否会有"超跌反弹"）
2. Wings of Fantasy是否维持$1,200+？（如果Wings也崩了，Labubu将失去最后一个价格锚点）
3. Dimoo×皮克斯联名的具体时间和市场反应。
4. Skullpanda下款新品的发布时间——空窗期越长，IP热度流失越严重。
