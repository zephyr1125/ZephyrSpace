## 1. 本期结论摘要

- **🔴 8/20 H1 中报落地：泡泡玛特"单一 IP 依赖"首次获官方数据证实结构性缓解。** THE MONSTERS（Labubu）H1 收入 44.5 亿、**-7.5%（爆火以来首次下滑）**，占比从 H1 2025 的 34.7% 降至 **26.0%**。与之对应，**星星人 TWINKLE TWINKLE H1 收入 26.5 亿、+580.6%，跃居第二大 IP（占比 15.4%）**。CRYBABY（16.3 亿，+34%）、DIMOO（16.2 亿）、SKULLPANDA（15.5 亿，+27.1%）、HIRONO（10.1 亿）也全部过 10 亿（**共 5 个非 Labubu IP 过 10 亿**）——**这是监控启动以来「多 IP 接力」首次从"候选信号"升级为"财务事实"**。

- **🔴 星星人是本期唯一四层验证齐备（L2+L3+L4+L5）的 IP。** 8/20 首款搪胶毛绒「动物农场」全渠道秒罄（得物预约 2.4 万、抖音单条 800 万赞、段永平"我也抢不到"），隐藏款峰值 1799 元（13 倍溢价，8/21 回落至 843 元/5.5x），千岛整端 3 日成交 791 套。**上期"产品空窗 8 个月"的前提被彻底证伪**——那是在等这个系列。

- **🔴 MOLLY 是本期最大单 IP 负面信号：H1 -33.6%（9.01 亿），掉出前三。** 星巴克亚太 8 市场联名落地（L2 运营动作）未能扭转收入下滑。"联名潮过后 Molly 自身基本盘是否扩大"这个上期悬而未决的问题，被 H1 数据**否定性回答**。Molly 从 B 线跌落至 C 档。

- **🟡 Labubu 存量投机退潮深化，但"投机热度"是"转移"而非"消失"。** Labubu 4.0 盲盒线 8/21 千岛数据显示 13 款除隐藏外全部破发（-42%~-71%），Wings of Fortune 挂卡版（此前追踪的"Wings of Fantasy"已证伪命名）破发 -39%。但星星人动物农场首发 48 小时 13 倍溢价显示——资金从 Labubu 存量产品**转移到新 IP 首发**，而非离场。

- **🔴 管理层主动降速 + 资本动作对冲。** 王宁确认 2026 为"经营调整年"、明确"今年大概率完不成年初 20% 营收增长目标"、宣布未来 6 个月 **20–50 亿元回购**、不派中期息。库存周转天数 **123→201 天**（海外前置备货+美国预测偏差）。

- **🟡 业绩 miss 但股价尾盘收窄，段永平继续力挺。** 8/21 裂口低开 8.2%（141.1），收跌 3.06% 至 149 港元（盘中触及 52 周低点 140.1）。12 家大行几乎全面下调目标价（大摩 203 vs 摩通 120，分歧拉大至近 70%）。段永平 8/20 晚雪球"财报觉得蛮好、长期不贵"。

- **本期核心判断：多 IP 接力在收入规模/结构层面获财务验证（历史性转折）+ Labubu 存量收入首次转负（能力③首次官方检验）。** 3 个 IP 达 B 线（TWINKLE 新进、MOLLY 退出，净数不变），多 IP 健康指数维持 43%。**但接力成功是"收入结构"层面，不是"利润质量"层面——经调整净利仅 +9.5% 主要受约 7.2 亿汇兑损失（经调整口径未剔除汇兑损益）+ 毛利率下降影响，而非 IP 接力质量本身。**

## 7. 本期核心判断

**本期泡泡玛特 IP 侧面数据呈现为：【多 IP 接力获财务验证（历史性转折）+ Labubu 存量收入首次转负（能力③首次官方检验）——8/20 H1 中报是分水岭，星星人跃居第二大 IP，MOLLY 掉出前三】**

核心理由是：

1. **8/20 H1 中报首次给出"多 IP 接力"的官方财务验证。** THE MONSTERS -7.5%（占比 26%）vs 星星人 +580.6%（第二大 IP，15.4%）+ CRYBABY +34% + DIMOO + SKULLPANDA +27.1% + HIRONO——共 5 个非 Labubu IP 过 10 亿。上期的"接力候选信号"本期升级为"接力财务事实"——这是本监控启动以来最重大的结构性转折。

2. **星星人是本期唯一四层验证齐备的 IP。** 8/20 动物农场秒罄（L2 落地+L3 流量+L4 秒罄）+ H1 +580.6%（L5 财务），综合分跃居第一、基本盘分 54→64。上期"产品空窗 8 个月"的前提被证伪。

3. **MOLLY 是本期最大单 IP 负面信号——H1 -33.6% 掉出前三。** "联名潮过后 Molly 自身基本盘是否扩大"被 H1 数据否定性回答，Molly 从 B 线跌落 C 线。这是"联名能力 ≠ IP 生命力"最生动的案例。

4. **Labubu 收入拐点官方确认——能力③（爆款退潮后维持长期收入）首次官方检验且偏负面。** -7.5% 是"增长转负"非"需求崩塌"，但叠加 4.0 全破发 + Wings 锚点证伪 + 库存周转 201 天，Labubu 从"增长引擎"变成"需要防守的基本盘"。

5. **多 IP 接力在收入规模/结构层面已获很强验证，但不能据此宣布"高质量接力成功"。** 非 THE MONSTERS 艺术家 IP 收入同比约 +46%（THE MONSTERS 少约 3.6 亿，其他艺术家 IP 增约 34.2 亿），收入层面接力很强。但经调整净利仅 +9.5% 主要受约 7.2 亿汇兑损失（经调整口径未剔除汇兑损益）与毛利率下降（70.3%→69.7%）影响，而非 IP 接力质量本身；海外收入转弱（约 -11.1%）是另一个公司级变量。缺少分 IP 利润率数据，无法判断星星人/CRYBABY 等新增长 IP 能否复制 Labubu 高峰期的盈利质量。管理层的"经营调整年"+20-50 亿回购，是对增速放缓现实的承认。
