L7 · 最上游 基础工业材料
Industrial Base Materials

机床的基础物质层，直接决定刀具切削极限、主轴轴承寿命与伺服电机功率密度。 工具钢与硬质合金决定刀具能加工的材料上限；稀土永磁体 是伺服电机的核心磁路；精密铸铁与花岗岩构成机床床身的稳定性基础。

战略要点：中国稀土储量占全球 60%，钕铁硼产量占全球 90% 以上， 是产业链中极少数中国具备全球定价权的领域。高牌号磁体（N52H/N55）仍落后日本 TDK； 工具钢则几乎完全依赖欧洲进口。

L6 精密切削刀具与工具系统
Precision Cutting Tools

机床与工件之间直接接触的消耗性"牙齿"。 刀具材质（硬质合金/CBN/金刚石）、涂层技术（PVD/CVD）和 刀柄/工具系统（BT、HSK、CAPTO 标准）共同决定加工效率、 表面质量与换刀稳定性。全球刀具市场规模约 300 亿美元/年。

中国竞争力：国产刀具在通用中低端领域（汽车、工程机械等）已形成竞争力， 株洲钻石、欧科亿毛利率超 40%。精密加工（航空钛合金、高温合金）及超硬材料（CBN/PCD） 刀具仍依赖欧日进口。

L5 高精度主轴系统
High-Precision Spindle Systems

主轴是机床的"心脏"，直接决定转速上限（rpm）、 径向/轴向跳动量（μm 级）与加工表面粗糙度。 电主轴（Motor-in-Spindle）将伺服电机与主轴一体化， 可达每分钟数万转；主轴轴承是支撑精度与寿命的关键限制件。

国产突破口：广州昊志机电是国内电主轴龙头，在通用机床市场份额超 30%； 高端超精密电主轴（20000 rpm+ / 跳动 <0.5μm）仍被 GMN/HSD 垄断， 主轴轴承 P2 级依赖日德进口。

L4 精密传动与运动部件
Precision Transmission & Motion

将伺服电机的旋转运动转化为直线运动，或在关节处实现高精度减速。 滚珠丝杠和直线导轨决定各轴的定位精度与重复精度（μm 级）， 谐波 / RV 减速器则是工业机器人与机床摆头关节的核心传动件。

RV 减速器（摆线针轮）
Nabtesco（纳博特斯克） Sumitomo（住友） 秦川机床 双环传动 中大力德
国产进展：滚珠丝杠/导轨领域 Hiwin 与国产品牌（南京工艺等）已在中端机床实现替代； 谐波减速器绿的谐波毛利超 50%，但高精度（<1 角分回差）型号仍与 Harmonic Drive 有差距； RV 减速器国产替代率约 40%。

L3 伺服驱动与运动控制
Servo Drives & Motion Control

机床各轴的"肌肉"。伺服电机将电能高效转化为精准的旋转力矩， 伺服驱动器闭环控制电流/速度/位置三环； PLC / 运动控制器统筹多轴协调运动， 是 CNC 系统指令的最终执行层。

L2 CNC 数控系统与工业软件
CNC Controllers & Industrial Software

机床的"大脑"。CNC 控制器解析 G 代码、实时规划多轴插补路径， 并通过伺服接口闭环控制各轴运动。 CAD/CAM 软件将 3D 设计转化为刀具路径（NC 程序）， 是机床"思维"的上游输入。

L1 · 最下游 工业母机整机 OEM
Machine Tool OEM

整合上游六层全部子系统，完成机床总装、精度调试与验收， 向半导体设备厂、航空航天、汽车模具等下游交付完整机床。 整机竞争力的核心是热补偿算法、几何精度标定与长期服务口碑， 而非单纯的零件采购能力。高端五轴机床须通过精度留样（如球杆仪 Ballbar 检测）。
