# 财报预告监控（forecast-preview-monitor）

## 定位

在两次财报的空窗期，捕捉全市场业绩预告的**结构化画像**：谁发了预告、方向如何、
估值贵不贵、近期景气度（同比）、集中在哪些申万二级行业。
同时扫描正式半年报，命中 watchlist 标的时醒目提醒三件套分析更新。
按季度维护一份可增量更新的文档。

**这是纯数据流程，脚本一步到位，不需要 AI 逐条分析或二次确认。**

## 数据链路

| 步骤 | 数据源 | 拿到什么 |
|---|---|---|
| 1 | CNINFO `hisAnnouncement/query`（`category_yjygjxz_szsh`，stock 留空=全市场） | 区间内所有发预告的公司清单（code/简称/标题/日期/PDF） |
| 2 | CNINFO `p_stock2238`（结构化预告，逐只） | **净利润下限/上限（万元）、净利增减幅区间(%)、业绩类型**、预告内容全文 |
| 3 | 理杏仁 `fundamental/non_financial`（批量≤100） | PE_ttm / PB / PS_ttm / 市值 / 股息率 |
| 4 | 理杏仁 `fs/non_financial`（**每次仅 1 只**） | 最近季度营收/净利 → 与去年同期算同比 |
| 5 | 理杏仁 `company/industries` | 申万2021 一级+二级行业分类 |
| 6 | CNINFO `hisAnnouncement/query`（`category_bndbg_szsh`）→ 与 watchlist JSON 交叉比对 | 命中 watchlist 的正式半年报 → 提醒三件套更新 |

## 执行

```bash
# 时间范围 + 自动季度 label（按结束日期所在自然季度，如 end=2026-07-03 → 2026Q3财报预告）
python scripts/forecast_monitor.py 2026-06-01 2026-07-03

# 显式指定 label（半年报预告应归 Q2，跨季度时务必显式指定，增量写同一份文档）
python scripts/forecast_monitor.py 2026-06-20 2026-07-03 --label 2026Q2财报预告
```

**输出**：
- 权威数据 JSON：`data/forecast_scan/<label>.json`（按 code 去重，重复扫描更新为最新）
- Obsidian 文档：`02-主题/财报预告/<label>.md`

## 增量更新机制

- JSON 是权威存储，MD 每次从 JSON 全量重渲染（不做字符串拼接，避免脏数据）。
- 同一 label 反复跑 = 增量合并：已收录公司会被最新数据覆盖，新公司追加。
- 每次扫描在 `scan_log` 追加一条（时间/区间/新增数/更新数），文档头部显示最近一次。
- 典型用法：季度内每天/每周跑一次「6-01 至今」，或只跑「昨天至今」增量补最新。

## 文档结构

1. **申万二级行业分布表**：各二级行业已发预告公司数、占比、平均营收同比、平均净利同比
   —— 用于看哪个行业在集体预喜/预警。
2. **⚠️ Watchlist 半年报告警**（有命中时）：公告日/代码/简称/Watchlist档位/公告标题。
   —— 命中 strategiс/core/growth 任一档位的公司正式半年报时出现，提醒需安排三件套分析更新。
3. **个股预告列表**：公告日/代码/简称/方向/预告净利区间/净利增幅/申万二级/PE/PB/市值/营收同比/净利同比。其中预告净利区间和净利增幅来自 CNINFO 结构化 API。

## 口径与坑（重要）

1. **理杏仁估值 `date` 必须是已收盘交易日**：传公告日/未来日返回空。脚本自动回退最多 7 天找最近交易日。
2. **`fs/non_financial` 每次只接受 1 只股票**：批量会报 `must contain 1 items`，故逐只查询（区间大时耗时，脚本已加 0.15s 限速）。
3. **CNINFO `announcementTime` 是 UTC 毫秒**：+8h 转北京时间后取日期，否则会错位一天。
4. **方向优先使用 CNINFO 结构化 API**（`p_stock2238`）：返回业绩类型如「业绩大幅上升」「预计扭亏」「预计减亏」「业绩预亏」等，比标题正则（只区分预增/预减/扭亏/未标明）更精细。API 不可用时回退标题正则。
5. **同比口径**：是最近一期财报（累计）vs 去年同期的**已实现**同比，不是预告本身预测的区间值。作为景气度参考，非预告口径。
6. **申万二级**：`company/industries` 返回完整层级，二级=代码 `XXYY00` 且 `YY!=00`（如 220400 化学纤维）。
