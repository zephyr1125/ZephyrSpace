# A股质量错杀筛选（cn-quality-mispricing-screen）

## 定位

用 CNINFO 拿全A股清单，理杏仁 fundamental 批量做价格/市值/PE 粗筛，tushare 补 52 周高点跌幅，
理杏仁 fs 拉 7 年年报财务做四维量化排序，最后 AI 对 A 档候选执行 7 条质量指标精筛。
三步流水线，从全市场约 5400 只 A 股到 3-5 家值得开三件套深度分析的标的。

**核心假设**：好公司 + 大跌幅 + 合理估值 = 值得深度研究。本 skill 只做筛选和排序，
不替代三件套（深度分析+管理层档案+估值分析）。

**A股特殊性**：
- A股整体估值中枢高于港股（PE 中枢约 15-18 vs 港股 12-14），评分中的估值折价锚点设为 18x
- A股财务数据走审计口径（理杏仁 fs），无 IFRS/US GAAP 转换歧义，数据质量优于 yfinance 对港股的覆盖
- 理杏仁 `fs/non_financial` 只服务**非金融企业**，银行/券商/保险会被返回空数据（标"数据不足"，不参与评分）
- A股小盘流动性优于港股，市值门槛可略低（流通市值 ≥ 50 亿）
- **周期股陷阱**：矿业/化工等强周期股在商品高点时 3 年净利 CAGR 会虚高，Step 3 精筛必须查 10 年 ROE 均值

## 三步流水线

```
CNINFO全A清单 + 理杏仁粗筛   tushare52周高点 + 理杏仁财务排序   AI 7指标精筛
   → 初筛 CSV                    → 二筛 CSV                    → 最终报告
   (全市场→~800只)              (~800→A/B/C档)                 (A档→3-5只推荐)
```

## Step 1: CNINFO 全A清单 + 理杏仁 fundamental 粗筛

```bash
# 基础运行（会标记已在 watchlist 的标的但不排除）
python scripts/cn_mispricing_screen.py --date YYYY-MM-DD

# 自动排除已在 watchlist 中的 A 股标的
python scripts/cn_mispricing_screen.py --date YYYY-MM-DD --skip-watchlist

# 仅对前 N 只候选做财务评分（测试/快速验证用）
python scripts/cn_mispricing_screen.py --date YYYY-MM-DD --limit 100
```

`--skip-watchlist` 自动读取 `data/watchlist_core.json` 和 `data/watchlist_growth.json`，
提取所有 `.SH`/`.SZ` 代码并排除。**每次运行都应使用此标志。**

数据源分工：
- **全A清单**：CNINFO `szse_stock.json`（与 `cninfo_api._load_org_ids` 同源，约 5400 只 A 股）
- **股价/市值/PE**：理杏仁 `cn/company/fundamental/non_financial`（批量，单批 ≤100 只）
- **52周高点**：tushare `daily`（逐交易日全市场 high，取 1 年 max）

粗筛参数（硬编码在脚本中，可按需调整）：

| 参数 | 阈值 | 逻辑 |
|------|------|------|
| 股价 | ≥ CNY 5 | 排除仙股/低价股 |
| 流通市值 | ≥ CNY 50亿 | 排除微型股（A股小盘风险低于港股，门槛略低） |
| PE TTM | 6–30 | 排除亏损和无理估值（A股中枢高于港股，上限放宽到 30） |
| 距52周高点跌幅 | ≥ 15% | 确保"错杀"而非新高 |

输出：`data/screens/A股质量错杀初筛_YYYY-MM-DD.csv`

## Step 2: 理杏仁 fs 财务 + 四维量化排序

同一脚本自动完成：理杏仁 `fs/non_financial` 逐只拉 7 年年报（含 `m.*` 财务指标树），计算：

**四维评分（0–100）**：
- **增长质量（30%）**：5Y/3Y 营收 CAGR、净利润 CAGR、跨周期一致性
- **现金流质量（30%）**：经营现金流趋势、FCF 转化率、应收/存货 vs 营收剪刀差、净利率、毛利率
- **资本质量（25%）**：ROA、资产负债率、利息保障倍数、ROE、债务权益比
- **估值折价（15%）**：PE 偏离度（A股中枢 18x）、距 52 周高点跌幅

**异常惩罚项**：增速异常(–12)、利润增速脱节(–7)、ROE>40%(–6)、应收增长>营收(–8)、
经营现金流为负(–10)、FCF/NI<70%(–8)、股数膨胀>2%(–6)

**评级分档**：
| 档位 | 总分 | 含义 |
|------|------|------|
| A-优先三件套 | ≥72 且惩罚<12 | 质量+折价兼备，值得立即开三件套 |
| B-保留观察 | ≥58 | 有一定吸引力但存在瑕疵，等下一轮 |
| C-暂缓 | <58 | 问题显著，不值得现在花时间 |

输出：`data/screens/A股质量错杀二筛排序_YYYY-MM-DD.csv`

> ⚠️ 理杏仁 `fs/non_financial` 为**单只接口**（`stockCodes` 必须只含 1 只），
> 脚本用 3 线程 + 重试退避拉取，全市场约 700 只候选需 ~1-2 分钟。

## Step 3: AI 7 条指标手工精筛

对 A 档候选逐家执行以下 7 条检查。**数据优先用二筛 CSV 已拉取的字段；
缺的字段（10 年 ROE、5 年累计 FCF 符号、股本长期变化）用 WebSearch + WebFetch 补。**

### 7 条去劣指标

| # | 指标 | 排除条件 | 数据来源 |
|---|------|---------|---------|
| 1 | 10年平均ROE | < 8% | 理杏仁 fs + WebSearch 补 |
| 2 | 5年累计自由现金流 | 为负 | 理杏仁 `m.fcf` |
| 3 | 利息覆盖倍数（EBIT/利息） | < 2倍 | 理杏仁 `ps.ebit`/`ps.ieife` |
| 4 | 长期毛利率 | < 15% | 理杏仁 `m.gp_m` |
| 5 | 经营现金流 / 净利润（5年均值） | < 0.7 | 理杏仁 `m.ncffoa_np_r` |
| 6 | 长期净利率 | < 5% | 理杏仁 `m.np_s_r` |
| 7 | 5年总股本膨胀 | > 20%（非并购原因） | 理杏仁 `bs.tsc` + WebSearch |

### 3 条豁免规则

**豁免 A（战略投入期 → 第1条）**：上市不足10年 + 毛利率>30% + 近2年OCF为正

**豁免 B（主动低利润率 → 第6条）**：毛利率>30% + 近2年净利率回升至5%以上

**豁免 C（高周转薄利 → 第4/6条）**：ROE>20% + OCF/NI>1.0 + 会员制/平台佣金/高周转薄利模式

### 精筛输出格式

```markdown
## {公司名} ({代码}) — 精筛结论

| 指标 | 数据 | 判定 |
|------|------|------|
| ① 10Y 平均ROE | XX% | ✅/❌/⚠️ |
| ② 5Y 累计FCF | CNY X.X亿 | ✅/❌ |
| ③ 利息覆盖 | X.Xx | ✅/❌ |
| ④ 毛利率 | XX% | ✅/❌ |
| ⑤ OCF/NI | X.XX | ✅/❌ |
| ⑥ 净利率 | XX% | ✅/❌ |
| ⑦ 股本膨胀 | X% | ✅/❌ |

**综合判定**：✅ 通过 / ⚠️ 豁免通过（条款X）/ ❌ 排除

**一眼印象**（2-3句话）：商业模式、护城河、为什么跌、值不值得深挖。
```

## 最终报告

执行完毕后输出以下汇总到对话中：

1. **筛选摘要**：CNINFO N 只 → 二筛 A 档 M 只 → 精筛通过 K 只
2. **推荐列表**：精筛通过的标的，含二筛总分、PE、跌幅、一眼印象
3. **CSV 路径**：初筛和二筛文件位置
4. **下一步建议**：对推荐标的，建议运行「全面分析 XXX」（三件套）

## 注意事项

1. **交易日解析**：理杏仁 fundamental 对周末/节假日 date 返回空列表，脚本自动用 tushare 交易日历回退到最近交易日
2. **理杏仁批量上限**：`fundamental/non_financial` 单批 ≤100 只；`fs/non_financial` 单只，批量会返回 ValidationError
3. **金融股覆盖**：银行/券商/保险不在 `fs/non_financial` 服务范围，返回空数据被标"数据不足"（不直接排除，但不会进 A/B 档）
4. **周期股陷阱**：矿业/化工强周期股在商品高点时 3 年 CAGR 虚高、10 年 ROE 均值被高估值掩盖，精筛阶段必须查 10 年平均 ROE 和周期位置
5. **时效性**：理杏仁 fundamental 为实时估值，fs 年报可能有 1-2 季度延迟
6. **A股特有风险**：商誉减值、大股东质押/占用、财务造假（如康美/獐子岛式），精筛阶段需 WebSearch 搜索"[公司名] 商誉 质押 监管 问询"
7. **Watchlist 动态排除**：运行脚本时使用 `--skip-watchlist` 自动排除已有 A 股标的；Step 3 精筛前也应 `grep` 两个 watchlist JSON 确认候选不在其中
8. **已有深度分析/管理层档案的标的**：即使不在 watchlist，若 `深度分析/` 或 `管理层档案/` 已有文件，也应标注并跳过（或提示用户复核）
9. **板块区分**：精筛阶段标注板块属性（沪/深/创/科/北），科创板/北交所流动性与小盘风险权重不同
10. **API 用量**：全市场跑一遍约 60+ 次理杏仁 fundamental + 700+ 次 fs + 260 次 tushare，理杏仁和 tushare 均计入 `data/api_usage/`（理杏仁 ¥1800/年、tushare 免费 tier）

## 与三件套的关系

本 skill 是三件套的**上游筛选工具**。通过精筛的标的 → 运行 `全面分析 XXX` 开三件套。
不要在 skill 内部跳到三件套流程——保持职责边界清晰。
