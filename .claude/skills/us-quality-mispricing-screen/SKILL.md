# 美股质量错杀筛选（us-quality-mispricing-screen）

## 定位

用 Tiger Trade API 做全市场粗筛（价格、市值、PE、跌幅），yfinance 补全财务数据后
四维量化排序，最后 AI 对 A 档候选执行 7 条质量指标精筛。三步流水线，从全市场到 3-5 家
值得开三件套深度分析的标的。

**核心假设**：好公司 + 大跌幅 + 合理估值 = 值得深度研究。本 skill 只做筛选和排序，
不替代三件套（深度分析+管理层档案+估值分析）。

## 三步流水线

```
Tiger API 粗筛           yfinance + 量化排序        AI 7指标精筛
   → 初筛 CSV               → 二筛 CSV               → 最终报告
   (全市场→~80只)           (~80→A/B/C档)           (A档→3-5只推荐)
```

## Step 1: Tiger API 参数粗筛

```bash
# 基础运行（会标记已在 watchlist 的标的但不排除）
python scripts/us_mispricing_screen.py --date YYYY-MM-DD

# 自动排除已在 watchlist 中的标的
python scripts/us_mispricing_screen.py --date YYYY-MM-DD --skip-watchlist
```

`--skip-watchlist` 会自动读取 `data/watchlist_core.json` 和 `data/watchlist_growth.json`，
提取所有 `.US` 代码，从粗筛结果中排除。**每次运行都应使用此标志，避免重复分析已在关注列表中的公司。**

粗筛参数（硬编码在脚本中，可按需调整）：

| 参数 | 阈值 | 逻辑 |
|------|------|------|
| 股价 | ≥ $5 | 排除仙股 |
| 流通市值 | ≥ $2B | 排除微型股 |
| PE TTM | 8–30 | 排除亏损和无理估值 |
| 距52周高点跌幅 | ≥ 15% | 确保"错杀"而非新高 |

输出：`data/screens/美股质量错杀初筛_YYYY-MM-DD.csv`

## Step 2: yfinance 补字段 + 四维量化排序

同一脚本自动完成：用 yfinance 并发拉取 5 年财务报表，计算：

**四维评分（0–100）**：
- **增长质量（30%）**：5Y/3Y 营收 CAGR、净利润 CAGR、跨数据源一致性
- **现金流质量（30%）**：经营现金流趋势、FCF 转化率、应收/存货 vs 营收剪刀差、净利率、毛利率
- **资本质量（25%）**：ROA、资产负债率、利息保障倍数、ROE、债务权益比
- **估值折价（15%）**：PE 偏离度、距 52 周高点跌幅

**异常惩罚项**：季度增速异常(–12)、利润增速脱节(–7)、ROE>40%(–6)、应收增长>营收(–8)、
经营现金流为负(–10)、FCF/NI<70%(–8)、股数膨胀>2%(–6)

**评级分档**：
| 档位 | 总分 | 含义 |
|------|------|------|
| A-优先三件套 | ≥72 且惩罚<12 | 质量+折价兼备，值得立即开三件套 |
| B-保留观察 | ≥58 | 有一定吸引力但存在瑕疵，等下一轮 |
| C-暂缓 | <58 | 问题显著，不值得现在花时间 |

输出：`data/screens/美股质量错杀二筛排序_YYYY-MM-DD.csv`

## Step 3: AI 7 条指标手工精筛

对 A 档候选逐家执行以下 7 条检查。**数据优先用 yfinance 已拉取的字段；
yfinance 缺的字段，用 WebSearch + WebFetch 补。**

### 7 条去劣指标

| # | 指标 | 排除条件 | 数据来源 |
|---|------|---------|---------|
| 1 | 10年平均ROE | < 8% | yfinance + WebSearch 补 |
| 2 | 5年累计自由现金流 | 为负 | yfinance FCF 字段 |
| 3 | 利息覆盖倍数（EBIT/利息） | < 2倍 | yfinance |
| 4 | 长期毛利率 | < 15% | yfinance |
| 5 | 经营现金流 / 净利润（5年均值） | < 0.7 | yfinance |
| 6 | 长期净利率 | < 5% | yfinance |
| 7 | 5年总股本膨胀 | > 20%（非并购原因） | yfinance |

### 3 条豁免规则

**豁免 A（战略投入期 → 第1条）**：上市不足10年 + 毛利率>30% + 近2年OCF为正

**豁免 B（主动低利润率 → 第6条）**：毛利率>30% + 近2年净利率回升至5%以上

**豁免 C（高周转薄利 → 第4/6条）**：ROE>20% + OCF/NI>1.0 + 会员制/平台佣金/高周转薄利模式

### 精筛输出格式

```markdown
## {公司名} ({代码}) — 精筛结论

| 指标 | 数据 | 判定 |
|------|------|------|
| ① 10Y 平均ROE | XX% | ✅/❌/⚠️ |
| ② 5Y 累计FCF | $X.XB | ✅/❌ |
| ③ 利息覆盖 | X.Xx | ✅/❌ |
| ④ 毛利率 | XX% | ✅/❌ |
| ⑤ OCF/NI | X.XX | ✅/❌ |
| ⑥ 净利率 | XX% | ✅/❌ |
| ⑦ 股本膨胀 | X% | ✅/❌ |

**综合判定**：✅ 通过 / ⚠️ 豁免通过（条款X）/ ❌ 排除

**一眼印象**（2-3句话）：商业模式、护城河、为什么跌、值不值得深挖。
```

## 最终报告

执行完毕后输出以下汇总到对话中：

1. **筛选摘要**：Tiger 粗筛 N 只 → 二筛 A 档 M 只 → 精筛通过 K 只
2. **推荐列表**：精筛通过的标的，含二筛总分、PE、跌幅、一眼印象
3. **CSV 路径**：初筛和二筛文件位置
4. **下一步建议**：对推荐标的，建议运行「全面分析 XXX」（三件套）

## 注意事项

1. **Tiger API 限制**：部分账户的 `market_scanner` 不返回财务字段，此时完全依赖 yfinance 补全
2. **yfinance 数据质量**：非标准审计数据，部分字段可能缺失（标注"数据不足"而非直接排除）
3. **行业覆盖**：不排除金融/REIT，但在精筛时标注"第3条不适用"
4. **时效性**：Tiger 粗筛数据为实时行情，yfinance 财报可能有 1-2 季度延迟
5. **Watchlist 动态排除**：运行脚本时使用 `--skip-watchlist` 自动从 `watchlist_core.json` 和 `watchlist_growth.json` 读取已有标的并排除。Skill 的 Step 3 精筛阶段也应先 `grep` 两个 watchlist JSON 确认候选不在其中
6. **已有深度分析/管理层档案的标的**：即使不在 watchlist 中，如果在 `深度分析/` 或 `管理层档案/` 目录已有文件，也应标注并跳过（或提示用户复核）

## 与三件套的关系

本 skill 是三件套的**上游筛选工具**。通过精筛的标的 → 运行 `全面分析 XXX` 开三件套。
不要在 skill 内部跳到三件套流程——保持职责边界清晰。
