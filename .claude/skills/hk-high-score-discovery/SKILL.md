# 港股未收录高分企业筛查（hk-high-score-discovery）

## 定位

`.claude/skills/cn-high-score-discovery` 的港股同款：**完全不看当前股价**，只从「企业质量能否支撑
B_GROWTH/A_CORE 级（深分≥70/76 + 管档≥70/76）」角度，粗排尚未被本知识库深度覆盖的港股优质公司，
作为未来开「全面分析（三件套）」的上游候选清单。不看价格 → 无需定期跑 → **持久候选池 + 分批复核**消化大列表。

## 港股数据层差异（与 A股版最重要区别）

| 项 | 港股做法 |
|---|---|
| 宇宙 | **Tiger 选股器**，仅设 `流通市值≥HKD 200亿`（实测 337 家），无价格/PE/跌幅门槛 |
| 财务 | **yfinance 逐只 ~5 年年报**（非标审计数据、字段常缺 → 缺失中性不计分） |
| 行业 | yfinance `sector` 排金融（Banks/Insurance/Financial Services…）+ 名称含 -REIT；**地产开发商保留** |
| 审计意见 | yfinance 无 → **无自动审计红旗** |
| 管理层红旗 | **无 CNINFO/理杏仁批量接口** → 全池不自动打红旗，Run B 逐家 Web/Tavily 核（见下） |
| 覆盖率 | `00-首页/公司索引.md` 港股节 `- [[名称]]（00005）` → code→名称；watchlist/低分登记 `.HK` 硬排 |

沿用 A股版决策：**持久池 + 分批复核**、**宽松口径**（只硬排 watchlist+低分登记，有旧研究打标不排除）、
分数 = 粗排工具 ≠ 真深分、不写 watchlist、不自动开三件套。

## Run A：建池 / 刷池（少跑，财报季后或半年一次）

```bash
python scripts/hk_high_score_pool.py
# 常用参数：--min-cap 30 / --min-score 50 / --codes 00322,01929 / --limit 60 / --no-cache
```

- 宇宙由 Tiger 现扫（快）；逐只 yfinance 只在缓存未命中时拉（337 家首次 ~10 分钟，之后增量近零）。
- 脚本保留旧池 review 进度。产物行 `代码` 用知识库口径 `00700.HK`，含 `管理层红旗="RunB核"` 占位。
- 初值阈值 ≥70 Ⅰ候选 / 60–70 Ⅱ候选（首跑校准后回填 SKILL）。

## Run B：分批复核（每次调用实际动作）

> 每次只精筛池头 pending 前 5~8 家（Ⅰ优先、全新优先）；港股管理层面比 A股重，每家都需 Web 核。

1. **取批**：读 `港股高分候选池.json`，`review_status=pending` 且质量分最高 N 家。
2. **逐家**：读池内财务快照校验质量分 → **管理层/红旗 Web 核**（Tavily/WebSearch）→ 有旧研究选跳过/更新，
   全新认真评 → 补商业模式一眼。
   **HK 管理核清单**：审计师是否四大/有无保留意见或频繁换所；老千信号（股权高度集中、频繁供股/合股/改名、
   关联交易掩盖利润）；大股东质押/资金占用；被做空/沽空报告史；处罚/诉讼；派息与股本行为历史。
3. **判定**：建议开三件套（预估深分+管档≥70）/ 疑点需深挖 / 排除（红旗证据实）。
4. **主 Agent 写回** `review_status/reviewed_date/notes` 到池 JSON（子 Agent 不得写文件）。
5. 对话小摘要 + 强推 2~3 家「建议全面分析 XXX」。

## 质量分口径（脚本 quality_score，港股特有调参）

**五维 100 分：growth20 + profit28 + cash27 + capital20 + 股本纪律5 − 惩罚。** 与 A股版比：
- **轻成长重盈利现金流**：港股成熟高 ROE 现金牛多（康师傅等营收停滞但质量极高），成长停滞不再压到 Ⅰ 线下；
- **高周转薄利豁免**：ROE≥18 且现金转化好且无 OCF 负年 → 低毛利/低净利不拖累（对应错杀 skill 豁免 C，
  康师傅净利率4%仍是 Ⅰ）；
- **无审计/无分红史**：审计红旗与分红率维度缺失，仅靠财务与 Run B Web 核兜底；
- **NaN→中性35**（严禁泄漏进 clamp 致假满分）。

惩罚：增速异常、利润增速脱节、ROE>40、应收增速>营收、OCF3Y萎缩>5%、多数年FCF为负、股本膨胀>2%、OCF负年数≥3。

> 校准记录：首版冒烟用 康师傅70.4→Ⅰ / 周大福66·联想64（薄利+应收噪声）→边界 / 恒安52（ROE走低）。
> Ⅰ/Ⅱ 阈值与 min-cap 全量首跑后回填。

## 注意事项

1. **代码三态**：Tiger `00700`(5位) / Yahoo `0700.HK`(4位) / 知识库 `00700.HK`。池内统一 `.HK` 口径，脚本内部全转，防错位。
2. **yfinance 慢且偶失败**：字段不足标「数据不足」不排除；个别 404（已退市/改名）自然跳过。
3. **金融/REIT 已排除**（无 CNINFO 专用端点，yfinance 指标对银行/保险失真）；地产开发商保留、靠资本维度罚高负债。
4. **H股/红筹/香港本地**：Run B 标注注册地属性；A+H 已覆盖侧靠 watchlist/公司索引排除。
5. **分数≈深分 E 维粗排**，管理层分数终以三件套为准；Run B 管理层核是唯一治理把关，别省。

## 与三件套的关系

上游候选生成器。Run B 推荐 → 用户触发「全面分析 XXX」。本 skill 不写 watchlist、不自动开三件套。
