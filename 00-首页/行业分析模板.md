### 维度 3：规模经济方向（X/15）

> 核心问题：越大越容易赚钱，还是越大越难？这决定了龙头的利润护城河是否越做越厚。

| 类型 | 得分 | 说明 |
|---|---|---|
| 强正向规模经济 | 13–15 | 越大越赚钱——固定成本高、网络效应强、平台型商业模式 |
| 弱正向规模经济 | 9–12 | 规模有助于降本，但边际效益递减 |
| 中性 | 6–8 | 规模与利润相关性不强 |
| 负向规模经济 | 3–5 | 越大越难管理，或产能扩张直接压低行业定价 |
| 强负向规模经济 | 1–2 | 规模越大利润越薄（如劳动密集型低端制造） |

### 维度 4：进入壁垒叠加（X/15）

> 核心问题：外来者要复制这门生意，需要跨越几道门槛？门槛越多越高越好。

叠加式计分（每项有效壁垒独立得分，上限 15 分）：

| 壁垒类型 | 最高分 | 是否存在 | 实际得分 | 说明 |
|---|---|---|---|---|
| 监管/牌照壁垒 | +4 | ✅/❌ | | 无法绕过的法规准入、特许经营权、行政许可 |
| 技术/专利壁垒 | +4 | ✅/❌ | | >5年技术积累，或核心工艺/IP形成的护城河 |
| 资本壁垒 | +3 | ✅/❌ | | 单条产线投资>5亿，或建设周期>18个月 |
| 品牌/客户认证壁垒 | +3 | ✅/❌ | | 客户认证周期>12个月，或品牌信任度难复制 |
| 网络/生态/数据壁垒 | +4 | ✅/❌ | | 用户/数据飞轮效应，或生态系统锁定 |
