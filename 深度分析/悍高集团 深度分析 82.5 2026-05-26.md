- 创始人背景：欧锦锋为自然人创业型，非国企改制或政府背景
- 成立时间节点：2004 年正值中国加入 WTO 后制造业出口爆发期，也是国内定制家具行业萌芽期——时机精准
- 原始主营业务：家居五金配件的 OEM/ODM 代工（为国内外家具厂生产铰链、导轨等）
- 初始行业地位：顺德众多五金代工厂之一，非领先者

## 维度 B：商业模式质量

### B0. 早期商业模式溯源（创立至上市期）

**九要素商业模式画布**：

| 要素 | OEM 代工阶段（2004–2015 年）| 品牌化阶段（2015–至今）|
|---|---|---|
| 客户群体 | 国内外家具厂/橱柜厂 | 国内定制家居品牌（OEM→ODM→OBM）+ 海外经销商 |
| 价值主张 | 低成本、稳定质量 | "HIGOLD 悍高"品牌五金——高品质、设计感、品牌信赖 |
| 渠道通路 | 直销大客户 | 经销商网络 + 直销大客户（索菲亚/欧派等）+ 电商 |
| 客户关系 | 按订单采购 | 品牌复购 + 长期合作 |
| 收入来源 | 按件代工费 | 品牌溢价定价 + 户外家具新品类 |
| 核心资源 | 产能、成本控制 | 品牌、研发设计、自动化产线、渠道网络 |
| 关键活动 | 生产制造 | 品牌营销 + 产品研发 + 渠道管理 |
| 重要合作伙伴 | 钢材/锌合金供应商 | 定制家居品牌 + 经销商 + 海外客户 |
| 成本结构 | 原材料 60%+、人工、制造费用 | 原材料 50%+、研发 3.4%、销售 7.3%（2025年）|

**关键判断**：
- 是否为"辛苦钱生意"：**早期是**（OEM 代工，净利率仅 6.5%）。但现在已**转型为品牌消费品**（净利率 19.6%，接近定制家居品牌商水平）。
- 毛利率质变节点：2019-2022 年，毛利率从 ~28% → ~32%（品牌初步建立）；2023-2025 年，毛利率从 ~34% → ~37%（品牌溢价+规模效应+自动化降本三重叠加）。
- 商业模式本质变化：**有本质性变化**——从"五金代工商"到"品牌五金集团"，驱动力是品牌建设投入+产品设计能力+自动化产线。

**历史商业模式分类**：
- [x] 轻资产高毛利可复制型（品牌溢价+自动化生产+产业集群支撑，天生优质）

> 悍高是 A 股制造业中少有的"轻资产+高毛利+高ROE"三角同时成立的标的——固定资产仅占总资产 20.6%，但毛利率 37.2% 且仍在改善。
