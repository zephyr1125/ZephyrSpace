## 维度 A：历史基因与公司 DNA（7/10）

### A1. 公司起源与创始基因

云南铝业股份有限公司前身为**云南铝厂**，始建于上世纪70年代，位于云南省昆明市呈贡区，依托云南丰富的水电资源发展电解铝。1998年3月进行股份制改组，以原厂净资产折为国有法人股2.3亿股，1998年4月8日在深交所上市（发行价4.90元，发行PE 14倍，募资3.78亿元）。（来源：公司概况 + 巨潮IPO档案）

**起源基因判断**：政策红利型 + 资源依赖型。公司从设立起就依赖「云南水电资源 + 地方国企身份」两大禀赋，属于典型的资源型国企起源，非技术驱动、非创始人驱动。

### A2. 历史控制权稳定性

| 时间段 | 实际控制人 | 性质 |
|---|---|---|
| 1998–2019 | 云南省人民政府国资委 | 地方国资 |
| 2019–今 | **中国铝业集团（中铝集团）** | 中央央企 |

控制权变更 **1 次**：2019年中铝集团通过无偿划转等方式取得云铝股份控制权，将其纳入央企铝业板块（云南冶金集团亦划入中铝）。截至2026H1，中国铝业股份持股29.10% + 云南冶金集团持股13.00%，合计42.10%，同受中铝集团控制。（来源：2026年半年度报告摘要）

**判断**：变更 1 次且为央企战略整合，属主动整合而非股权争夺/财务危机，A2 不扣分。但需注意：公司本质上是中铝集团的**生产平台**，战略自主权有限，经营层面受集团统一管控。

### A3. 资本运作历史

- **融资历史**：上市以来累计融资 143.8亿元（IPO 3.78亿 + 历次定增/配股约140亿），累计分红 73.8亿元，分红融资比约 51.4%。（来源：理杏仁 hot/df）
- **并购行为**：以内部扩产（自建电解铝产能）为主，无重大跨界并购，商誉极低。2025年对资不抵债且无持续经营能力的子公司**云铝沥鑫实施破产清算**（2025年12月不再并表），属主动止损。
- **无"卖资产保利润"行为**：2021–2025年扣非净利/归母净利均>90%（2020年周期低谷为85.4%），无靠处置资产粉饰利润痕迹。

**A3 判断**：融资规模偏大（重资产行业属性使然），但用途清晰（产能建设）、无乱并购、无商誉地雷、有主动止损行为 → 3/4。

## 维度 B：商业模式质量（13/20）

### B0. 早期商业模式溯源

**九要素画布（创立期 vs 当下）**：

| 要素 | 创立期（90年代） | 当下（对照） |
|---|---|---|
| 客户群体 | 国内铝材加工企业 | 铝加工+终端（汽车/轨交/电力/包装/3C） |
| 价值主张 | 提供稳定的电解铝供给 | 绿色低碳铝（碳足迹全球领先）+ 一体化降本 |
| 渠道通路 | 直销+区域销售 | 中铝国贸/佛山国贸分销 + 直销 |
| 客户关系 | 按需采购、随行就市 | 长期框架合同为主 |
| 收入来源 | 按吨计价（铝锭市价） | 按吨计价 + 加工费 |
| 核心资源 | 云南水电 + 电解铝牌照 | 水电+产能指标+绿色铝认证+氧化铝自给 |
| 关键活动 | 电解生产 | 全产业链一体化 + 极致经营降本 |
| 成本结构 | 电力占比极高（>50%） | 原材料59% + 燃料动力34%（电力仍是核心变量） |
| 重要伙伴 | 云南省电力系统 | 中铝集团体系（财务/贸易/资源）+ 南方电网 |

**关键判断**：
- 是否为"辛苦钱生意"：**是**。重资产（总资产505亿）+ 长回报周期 + 盈利随铝价剧烈波动。
- 成本结构质变节点：2020年前后中铝入主 + 大规模投产完成后进入运营收获期，叠加资产负债率从66%降至20%，单位成本结构和财务费用显著改善。
- 早期与当下本质变化：**无本质性变化**，仍是"电解铝→加工"一体化，但边际上增加了绿色溢价（碳足迹认证）和资源综合利用（再生铝/铝灰）。

**历史商业模式分类**：重资产低毛利但构建垄断壁垒型（产能指标 + 电力资源双重壁垒，不可复制）。

### B1. 当下业务板块全景

| 业务名称 | 营收占比(2025) | 毛利率(2025→2026H1) | 增速(2025→2026H1) | BCG定位 |
|---|---|---|---|---|
| 电解铝（有色金属冶炼） | 56.8% | 18.2% → **34.0%** | +10.1% → +20.5% | 现金牛/周期明星（景气高位） |
| 铝加工产品 | 42.0% | 15.2% → **29.9%** | +10.4% → +18.1% | 明星（合金化/高端化方向） |
| 其他（再生铝/资源利用） | 1.2% | 5.9% | +12.9% | 培育 |

（来源：2025年报 营业收入构成；2026年半年报 分产品毛利率，2026-08-27）

**结构判断**：业务高度单一（铝占99%），但按产品线拆解呈现「电解铝（周期现金牛）+ 铝加工（成长明星）+ 再生铝（培育）」结构。**注意：2026H1毛利率34%/29.9%处于周期景气高位，2025全年仅18.2%/15.2%，不可将峰值毛利当作常态。**

一体化协同：年产氧化铝140万吨（自给率约45%）、阳极炭素80万吨、石墨化阴极2万吨、绿色铝合金161万吨，全产业链自给显著降低中间成本。（来源：2025年报摘要）

### B2. 盈利机制解析

| 盈利模式 | 判断结论 |
|---|---|
| 收费方式 | 按吨计价（铝锭/铝加工产品随行就市） |
| 复购特征 | 下游持续性采购（框架合同），但价格每期重定 |
| 需求刚性 | **刚性必需**（工业基础材料，轻量化/新能源/电力需求） |
| 成本结构 | **固定+能源成本主导**（电力占成本约34%，重资产） |
| 规模效应 | 强（大规模电解铝单位能耗/成本显著低于小厂） |

**结论**：这是一家「**重资产一体化的周期制造商**」模式的公司，需求刚性但价格随行就市，规模效应与电力成本决定利润弹性。盈利波动主因是铝价，非公司可控。

### B3. 定价权深度评估

**第一步：来源判断**

| 来源类型 | 是否具备 | 佐证 |
|---|---|---|
| 品牌溢价 | ❌ | 铝锭无品牌溢价，绿色铝溢价尚未充分变现 |
| 客户转移成本 | ❌ | 大宗商品，客户按市价切换供应商 |
| 网络效应 | ❌ | 无 |
| 监管/资质壁垒 | ✅ | 电解铝产能指标（全国4500万吨天花板）稀缺 |
| 成本领先 | ✅ | 水电铝（清洁能源比例87.5%），电力成本显著低于火电铝 |
| 垂直整合 | ✅ | 氧化铝/炭素/铝土矿自给，一体化降本 |

**综合评级**：⭐⭐（中偏弱）——公司是**成本领先者**而非价格制定者。铝价由全球供需决定，公司通过成本优势获取超额利润差。

**第二步：历史数据验证**
- 近5年毛利率：14.2%（2020）→ 20.4%（2021）→ 14.9%（2022）→ 15.8%（2023）→ 13.2%（2024）→ 16.8%（2025）→ 34.0%（2026H1）——**剧烈波动，典型周期属性**。
- 主动提价记录：无（价格被动接受者）。
- **红旗警示**：毛利率波动完全由铝价主导，定价权在景气上行期看似很强（2026H1 34%），但这是**周期属性伪装成护城河**，景气下行立即回吐。

### B4. 业务可持续性评估

- **TAM**：全球铝消费规模超1亿吨/年，中国占比约55%。中国电解铝产能天花板4500万吨已基本触顶，供给侧刚性约束明确。
- **行业生命周期**：成熟期偏成长——需求端受新能源（汽车轻量化/光伏支架/电网）、AI数据中心（电力扩容拉动电网用铝）等驱动，仍有结构性增量；供给端受产能天花板约束，**行业供需长期紧平衡**（注：当前"高铝价中枢"属周期景气判断，非结构性依据）。
- **内生增长**：公司增长以存量产能满产 + 产品结构升级为主（铝商品产量2025年仅+6.47%），量增有限，利润弹性主要来自价格与成本差。
- **公司自身增量**：2026年计划铝商品产量319万吨 vs 2025年实际322.59万吨——**无产能扩张计划**，盈利增长靠铝价中枢上移 + 成本端氧化铝价格走弱。

### B 维度小结

B0=2（重资产构建垄断壁垒，分类明确）、B1=3（高度单一但一体化逻辑清晰）、B2=2（刚需+规模效应但价格随行就市）、B3=3（成本领先+一体化，但周期主导定价权）、B4=3（成熟期供给侧约束，需求有结构性增量）。**B=13/20**。

## 维度 C：竞争格局与护城河（15/20）

### C1. 市场地位

- 电解铝产能约**308万吨/年**，全国排名**前五**（第一梯队），与中铝、宏桥、信发等并列头部阵营（来源：公司2025年报 + 行业公开数据）。
- 全国电解铝产能约4500万吨，公司产能占比约7%。
- 全国**规模最大的绿色低碳铝供应商**（清洁能源占比87.5%，9个国家级"绿色工厂"）。

**一线/二线判断**：第一梯队（Top5，规模+成本+绿色三重领先）。

### C2. 产业链话语权（纵向）

| 判断维度 | 结论 | 佐证依据 |
|---|---|---|
| 上游议价能力 | **较强** | 铝土矿自采（自产矿量2026H1同比+14%）+ 氧化铝自给140万吨 + 阳极炭素自给80万吨，大宗原料自给率提升降低价格波动冲击 |
| 下游议价能力 | **弱** | 铝锭/铝加工按市价销售；名义客户集中于中铝集团分销渠道（**第一大客户中铝集团占销售额32.18%**，2025年报），但该集中属集团内部协同分销，真实终端需求分散 |
| 成本传导能力 | 弱 | 铝价由市场决定，公司无法向下游转嫁成本，只能内部消化（氧化铝自给/水电优势） |
| 需求传导敏感性 | 即时 | 铝价随LME/国内现货每日波动，当期传导 |
| 产业链景气周期 | 上行 | 2026年电解铝紧平衡加剧，氧化铝价格走弱扩大行业利润基础，预计铝价中枢维持高位 |

**产业链定性结论**："喝汤偏吃肉"——上游一体化能力强（控制成本端），下游价格随行就市（无法主导收入端）。本质是**成本领先者**，利润取决于「铝价-成本」价差。

### C3. 横向竞争格局

- 市场结构：**寡头垄断**（中国电解铝CR5约45%，产能指标限制新进入者）。
- 价格战：无（供给侧受产能天花板约束，行业整体盈利改善）。
- 与第一名差距：规模上低于中国宏桥（约646万吨）、中铝集团整体，但在**水电铝细分赛道**是绝对龙头；在云南区域具备资源垄断地位。

| 资质壁垒 | 🔴强 | **电解铝产能指标**全国4500万吨天花板已满，新产能只能置换，存量产能稀缺 |
| 规模壁垒 | 🔴强 | 308万吨规模带来的采购/能耗/管理摊薄优势 |

**综合护城河强度**：⭐⭐⭐⭐（4星）——产能指标+水电资源+规模三重壁垒，护城河较深但盈利兑现依赖铝价。

## 最终结论

### 公司质量评级：⭐⭐⭐⭐（优质）（77/100）

**核心竞争优势（数据支撑）：**
1. **[成本+资源护城河]**：全国最大绿色低碳铝供应商，清洁能源占比87.5%（碳排为煤电铝20%），叠加氧化铝/炭素自给的一体化降本，铝液交流电耗行业领先（来源：2025年报核心竞争力分析）。
2. **[供给侧稀缺性]**：电解铝产能指标全国4500万吨天花板触顶，公司308万吨产能（全国前五）成为稀缺资产，紧平衡格局下盈利中枢抬升（来源：2025年报 + 行业产能政策）。
3. **[现金流质量]**：净现比连续7年>100%，2026H1 OCF 83.8亿，FCF约82亿，资产负债率19.8%净现金，资本开支收获期现金流极优（来源：CNINFO/东方财富）。

**核心隐患（数据支撑）：**
1. **[强周期盈利]**：2026H1电解铝毛利率34%处于景气高位（2025全年仅18.2%），盈利高度依赖铝价-成本价差，2020年低谷ROE仅8%（来源：公司财务数据）。
2. **[关联交易集中]**：关联销售约180亿占营收30%（中铝系分销体系），中铝财务存款34亿，存在集团利益协调复杂度（来源：2025年报关联交易）。
3. **[管理层集中轮换]**：2025年董事长/总经理/财务总监/董秘4核心岗位全部换人（中铝系统内轮岗），执行连续性需观察（来源：2025年报董监高变动）。

**长期重仓适配度判断**：
