## A 历史基因与公司DNA

### A1 起源与控制

- 公司为香港上市平台，核心经营资产是中粮可口可乐装瓶业务。
- 最终控制人为中粮集团有限公司，属于中央国有企业控制链。
- 2026H1控股链持有2,072,688,331股，占已发行股本74.10%（S001）。
- 控制权集中提升战略稳定性，也降低公众股东对重大决策的影响力。

### A2 与TCCC的长期关系

- 特许经营权来自与The Coca-Cola Company的多项装瓶协议。
- 协议赋予集团在19个省级行政区准备、包装、分销和销售TCCC品牌产品的独家权利。
- 年报称双方关系长期持续，续期或延期按过往经验无须支付对价（S003附注17）。
- 特许权被列为无限寿命资产，但“无限寿命”是会计估计，不是法律上的永久权利。

### A3 资本运作基因

- 当前资产负债表无银行及其他借贷，资本结构偏保守。
- FY2025资本开支现金支付：物业厂房设备1,048.816、无形资产11.699。
- 2026-06-30已订约未计提资本承诺143.025，规模相对现金储备可控。
- 尚未取得足够长周期并购成功率资料，因此不把“无重大失败”写成事实。

### A4 基因分类

- 分类：经营型、品牌授权与渠道运营型。
- 非纯品牌所有者：品牌资产和配方核心控制权在TCCC。
- 非纯制造商：独家区域、渠道密度和系统协同构成额外壁垒。
- A维度子项：A1 2/3、A2 2/3、A3 3/4，合计7/10。

## B 商业模式质量

### B0 商业模式画布

| 要素 | 当前模式 |
|---|---|
| 客户 | 中国内地零售、餐饮、经销及终端消费者链条；无单一客户占收入10%以上 |
| 价值主张 | 提供高认知度、即时消费的可口可乐系列饮料及配送服务 |
| 渠道 | 多层级经销、传统零售、现代渠道、智慧零售和线上会员平台 |
| 收入 | 以饮料销售为主，频次高、客单低、需求具有消费属性 |
| 核心资源 | 19省级区域特许经营权、装瓶产能、分销网络、中粮与TCCC合作关系 |
| 关键活动 | 生产、装瓶、仓储、配送、营销、渠道执行和终端陈列 |
| 合作伙伴 | TCCC、中粮体系、非控股股东及相关供应链主体 |
| 成本结构 | 原料、包装、生产、物流和销售费用占主导，规模效应重要 |

| 汽水 | 16,684.628 | 75.6% |

- 汽水占比超过70%，属于明显的品类集中。
- 果汁提供第二品类，但规模远小于汽水。
- 功能饮料占比仍低，不能仅凭行业趋势称为成熟增长引擎。
- 公司只披露一个经营分部，不能把管理层提出的三大业务方向当作已独立盈利分部。

### B2 盈利机制

- 收费方式：按产品销售，非订阅制。
- 复购特征：高频复购，但消费者品牌忠诚最终主要归属于TCCC品牌。
- 需求属性：大众消费，具一定防御性，同时受天气、促销、渠道库存和可选消费环境影响。
- 成本结构：变动成本与销售配送费用显著，规模、路线密度和采购协同决定边际利润。
- 规模效应：区域网络越密集，生产、仓储、物流和营销效率越好。

### B3 定价权

- 品牌溢价：强，但公司与TCCC共享该价值。
- 渠道控制：中强，来自19省级区域覆盖和终端执行能力。
- 转移成本：对终端消费者不高，对装瓶体系和区域网络较高。
- 成本传导：需结合TCCC定价、市场竞争及促销策略，非公司单方面决定。
- 结论：定价权中强，不能等同于完全自主的品牌定价权。

### B4 持续性

- 2021–2025收入由19,784.422增至22,070.162，四年CAGR约2.8%。
- 同期归母利润由572.415增至861.968，四年CAGR约10.8%。
- 利润增长快于收入，显示效率改善比销量扩张更重要。
- 2025收入同比约2.7%，归母利润仅约0.2%，利润增速已明显放缓。
- 2026H1收入同比约4.0%，归母利润同比约7.8%，出现改善但只有半年度。
- B维度子项：B0 1/2、B1 3/4、B2 3/3、B3 4/6、B4 3/5，合计14/20。

## C 竞争格局与护城河

### C1 市场地位

- 公司未在冻结证据中披露全国市占率或CR5，相关数值标记未知。
- 可确认的优势是19个省级行政区的TCCC品牌独家装瓶与分销权。
- 该区域权利和既有产能使新进入者很难复制同等网络。
- 收入全部来自中国内地客户，不应外推到港澳经营覆盖。

### C2 上游与品牌方

- TCCC掌握品牌、配方及装瓶协议，是关键合作方也是重要约束方。
- 包材、糖和能源成本可能影响毛利率，公司通过采购协同和全价值链降本缓冲。
- 2025关联方采购规模大，说明供应链协同显著，也带来定价与利益冲突审查需要。

### C3 下游

- FY2025没有单一客户贡献收入10%以上（S003附注6）。
- 客户分散降低单一客户违约风险。
- 渠道执行和配送半径带来本地网络优势。
- 消费者仍可在饮料品牌之间快速切换，因此终端替代威胁存在。

### C4 护城河分解

| 壁垒 | 强度 | 判断 |
|---|---|---|
| 品牌 | 强 | TCCC品牌强，但并非上市公司完全拥有 |
| 特许经营权 | 强 | 19省级区域独家权；续期仍是关键长期风险 |
| 规模与渠道 | 强 | 生产、配送、终端覆盖难以短期复制 |
| 技术 | 中低 | 装瓶技术可复制，数字化主要改善效率 |
| 网络效应 | 中 | 路线密度与终端覆盖形成局部网络效应 |
| 客户锁定 | 低 | 终端消费者切换成本低 |

### C5 五力结论

- 供应商议价：中等偏强，尤其是品牌方和关键原料。
- 买方议价：分散终端较弱，大型渠道可能较强。
- 同业竞争：强，软饮料市场品牌与促销竞争持续。
- 替代品：强，茶饮、咖啡、无糖与功能饮料均构成替代。
- 新进入者：品牌可进入，但复制区域装瓶网络和授权关系难。
- C维度子项：C1 4/6、C2 3/5、C3+C4 7/9，合计14/20。

## D 战略与执行

### D1 战略主线

- 2025管理层强调“重塑”、全价值链成本管理和数智化。
- 2026方向为多元增长、多维创新、多能数智。
- 基石业务仍是可口可乐装瓶，战略没有脱离现有能力圈。
- 平台业务和营养健康食品被定义为第二增长动能，尚属培育期。

### D2 执行证据

- 2025收入和经营利润创披露期高位，经营利润同比约6.1%。
- 首家数智化工厂在陕西投产，属于可验证的供应端行动。
- 收入增长较慢，表明数智化目前更多体现为效率而非需求爆发。
- 冻结证据没有连续三年量化经营目标，长期兑现率只能部分评价。
- 未取得完整电话会原话，D2受证据上限约束。

### D3 PESTEL

| 因素 | 影响 |
|---|---|
| 政策 | 提振消费与营养健康政策可能利好，但食品安全监管持续严格 |
| 经济 | 居民消费恢复有利，弱需求和价格竞争构成压力 |
| 社会 | 健康化、无糖化改变产品组合，传统含糖汽水承压 |
| 技术 | 智慧工厂、路线优化和会员数据可提升效率 |
| 环境 | 包装、水资源、能耗和碳排放是长期运营约束 |
| 法律 | 装瓶协议、食品安全、广告和关联交易合规重要 |

### D4 价值链

- 高价值环节：品牌授权关系、渠道控制、终端执行和供应链效率。
- 低价值环节：标准化装瓶制造本身，容易受到成本波动影响。
- 公司资源正在向数智工厂、渠道精细化和平台协同倾斜。
- 第二曲线尚未披露独立回报，不能提前认定其创造价值。

### D5 SWOT

- S：区域特许经营权、强品牌、渠道规模、净现金。
- W：依赖TCCC、单一分部、少数股东分享较大比例集团利润。
- O：无糖与功能饮料、渠道数字化、营养健康食品。
- T：消费疲弱、健康趋势对传统汽水的替代、续约和关联交易风险。
- 最大SO：利用渠道与品牌推出多品类并提高终端效率。
- 最大WT：传统汽水集中叠加品牌方控制，第二曲线若失败则增长有限。
- D维度子项：D1 4/4、D2 2/5、D3 2/3、D5 2/3，合计10/15。

## 反证条件

1. TCCC装瓶协议不再按历史条件续期，或独家区域发生实质收缩。
2. 汽水收入持续负增长，功能饮料与其他新品三年内仍无法形成可见贡献。
3. 毛利率跌破减值测试关键假设区间且无法通过效率改善修复。
4. 关联交易被监管认定不公允，或中粮体系资金安排造成损失。
5. 合并现金流强但归母分红、归母利润或归母净资产长期不增长。
6. 重大食品安全、环境、安全生产或反垄断处罚影响核心经营。
7. 商誉或无限寿命特许经营权出现重大减值。

## 最终结论

### 公司质量评级：⭐⭐⭐ 良好（69/100）

**核心优势：**

1. 19省级区域的TCCC独家装瓶与分销权叠加强渠道网络，形成难复制的运营壁垒。
2. FY2025合并OCF3,229.308，2026-06-30无银行及其他借贷、现金5,898.074，财务韧性突出。
3. 2021–2025归母利润四年CAGR约10.8%，效率提升快于收入增长。

**核心隐患：**

1. 汽水占收入75.6%，且品牌与核心授权并非上市公司完全拥有。
2. 2025非控股权益分享集团利润约39.6%，集团现金流不可直接归母。
3. 关联采购规模大、控股权高度集中，公允性与小股东保护是长期审查重点。

**长期持有适配度：**

中国食品更接近成熟消费渠道资产，而非高增长品牌所有者。69分对应“良好”；与管理层70分合计139，Watchlist等级为NONE，但不是结构性“不入”。估值中枢HKD2.72，机械买入价HKD2.08。
