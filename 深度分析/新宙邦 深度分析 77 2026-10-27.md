## A 历史基因与控制结构

公司经济本质为电子化学品与功能材料制造平台，不是资源储量型企业。
创始期从电容器化学品延伸至锂电电解液，核心积累是配方、工艺和客户认证。
历史起源及早期资本路径复用前版，当前持续性由S3—S7年报核验。
不能把精细化学品的研发能力直接视为终端品牌垄断。

S1 p5—6：2026-09-30覃九三持股102,779,885股，13.63%；周达文7.54%。

覃九三与邓永红为夫妻；前十名股东表中列示相关股份质押、标记或冻结数量为0。

历次资本运作围绕电子材料延伸；2020定增、2022可转债及当前H股申请均需关注回报。

## B 商业模式质量

### 创立期与当下九要素

| 要素 | 创立期 | 当前 |
|---|---|---|
| 客户 | 电容器制造商 | 电池、电子信息、医药及精细化工客户 |
| 价值主张 | 配方稳定与可靠供货 | 高纯度、配方、品质、全球交付与成本 |
| 渠道 | 直接客户开拓 | 大客户认证后持续供应 |
| 客户关系 | 工程配合及复购 | 批次验收、技术支持、持续采购 |
| 收入 | 材料销售 | 按产品/数量销售，非订阅 |
| 资源 | 化学工艺人才 | 研发、基地、认证、原料及品牌 |
| 活动 | 配方研发制造 | 研发、制造、认证、安环和跨国经营 |
| 伙伴 | 原料供应商 | 原料商、合营企业、产业合作方 |
| 成本 | 原料与工厂 | 原料主导，同时承担固定资产和研发成本 |

判断：早期就是需要工厂、营运资金和长期客户开发的辛苦钱生意。
建设转运营可以提高利用率，却不会自动形成持续高毛利。
规模化和高端产品使结构改善，但当前主收入仍受周期价格影响。
历史模式分类取“重资产制造、依靠工艺与认证建立壁垒”，不宣称已形成垄断。

### 定价权与可持续性

成本领先和一体化比品牌溢价更重要。
H1电池毛利率15.32%较2025全年10.93%修复，依据S2与S3分部表。
集团2026前三季毛利率由收入减成本推算为23.53%，Q3单季没有证明全面提价。
2021—2025利润经历高峰与回落，2023归母利润同比降42.50%（S5 p8）。
因此不能把一轮行业复苏当作永久提价权。
技术迭代、固态电池、PFAS相关法规与海外本地化都是长期变量。
TAM和最新市占率未采用未经验证的数字；增长假设依公司实际业务与再投资约束。

## C 竞争格局与护城河

电解液处于规模、技术和服务竞争，单纯产能并非不可复制壁垒。
历史报告的“第一梯队”保留为定性定位，不虚构最新精确排名或CR5。
高纯材料认证、研发积累与批次稳定性增加替代成本。
海外生产能改善当地响应，同时增加建设成本、法规和汇率风险。

波特五力判断：买方强、同行竞争强、供应商中等、替代技术中等、进入者中等。
