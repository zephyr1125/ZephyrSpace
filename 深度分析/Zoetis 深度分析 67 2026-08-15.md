## 维度 A：历史基因与公司 DNA

### A1. 公司起源与创始基因

Zoetis 起源于 Pfizer 的动物健康业务，拥有 60 余年兽药研发与商业化积淀。2012 年 Pfizer 决定将动物健康业务分拆，2013 年 2 月 Zoetis 以 IPO 独立上市（当时全球最大动物健康公司）。创始基因为**先发优势型 + 技术/监管壁垒型**——兽药研发需多年临床与监管审批，Pfizer 的管线、专利、全球注册体系是天然护城河。

### A2. 历史控制权稳定性

上市至今**无实际控制人变更**，股权高度分散（机构持股约 85%），无控制权争夺、无壳资源操作痕迹。控制权稳定性极强。

### A3. 资本运作历史

- IPO（2013）后无增发/配股，融资克制。
- 并购聚焦主业（伴侣动物管线、诊断、基因组），规模偏小（Jurox、Basepaws、Neogen 基因组 $160M）。
- 无"卖资产保利润"行为。
- ⚠️ 唯一瑕疵：2024-2025 年通过增发债务 $2.5B 加杠杆回购（详见 F2.5），属资本运作的时机性失误。

### A4. 历史基因分类

- [x] **经营型**：专注动物健康主业，靠研发+商业化驱动增长，管理层稳定。

## 维度 B：商业模式质量

### B0. 早期商业模式溯源

| 要素 | 创立初期（Pfizer 动物健康时代） | 当下 |
|---|---|---|
| 客户群体 | 兽医、畜牧生产者 | 兽医诊所 + 宠物主（DTC）+ 畜牧生产者 |
| 价值主张 | 抗感染/疫苗治疗动物疾病 | 伴侣动物差异化疗法 + 预防保健 + 诊断 |
| 收入来源 | 兽药销售 | 处方药 + 疫苗 + 诊断 + 基因组（订阅/耗材混合） |
| 核心资源 | 研发管线、全球注册、品牌 | 同上 + 兽医渠道关系 + 数据平台 |
| 关键活动 | 研发、生产、注册、销售 | 差异化创新 + 商业化 + 诊断生态 |
| 成本结构 | 制造为主 | 高毛利（变动成本主导，规模化后费用摊薄） |

**关键判断**：这是一门"轻资产高毛利 + 监管壁垒"的生意——核心资产是知识产权、品牌和渠道，而非重资产工厂；毛利率长期 70%+，是典型的"天生优质"商业模式。从 Pfizer 时代到当下，商业模式从"泛兽药"进化为"伴侣动物差异化治疗 + 预防保健 + 诊断"的生态化平台，驱动力是宠物人性化（pet humanization）趋势。

- [x] 轻资产高毛利可复制型（天生优质，规模化后 ROE 持续提升）

> 伴侣动物占比 69.6%，存在单一业务集中，但内部可进一步拆分为：皮肤科（Apoquel/Cytopoint）、驱虫（Simparica 系列）、OA 疼痛（Librela/Solensia）、疫苗、诊断——其中皮肤科与驱虫是成熟现金牛，OA 疼痛（Librela）与诊断是成长明星，正遭遇竞争与安全挑战。

### B2. 盈利机制解析

| 盈利模式 | 判断结论 |
|---|---|
| 收费方式 | 按处方药销售（一次性/复购）+ 疫苗预防（年度复购）+ 诊断（耗材订阅式） |
| 复购特征 | 中高复购（疫苗/驱虫为年度预防，皮肤科/OA 为慢性病长期用药） |
| 需求刚性 | 刚性偏强（宠物医疗为必需开支，但可选消费属性在价格敏感期显现） |
| 成本结构 | 变动成本主导，毛利率 72% |
| 规模效应 | 中强（研发费用可摊薄，商业化网络复用） |

**结论一句话**：这是一家「高毛利处方药 + 预防保健」模式的公司，复购率中高、需求偏刚性、有规模效应，但"可选消费"属性在 2026 年价格战中被放大。

### B4. 业务可持续性

- 全球动物健康市场（药品+诊断）TAM 约 $50-60B，Zoetis 收入 $9.47B 居全球第一（狭义药品口径份额 ~17-19%，广义含诊断/服务口径 ~11%）；伴侣动物是结构性增长赛道（宠物人性化、宠物老龄化）。

- 近 3 年营收增长中有机增长占比 ~97%（并购极小，Neogen $160M 占比 <2%），几乎纯内生。

## 最终结论

### 公司质量评级：⭐⭐⭐ 良好（67/100）

**核心竞争优势（数据支撑）：**
1. **全球动物健康绝对龙头**：收入 $9.47B（约为第二名 Merck $5.88B 的 1.6 倍）、伴侣动物药物份额 ~28%，规模与品牌壁垒深厚（来源：2024 行业排名 + FY2025 10-K）。
2. **顶尖财务质量**：毛利率 72%、净利率 28%、ROIC 27.3%、OCF/净利润 ~109%、FCF $2.3B，现金流转化极强（来源：FY2021-FY2025 财报）。
3. **高壁垒差异化商业模式**：兽药 FDA 审批 + 单抗/JAK 专利 + 全球兽医渠道，护城河真实（来源：10-K 业务描述 + 行业分析）。

**核心隐患（数据支撑）：**
1. **竞争侵蚀**：Elanco Zenrelia 成 T4Q blockbuster（Apoquel 首个规模化竞品）、Credelio Quattro 份额加速，Q1 2026 美国伴侣动物 -11%、皮肤科 -11%（来源：Elanco/ Zoetis 2026 财报）。
2. **增长失速 + 指引反复**：2026 年两度下调指引，有机增速从 +2~5% 至 -3~-1%，收入增速从 2021 +16.5% 断崖（来源：2026 财报指引）。
3. **治理/诚信折损**：证券集体诉讼（CEO+CFO 点名）+ Librela 安全争议，管理层"淡化风险"表述被系统性引用（来源：SDNY 1:26-cv-04401）。

**长期重仓适配度判断**：
> 本公司得分 67 分，评级为「⭐⭐⭐ 良好」。
> 核心优势是"全球动物健康龙头 + 顶尖财务质量 + 真实护城河"，最大隐患是"竞争份额侵蚀 + 增长失速 + 证券诉讼悬顶"。
> 建议：**标准持仓（2-5%）观察**，而非核心仓位——公司质量仍在"良好"区间，但当前处于基本面恶化的关键验证期（竞争 + 诉讼 + 安全三重压力叠加），宜等待 2027 年份额企稳或诉讼明朗后再评估是否升级仓位。当前估值（PE 12x，历史 30x+）已充分反映悲观预期，但"错杀"与"价值陷阱"的分野取决于护城河是否永久受损，这一判断需 2027 年数据验证。
