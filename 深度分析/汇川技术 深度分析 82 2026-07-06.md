- 2003年，朱兴明带领约30名技术人员从"华为电气"（华为与艾默生合资公司）离职创业

## 维度 B：商业模式质量（15/20）

### B0. 早期商业模式溯源

**九要素画布 — 创立初期（2003-2010）vs 当下（2026）**：

| 要素 | 创立初期 | 当下 |
|---|---|---|
| 客户群体 | 中高端设备制造商（纺织机械、注塑机、电梯）| 新能源汽车主机厂 + 锂电光伏 + 3C + 机器人整机厂 |
| 价值主张 | 国产变频器替代进口，性能接近但价格低40-50% | 完整运动控制解决方案（变频+伺服+PLC+驱动），一站式国产替代 |
| 渠道通路 | 工程师专家直销（华为模式）| 直销+渠道+全国服务网络 |
| 收入来源 | 变频器硬件销售 | 设备销售 + 服务 + 系统集成 |
| 核心资源 | 矢量变频控制算法 + 工程师团队 | 专利群（运动控制）+ 研发体系 + 品牌 + 渠道 |
| 成本结构 | 研发高比例（~10%营收）+ 制造成本 | 研发8-9%营收 + 制造 + 渠道 + 管理 |

**关键判断**：
- 起步并非辛苦钱——高端变频器毛利率超35%，资本回报周期短
- 早期→当下本质变化：从单一变频器到全栈工业自动化，新增了低毛利新能源汽车板块
- **历史商业模式分类**：✅ 轻资产高毛利可复制型（但已向重资产小幅漂移）

### B1. 当下业务板块全景

| 业务名称 | 营收占比（估算）| 毛利率 | BCG 定位 |
|---|---|---|---|
| 工业自动化（通用自动化+工业机器人）| ~55% | >40% | **明星+现金牛** |
| 新能源汽车（电控/OBC/驱动总成）| ~30% | ~20% | **问题（规模扩张但低利润）**|
| 智慧电梯及楼宇 | ~10% | ~25% | **现金牛** |
| 机器人（工业+人形机器人零部件）| ~5% | 暂不稳定 | **问题→明星（待验证）**|

核心结论：工业自动化板块是利润发动机（~55%营收但贡献>70%利润），新能源汽车是营收规模驱动力但是利润率拖累。

### B2. 盈利机制解析

| 盈利模式 | 判断 |
|---|---|
| 收费方式 | 设备销售（一次性）+ 配件维护，主体为项目型 |
| 复购特征 | 中等（产品生命周期3-8年，大客户连续下单）|
| 需求刚性 | 中等（工业制造必需，但资本开支有周期性）|
| 规模效应 | 中等（研发摊薄+采购规模降本，但新产线投入不断）|

> 这是一家「技术型硬件销售+项目制」模式的公司，中等复购率，工业刚性需求，有但非强规模效应。

### B3. 定价权深度评估

**历史毛利率验证**：

| 时间节点 | 毛利率 | 趋势 |
|---|---|---|
| ~2020年 | ~39% | 历史高点 |
| FY2023 | 33.55% | 持续下滑 |
| FY2024 | 28.70% | 持续下滑 |
| FY2025 | 28.95% | 小幅回升 |
| Q1 2026 | 29.08% | 低位企稳 |

**核心警示**：5年毛利率下滑约10pct。但**需要区分驱动因素**：
1. 新能源汽车（~20%毛利率）占比从0增至~30% → 结构性稀释（非定价权丧失）
2. 通用自动化板块自身毛利率仍维持>40% → 核心业务定价权未实质恶化
3. 2026年6月通用自动化订单+40%，汇川利用定价权将成本转嫁下游 → 定价权正在发挥作用

**综合评级**：⭐⭐ 中等（核心业务定价权存在，整体被新能源汽车结构稀释）

### B4. 业务可持续性

- TAM（工业自动化）：中国低压变频器+伺服+PLC合计约1500-2000亿元，行业成长期
- 增长驱动力：制造业数字化（工业自动化）+ 人形机器人新赛道 + 海外扩张 + H股上市后国际化提速
- 内生增长占比：>95%（历史并购极少）

## 最终结论

### 公司质量评级：⭐⭐⭐⭐ 优质（82/100）

**核心竞争优势（数据支撑）：**

1. **不可复制的工业自动化核心护城河**：通用伺服国内市占率~32%（全国第一），低压变频器约17%（全国第一），PLC国内前三。竞争地位建立在20年技术积累（研发8-9%营收，高于行业2倍）+ 华为基因销售体系之上。（来源：FY2025年报、智堡引用高盛/摩根士丹利研报）

2. **罕见的"又大又快又稳"内生增长能力**：2019-2025年营收CAGR 35.2%、净利CAGR 30.8%，现金流质量优秀（FY2024/2025 OCF/净利分别169%/132%），商誉近零。2026年6月通用自动化订单+40%，核心引擎仍在加速。（来源：CNINFO、智堡研报，实际值）

3. **创始人稳定掌舵 + 激励深度绑定**：朱兴明23年执掌，从未有控制权危机；855人股权激励+长效超额利润分成；治理合规零瑕疵。管理层档案评分85/100（卓越）。（来源：管理层档案，理杏仁）

**核心隐患（数据支撑）：**

1. **净利率结构性压缩，2026年成本端新增压力**：整体毛利率从~39%（2020）→29%（2025），Q1 2026净利-23.4%。2026年新增铜、芯片涨价压力——管理层通过提价5-20%应对，Q2起效果待验证。若全年毛利率无法守住28%+，EPS可能跌破2.0元。

2. **H股上市137亿融资的摊薄风险**：2026-04-28递交港交所申请。若H股以折价发行（港股通常较A股折价10-20%），对A股股东存在5-10%的净资产摊薄。

3. **人形机器人是"高期待、低收益"的早期阶段**：公司已突破行星滚柱丝杠、关节模组等关键零部件，但商业规模收入预计2027年起。当前股价PE 41x（TTM）已在一定程度上priced in机器人溢价。

**长期重仓适配度判断**：

> 本公司得分 **82分**，评级为「⭐⭐⭐⭐ 优质」。
>
> 核心优势是"中国工业自动化绝对龙头 + 23年创始人稳定掌舵 + 高速内生增长 + 优异现金流"，最大隐患是"净利率结构性压缩 + 2026年成本端压力 + H股融资摊薄风险"。
>

>
> 汇川技术是少数同时具备技术护城河、高速内生增长和优质治理的A股工业龙头。在合理估值区间（2026E PE约28-32x，对应约62-71元），可作为核心组合的5-10%仓位长期持有。当前PE TTM 41x偏高但2026E PE 32x尚在合理上限附近。
