## 维度 A：历史基因与公司 DNA（8/10）

### A1. 公司起源与创始基因

沪电股份的前身是**台湾沪士集团**（WUS Group）在中国大陆设立的合资制造企业。WUS集团是台湾PCB行业的重要制造商，1971年成立于台湾，专注于企业通讯级PCB制造，在通讯PCB（路由器、交换机）领域积累了20年以上的技术沉淀。

1988年，WUS集团进入中国大陆，在昆山设立生产基地（沪士电子昆山），后逐步扩展。A股上市实体（深圳市沪电股份有限公司）于2010年在深交所IPO，是WUS集团大陆业务的主要资本化平台，主要涵盖黄石、惠州等工厂。

**创始基因分类：技术驱动型 + 先发优势型**

| 维度 | 判断 |
|---|---|
| 创始人背景 | 台资专业PCB制造商WUS集团，有工业级技术积累 |
| 市场切入点 | 企业通讯PCB（路由器/交换机），先发于国内同行 |
| 技术来源 | 台湾/日本PCB工艺引进+持续R&D |
| 初始行业地位 | 早期跟随全球头部（Ibiden/TTM），但在大陆属于先发领先者 |

**结论**：该公司成立于1988年（大陆生产基地），由台湾专业PCB制造商WUS集团创立，初始定位为企业通讯PCB，属于**技术驱动+先发优势**型起源基因。

**A1 得分：3/3**

## 维度 B：商业模式质量（15/20）

### B0. 早期商业模式溯源

**商业模式画布（创立期 vs 当下）**：

| 要素 | 创立初期（1988-2010） | 当下（2024-） |
|---|---|---|
| 客户群体 | 中小型通讯设备厂商（国内OEM） | 华为、海外云厂商（经Celestica/Foxconn EMS间接供货）、汽车OEM |
| 价值主张 | 稳定交付中高层数通讯PCB | 高速/高频PCB解决方案，支持AI算力；汽车域控制器级PCB |
| 渠道通路 | 直销+代理商 | 直销为主（大客户直接谈判），部分通过EMS |
| 客户关系 | 产品认证后重复采购，年度框架订单 | 产品认证+年度框架+追加单，切换成本极高 |
| 收入来源 | 按件/批次计费，交付即结算 | 同左，但ASP（平均售价）随层数/复杂度提升 |
| 核心资源 | PCB制造工艺（台湾引进），熟练操作工人 | 高端PCB制程能力（32+层，LDI，阻抗控制），认证资质，产能 |
| 关键活动 | 制程管控，准时交货 | 同左 + 高速PCB研发，客户认证管理，产能扩建 |
| 重要合作伙伴 | 铜箔、CCL（覆铜板）供应商 | 同左 + 高端设备供应商（日本KLA、荷兰ASML等） |
| 成本结构 | 固定成本主导（设备折旧60%+），原材料约25% | 同左，规模化后固定成本占比略降 |

**关键判断（已明确回答）**：

1. **是否为"辛苦钱生意"**：是。PCB制造是重资产生意（设备折旧高、环保要求严、认证周期长、良率管控复杂）。初期投入大、回报周期3-5年。
2. **建设期→运营期切换，毛利率质变节点**：约2020-2022年黄石工厂产能爬坡完成后，毛利率从2021年的27.2%稳步提升。2024年AI PCB需求爆发后，产品结构进一步上移（高价AI服务器PCB占比提升），毛利率快速提升至34-35%。毛利率"质变"节点在2022-2024年产品结构向AI PCB迁移。
3. **早期与当下是否有本质性变化**：核心制造能力一脉相承，但价值定位发生根本迁移：从"通用通讯PCB供应商"（低差异化）→ "全球少数能量产AI服务器高层PCB的制造商"（高差异化）。变化驱动力是AI算力基础设施投资浪潮 + 公司自身技术积累。

**历史商业模式分类：重资产低毛利但构建垄断壁垒型** → 正在向**构建垄断壁垒后迎来高盈利期**的阶段演进。

### B2. 盈利机制解析

| 盈利模式 | 判断 |
|---|---|
| 收费方式 | 按件/批次计费（B2B制造交付） |
| 复购特征 | **半高频复购**：产品认证后，客户在该产品代次内持续采购；每代新产品需重新认证（6-18个月），认证完成后粘性极高 |

**结论**：这是一家「重资产B2B制造」模式的公司，复购率中高（认证周期内高粘性），AI基础设施需求当前刚性，有一定规模效应（特别是在高层数PCB的良率和成本方面）。

### 公司质量评级：⭐⭐⭐⭐ 优质（79/100）

**核心竞争优势（数据支撑）**：

1. **AI PCB认证壁垒构建的深度护城河**：公司已完成主要海外云厂商AI服务器PCB认证（2023年），批量供货32层以上高速PCB。认证周期12-18个月意味着竞争对手无法快速复制，而单产品代次的认证具有强粘性。2024年通讯市场板收入同比+71.94%，直接体现壁垒价值。（来源：2024年报分部收入；Tavily研报）

2. **净利率驱动的高质量ROE提升**：ROE从2021年的15.85%提升至2025年的28.57%，提升来源100%是净利率从14.3%→20.2%的改善，权益乘数（1.61→1.79）仅温和上升。这是最健康的ROE提升路径。OCF/净利五年平均119%，现金流质量优异，财务数据可信度高。（来源：理杏仁fs API + 东方财富MGJYXJJE）

3. **战略清晰度与执行力的历史验证**：5年年报战略从未漂移，连续超额达成年报承诺目标，AI PCB转型比主要竞争对手领先1-2年。营收CAGR 20.5%、净利润CAGR 23.3%（2020-2025），且几乎全部为有机增长，无并购注水。（来源：理杏仁 + 东方财富财务数据）

**核心隐患（数据支撑）**：

1. **AI CapEx投资周期性风险**：公司75%营收集中于企业通讯市场板（含AI服务器PCB），该业务高度依赖全球云厂商资本开支。历史上AI CapEx有明显周期性（如2020-2021年短暂放缓），若2026-2027年出现超预期收缩，公司收入和利润弹性将双向放大。当前PE TTM约46x，定价已充分反映乐观预期。（来源：Eastmoney数据；行业历史）

2. **台湾母公司渐进减持叠加H股摊薄**：WUS GROUP HOLDINGS持股从上市时~17%降至当前11.27%，方向持续向下。同时公司已申请H股上市（2025年11月提交HKEX，尚未定价），完成后A股将面临摊薄。两者叠加可能对A股估值形成压制，且动机尚不完全透明。（来源：理杏仁major-shareholders-shares-change；HKEX文件sehk25112802784）
