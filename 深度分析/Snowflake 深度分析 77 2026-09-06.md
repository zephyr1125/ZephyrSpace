## 维度 A：历史基因与公司 DNA（9/10）

### A1. 公司起源与创始基因（3/3）

Snowflake 于 **2012-07-23** 在加州 San Mateo 创立，三位创始人均为数据库领域老兵：
- **Benoit Dageville / Thierry Cruanes**：前 Oracle 数据库架构师（Oracle RAC/并行查询背景）
- **Marcin Zukowski**：前 CWI 研究员、Vectorwise 联合创始人（博士研究即向量化执行，构成 Snowflake 核心执行引擎基础）

**起源基因**：技术驱动型 + 先发优势型。团队预判「云上数仓机会被低估」，从第一天即为云原生设计（multi-cluster shared-data，存储/计算分离），2014 年走出 stealth，2015-06 首个产品上线，随后多云扩张（AWS 2014 / Azure 2018 / GCP 2019）。这是「看懂被巨头忽略的技术拐点 + 数据库顶尖团队」的典型技术型创业，非资源/政策/渠道驱动。

### A2. 历史控制权稳定性（3/3）

- 无实控人、无控制权争夺、无壳资源痕迹。
- IPO 曾设 Class B（10 票/股），但 **2021-03-01 全部自动转换并注销** → 单一普通股、每股 1 票至今。
- 创始人存续：Dageville 2025-10 转 Chief Architect、2026-06 起退日常运营、留任董事；Cruanes 仍为联合创始人/CTO；Zukowski 2024-02 离开（转投资人）。

### A3. 资本运作历史（3/4）

| 事项 | 时间 | 性质 | 评价 |

| IPO（纽交所）| 2020-09-16 | 史上最大软件 IPO，募资 ~$3.4B @$120，首日 +111% | 定价融资合理；Berkshire/Salesforce 各 $250M 基石 |

## 维度 B：商业模式质量（16/20）

### B0. 早期商业模式溯源（2/2）

创立期 vs 当下的画布对照核心判断：

| 要素 | 创立初期（2012–2019）| 当下（FY2026-27）|
|---|---|---|
| 客户群体 | 云先行的大中型数据团队 | 企业级为主：829 家 Forbes G2000、828 家 $1M+ 客户、~1.45 万总客户 |
| 价值主张 | 免运维、弹性、云原生的数据仓库 | 跨云数据 + AI/agentic 一体化「AI Data Cloud」|
| 收入来源 | 按用量计费（compute credits + 存储）| 同左 + AI credits（agentic 按 token 型计费）|
| 成本结构 | 重研发、轻资产（租云算力）| R&D 为主 + 多云采购算力；产品毛利稳态 74–76% |

**三个关键判断**：
- 辛苦钱生意？**否**——轻资产、高毛利（产品 non-GAAP GM 76%）SaaS。
- 毛利率质变节点：产品收入过 $1B（FY2022）后 GM 稳定于 74–78%，未再大幅扩张 → 产品定价/成本结构已稳态。
- 早期 vs 当下本质变化：从「数据仓库」扩为「数据 + AI 平台」，本质仍是数据基础设施，驱动力 = AI 工作负载。

**历史商业模式分类**：✅ 平台/网络效应型（数据分享 Marketplace + data gravity，规模化后毛利高企）。

### B1. 当下业务板块全景（3/4）

| 业务 | 收入占比 | 毛利率(non-GAAP) | 增速 | BCG |
|---|---|---|---|---|
| 产品收入（数据仓库/湖/Cortex AI/AI agents 消费）| ~95.5%（FY26 $4,472M）| 76%（FY27 指引降至 ~74%）| +29%(FY26)→+37%(Q2 FY27) | 明星（加速中）|
| 专业服务 | ~4.5% | -31%（FY26，非 GAAP）| — | 瘦狗/催化项 |

- 业务高度单一（产品 >95%）：核心就是「客户在 Snowflake 上消费 compute/存储/AI credits」。这是清晰逻辑的集中，非风险分散型。
- 内部的成长引擎：传统 warehouse 消费（存量扩张）→ + 数据湖/开放表 + **AI/agentic（CoCo 编码 agent 9,100+ 账户、CoWork 5,800 账户）**。管理层口径 Q2 FY27 加速的一半来自 AI 产品。

### B2. 盈利机制解析（3/3）

- 收费方式：**按用量（consumption）** + 容量合约（capacity，RPO 主要来源），AI/agentic 自 2026-04-01 起按 token 型 AI credits 计费（无订阅制）。
- 复购特征：极高——NRR 126%（每 100 美元存量客户次年消费 126 美元）；**自 FY2024 高位 131% 连降至 FY2026 125% 后，Q1 FY27 首次回升至 126%（仍低于 FY24 峰值）**。
- 需求刚性：中偏强——数据基础设施是刚需，但消费额有弹性（客户 FinOps 优化会压缩用量）。
- 成本结构：变动成本为主（云算力转嫁 + 自研引擎摊销），毛利随规模略扩。
- 规模效应：中（非传统强规模效应；毛利已稳态 76%）。
> 结论：这是一家「高复购、刚需偏强、按用量付费的平台」公司，收入随客户实际消费波动——**增长真实但有使用量弹性**。

### B3. 定价权深度评估（4/6）

**来源判断**：

| 来源 | 是否具备 | 佐证 |
|---|---|---|
| 品牌溢价 | ⭐⭐ | 品类定义者，但对大客户谈判是采购专业流程 |
| 客户转移成本 | ⭐⭐⭐ | 数据重力 + 数万 BI/ETL 工具集成 + 治理/catalog，迁移昂贵 |
| 网络效应 | ⭐⭐ | Data Sharing/Marketplace：组织间共享创造弱网络效应 |
| 监管/资质壁垒 | ⭐ | 企业合规认证（SOC2 等）非排他 |
| 成本领先 | ⭐ | 计算无成本优势（对手打价格战）|
| 垂直整合 | ⭐ | 底层依赖 AWS/Azure/GCP |
| **综合评级** | **⭐⭐⭐ 中偏强** | 锁定向"数据 + catalog/治理"，计算/存储层被商品化 |

**历史数据验证**：
- 产品 non-GAAP GM：FY23 75% → FY24 78% → FY25 76% → FY26 76% → **FY27 指引 ~74%（AI 负载拉低）**。毛利率小幅下行而非提价——定价权在「维持高价 + 靠量扩张」，而非主动提价。
- **隐性价格让利**：公司披露产品效率提升带来 ~6.2–6.3%/年「计费逆风」（同样的工作负载耗更少 credits）= 实际对客户的单位降价，但靠用量增长对冲。
- **红旗**：🔴 存储层被 Iceberg/open format 商品化；🟡 对手 Databricks/云厂商打 AI 推理价格战。

> 桥接说明：产品毛利率为非 GAAP 经营口径（不扣 SBC）；SBC 属费用端、计入 E1 的 GAAP 损益扣分，不属毛利端，两者不构成双重叙事。

### B4. 业务可持续性评估（4/5）

- TAM：公司自述口径 $90B（2021）→ $290B by 2027（2022 ID，含四块）；第三方「数据湖仓」市场 2024 $11.9B → 2034E $105.9B（~25% CAGR）。
- 生命周期：**成长期**（渗透率仍低，企业数据 + AI 化双驱动）。
- 未来增长驱动：AI 工作负载（CoCo/CoWork/AI 函数）→ 更多数据上平台 + 存量用例扩张 + 遗留迁移提速（AI 把迁移周期从 3 年压到 1–2 季度）。
- 内生 vs 外延：内生主导（并购贡献 FY27 增速仅 ~1pt）。
- 可持续性风险点：AI 变现基数仍小（第三方估 ~$100M run-rate，<2% 收入），若 agentic 收入不及预期则回到 30% 以下增长平台。

## 维度 C：竞争格局与护城河（15/20）

### C1. 市场地位（5/6）

- 细分市场：云数据平台/湖仓双雄格局——**Snowflake ~20% vs Databricks ~15%**（Sparity 口径，2025）；前五（含 Microsoft/AWS/Google）合计 47%+。
- 本公司在「企业级 SQL 数据仓库 + 多云数据基础设施」是第一梯队龙头；在「AI 基础设施 / AI 变现」落后 Databricks（DB AI run-rate >$1B vs SNOW ~$100M 第三方估）。
- 市占趋势：数仓侧稳定，AI 侧追赶中。

### C2. 产业链话语权（3/5）

| 判断维度 | 结论 |
|---|---|
| 成本传导 | 上游云算力成本可部分转嫁（按 credits 计费价签）；与 AWS 签 5 年 $6B 协议锁定算力/带宽成本 |
| 需求传导 | 下游消费即时传导（按用量），无库存缓冲 |
| 产业链景气 | AI 上行期，但竞争使毛利边际承压 |
| 综合议价 | 下游=企业数据团队：数据重力赋予较强留存议价；上游=同为大云厂商（AWS/Azure/GCP），既是供应商又是竞对。**净效应："半吃肉半喝汤"** |

**集中度**：G2000 客户贡献收入 ~41–43%（Q4 FY26 官方 43%、H1 FY27 ~41%）；消费型 SaaS 客户通常分散，前五大客户占比未见 >30% 单一客户信号。

### C3. 横向竞争格局（并入 C4 计分）

竞争强度高：Snowflake vs Databricks（lakehouse）为「两线战争」；AWS Redshift/S3 Tables、BigQuery、Azure Synapse/Fabric 在各自云内锁定；DuckDB/MotherDuck 边缘扰动。数仓侧无全面价格战（Snowflake 靠效率让利而非砍价）。

### C4. 进入壁垒评估（C3+C4 = 7/9 → 综合 4 星）

| 壁垒类型 | 强度 | 佐证 |
|---|---|---|
| 技术壁垒 | 🟡 中 | 云原生 shared-data 引擎难以复制，但 Databricks/云巨头已具同等能力 |
| 生态/切换成本 | 🔴 强 | 数据在平台 + 数万 BI/ETL 深度集成 + Horizon/Polaris catalog 治理，迁移成本高 |
| 网络效应 | 🟡 中 | Data Marketplace 组织间共享，弱-中网络效应 |
| 品牌/信任 | 🟡 中 | 企业级信任（G2000 829 家），但非排他 |
| **综合** | **⭐⭐⭐⭐（4 星）** | 护城河真实但**正在软性化**（见下）|

**护城河侵蚀论（必须正视的反方）**：
- **Iceberg 已在开放表格式之争胜出**：存储锁定向大幅下降（数据可迁出 Snowflake 存储）；行业共识"compute 护城河消失、锁定向 catalog/semantic layer 上移"。
- Snowflake 的反制：拥抱 Iceberg（引擎直读 Iceberg 表）+ 开源 Polaris/治理层，赌「性能 + 治理 + 生态」留客。
- **历史已量化该逆风**：FY2025 期初披露效率提升 + 存储分层 + Iceberg 外迁合计构成 ~6.2–6.3%/年产品收入逆风。
- **Net 判断**：护城河未倒（数据重力 + 控制面上移 + 品类心智），但**从"结构性锁定"降为"软性锁定"**，需靠持续产品领先维持；这是不给 5 星的核心理由。

## 维度 D：战略清晰度与执行力（13/15）

### D1. 战略一致性分析（4/4）

- **Ramaswamy 任内（2024-02 起）战略高度一致**：从「Data Cloud」转向「AI Data Cloud」，主打 agentic AI（CoCo/CoWork/Cortex Agents）+ 模型中立 + 跨云，2.5 年无主题漂移。

### D2. 战略执行验证——长期兑现率（4/5）

**长期目标 vs 实际**：

| 目标 | 设定 | 结果 |
|---|---|---|
| FY2029 产品收入 $10B | 2021-06 / 2023-06 重申"非常有信心" | **2024-02 撤回**（本维度唯一单次扣分项）。按 FY2026 实际 $4.47B 到 $10B 需 ~31%/年 × 3 年，即便按 FY27E $6.07B 也需 ~28%/年——目标过度乐观，撤稿是纠错但公信力成本高 |
| FY2027 产品收入 $6.07B(+36%) | 2026-02 $5.66B → 05 $5.84B → 09 $6.07B | ⏳ 已两度上调，待验证（此前两度均兑现）|
| 长期利润率模型（2022 ID）| FY29 op margin 20% / S&M 35% / R&D 15% | 路径：op margin FY25 6% → FY26 10% → FY27 指引 14.5%，方向一致 |

**季度指引兑现率（近 8 季，产品收入）**：

| 季度 | 实际 | YoY | 指引→结果 |

## 最终结论

### 公司质量评级：⭐⭐⭐⭐ 优质（77/100）

**核心竞争优势（数据支撑）：**
1. **多云中立 + 数据重力的护城河（已软性化但仍真实）**：829 家 Forbes G2000（~41-43% 收入）、828 家 $1M+ 客户，同一 SQL 工作负载可在 AWS/Azure/GCP 运行——云巨头各自数据平台无法复制（来源：Q2 FY27 PR）。
2. **企业级 SQL 生态 + 数据分享网络效应**：数万 BI/ETL 工具深度集成，Data Marketplace 创造组织间共享；NRR 126%（五季首升）、RPO $9.0B（+30%）验证留存与前瞻（来源：Q2 FY27 PR）。
3. **AI 驱动的增长再加速**：产品收入 +29%(FY26)→+37%(Q2 FY27) 连续三季加速，管理层口径一半来自 AI 产品（CoCo 9,100+/CoWork 5,800 账户）；non-GAAP op margin 6%→10%→14.5% 指引（来源：Q2 FY27 财报电话会）。

**核心隐患（数据支撑）：**
1. **GAAP 持续亏损 + SBC 高企**：FY2026 GAAP 净亏 $1.33B，SBC $1.6B=营收 34%；FCF 为正但短周期计费化将压缩 FCF $377–741M（来源：FY2026 10-K）。
2. **护城河系统性软性化**：Iceberg/open format 胜出使存储锁定消失（~6.2%/年计费逆风已量化）；Databricks AI 变现领先 ~10 倍（来源：2024-02 财报 + 行业数据）。
3. **治理/摊薄折价**：Say-on-Pay 连续两年未过、前 CEO 巨额减持、证券集体诉讼在审；股本以 ~3.4%/年净稀释（来源：2025/2026 DEF 14A、Form 4）。

**长期重仓适配度判断**：
> 本公司得分 **77**，评级「⭐⭐⭐⭐ 优质」。
> 核心优势是"多云数据 + AI 数据层的一线平台，正在用 AI/agentic 重拾 37% 增长"，最大隐患是"GAAP 盈利质量（SBC 34%）+ 数据平台层商品化趋势"。
> 建议：**优质成长平台但非核心重仓级**（缺 GAAP 盈利证明 + 治理折价 + E/F 维度拉低）。
> ⚠️ **档位结论（强制明示）**：深分 77 + 管档 70 = **147 < B_GROWTH 入池门槛 150** → **不写入 watchlist_growth/core，仅作跟踪观察标的**。现价同时处于估值追高区（合理价中枢 ~$235），基本面与价格双重不支持当前建仓。
