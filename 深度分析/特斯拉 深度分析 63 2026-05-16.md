## 维度 A：历史基因与公司 DNA（8/10）

### A1. 公司起源与创始基因

**成立背景**（实际值，已发布）：
- 特斯拉汽车公司由 Martin Eberhard 和 Marc Tarpenning 于 **2003年7月** 创立，定位为高性能纯电动汽车制造商
- Elon Musk 于 **2004年2月** 参与A轮融资（$6.35M），成为最大个人股东和董事会主席
- 2008年金融危机期间，公司濒临破产，Musk 注入个人资金并接任 **CEO**（2008年10月），完全主导公司方向
- **基因类型**：先发优势型 + 技术驱动型 + 愿景领导型

**关键判断**：Tesla并非Musk创立，但他在危机时刻介入并彻底重塑了公司。这种"创始人接管型"基因具有双重性——带来极强执行魄力，也埋下个人风险过度集中的隐患。

## 维度 B：商业模式质量（13/20）

### B0. 早期商业模式溯源（2003-2012年）

**九要素商业模式画布（创立期 vs 当下对照）**：

| 要素 | 创立初期（2003-2012）| 当下（2025-2026）|
|---|---|---|
| 客户群体 | 高净值早期技术采纳者（Roadster买家，$10万+）| 主流消费者（Model 3/Y，$3万-6万） + 企业储能 + 政府/电网 |
| 价值主张 | 证明电动车可以性能卓越，打破"高尔夫球车"偏见 | 软件定义汽车 + 降低拥有成本 + 清洁能源生态系统 |
| 渠道通路 | 少量实体店 + 网络直销 | 直营门店 + 线上直售（无传统经销商）|
| 客户关系 | 个性化高接触（定制化Roadster）| OTA自动更新 + 超充网络黏性 + FSD订阅 |
| 收入来源 | 汽车一次性销售（低毛利） | 汽车销售 + FSD收费 + 监管积分 + Megapack + 服务 |
| 核心资源 | Musk个人信用背书 + 莲花Elise平台授权 + 少量工程师 | 专有电池/芯片技术 + FSD AI算力 + 超充网络 + 全球4工厂 |
| 关键活动 | 小批量手工生产 + 技术验证 | 大规模自动化制造 + 软件迭代 + AI训练 |
| 重要合作伙伴 | 莲花汽车（底盘）、松下（电池）| 松下/CATL/LG（电池）；台积电（AI芯片）；自研比例持续提高 |
| 成本结构 | 变动成本主导，高度依赖供应商 | 混合型：大量固定成本（工厂）+ 递减变动成本（电池） |

**关键判断**：
- **是否为"辛苦钱生意"**：是。创立期是典型重资产+超长回报周期+早期亏损。Tesla从2003年到2020年几乎持续亏损（17年）才实现全年GAAP盈利。
- **成本结构质变节点**：2019-2020年，上海工厂投产后规模经济显现，毛利率从~20%提升至25%+，是从"辛苦建设期"切换到"收获期"的关键转折。
- **早期vs当下本质变化**：从"制造电动跑车证明可行性"演变为"平台化软件定义汽车公司+能源公司"，变化深度极大，驱动力是FSD/OTA软件层的逐步形成。

**历史商业模式分类**：**重资产低毛利但构建垄断壁垒型** ✓（典型早期辛苦重资产，用产能和数据构建护城河）

### B1. 当下业务板块全景

**重要提示**：

**单一业务过度集中风险**：汽车占73%，但趋势是下降中，结构向好。

### B2. 盈利机制解析

| 盈利模式 | 判断结论 |
|---|---|
| 收费方式 | 汽车：按件销售；FSD：一次性$8,000或$99-199/月订阅；Megapack：按项目；Supercharger：按电量/时间 |
| 复购特征 | 汽车：低频（3-7年换车周期）；FSD订阅：年度续费；能源：项目续签 |
| 需求刚性 | 交通是刚性需求，但电动车是可选（可买燃油车替代） |
| 成本结构 | 固定成本主导（4座超级工厂+研发+全球服务网络） |
| 规模效应 | 强（电池采购/制造规模越大，单位成本越低；FSD AI训练数据累积具有明显规模效应） |

**结论**：这是一家「重资产直销+软件服务化升级」模式的公司，汽车复购率低，FSD订阅化黏性在增长，有中等规模效应，但尚未进入"订阅收入主导"阶段。

## 维度 C：竞争格局与护城河（13/20）

### C1. 市场地位

**竞争地位**：全球BEV**营收第一**（$94.8B），但**销量已被BYD超越**（若含PHEV BYD更高）。美国市场仍绝对领导，中国市场持续失守。

### C2. 产业链话语权（纵向）

**上游议价能力**：
- 锂电池：松下（合作10+年，内华达超级工厂）、CATL、LG能源；同时自研4680电池降低依赖
- 半导体芯片：对台积电依赖（FSD芯片代工），但特斯拉自研HW3/HW4/Dojo，垂直整合显著
- 稀土/锂资源：无直接资源持有，与大宗商品价格波动相关
- 评级：**中等偏强**——自研电池+芯片减少了对单一供应商依赖

**下游议价能力**：
- 直销模式，无传统经销商，**完全控制终端定价和客户数据**
- 客户为分散个体消费者（非寡头采购），下游集中度极低
- 评级：**强**——直销模式是Tesla最独特的竞争优势之一

**产业链四维系统性判断**：

| 判断维度 | 结论 | 佐证依据 |
|---|---|---|
| 成本传导能力 | 弱——历史上主动降价而非被动转嫁成本，说明终端定价权比供应链成本更脆弱 | 2022-2024连续多轮降价，毛利率下滑 |
| 需求传导敏感性 | 即时——消费者订单直接可见，无经销商库存缓冲 | 直销+在线下单，供需调节更快但也更暴露 |
| 产业链景气周期 | 电动车渗透率仍在提升，但增速放缓，2023-2025处于竞争强化期 | 全行业毛利率普降 |
| 综合议价能力评估 | 下游（消费者侧）议价能力强；上游供应链自研比例提升，减少被卡脖风险 | 直销模式+自研电池/芯片 |

**产业链定性结论**："**喝汤**"（参与者，非主导者）——Tesla在BEV链中地位强但非不可或缺，没有对整个产业链定价权的控制力。

- **正面结论**：Tesla经营层面持续创造真实现金，业务没有"假盈利"风险
- **FCF口径说明**：Tesla官方FCF = OCF - CapEx paid = $14,747M - $8,527M = $6,220M（官方口径，已在财报中披露）

**SBC调整后FCF**：
- 真实可归属股东的FCF = FCF - SBC = $6,220M - $2,825M = **$3,395M**（SBC代表对现有股东的实质性稀释）
- 调整后FCF Margin = $3,395M / $94,827M = **3.6%**（显著低于名义FCF Margin 6.6%）

🔴 **重大警告（SBC）**：FY2025 SBC/GAAP净利润 = **74.5%**。这意味着：
  - 对股东而言，每创造$1 GAAP盈利，就有$0.75通过SBC流向管理层和员工
  - SBC是真实经济成本（通过股权稀释），不因"非现金"而可忽视
  - FY2025若按"GAAP净利润 - SBC"估算实质盈利：$3,794M - $2,825M = **$969M**（约10亿美元）

**融资全面核查**（坑14检查）：
- FY2025股票发行：$1,186M（实际值，主要来自SBC行权）
- 近5年无大规模增发/配股/可转债记录（Tesla财务状况良好，不需外部融资）
- 持续SBC稀释是主要摊薄来源，非债务工具

## 最终结论

### 公司质量评级：⭐⭐⭐ 良好（63/100）

**核心竞争优势（数据支撑）：**

1. **FSD真实驾驶数据壁垒 + 直销模式**：600万+辆在网车辆持续回传驾驶数据（推断，非官方披露），Waymo约2000万英里，差距约300倍。直销模式每辆车节省约10%经销商利润，是全行业唯一大规模纯直销汽车企业，终端定价权和客户数据控制力无可比拟。（来源：Tesla 10-K，行业分析推断）

2. **净现金$35.7B + OCF质量极高（389%净利润比）**：净现金头寸$35.683B（实际值，FY2025），几乎没有财务压力，可支撑多年高CapEx投入和高风险项目；OCF/$14.75B远超GAAP净利润$3.79B，说明业务现金创造能力真实可靠。（来源：Tesla FY2025 10-K）

3. **能源业务高增长 + 垂直整合护城河**：能源分部FY2025 $12.77B，同比+27%（实际值），毛利率高于汽车分部，且全球电网储能需求正进入加速期；特斯拉自研电池/芯片/软件/充电网络的垂直整合程度是全行业最高，长期成本优势将持续。（来源：Tesla FY2025 10-K）

**核心隐患（数据支撑）：**

1. **FSD/Robotaxi承诺持续落空，科技溢价面临估值归零风险**：FSD"完全自动驾驶"承诺始于2016年，至2026年仍为Level 2+监督驾驶；Robotaxi多次承诺商业化均延误。当前TTM GAAP PE ~387x，EV/EBITDA ~147x，估值完全基于期权价值兑现预期。一旦市场确认FSD时间线继续推迟，估值可能重置至传统汽车企业倍数（5-10x EV/EBITDA），意味着股价巨大下行风险。（来源：任务提供估值数据；SEC EDGAR执行历史）

2. **马斯克个人代理问题 + 治理结构性缺陷**：马斯克同时掌控Tesla/SpaceX/X/xAI/Neuralink，精力无法专注；$56B薪酬方案被特拉华法院认定程序违规（2024年裁决）；xAI Grok集成到特斯拉系统的关联交易条款透明度不足；马斯克DOGE政治争议已导致欧洲销量受损。这些不是"短暂事件"，而是结构性治理缺陷。（来源：Delaware Court Order 2024；Tesla 10-K相关披露）

3. **盈利能力结构性恶化：ROIC < WACC，SBC侵蚀净利润74%**：FY2025 ROIC约7%（推算），可能低于资本成本（估计WACC约9-10%），意味着特斯拉正在以低于资本成本的回报率投入资金；SBC $2.825B / GAAP净利润 $3.794B = 74.5%，若从FCF $6.22B扣除SBC，真实可归股东FCF仅约$3.4B，P/FCF调整后约470x。（来源：Tesla FY2025 10-K，WACC为推算值）

**长期重仓适配度判断**：
