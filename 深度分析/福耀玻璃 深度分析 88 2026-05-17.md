## A 历史基因与创始人背景（10/10）

### A1 技术/先发型起源（3/3）

曹德旺1987年以340万元承包福清市异形玻璃厂，当时中国汽车玻璃市场几乎被进口产品垄断（外资占比>80%）。他选择切入当时技术门槛极高、国内几乎空白的汽车安全玻璃赛道：

- **时代背景**：1987年中国没有能自主生产合格汽车挡风玻璃的工厂，主要靠进口或日本技术授权。
- **先发动作**：主动引进美国PPG公司技术授权，但随即推进自主研发，在取得PPG授权后5年内脱离技术依赖。
- **结果验证**：1993年A股上市时已是国内最大汽车玻璃企业，上市即有实质性护城河，不是"讲故事"上市。

**分类：经营型起源（不依赖政策租金，主要靠技术+执行力建立壁垒）**

### A2 控制权稳定性（3/3）

| 时间段 | 控制权状态 |
|---|---|
| 1987-2015 | 曹德旺家族全程控制，无强制性稀释 |
| 1995-2007 | 圣戈班持股约~20%（战略合作），属市场化引入，非被动稀释 |
| 2007-2015 | 福耀主动回购圣戈班股份，强化控制权，显示主动资本意识 |
| 2015至今 | A+H两地上市，Cao家族合计持股仍约74%，实控地位稳固 |
| 2025 | 曹德旺主动退休为"终身荣誉主席"，儿子曹晖接任，传承经规划、非意外 |

传承逻辑：曹晖自年轻时即参与管理，并非仅凭关系接班，过渡期平稳。曹德旺仍以荣誉主席身份出席2026年4月股东会，连续性有保证。

## B 商业模式质量（16/20）

### B0 商业起点可追溯（2/2）

- **1987年起点**：汽车玻璃工厂技术承包，切入汽车配件制造
- **早期商业逻辑**：以低于进口价50%的价格攻占中国OEM市场，牺牲短期利润换取规模（价格战+规模化降本），再用规模压低成本形成正向循环
- **从规模到品牌**：2000年代开始供货丰田、大众等全球OEM，逐步从价格竞争升级为品质竞争，再到技术竞争

### B1 业务健康度（3/4）

**业务构成（2025年，⚠️估算口径——福耀官方年报不提供分地区分部收入，以下基于公开分析师报告/调研纪要估算，非官方分部披露数据，精确数字请查年报附注"营业收入分析"）**：

| 业务板块 | 收入占比 | BCG象限 |
|---|---|---|
| 汽车玻璃（中国）| 约60-62% | ⭐ 明星 / 🐄 现金牛（成熟主力） |
| 汽车玻璃（美洲，主要美国）| 约15-17% | ❓ 问题（2024年开始盈利，扩张中） |
| 汽车玻璃（欧洲，主要德国）| 约5-7% | 🐄 现金牛（稳定，但当地竞争较激烈） |
| 汽车玻璃（ARG售后/其他）| 约8-10% | 🐄 现金牛（稳定高利润率） |
| 浮法玻璃/其他 | 约7-9% | 🐄 现金牛（支撑自供原料，低增长） |

**集中度评估**：单产品（汽车玻璃）集中度~91%，形式上单一，但实质上：
1. 地理分散覆盖了宏观风险
2. 产品技术代际升级（传统→功能→智能）提供成长空间
3. 浮法玻璃自供降低原材料依赖

**评分扣分原因**：单产品集中度高，若全球汽车需求持续下滑（电动化重组期），短期收入压力无缓冲。但这是战略选择，不是管理失误。

### B2 营收质量与粘性（2/3）

**营收机制**：
- **OEM合同供货**：与丰田、大众、通用、宝马等签署1-3年供应合同，每款车型通过认证后成为指定供应商，换标需要~2年重新认证，形成粘性
- **ARG售后市场**：每年~7000万辆汽车因事故或老化需更换玻璃，需求更平滑，不跟随新车销量周期
- **混合结构优势**：OEM随产量波动，ARG提供底部支撑

**评分扣分原因**：B2B OEM合同定价权在客户方（大型整车厂议价能力较强），叠加汽车行业总体3-5年销量周期波动，收入黏性介于"重复消费"和"项目制"之间，不如消费品高。

### B3 定价权（5/6）

| 要素 | 评估 |
|---|---|
| 市场集中度 | CR4~92%，福耀37%全球第一，寡头定价能力强 |
| 毛利率趋势 | 35.39%(2023) → 36.23%(2024) → 37.27%(2025) → 37.38%(2026Q1)，连年提升 |
| ASP趋势 | 普通挡风玻璃均价上升；智能玻璃（HUD/调光）单车价值量200→1000元+ |
| 切换成本 | OEM需重新认证（2-3年），设计变更成本高，锁定效应明显 |
| 上游成本 | 主要原料（石英砂、纯碱）价格下行，毛利率提升有成本顺风助力 |

**扣分原因**：下游OEM大客户（大众、丰田等）仍有一定议价权，价格谈判中福耀不能完全主导。但长期来看定价权在改善。

### B4 业务可持续性（4/5）

**增长逻辑**：

| 驱动因素 | 量化 | 确定性 |
|---|---|---|
| 全球汽车产量温和增长（3-4%/年）| 基础量+3-4% | 高 |
| 单车ASP提升（功能玻璃渗透率↑）| 单车600元→2000元潜力 | 中高 |
| 中国以外OEM客件占比提升 | 欧美份额仍有空间 | 中 |
| 新能源汽车天幕/大玻璃面积增加 | NEV天幕覆盖率>60%，面积增加30%+ | 高 |
| AR-HUD前挡玻璃升级 | ASP从200元→500-1000元 | 中高 |

**尾部风险**：
- 自动驾驶普及若大幅降低事故率 → ARG需求下降（长期，5年以上）
- 极端情况：全球整车产量持续萎缩 → 减量风险

**结论**：可持续性强，ASP升级逻辑清晰，NEV大玻璃面积趋势长期利好。

**优势**：纯汽车玻璃专注度>90%，竞争对手均多元化分散精力，专注带来深度成本与技术优势。

### C2 产业链位置（4/5）

**上游（原材料）**：
- 主要原材料：石英砂、纯碱、银浆（镀膜）
- 自有浮法玻璃产能（7条浮法线）→ 覆盖部分原料，降低依赖度
- 剩余纯碱/化工品属大宗商品，有替代性，单一供应商风险低

**下游（客户）**：
- 全球前20大整车厂几乎全是客户（大众、丰田、通用、宝马、奔驰、特斯拉、比亚迪等）
- 单一客户占比：大众集团约15-18%（全球供应），集中度可控
- OEM议价地位偏强，但福耀规模优势+认证壁垒形成反制
- 扣分：确实"吃汤"但汤碗很大；在特定客户谈判中处于相对被动

**结论**：上游主动管控，下游半锁定，整体产业链位置"偏上游端"，有一定护城河。

## D 战略清晰度与执行力（13/15）

### D1 战略一致性（4/4）

福耀自1987年以来，战略主线清晰从未偏移：

```
阶段一（1987-2000）：进口替代，国内规模化 → "中国第一"
阶段二（2000-2015）：全球OEM客户拓展，海外工厂布局 → "全球化"
阶段三（2015至今）：功能玻璃→智能玻璃，提升单车价值量 → "智能化"
```

每个阶段战略目标清晰，从未涉足与汽车玻璃无关业务（房地产/金融/互联网等），是中国制造业稀有的"专一化"样本。

**关键观察**：2022-2024年FCF/净利较低（41-58%），原因是公司处于密集扩产周期（美国/德国/中国新增产能），并非利润质量下降。OCF/净利长期>100%，说明会计利润有真实现金流支撑，不存在利润虚增。

**⚠️ 2026Q1异常——毛利增加但净利下滑量化**：
- 2026Q1毛利润同比 **+3.84亿（+11%）**，但归母净利润同比 **-3.18亿（-15.7%）**
- 差值：毛利以下费用同比增加约 **7亿**（3.84 + 3.18 = 7.02亿 YoY）
- 可能来源：①财务费用上升（扩产债务利息）；②汇兑损失（2025年末以来人民币小幅升值，海外收入折算减少）；③所得税率变化
- **结论**：毛利率同步升至37.38%（质量指标向好），净利下滑属费用端异常，已识别为非经营性因素；待2026H1报告披露完整费用明细后验证，当前评分基于2025年报不受此影响

**⚠️ 2026Q1 OCF骤降**：2026Q1每股OCF仅0.137元（vs 2025Q1的0.769元），绝对值约3.6亿 vs 上年同期约20亿。Q1现金流季节性偏低（春节后应收款峰值），但此下滑幅度仍值得持续跟踪。

**✅ 2026H1 OCF 已核实（半年报，2026-08-18）**：

| 指标 | 2026H1 | 2025H1 | 同比 |
|---|---|---|---|
| OCF | 45.51 亿 | 53.54 亿 | **-15.01%** |
| 归母净利 | 39.70 亿 | 48.05 亿 | -17.37% |

- **Q1 OCF 骤降已由半年报解释**：公司口径归因为「上年末应付票据于本报告期兑付（现金流出同比增加）+ 减少商业汇票、增加现金结算采购款」，属**营运资本结算方式切换**。但半年报未附完整营运资本变动明细表，此归因只能作为"公司陈述的原因"采信——OCF/净利 114.6% 能证明现金覆盖良好，却不足以单独证明 -15% 的下降**完全**属于结算节奏、不含其他营运资本占用因素，需后续跟踪应收/存货周转。
- **OCF/净利仍 >100%**：H1 归母净利 39.70 亿 vs OCF 45.51 亿 = 114.6%，会计利润仍有真实现金流支撑，质量指标未破位。
- **汇兑损失是 H1 净利下滑的首要且压倒性原因**：H1 汇兑损失 8.03 亿（上年同期汇兑收益 6.02 亿，双向影响 14.05 亿）。剔除汇兑后，利润总额同比 **+4.78%**，说明主营经营面总体稳健；但美国工厂火灾非常损失（1.35 亿）、税费变化等仍有次要影响，不能归为"唯一"。

**福耀玻璃是一家罕见的高质量A股工业企业**，在六个维度均无明显弱项：

2. **商业模式**：重资产寡头，进入壁垒极高，智能玻璃升级打开新的价值空间
3. **护城河**：全球37%市占率是量化护城河，认证切换成本+规模成本护城河协同
