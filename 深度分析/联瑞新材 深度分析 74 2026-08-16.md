## 维度 A：历史基因与公司 DNA

### A1. 公司起源与创始基因

联瑞新材前身 **江苏省东海硅微粉厂** 成立于 **1984年**，是中国最早从事硅微粉工业化生产的企业，至今已有 **42年** 行业历史。创始人 **李长之**（1944年生）自1979年起担任连云港金刚砂厂厂长，1984年创办东海硅微粉厂并任厂长直至2002年。

2002年4月，由广东生益科技（现金出资4,000万）与原东海硅微粉厂（技术及无形资产作价1,500万）合资设立连云港东海硅微粉有限责任公司，注册资本5,500万元。**这是联瑞新材的法人起点**——生益科技作为国内覆铜板龙头，既是战略股东也是核心下游客户。

2014年8月整体变更为股份有限公司，**李晓冬**（李长之之子）出任董事长兼总经理（现通过直接+间接控制约37.63%表决权），标志着公司从"国企老厂长时代"平稳过渡到"二代产业化扩张时代"。

> 该公司成立于1984年（前身），由李长之（技术背景行业元老）创立，初始定位为国内首家工业化硅微粉生产企业，属于**先发优势型 + 技术驱动型**起源基因。2002年引入下游龙头生益科技战略入股，形成"产业资本+技术团队"的双轮驱动结构。

**结论**：先发优势型 + 技术驱动基因（来源：公司招股说明书、百度百科词条、新浪财经高管信息页）

## 维度 B：商业模式质量

### B0. 早期商业模式溯源（创立至上市期）

**九要素商业模式画布（创立期 vs 当下对照）**：

| 要素 | 创立初期（2002-2014） | 当下（2020至今） |
|------|---------------------|-----------------|
| 客户群体 | 覆铜板厂商为主（生益科技核心） | EMC封装料厂商(~45%) + CCL覆铜板(~25%) + 热界面材料等(~30%) |
| 价值主张 | 替代进口，提供国产硅微粉 | 高端球形硅微粉国产替代 + Low-α球粉打破日本垄断 |
| 渠道通路 | 直销，依赖生益科技体系 | 直销为主，客户覆盖华海诚科、生益科技、建滔等 |
| 客户关系 | 年度框架合同，战略股东关系 | 认证型供应商（认证周期1-2年，粘性强） |
| 收入来源 | 角形硅微粉销售（低附加值） | 球形硅微粉为主（高附加值），吨价提升驱动增长 |
| 核心资源 | 石英矿源+研磨分级技术 | 全球唯一三类球化技术平台 + 40年工艺 Know-how |
| 关键活动 | 研磨、分级、提纯 | 火焰熔融球化、Low-α控制、亚微米级粉体制备 |
| 重要合作伙伴 | 生益科技（既是股东也是客户） | 生益科技、华海诚科等 + 先进封装产业链 |
| 成本结构 | 直接材料成本主导（角形粉体~63%） | 燃料动力成本主导（球形粉体~45%）+ 能源价格波动 |

**关键判断**：
- 是否为"辛苦钱生意"：**早期的角形硅微粉是典型的辛苦钱**（低毛利、大吨位、同质化竞争），**球化转型后进入高附加值区间**（球形硅微粉ASP是角形的数倍）
- 成本结构变化：从材料成本主导（角形）→ 能源+技术成本主导（球形），2026H1能源成本增加已实质拖累毛利率（详见B3）
- 早期与当下本质性变化：**产品升级驱动商业模式质变**——从"卖砂子"升级为"卖功能性电子填料解决方案"

**历史商业模式分类结论**：
- [x] 重资产低毛利但构建垄断壁垒型（辛苦起步，护城河极深，不可复制）

### B1. 当下业务板块全景

根据2026半年报 MD&A + 申万宏源研报（来源：2026半年报"经营情况讨论" + 2023年报 + 申万宏源2024.7深度研报）：

| 产品类别 | 营收占比(估) | 毛利率特征 | 增速趋势 | BCG 定位 |
|----------|-------------|-----------|----------|----------|
| 球形硅微粉（EMC用） | ~40-50% | 高（40%+综合） | ⬆ 快速增长（先进封装驱动） | **明星** |
| 球形硅微粉（CCL用） | ~20-25% | 中高 | ⬆ 稳健增长（高频高速CCL驱动） | **明星** |
| 角形硅微粉 | ~20-25% | 中等 | ➡ 稳定/微增 | **现金牛** |
| 球形氧化铝粉体 | ~5-10% | 高 | ⬆ 快速增长（导热材料驱动） | **问题→明星** |

> 注：公司官方未单独披露各产品线精确营收占比。2026半年报 MD&A 首次明确"角形硅微粉、泛用品球形二氧化硅、球形氧化铝等利润基本盘产品市场份额稳步提升，亚微米系列、Low α系列、液相制备法球形二氧化硅等高成长性序列产品销售呈较快增长趋势"——证实产品结构持续优化。

**业务集中度**：单一产品类别（硅微粉整体）占营收>90%，属于**高度集中于一个品类**。但在硅微粉内部，产品结构从角形向球形持续升级，形成"成熟品类现金牛 + 高端品类明星"的内部梯队。

**成长引擎**：AI服务器/高性能计算 → 先进封装（HBM/2.5D/3D）→ Low-α球形硅微粉需求增长。2026H1营收+21.21%，2026年上半年"销售至高性能覆铜板领域的相关产品营收占比呈上升趋势"。

## 最终结论

### 公司质量评级：⭐⭐⭐⭐ 优质（74/100）

**核心竞争优势（数据支撑）：**
1. **国内球形硅微粉绝对龙头 + 全球唯一三类球化技术平台**：联瑞新材是国内第一、全球前五的电子级硅微粉生产商，全球唯一同时掌握火焰熔融法、高温氧化法、液相制备法三种球化技术。42年工艺积累构成极深Know-how护城河。（来源：2026半年报 MD&A + 申万宏源研报）
2. **极高质量的财务特征**：近3年OCF/净利均值约110%；扣非净利占归母净利>89%；5年营收CAGR约22%、净利CAGR约21%；零商誉——在A股材料公司中属顶尖水平。（来源：CNINFO API 2021-2025年报 + 2026半年报，实际值）
3. **精准卡位AI/先进封装材料赛道**：Low-α球形硅微粉是HBM/2.5D/3D先进封装不可替代的关键填料，联瑞是唯一有能力打破日本雅都玛垄断的中国企业。2026H1营收+21.21%，高端产品放量验证了赛道卡位。（来源：2026半年报 + Yole先进封装市场报告）

**核心隐患（数据支撑）：**
1. **强周期性暴露**：2022年半导体下行周期中营收增速从54.6%骤降至5.96%。联瑞无法脱离半导体周期约束，当前处于周期相对高位。（来源：CNINFO API 2021-2023数据）
2. **利基市场天花板有限 + 2026H1增收不增利**：国内硅微粉市场约53亿元，天花板对估值构成约束；2026H1净利增速（+7.48%）远低于营收增速（+21.21%），毛利率下滑2.8pct + 财务费用同比增加1875万元（由-49万转+1826万）侵蚀利润弹性。（来源：2026半年报，实际值）
3. **下游客户集中度高 + 治理边际波动**：前五大客户应收账款占比52%，生益科技既是第一大客户又是第一大股东；财务负责人约2年半内3任变动、核心技术人员姜兵减持、审计机构更换，治理信号边际偏负面。（来源：2026半年报 + 2025年报）
