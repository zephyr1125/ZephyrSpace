## A. 历史基因与公司DNA（9/10）

### 创始人基因

ResMed 由 **Dr. Peter C. Farrell** 于1989年创立。Farrell 本人是生物医学工程师出身，在悉尼大学任教期间研究无创通气技术。公司名 "ResMed" = **Res**piratory **Med**icine。

创始故事有几个关键基因特征：
- **科学家创业**而非商人为之：技术驱动从一开始就刻在DNA里
- **澳大利亚起源、美国商业化**：总部在悉尼（研发）→ 运营中心在圣地亚哥（市场），双重基因
- **患者导向**："改善数百万人生活质量"的使命从1989年延续至今未变

### 控制权演变

| 阶段 | 关键事件 |
|------|---------|
| 1989-1995 | 创始人 Peter Farrell 创业，研发CPAP设备 |
| 1995 | 澳交所IPO |
| 1999 | 纽交所上市 |
| 2013 | Mick Farrell（创始人儿子）接任CEO，Peter退居Chairman |
| 2023 | Mick Farrell 兼任 Chairman，Peter 退居Chairman Emeritus |
| 2026 | 创始人仍在董事会(Chairman Emeritus)，Mick Farrell身兼CEO+Chairman |

### DNA评估

✅ **优势**：
- 25年管理层内部培养——CEO在公司干了一辈子，不是空降兵
- 技术驱动基因——研发支出稳定占营收7%
- 使命一致性极高——"改善呼吸健康"的叙事35年未变

⚠️ **关注点**：
- Farrell父子传承——CEO是创始人儿子。不是问题（Mick确实有能力），但需要独立董事有效制衡
- CEO/Chairman兼任——不是最佳实践，尽管有Lead Independent Director

**DNA评分：9/10**。创始人科学家基因+内部培养CEO+35年使命一致性。父子传承是注意项但不减分——Mick Farrell在任13年的成绩单本身就是最好的辩护。

## B. 商业模式质量（18/20）

### 业务结构

ResMed 的收入来自三个相互强化的板块：

```
┌─────────────────────────────────────────┐
│         睡眠与呼吸健康 (~88%)              │
│  ┌──────────────┐  ┌──────────────────┐  │
│  │  设备 ~51%    │  │  面罩及配件 ~37%   │  │
│  │  CPAP/APAP/  │  │  面罩/头带/耗材/  │  │
│  │  BiLevel/诊断 │  │  家庭睡眠检测     │  │
│  └──────────────┘  └──────────────────┘  │
├─────────────────────────────────────────┤
│       residential Care Software (~12%)    │
│   Brightree + MEDIFOX DAN + MatrixCare   │
│   + myAir + AirView 云平台                │
└─────────────────────────────────────────┘
```

### 商业模式三维经常性收入

| 层级 | 收入模式 | 续费/复购驱动 | 收入占比 |
|------|---------|-------------|---------|
| 硬件 | CPAP设备一次性销售（5-7年更换周期） | 保险报销周期+技术进步驱动更换 | ~51% |
| 耗材 | 面罩/管路/水箱定期更换（3-6月周期） | 磨损+卫生+保险覆盖——纯复购 | ~37% |
| SaaS | Brightree/MEDIFOX DAN/MatrixCare订阅 | 工作流嵌入→高切换成本 | ~12% |

**核心洞察**：每一次设备销售创造一个5-7年的耗材复购流。2,700万+全球云连接设备意味着一个庞大且持续增长的年金池。

### B1 业务板块深度分析

**设备板块（51%营收，增长 ~8% CC）**

- 旗舰产品：AirSense 11（CPAP/APAP）、AirCurve 11（BiLevel）
- 竞争差异化：AI舒适度调节（Smart Comfort，FDA 2025年12月批准）、云连接（100%设备可联网）
- 壁垒：处方设备——需要医生处方+睡眠实验室诊断→保险报销，不是消费品
- 风险：GLP-1减肥药可能减少CPAP新增需求（中长期）

**面罩及配件（37%营收，增长 ~12%）**

- 核心产品：AirTouch N30i、AirFit F40、F30i Comfort/Clear织物面罩
- 商业模式最优环节：纯复购——每位CPAP用户年均消费~$300-500面罩/配件
- 毛利率高于设备（~65-70% vs ~55-60%），是利润引擎
- 可以跨品牌使用——即使患者用Philips机器，也可以用ResMed面罩

**SaaS/数字健康（12%营收，增长 ~7%）**

- Brightree：HME（家庭医疗设备）计费和库存管理——细分市场垄断
- MEDIFOX DAN：德国居家护理文档平台
- AirView：医生远程监控平台，3,600万患者
- myAir：患者自助应用，1,190万用户
- 网络效应：越多人用→数据越多→AI越智能→越难离开

## 综合评定

### 核心逻辑

ResMed 是全球睡眠呼吸设备的绝对龙头，当前被三重暂时性利空错杀：

1. **GLP-1恐惧**：市场认为减肥药会消灭睡眠呼吸暂停→但真实世界数据（195万患者）表明GLP-1+CPAP用户依从性*更高*，且睡眠呼吸暂停并非纯肥胖病

**三重错杀叠加 → PE 18.6x 对一家 ROE 23%+ 毛利率 59%+ 经常性收入 ~49% 的医疗设备龙头来说，是罕见的下注窗口。**
