## 维度 A：历史基因与公司 DNA（8/10）

### A1. 公司起源与创始基因

ARM Holdings 成立于 **1990 年 11 月 12 日**，英国剑桥，由 Acorn Computers、Apple 和 VLSI Technology 合资组建，前身为 Acorn Computers 的芯片设计部门。

- **创始人背景**：12 名工程师从 Acorn 的 ARM（Acorn RISC Machine）处理器项目独立出来。属于**技术驱动型创业**，非政府背景或资源依赖型。
- **成立时间节点**：1990 年正值 RISC 架构兴起期（MIPS、SPARC、PowerPC 百花齐放），ARM 定位低功耗嵌入式处理器，避开了与 Intel x86 在 PC 市场的正面竞争。
- **原始主营业务**：CPU 架构 IP 授权——不制造芯片，只设计指令集和处理器核心，授权给半导体公司集成到自己的芯片中。
- **初始行业地位**：**边缘参与者**——在 1990 年代的 CPU 市场中，x86（Intel/AMD）统治 PC/服务器，ARM 仅存在于嵌入式设备（Apple Newton PDA 是其第一个重要设计 win）。

**结论**：ARM 的起源基因是**先发优势型**（在低功耗 RISC 领域最早布局）+ **技术驱动型**。它不是靠政策红利或资源垄断起步，而是靠设计效率和商业模式的创新——IP 授权模式让它在不承担芯片制造风险的前提下实现了架构的广泛扩散。

## 维度 B：商业模式质量（17/20）

### B0. 早期商业模式溯源

**九要素商业模式画布（创立期 vs 当下对照）**：

| 要素 | 创立初期（1990-2000）| 当下（2026）|
|---|---|---|
| 客户群体 | 嵌入式设备芯片商（TI、Nokia）| 全球所有主要半导体公司 + 云厂商 |
| 价值主张 | "低功耗 RISC CPU 核心设计" | "AI 时代无处不在的计算平台" |
| 渠道通路 | 直接技术授权谈判 | 标准化授权（ATA/AFA）+ CSS 捆绑 + 直销 |
| 客户关系 | 项目制技术合作 | 长期架构授权 + 年度续费 + 芯片级 Royalty |
| 收入来源 | 一次性 License 费为主 | License（47%）+ Royalty（53%）+ 硅芯片（新增）|
| 核心资源 | CPU 架构专利 + 设计团队 | ARM 指令集生态 + 1000+ 授权客户 + 软件生态 |
| 关键活动 | 设计 CPU 核心、签署授权协议 | 架构研发 + 生态建设 + 自研芯片（新增）|
| 重要合作伙伴 | 晶圆厂（TSMC 等）、EDA 工具商 | 代工厂 + 云厂商 + AI 公司 + 芯片客户 |
| 成本结构 | 几乎纯人力（R&D + 销售）| 人力为主（R&D 56% + SG&A 23%），芯片业务增加制造成本 |

**关键判断**：
- 是否为"辛苦钱生意"：**否**。ARM 从第一天起就是轻资产 IP 授权模式，不承担芯片制造的资本开支和库存风险。
- 毛利率质变节点：ARM 的毛利率始终维持在 95%+ 水平，因为 IP 授权的边际成本接近零。不存在"建设期→运营期"的质变——天生高毛利。
- 商业模式本质性变化：**唯一一次本质变化是 2026 年 AGI CPU 自研芯片**，从纯 IP 授权商变为同时是芯片制造商，这从"卖地图的人"变为"自己也去挖金矿"。

**历史商业模式分类结论**：
- [x] **轻资产高毛利可复制型**（天生优质，规模化后 ROE 持续提升）

### B2. 盈利机制解析

| 盈利模式 | 判断结论 |
|---|---|
| 收费方式 | License（前期固定费+年度续费）+ Royalty（按芯片出货量抽成）+ CSS（捆绑 IP 打包） |
| 复购特征 | **极高复购**——芯片设计周期 3-5 年，一旦选定 CPU 架构，后续迭代极难切换 |
| 需求刚性 | **刚性必需**——每颗 SoC 都需要 CPU 核心，ARM 在移动端没有替代方案 |
| 成本结构 | **固定成本主导**——R&D 是最大支出（FY2026 占收入 56%），芯片出货量增长不增加 ARM 的边际成本 |
| 规模效应 | **强**——Royalty 模式下，芯片出货量越大 ARM 单位收入成本越低（接近纯利润） |

**结论一句话**：
> 这是一家「**技术平台税**」模式的公司，复购率极高，刚性需求，有极强的规模效应。每卖出一颗含 ARM 架构的芯片，ARM 就能收到一笔接近纯利润的 Royalty。

- 下游客户切换成本：**极高**——切换 CPU 架构意味着重写整个软件栈、重新设计 SoC、重新验证兼容性，周期 3-5 年，投入数亿美元。
- ⚠️ **但**：当最大的客户（Apple、Qualcomm、NVIDIA）同时也是最强大的科技公司时，它们有能力自研替代方案或在 RISC-V 上投入——这不是传统意义上的"客户集中度风险"，而是"客户能力风险"。

**产业链四维系统性判断**：

| 判断维度 | 结论 | 佐证依据 |
|---|---|---|

| 产业链景气周期 | **上行**——AI 基础设施军备竞赛驱动芯片设计需求爆发 | 云厂商资本开支 2025-2026 持续增长 |

**产业链定性结论**：**"吃肉"**（主导者）—— ARM 不承担芯片制造的资本风险，但从每一颗芯片中获得稳定抽成。但从 2026 年起，它自己也开始"采矿"了。

### C3. 横向竞争格局

**三大 CPU 架构竞争**：

| 架构 | 代表厂商 | 优势 | 劣势 |
|---|---|---|---|
| **x86** | Intel、AMD | 最深的软件生态，x86 兼容性可追溯 40 年 | 功耗高，Server 份额被持续侵蚀 |
| **ARM** | ARM Holdings | 功耗比最优，移动端绝对主导，Server 增速最快 | 自研芯片引发客户冲突，FTC 风险 |

- **第一名差距**：ARM 与 x86 在服务器端的差距正在快速缩小——从 2025Q1 的 11.5% 到 2026Q1 的 17.7%。

### E1. ROE 质量与杜邦分析

ROE = 净利率 × 资产周转率 × 权益乘数

| 年份 | 净利率 | 资产周转率 | 权益乘数 | ROE |
|---|---|---|---|---|
| FY2024 (Mar 2024) | 9.5% | 0.41x | 1.50x | 5.8% |
| FY2025 (Mar 2025) | 19.8% | 0.45x | 1.31x | 11.6% |
| FY2026 (Mar 2026) | 18.4% | 0.46x | 1.29x | 10.9% |

**驱动因素判断**：
- ✅ **净利率驱动**：ROE 的核心来源是 18-20% 的净利率，运营效率提升（FY2024 → FY2025 净利率翻倍）
- ✅ **资产周转率改善**：轻资产模式下，收入增速 > 资产增速
- ✅ **权益乘数低且下降**：1.29x 极低杠杆，无债务驱动的 ROE 虚高

> ROE 10.9%（FY2026）对于一家 97% 毛利率的科技公司并不算高——这主要因为 R&D 投入极高（占收入 56%），大量利润被再投资于研发而非沉淀为净资产回报。这是"当期利润低但长期竞争力构建"的典型特征。

### F2.5. 资本配置纪律

**① 资本支出（Capex）纪律**

ARM Capex 极低（FY2025 $239M，占收入 6%），与轻资产 IP 授权模式匹配。**2026 年起 AGI CPU 自研芯片将改变这一特征**——芯片流片、IP 购买、供应链建设将大幅推高 Capex。

**② 并购记录**

ARM 历史上几乎不做并购，增长全部有机。这是**优秀的资本配置纪律**——没有高价收购、没有商誉减值风险、没有整合失败。

**③ 回购**

无。

**④ AGI CPU 战略——资本配置的逻辑跳跃**

从轻资产 IP 授权到自研芯片制造的转变，是 ARM 历史上最大的资本配置决策：
- R&D 从 FY2025 $2.07B 增至 FY2026 $2.78B（+34%），其中相当部分投入 AGI CPU 研发
- 芯片制造的资本密集度远高于 IP 授权——未来 Capex / 营收比将显著上升
- SoftBank 关联咨询收入 $704M（占 FY2026 收入 14.3%，YoY +384%）可能部分用于补贴 AGI CPU 开发

**⑤ 历史先例**

ARM 在历史上无自研芯片的先例可参考。管理层声称"从卖地图到自己挖矿"是战略升级，但这更像是**进入一个从未验证过能力的新领域**。正面类比（如 NVIDIA 从 GPU 到 AI 计算平台）可能不适用——NVIDIA 一直在做芯片，而 ARM 从未做过。

**资本配置纪律总体评估**：
> 历史上资本配置极好（零并购、有机增长、极低 Capex），但 AGI CPU 战略是一次未经能力验证的赌博。SoftBank $704M 关联咨询收入模糊了正常的商业收入和关联方利益输送的边界。
> 无先例可验证 → **不加分**。

### F3. 关联交易与内控透明度

**SoftBank 关联交易——本报告最重大的治理红旗**：

| 项目 | FY2025 | FY2026 | 变化 |
|---|---|---|---|
| SoftBank 关联咨询收入 | $145.5M | $704M | **+384%** |
| 占总收入比例 | 3.6% | 14.3% | — |
| FY2027 保底 | — | $300M（已签约）| — |

- **这是什么**：ARM 向 SoftBank 及其关联公司提供"咨询服务"并收取费用。SEC Filing 中披露为"related party transactions"。
- **为什么是问题**：
  1. 关联交易占总收入 14.3%——不是小数目
  2. 384% YoY 增长远超整体营收增速（22.8%）——这不是有机增长
  3. SoftBank 作为 86% 控股股东，完全有能力定价这些"咨询费"——这是否是变相的利益输送？
  4. 咨询服务的性质和定价缺乏透明度——ARM 到底为 SoftBank 提供了什么价值 $704M 的服务？
- **可能的合理解释**：SoftBank 利用 ARM 的 AI/芯片专业知识为其投资组合公司（如芯片设计初创公司）提供技术支持。ARM 按市场价收费。
- **可能的灰色解释**：SoftBank 通过关联交易从 ARM 提取现金，将上市公司利润转移至非上市的 SoftBank 体系。

**FTC 反垄断调查**：
- 2026 年 5 月公开报道 FTC 已启动正式反垄断调查，要求 ARM 保存相关文件
- Qualcomm 在输掉合同诉讼后，向 FTC/欧盟/韩国三地同时提交反垄断投诉
- 调查核心：ARM 是否滥用 CPU 架构市场支配地位，通过在授权中施加限制性条款或拒绝授权来排挤竞争对手

**交易所问询函**：NASDAQ 公开信息中未发现对 ARM 的问询或处罚记录。

## 最终结论

### 公司质量评级：⭐⭐⭐⭐ 优质（74/100）

**核心竞争优势（数据支撑）：**
1. **全球 CPU 架构近乎双寡头之一**：移动端 ~95% 市占率，开发者生态 + 软件栈适配构成极深锁定效应（来源：ARM FY2026 年报 + 行业数据）
2. **AI 基础设施转型的最大受益者之一**：服务器 CPU 份额从 FY2025Q1 的 11.5% 飙升至 FY2026Q1 的 17.7%，UBS 预测 2030 年达 40-45%（来源：UBS 2026Q1 服务器 CPU 市场报告）
3. **97% 毛利率的资产轻型商业模式**：Royalty（53%）+ License（47%）双引擎，每颗芯片出货贡献接近纯利润，不承担制造风险（来源：ARM FY2026 年报）

**核心隐患（数据支撑）：**
1. **FTC 反垄断调查可能从根本上改变商业模式**：美国 + 欧盟 + 韩国三辖区调查进行中，若强制 FRAND 许可条款，ARM 的定价权将受结构性约束（来源：FTC 2026 年 5 月通知 + Qualcomm 投诉文件）
2. **SoftBank 86% 绝对控制 + $704M 关联交易**：关联咨询收入占 FY2026 收入 14.3%，年增 384%，少数股东权益保护存结构性疑问（来源：ARM FY2026 SEC Form 20-F 关联交易披露）
3. **AGI CPU 自研芯片 = 历史上最大的战略赌博**：从"中立 IP 授权商"变为"客户竞争对手"，无芯片制造执行先例，最大风险交叉点（AGI CPU + FTC）

**长期重仓适配度判断**：
> 本公司得分 74 分，评级为「优质」。
> 核心优势是"全球 CPU 架构垄断性地位 + AI 计算浪潮最大受益者之一"，最大隐患是"FTC 反垄断调查可能从根本上改变其商业模式"。
> 建议：**适合标准持仓（2-5%）**，不宜做核心仓位（>10%）。FTC 调查结果将是评级方向的决定性变量：
> - 若调查无行动结案 → 可上调至 78-80 分
> - 若强制 FRAND 条款或限制自研芯片 → 可能下调至 60-65 分
> - 若 SoftBank 关联交易持续膨胀（FY2027 > $1B）→ F 维度可能触发 40% 警告线
>
> ⚠️ 以上结论仅为公司基本面质量判断。价格时机请参阅 `[[01-公司/ARM]]` 的 PreBuy 结论。
