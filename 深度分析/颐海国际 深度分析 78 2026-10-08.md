# 颐海国际深度分析

公司质量78分。它是一家现金创造能力较好、增长已成熟化的调味食品生产商。
海底捞品牌与渠道是优势，关联客户及可替代产品也决定其护城河有限。
2026上半年明显改善，但不应把半年反弹外推为多年两位数增长。
本轮采用简化流程的一位独立审核；验收结论见本轮审核记录，未证明与双复核等效。
本报告的年度基础是2025年报，增量是2026中报及截至10月8日可得公告。
财务实际值按人民币列示，股价估值另见估值报告，不能混用币种。
历史2026-07-19版本为74分，本轮重评78分，增加4分；旧版本保留。
变化包含原规则重新落到分项及新中报，不全归因于经营改善。

## A：历史基因

源头是四川海底捞2005年成都分支，2006年生产线为餐厅供货。[S8 PDF113]
2007年开始面向独立经销商，将餐饮配方与品牌转成工业化零售商品。[S8]
2013年设立开曼控股主体，2016年香港上市。[S8、S2 PDF50]
早期扩展依靠真实产品、产能与渠道，不是通过买壳更换主营。
招股书显示当时中高端火锅底料细分地位领先；此历史排名不充作2026全调味品排名。
上市至今主要控制家族仍为张勇与舒萍；家族信托重组不自动等于更换实控人。
控制沿革核验覆盖招股书以及2020–2025年报控制股东释义、权益和变动章节。[S1/S3–S8]
2026中报张勇披露权益325,896,021股，占31.44%；配偶、信托视同权益不能相加重复计算。[S2 PDF35–38]
施永宏夫妇信托相关权益130,132,992股，其退出董事长不等于股份清仓。[S2 PDF39]
近年现金流表的融资活动主要是股息、租赁及回购；2025年报确认未发行可转债。[S1]
历史IPO用途围绕生产基地、研发营销和营运资金；本轮没有发现卖资产保利润的主要模式。
分类为经营型，兼有餐饮消费与原料价格周期，不属于资源周期公司。

## B：商业模式与九要素

| 要素 | 创立至上市 | 当下 |
|---|---|---|
| 客户 | 海底捞及后续经销商 | 关联餐饮、零售消费者、第三方餐饮 |
| 价值主张 | 标准化火锅风味 | 便利、稳定、多口味、渠道适配 |
| 渠道 | 餐厅及经销批发 | 经销、KA、电商、海外直营对接 |
| 客户关系 | 集团采购与经销补货 | 重复采购，但消费者转移容易 |
| 收入 | 调味料按件销售 | 火锅、复合料、速食与少量其他 |
| 资源 | 品牌许可、配方、产线 | 品牌、终端覆盖、研发和供应网络 |
| 活动 | 采购生产、产品配送 | 选品、渠道管理、制造、食品安全 |
| 合作方 | 海底捞及原料供应商 | 品牌方、经销商、平台、餐饮客户 |
| 成本 | 原料、产线、包装物流 | 原料仍关键，营销和品类复杂度上升 |

早期不是纯轻资产平台：要建厂、有质量管控和物流要求。
相对高毛利来自品牌和渠道，不是固定资产自然形成垄断。
现在仍是同一产品制造销售逻辑，只是第三方占比更高、产品更复杂。
不存在应被认定为一次性建设完成后无再投资的基础设施模式。
可复制性中等：产品能工业化复制，品牌和渠道复制需要投入，用户不被技术锁定。

## C：竞争与价值链

当前比较对象包括天味食品等复合调味料企业，不把酱油龙头全部利润率直接移植。
消费者选择多、转移成本低，零售端品牌是优势而非必选基础设施。
海底捞品牌许可增强辨识度，也使独立品牌资产并非完全自有。[S8商标协议]
许可长期、独家、免许可费等条件依上市规则及协议范围；不能简化为无条件自有商标。
供应端原材料采购规模和多基地提供效率；原料涨价仍可能侵蚀毛利。
关联客户提供订单和开发反馈，同时对产品定价有强影响力。
2026H1关联收入约29.92%，比2025全年27.69%高，不能称关联依赖已单向下降。
集中度的风险是购买量或定价改变；不是因为毛利低就自动证明利益输送。
渠道及销售投入形成进入成本，但缺网络效应，配方迭代不能封锁竞争者。
全国覆盖支持稳定竞争地位；本轮未拿到2026可比口径份额，C1不用旧细分排名给绝对龙头满分。
护城河综合三星：品牌、供应链、渠道互相补充，但仍需持续投营销与新品。
五力判断：现有竞争偏强、替代品偏强、新进入者中等、供应商中等、集团买方偏强。
最大价值创造在品牌渠道与稳定口味的产品化，制造是必须的履约基础。
单独研发、生产、渠道环节利润率未披露，不以集团毛利冒充分环节利润率。
SKU过多导致资源分散是已经承认的效率弱点，2026能否真正精简需要继续跟踪。

## F：治理、资本与实质运营风险

郭强自2020-03-25任CEO，2026-04-24再任董事长；不能写成2026才接任CEO。[G3]
施永宏说明提早退休以兼顾家庭与个人事务；舒萍说明投入其他非竞争业务。[G3/G4]
这些是公告理由，不是已证实“内部争斗”或“经营危机”。
张凡来自海底捞并任非执行董事，不是独立董事；其任命不能被包装为独立性增强。
董事长兼CEO偏离守则C.2.1，公司已说明理由；合规披露不消除权力集中风险。[S2 PDF41]
审计委员会三人均为独立非执行董事，构成真实制衡程序。[S2 PDF42]
彭龙调查已披露并补位，但案件细节与颐海经营关联未知；不推断提名尽调失误为事实。
2026奖励计划采用已有股份，董事会决定归属条件，非新股发行；截至6月底没有授予。[G5、S2 PDF85]
已有股份未来授予仍可能摊薄目前享有盈利的外部股东份额，不等于完全无经济成本。
关联销售按框架协议，独董及核数师核查批准、定价政策及上限；这不是证明每笔交易经济最优。[S1 PDF115–119]
食品安全、供应商质量、生产批次追溯、召回准备是长期硬约束，品牌发生事故会放大损失。
Tavily公司、人物及食品安全检索结果归档，不以聚合站旧投诉推断本轮重大违法。
本轮没有取得可确认的重大食品停产处罚原件；ESG风险评为中等，不以没有搜索结果证明风险为零。

## 风险、反证和跟踪

若第三方连续两个半年度收入负增长且渠道库存上升，中等品牌壁垒和增长假设需要下调。
若关联毛利恶化同时应收超过约定账期，重新核查转移定价与资金占用。
若分红连续超出审慎现金桥并消耗净现金，不再以高派息等同高回报质量。
若发生公司经营相关的重大食品安全或结构性监管处罚，重新进入准入审查。
若主席CEO分设、激励新增明确经营门槛且执行稳定，可上调治理置信度。
若海外高增速伴随大幅存货和应收扩张，不把收入增长单独视作成功。
