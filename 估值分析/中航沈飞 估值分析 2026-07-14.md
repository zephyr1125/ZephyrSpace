军工主机厂的业绩具有极强的季节性——Q4/H2集中交付是行业常态。2025年全年净利35亿，H1约11.4亿（占32.5%），H2约23.6亿（占67.5%）。

## 多方法估值

### 方法选择说明

中航沈飞属于军工央企（战斗机总装垄断），盈利受订单节奏影响大、现金流健康、分红稳定但偏低。军工行业PEG法参考价值有限（利润增速波动剧烈），DDM不适用（分红率偏低）。适用方法：
- PE分位（30%）——盈利可预测、5Y+交易历史、行业PE参照系清晰
- PEG（0%）——军工企业利润受订单节奏剧烈波动，PEG严重失真，**不纳入**
- FCF Yield（20%）——OCF/净利109%健康，但军工Capex波动大
- 逆向DCF（30%）——验证隐含预期，区分"订单节奏扰动"与"结构性放缓"
- EV-EBITDA（0%）——军工企业轻资产（总装为主）+低负债，EV/EBITDA参考价值有限
- PVGO（20%）——军工企业增长预期分歧大（十五五 vs 平台期）

### 方法 4：PVGO（增长机会现值）

**计算步骤**：

| 参数 | 基于2025A EPS | 基于2026E EPS |
|---|---|---|
| Normalized EPS | 1.23 元 | 0.87 元 |
| Ke（权益成本） | 9.0% | 9.0% |
| SSV/股 = EPS/Ke | 13.67 元 | 9.67 元 |
| 当前股价 | 38.86 元 | 38.86 元 |
| PVGO/股 | 25.19 元 | 29.19 元 |
| 实际 PVGO% | **64.8%** | **75.1%** |
| 合理 PVGO% 判断 | **50%**（战斗机能——十五五列装+歼-35放量确定性强，但单一客户+单品依赖限制了PVGO上限） | 同上 |
| 合理价 = SSV/(1-合理PVGO%) | 13.67/0.50 = **27.34 元** | 9.67/0.50 = **19.34 元** |

**PVGO分析核心发现**：

```
股价38.86 元 = 13.67 元（稳态价值）+ 25.19 元（增长期权）[基于2025A]
股价38.86 元 = 9.67 元（稳态价值）+ 29.19 元（增长期权）[基于2026E]

SSV仅占股价的25-35%，65-75%来自对未来列装/新型号/军贸的预期。

当正常化EPS因H1业绩大幅下滑而从1.23→0.87时，
SSV从13.67→9.67元（-29%），但股价仍为38.86元（市场尚未反应），
导致实际PVGO%从64.8%→75.1%——进一步拉高了对未来的预期门槛。
```

| 对标 | PVGO% | 说明 |
|---|---|---|
| S&P 500 历史均值 | ~35% | Counterpoint Global / Morgan Stanley 2026 |
| 中航沈飞当前（基于2025A） | **64.8%** | 高于均值但低于三环集团88.5% |
| 中航沈飞当前（基于2026E） | **75.1%** | 若2026盈利未恢复，预期压力更大 |
| 可比军工（洛马/雷神） | ~40-50% | 美国军工巨头，更成熟的估值体系 |

**结论：合理价 ≈ 27.34 元（基于2025A，50%合理PVGO%，-29.6% vs 现价）**

> PVGO法对沈飞的估值偏低（27元），原因与FCF Yield类似——这是一个"稳态价值/增长预期"的结构分解工具，对利润剧烈波动的军工企业适配度一般。但PVGO提醒我们：2026H1的利润大幅下滑并非无关紧要——即使市场判断这只是"节奏问题"，利润下滑仍自动拉低了SSV，从而推高了实现股价所需的未来增长预期。**如果2026H2交付没有强势恢复，当前股价的压力将显著增大。**
