### 方法 4：DDM（股利折现）

> 华润三九股利支付率50%+、一年两次分红、DPS持续增长——DDM是评估这类"现金奶牛"最合适的绝对估值方法。

**输入参数**：

| 参数 | 值 | 说明 |
|---|---|---|
| DPS₀ (TTM) | 1.04 元 | 2025年报+中期分红合计（实际值） |
| 股利支付率 | ~50.6% | 2025年实际值 |
| 分红增长假设 g | 5% | 与利润增长同步（保守），低于历史DPS CAGR ~10% |
| 权益成本 Ke | 9.0% | A股央企，略低于A股标准9.5%（央企风险溢价低） |
| 永续增长率 | 3% | 中药行业长期需求增长（老龄化+消费升级） |

**DPS增长驱动**：
- 2025年DPS 1.04元 = 中期0.353元 + 末期0.59元 + 特别0.10元
- 如果利润从34.2亿→37亿（+8%），且支付率维持50%，则2026E DPS ≈ 1.11元

**戈登增长模型（单阶段）**：

```
P = DPS₁ / (Ke - g)
  = 1.04 × (1+5%) / (9% - 5%)
  = 1.092 / 4%
  = 27.30 元
```

**两阶段DDM（更合理的假设——前5年g=8%，之后永续g=3%）**：

| 年份 | DPS | 折现因子 | 现值 |
|---|---|---|---|
| 2026E | 1.12 | 0.917 | 1.03 |
| 2027E | 1.21 | 0.842 | 1.02 |
| 2028E | 1.31 | 0.772 | 1.01 |
| 2029E | 1.41 | 0.708 | 1.00 |
| 2030E | 1.53 | 0.650 | 0.99 |
| 终值（2030+） | 1.53×1.03/(0.09-0.03) = 26.27 | 0.650 | 17.08 |
| **合计** | | | **22.13 元** |

**H模型（两阶段，g₀=8%线性降至gₙ=3%，H=5年）**：

```
P = DPS₀ × [(1+gₙ) + H×(g₀-gₙ)] / (Ke - gₙ)
  = 1.04 × [(1.03) + 5×(0.08-0.03)] / (0.09 - 0.03)
  = 1.04 × [1.03 + 0.25] / 0.06
  = 1.04 × 1.28 / 0.06
  = 22.19 元
```

**估值结果总结**：

| 情景 | DDM方法 | 合理价 | vs 现价 |
|---|---|---|---|
| 保守（单阶段，g=3%） | 戈登增长 | 17.33 元 | -30.3% |
| 基准（两阶段，g₀=8%→3%） | H模型 | 22.19 元 | -10.8% |
| 乐观（单阶段，g=8%） | 戈登增长 | 104.00 元（不切实际） | — |

**结论：合理价 ≈ 22.19 元（-10.8% vs 现价）**

> DDM给出的估值低于当前股价，原因是高分红率（50%）挤占了用于增长的资金，使得DPS增速受限（永续g=3%）。但DDM未充分考虑天士力整合成功后利润加速增长的可能性。如果天士力整合在2-3年后释放利润（增速提升至12-15%），DPS增速可提至10%+，合理价将显著抬升。

### 方法 5：逆向 DCF

**标准参数**：

| 参数 | 值 | 说明 |
|---|---|---|
| 基准 EPS | 2.19 元 | 2026E一致预期 |

| 当前股价 | 24.88 元 | |

**逆向求解**：在当前股价24.88元下，市场隐含的10年EPS CAGR：

```
输入：P=24.88, EPS₀=2.19, r=9.0%, T=10年, 终值PE=18x
输出：隐含g ≈ 2.5%
```

**合理性检验**：

| 指标 | 数值 | 判断 |
|---|---|---|
| 市场隐含10年EPS CAGR | **~2.5%** | ✅ 极低，远超合理范围之下 |
| 历史5年EPS CAGR (2020-2025) | ~16.4% | 实际增速（含并购贡献） |
| 内生增速（扣除并购） | ~8-10% | 估计 |
| 中药行业长期增速 | ~8-12% | 老龄化+消费升级驱动 |
| 差距（隐含 vs 合理） | -6~-10pp | **市场过度悲观** |

**正向估值**：若假设合理10年EPS CAGR = 8%（内生增长+天士力整合成功后释放利润）：

```
输入：EPS₀=2.19, g=8%, r=9.0%, T=10年, 终值PE=18x
输出：合理价 ≈ 37.76 元
```

| 情景 | 假设g | 合理价 | vs 现价 |
|---|---|---|---|
| 保守（天士力整合失败，增速仅3%） | 3% | 26.28 元 | +5.6% |
| 基准（天士力整合成功，内生8%） | 8% | 37.76 元 | +51.8% |
| 乐观（整合大获成功+行业景气） | 12% | 52.91 元 | +112.7% |

**结论：合理价 ≈ 37.76 元（+51.8% vs 现价）**

> 逆向DCF揭示的核心发现：当前24.88元的股价隐含的10年EPS CAGR仅约2.5%——这意味着市场几乎不给华润三九任何增长预期（2.5% ≈ 通胀率 ≈ 零增长）。对于一个拥有"999"品牌、年营收316亿、市占率多品类#1-2的OTC中药龙头来说，这个隐含增速严重偏低——市场在过度悲观地定价"天士力整合失败+商誉减值+集采冲击"三重利空。
