### 方法 4：实物期权法（权重 10%）

PET 铜箔业务的本质是一个**深度虚值看涨期权**——要么成功（10 倍+回报），要么失败（趋近归零）。

**期权参数**：

| 参数 | 数值 | 说明 |
|---|---|---|
| **标的资产 S** | 30 亿 | PET 铜箔成功时的企业价值（乐观情景） |
| **执行价格 K** | 60 亿 | 赣州一期+二期总规划投资（二期 48.5 亿是否推进存疑） |
| **期限 T** | 5 年 | PET 铜箔产业化窗口期（2026-2031） |
| **无风险利率 r** | 2.5% | 10 年期国债 |
| **波动率 σ** | 80% | 极高——技术路线未定+竞争激烈+公司自身经营风险 |

> ⚠️ 实物期权法在此处的局限性：Black-Scholes 假设标的可交易、波动率恒定、期权可复制——这些假设对一家 A 股小市值转型公司都不成立。以下计算**仅作为思维框架，非精确估值**。

**简化 BS 计算**：

```
d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
   = [ln(30/60) + (0.025 + 0.64/2)×5] / (0.80×√5)
   = [-0.693 + (0.025+0.32)×5] / 1.789
   = [-0.693 + 1.725] / 1.789
   = 1.032 / 1.789
   = 0.577

d2 = d1 - σ√T = 0.577 - 1.789 = -1.212

N(d1) ≈ 0.718
N(d2) ≈ 0.113

Call = S×N(d1) - K×e^(-rT)×N(d2)
     = 30×0.718 - 60×0.882×0.113
     = 21.54 - 5.98
     = 15.56 亿
```

**加上 LED 背光残值**：

| 组成部分 | 价值(亿) |
|---|---|
| PET 铜箔期权价值 | 15.56 |
| LED 背光残值（PS 0.5x × 13 亿） | 6.50 |
| **合计企业价值** | **22.06** |
| 减：净有息负债 | -5.20 |
| **权益价值** | **16.86** |
| **每股价值** | **9.32 元** |

**敏感性分析**：

| S(成功价值) \ σ(波动率) | σ=60% | σ=80% | σ=100% |
|---|---|---|---|
| S=20 亿 | 6.82 元 | 7.41 元 | 8.12 元 |
