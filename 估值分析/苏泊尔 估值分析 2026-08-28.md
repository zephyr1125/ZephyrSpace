基于 2026 半年报（营收 114.10 亿 -0.59%、归母净利 8.68 亿 -7.70%）下修盈利预期，合理价值取 **37 元**，估值确定性 **0.55**。2026-08-28 收盘价 40.30 元，**高于合理价值约 9%**（相对机械买入线 +43.9%），处于"合理至偏贵区"。**当前价位不新建仓**：正式新仓门槛为 P ≤ 28.01 元；持有者回报主要依赖 6.5% 股息率。

## 多方法估值

### 方法 1：PE 分位法（权重 45%）

| 参数 | 值 |
|---|---|
| 2026E EPS | 2.43 元（基准） |
| 合理 PE | 15.5x |
| 价值 | 2.43 × 15.5 = 37.7 元 |

- 3Y PE_TTM 分位：P20=17.3x、P50=18.6x、P80=19.8x、min=15.0。当前 15.92x 处于 4.3% 分位（极低）。
- 但**分位极低主要反映增长转负**：2026H1 营收 -0.59%、净利 -7.70%，盈利收缩时历史分位锚定需打折。增长转负的公司合理 PE 应低于历史 P20，取 **15.5x**（对应股息率 6.4%）。
- 若以 2026E EPS 2.43 计算，15.5x 对应股价 37.7 元；16x 对应 38.9 元；17.3x（P20）对应 42.0 元——但 P20 隐含增长假设，当前不适用。

### 方法 2：DDM 股利折现（权重 30%）

| 参数 | 值 |
|---|---|
| 2026E DPS（D0） | 2.40 元 |
| D1 = D0 × (1+g) | 2.40 × 1.015 = 2.436 元 |
| Ke（要求回报） | 8.5%（成熟低增长高股息消费股） |
| 长期增速 g | 1.5% |
| 价值 | D1 / (Ke - g) = 2.436 / (0.085 - 0.015) = 34.8 元 |

- g 取 1.5%：公司近 100% 派息，利润增速≈股息增速，2026 增长转负背景下长期增速不能外推历史 12% 的 DPS 增速（那是派息率提升所致）。1.0% g → 32.5 元；2.0% g → 37.5 元。
- **敏感性**：DDM 对 g 极度敏感——恰恰因为留存率≈0，长期增长主要不能来自 ROE×留存，而要来自提价/销量/新品/市占率，因此 **g 是估值最关键且不稳定的假设**，1% 与 2% 的 g 差距即可让 DDM 价值相差 5 元。这也是 certainty 定为 0.55 的原因之一。
- 口径说明：若将 2.40 直接当作下一期股利 D1 而不再乘以 (1+g)，价值为 2.40/0.07=34.3 元。本报告采用严格 Gordon（D1 = 当期股利×(1+g)），取 34.8 元。

### 方法 3：股息率法（权重 15%）

| 参数 | 值 |
|---|---|
| 2026E DPS | 2.40 元 |
| 合理股息率 | 6.25% |
| 价值 | 2.40 / 0.0625 = 38.4 元 |

- 公司作为"类债券+品牌"标的，股息率是市场定价锚。历史 3 年股息率区间约 5.4%-6.5%（对应 PE 15.5-18.6x），当前 6.50%。增长转负后合理股息率 6.25%（略低于当前，反映市场已充分定价悲观）。
- 6.0% → 40.0 元；6.5% → 36.9 元。

### 方法 4：FCF/股息覆盖验证（权重 10%）

| 参数 | 值 |
|---|---|
| FY2025 OCF | 26.46 亿元 |
| FY2025 分红 | 20.96 亿元 |
| 覆盖倍数 | 126% |
| 2026 估算 OCF | ~20-23 亿元（H1 4.84 亿 + H2 旺季） |
| 2026 预计分红 | ~19.5 亿元 |

- 覆盖倍数尚可（FY2025 126%），但 2026H1 OCF 仅 4.84 亿（-5.5%）、应收 +15.8%，全年覆盖收窄。公司另有净流动性约 43.9 亿（货币资金+理财+大额存单），分红短期可持续。
- 不将其作为独立主方法（年报未拆"维护性 capex"，OCF 直接替代 FCF 会高估），仅作验证：37 元时股息率约 6.5%，覆盖可支撑。

### 加权合理价值

| 方法 | 价值 | 权重 | 独立性说明 |
|---|---:|---:|---|
| PE 分位 | 37.7 元 | 45% | 盈利锚：基于 EPS × 合理 PE，是独立信号 |
| DDM | 34.8 元 | 30% | 股东回报锚：与股息率法**高度同源**（底层变量同为 DPS，仅资本化方式不同），合并视为一个"股东回报锚"信号 |
| 股息率 | 38.4 元 | 15% | 股东回报锚：与 DDM 同源（均基于 DPS），**强相关** |
| FCF 覆盖验证 | —（38 元参考） | 10% | 现金流锚：独立于盈利类方法（基于 OCF/分红覆盖），弱相关 |
| **加权合理价值** | **约 37 元** | **100%** | 37.7×0.45 + 34.8×0.30 + 38.4×0.15 + 38×0.10 = **37.0 元**，取整 37 元 |

> **方法独立性声明（终审修正）**：3 类信号 = 盈利锚（PE 45%）+ 股东回报锚（DDM 30% + 股息率 15% = 45%）+ 现金流锚（FCF 覆盖 10%）。**DDM 与股息率是同一底层变量（DPS）的两种资本化方式，属高度同源信号**——"权重合计未超 50%"本身不构成独立性，两者必须合并视为一个股东回报锚。当前三个锚的输出值均在 34-39 元窄区间，方法重构不改变 37 元中枢。加权结果可信度中等（增长转负 + g 假设敏感）。

## 估值确定性认定（0.55，闭合计算）

```
基准 0.50
+ 0.10  盈利可预测（成熟消费、低波动，业务易理解）
+ 0.05  资产负债表清晰（净流动金融资产约 32 亿，无重大融资需求）
+ 0.05  方法收敛（PE/股东回报/现金流三锚落在 34-39 元窄区间）
- 0.05  增长转负且幅度不确定（2026E -7% 的假设依赖 H2 判断）
- 0.04  高派息可持续性存疑（OCF 覆盖收窄、H1 OCF 仅 4.84 亿、应收增速快于收入）
- 0.03  关联客户集中（SEB 关联销售占同类 28.20%，订单与定价外部不可验证）
- 0.03  g 假设敏感（留存≈0，增长依赖提价/新品/市占率，1% vs 2% 的 g 影响约 5 元）
= 0.50 + 0.20 - 0.15 = 0.55
```

> 苏泊尔业务易理解、估值不复杂，不似成长科技股仅 0.4 以下；但四变量（2026 利润降幅、2027 恢复、SEB 订单、派息维持）使确定性定为 0.55（中低），较初稿 0.58 略下调。

## 估值风险与需要修正的假设

1. 若 2026H2 内销/出口进一步走弱，基准 EPS 需向保守情景（2.39）靠拢，合理价下移至 ~35 元。
2. 若公司降低派息率以留存现金（2026 短期借款新增 + 应收上升信号），DDM/股息率估值需按新 DPS 重算，可能下修。
3. 若炊具品类延续 +5% 增长且新品类放量带动整体转正，合理 PE 可回升至 P20（17.3x），价值上修至 42 元。

## 估值证伪条件

1. 内销/出口收入持续下降且毛利率下行，目标 PE 应降至 14 倍以下。
2. OCF 持续低于净利润、分红难以由自由现金流覆盖，DDM 价值需下修。
3. AI 广告事件后品牌份额实质流失（明火炊具/电饭煲市占率下滑），品牌护城河折价。
