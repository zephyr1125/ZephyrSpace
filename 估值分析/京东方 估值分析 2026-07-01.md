## 三、多方法估值

### 方法论说明

京东方是**重资产强周期面板制造企业**，PE在周期低谷会极端高估（当前54x），在周期高峰会极端低估（2021年仅5x）。因此估值必须以**PB、EV/EBITDA、归一化盈利**为核心，PE仅作参考。

选用的4种方法及权重：

| 方法 | 权重 | 选择理由 |
|---|---|---|
| PB-周期分位法 | 35% | 面板重资产行业，PB比PE可靠；结合历史PB带判断周期位置 |
| EV/EBITDA | 25% | 重资产行业标准方法，消除折旧政策差异 |
| 逆向DCF | 20% | 验证当前市值隐含的FCF增长预期 |
| 归一化PE | 20% | 以中周期盈利替代TTM盈利，规避周期底部PE失真 |

### 方法1：PB-周期分位法（权重35%）

**输入参数**：

| 参数 | 值 | 来源 |
|---|---|---|
| BVPS（归母每股净资产）| **3.62 CNY** | 理杏仁 MC=3215亿 / PB=2.40x / 总股本370.44亿股 |
| 历史PB最低 | 0.86x | 2022年周期谷底（eniu.com） |
| 历史PB最高 | 2.48x | 2021年超级景气峰（eniu.com） |
| 近5年PB均值 | **1.38x** | 2020-2025年均值：(1.79+1.92+1.07+1.16+1.18+1.16)/6 |
| 近5年PB中位数 | **1.17x** | 接近2023-2025年PB中枢 |
| 当前PB | **2.40x** | 理杏仁 2026-06-30 |

**PB分位判断**：当前PB 2.40x处于近6年历史的**第95分位以上**（接近历史峰值2.48x），意味着市场在定价接近2021年超级景气水平的净资产回报预期。

**结构性调整论证**：2022年后面板行业发生了结构性变化，可能部分支撑更高的PB中枢：
1. 韩国LCD产能全面退出 → 大陆双寡头格局确立（京东方+TCL华星CR2>50%）
2. OLED业务从无到全球第二 → 第二增长曲线逐步兑现
3. 2025年首次股东回报规划（35%派息+45亿回购）→ 资本配置改善
4. 2027年后capex显著下降 → FCF拐点预期

给予结构性溢价**+0.25x PB**，调整后中周期合理PB中枢：1.17 + 0.25 = **1.42x**

| 情景 | 合理PB | 对应股价 | 逻辑 |
|---|---|---|---|
| 保守（周期底部）| 1.05x | 3.80 CNY | 略高于2022年谷底0.86x，反映行业结构改善 |
| **基准（中周期）** | **1.45x** | **5.25 CNY** | 5年均值1.38x + 结构性溢价0.25x，略有上浮 |
| 乐观（景气回暖）| 1.80x | 6.52 CNY | 接近2020年均值1.79x，假设OLED盈利+LCD价格温和上涨 |

**PB-ROE理论验证**：
- 归一化ROE(中周期) ≈ 5.0%（2020-2025扣非净利均值约53亿 / 净资产约1340亿 ≈ 4%，加回折旧高峰后的改善预期，上调至5%）
- 权益成本 r ≈ 10%（A股工业股标准）
- 可持续增长率 g = ROE × (1-payout) = 5% × 65% = 3.25%
- 理论合理PB = (ROE - g) / (r - g) = (5% - 3.25%) / (10% - 3.25%) = 0.26x

> PB-ROE理论值极低（0.26x），原因在于ROE远低于权益成本。这一结果印证了深度分析的核心判断——面板行业是"辛苦钱"生意，股东回报长期不足。但市场定价通常不会完全按理论PB-ROE运行，周期股的投资价值在于"景气上行时的PB修复"，而非"长期持有的PB-ROE回报"。

**方法1结论：基准合理价 ≈ 5.25 CNY（PB 1.45x），较现价8.68 CNY低39.6%。**

### 方法3：逆向DCF（权重20%）

**问题**：当前市值3,215亿隐含了什么样的长期FCF增长预期？

**输入参数**：

| 参数 | 值 | 说明 |
|---|---|---|
| 折现率(WACC) | 9.0% | A股工业股标准 |
| 终端增长率 | 3.0% | 长期名义GDP增速 |
| 成长期 | 10年 | 标准假设 |
| 当前FCF(归一化) | ~100亿 | OCF~450亿 - 维持性capex~200亿 - 扩张性capex~150亿(2027年后消退) |
| 2027后FCF(估) | ~200亿 | capex高峰过后，OCF 450 - capex 250 |
| 终端PE | 15x | 一般制造业（面板无品牌溢价） |

**逆向求解**：当前EV ~3,395亿（含净债务180亿），反推隐含的FCF CAGR。

使用简化模型：假设FCF从100亿线性增长至稳态，终端PE=15x。

经过试算：
- 若FCF维持100亿零增长：EV现值 ≈ 100/0.09 + 100×15/(1.09^10) ≈ 1111 + 635 = 1746亿（远低于当前EV）
- 若FCF从100亿以6%增长至10年后258亿：EV ≈ 2070 + 1095 = 3165亿
- **当前EV 3395亿隐含FCF 10年CAGR ≈ 7.0%**

**含义**：市场在定价京东方FCF从当前~100亿以约7%的年化增速增长10年，至约200亿稳态水平。

**评估**：
- 2027年后capex下降确实会释放FCF（从~400亿降至~250亿）
- 但OLED业务尚未稳定盈利，LCD行业量增有限
- 7% FCF CAGR在面板行业历史上是偏乐观的假设
- 更合理的FCF CAGR：3-5%（LCD量稳+OLED渗透+成本优化）

| 情景 | 隐含FCF CAGR | 对应EV | 对应市值 | 对应股价 |
|---|---|---|---|---|
| 保守（FCF CAGR 3%）| 3.0% | ~2,400亿 | 2,220亿 | **5.99 CNY** |
| **基准（FCF CAGR 5%）** | **5.0%** | **~2,900亿** | **2,720亿** | **7.34 CNY** |
| 乐观（FCF CAGR 7%）| 7.0% | ~3,395亿 | 3,215亿 | **8.68 CNY** |

**方法3结论：基准合理价 ≈ 7.34 CNY（隐含FCF 10年CAGR 5%），较现价8.68 CNY低15.4%。**

### 方法4：归一化PE法（权重20%）

**核心思路**：用中周期归一化盈利替代TTM盈利，规避周期底部PE失真。

**归一化盈利计算**：

| 方法 | 计算过程 | 归一化归母净利润 |
|---|---|---|
| 6年均值(含2021超级景气) | (50.36+258.31+75.51+25.47+53.23+58.57)/6 | **86.91亿** |
| 5年均值(剔除2021极值) | (50.36+75.51+25.47+53.23+58.57)/5 | **52.63亿** |
| 2027E一致预期 | 智堡/券商一致预期(估) | **~80-100亿** |
| **采用：中周期归一化** | **均值剔除极端值的加权** | **~65亿** |

> 采用65亿作为归一化净利润的理由：(a) 剔除2021超级景气（258亿）的异常值；(b) 2022-2023年扣非为负，扣非口径核心业务亏损；(c) 2024-2025年为弱复苏期，归母净利53-59亿，但政府补助占比约28%；(d) 65亿相当于2025归母净利上浮约10%，反映OLED减亏和费用优化的温和改善预期。

| 参数 | 值 |
|---|---|
| 归一化归母净利润 | **65亿 CNY** |
| 总股本 | 370.44亿股 |
| 归一化EPS | **0.175 CNY/股** |

**PE倍数选择**：

京东方历史上PE波动极大（4.29x~70.90x），用历史PE均值（~25x）需要结合行业结构变化调整。

| 调整项 | PE调整 | 理由 |
|---|---|---|
| LCD双寡头格局确立 | +3x | 行业竞争格局改善，盈利稳定性提升 |
| OLED第二增长曲线 | +2x | 全球第二，成长性溢价 |
| 股东回报制度化（35%派息）| +2x | 从"不分红"到"有底线"，DCF价值提升 |
| 国企治理折价 | -3x | 资本配置历史差，代理人问题 |
| 强周期属性 | -3x | 面板价格周期不可消除 |
| **调整后合理PE** | **~26x** | 基准25x +1x |

| 情景 | PE | 对应股价 | 逻辑 |
|---|---|---|---|
| 保守（周期底部PE）| 20x | **3.50 CNY** | 2023年PE低点参考，盈利低谷时PE应收缩 |
| **基准（中周期PE）** | **26x** | **4.55 CNY** | 归一化EPS 0.175 × 26x |
| 乐观（景气回升PE）| 32x | **5.60 CNY** | 假设面板价格回升+OLED盈利 |

**方法4结论：基准合理价 ≈ 4.55 CNY（归一化PE 26x），较现价8.68 CNY低47.6%。**

> 归一化PE法给出的估值最低，因为它用的是"正常化盈利"而非"周期回归盈利"。这意味着**即使京东方盈利恢复到正常水平（65亿），PE回到25-30x区间，股价合理位置也仅在4.5-5.5元区间**。当前8.68元的价格实际上在定价"景气回归"级别的盈利（120-150亿归母净利润）。
