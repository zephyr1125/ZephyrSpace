### 方法 3：DDM（下限锚，权重15%）

| 参数 | 值 | 说明 |
|---|---|---|
| DPS₀ (TTM) | 1.043 元 | 2025中期0.353+末期0.59+特别0.10 |
| 分红增长假设 g | 3% | 利润下滑，g下调 |
| 权益成本 Ke | 9.0% | A股央企 |

```
P = DPS₁ / (Ke - g) = 1.043×1.03/(0.09-0.03) = 17.90 元
```

**结论：合理价 ≈ 17.90 元（-25.9% vs 现价）——仅作安全边际下限锚**

> 单阶段永续DDM对处于并购整合期、分红政策调整期、盈利暂时下降的华润三九参数敏感度过高（Ke从9%改8.5%、或g从3%改3.5%都会使估值大幅波动）。17.9元仅作下限锚，不给25%重权。

### 参考（不计权重）：FCF Yield 与 PEG 的失真说明

- **FCF Yield（不计权重）**：原框架假设"2026E OCF 50亿 - 维护性Capex 16亿 = FCF 34亿"，但16亿维护性Capex仅为"营收5-6%"的行业比例假设。华润三九刚完成天士力大并购，同时拥有大量生产基地、新药研发、技改项目、并购子公司，扩张性资本开支与维护性Capex未拆分，34亿FCF不可复核。"FCF Yield 8.5%、明显低估"的结论暂不采信。
- **PEG（删除）**：2026年负增长使PEG失效；改用2023→2026的3年CAGR（~5%）又跨越昆药、天士力两次并购，拿"2023年老公司利润"与"2026年含两笔并购的集团利润"算CAGR，经济意义很弱。
