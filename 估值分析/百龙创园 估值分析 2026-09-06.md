## 风险与催化剂（2026H1 更新）

### 上行催化剂
1. **可转债证监会注册通过 + 泰国顺利融资** → 消除资金缺口不确定性，摊薄落地明朗。
2. **2026H2 干燥扩产爬坡放量** → 若 H2 收入增速重回 20%+，2026E EPS 有上调空间。
3. **阿洛酮糖国内提货回补 + 结晶果糖原料降本** → 毛利率再上行 + 国内收入弹性。
4. **若美国关税缓和/泰国提前** → 风险折价收窄，估值修复。

### 下行风险
1. **美国关税升级**（2025 美国收入占 42.63%）→ 2026H2-2027 盈利下修。
2. **可转债证监会不注册/发行失败** → 泰国资金缺口需高成本补足。
3. **Q2 动能放缓延续（剔除汇兑后 H2<15%）** → 2027E 一致预期下修。
4. **汇兑继续侵蚀 + 窦光朋质押扩大** → 利润与治理双重折价。
