## 正常化盈利

投行盈利具有天然波动性，正常化估值必须使用跨周期中枢：

| 财年 | Adj. EPS | 说明 |
|---:|---:|---|
| FY2021 | $4.62 | |
| FY2022 | $7.10 | 峰值 |
| FY2023 | $4.54 | |
| FY2024 | $4.49 | 官方数据，非初版错写的~$5.30 |
| FY2025 | $6.29 | |
| FY2026 | $7.56 | 历史峰值 |
| Q1 FY2027年化 | ~$5.40 | |

FY2021-FY2026简单平均：$(4.62+7.10+4.54+4.49+6.29+7.56)/6 = **$5.77**。

考虑业务规模扩大（GCA并表、MD人数从FY2021的~200增至354）、FVA稳定增长，将长期正常化EPS适度提高至**$6.00**——已是六年平均值的104%，足够反映结构性改善。

正常化FCF约$6.75/股（HLI capex极低，OCF与FCF高度接近，扣除SBC抵消所需回购后）。

## 方法一：中周期PE（权重40%）

HLI的#1三项排名和三段式模型支持相对于纯并购精品投行的溢价。但FY2022-2023间EPS曾下降约36%，周期性是真实的。

给予中周期Adj. EPS 18倍（Evercore/Moelis 14-16x与Moody's/S&P 22-25x之间）：

`$6.00 × 18 = $108`。

本方法结果：**108美元**。

## 方法二：FCF收益率（权重35%）

正常化FCF约$6.75/股。投行FCF含金量高（capex极低），但波动性要求更高收益率。

给予5.9%正常化FCF收益率（接近6%，反映Q1-15.6%不确定性）：

`$6.75 / 5.9% = $114.4`。

本方法结果：**114美元**。

## 方法三：简化DCF（权重25%）

- 起始FCF：$6.75/股
- 前五年增长：5%
- 折现率：9.0%
- 永续增长：2.5%

| 年份 | FCF/股 | PV @9% |
|---:|---:|---:|
| 1 | 7.09 | 6.50 |
| 2 | 7.44 | 6.26 |
| 3 | 7.81 | 6.03 |
| 4 | 8.20 | 5.81 |
| 5 | 8.61 | 5.60 |
| **前五年PV合计** | | **30.20** |

终值：$8.61 × 1.025 / (9.0% - 2.5%) = $135.80

PV of 终值：$135.80 / 1.09⁵ = $88.30

DCF合计：$30.20 + $88.30 = **$118.50**。

本方法结果：**119美元**。

## 确定性与仓位

0.55的偏低确定性来自：

- 交易关闭时点无法准确预测，单笔收费结构波动很大。
- Q1 CF交易数量未降但收入下降24%——费率波动比交易量更难预测。
- FY2022-FY2023间EPS曾下降约36%，年度盈利回撤可极深。
- 当前无法确定Q1是暂时扰动还是新一轮下行。
- Intrepid交易价格与未来盈利贡献未披露。
- 现金流受奖金支付、SBC和回购方式影响。
- Pipeline没有合同式确定性。

但不必降至0.50以下：无重大债务、三条业务线有真实互补、品牌地位强、数据相对透明。

公司质量80、管理层81、双评分合计161，达到A_CORE标准。
