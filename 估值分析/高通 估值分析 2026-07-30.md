## 三、多方法估值

### 方法选择矩阵

> ⚠️ 此前版本包含 PVGO 作为独立方法（10% 权重）——但 PVGO 与 PE 分位和逆向 DCF 高度重复，且其"EPS/Ke = 无增长价值"的假设忽略了维持研发、Capex 和营运资本所需的再投资。本次移除 PVGO 独立权重，重新分配至 FCF Yield 和逆向 DCF。

| 方法 | 适用性 | 权重 | 说明 |
|---|---|---|---|
| **FCF Yield** | 🔴 最适用——FCF 仍是高通估值最可靠锚点 | **30%** | ⬆️ +5%（承接 PVGO 权重） |
| **PE 历史分位** | 🟡 适用——转型期 PE 中枢需下调 | **20%** | — |
| **逆向 DCF** | 🟡 适用——验证市场对转型期的隐含定价 | **25%** | ⬆️ +5%（承接 PVGO 权重） |
| **PEG（through-cycle）** | 🟡 有限——需穿越 trough→恢复周期 | **15%** | — |
| **EV/EBITDA** | 🟡 辅助——倍数随利润率走弱而下调 | **10%** | — |

### 方法 3：逆向 DCF（权重 25%）

**核心问题：当前股价隐含了多高的长期 FCF 增长率？**

| 参数 | 值 |
|---|---|
| 基准 FCF/股 | **~$9.50**（FY2026E 正常化） |
| 折现率（WACC） | **9.0%** |
| 成长期 | **10年** |
| 终值 FCF Yield | **7.0%**（→ 终值倍数 ~14.3x） |

> ⚠️ 此前版本使用 EPS 而非 FCF 构建 DCF，且增长率和估值之间的敏感度结构可疑（2.5%→$143, 5%→$150, 8%→$204）。本次使用 FCF 为锚、终值 FCF Yield 替代终值 PE，消除重复计价。

**逆向求解**：

| 隐含 10Y FCF CAGR | 对应估值 | 判断 |
|---|---|---|
| **~3.5%** | ~$156（当前价） | 市场隐含——接近仅靠回购增厚 |
| 2% | ~$124 | 悲观——零有机增长 |
| 5% | **~$145** | 基准——回购 ~2.5% + 有机 ~2.5% |
| 7% | ~$172 | 乐观——汽车/DC 超预期 |

| 情景 | FCF CAGR | 合理价 |
|---|---|---|
| 保守 | 2% | $124 |
| 基准 | 5% | **$145** |
| 乐观 | 7% | $172 |

**结论：合理价 ≈ $145（基准），vs 现价 $155.68 轻微溢价**

### 方法 4：PEG（through-cycle）（权重 15%）

> 传统 PEG 在 EPS 负增长期失效。采用周期穿越法：从 FY2027E trough（~$9.50）→ FY2029E 恢复（~$12.00），2Y CAGR ≈ 12%。

| 输入参数 | 值 |
|---|---|
| FY2027E trough EPS | ~$9.50 |
| FY2029E 恢复 EPS | ~$12.00 |
| Trough→恢复 2Y CAGR | **~12%** |
| 转型期合理 PEG | **1.25x** |
| 隐含 PE（on FY2027E） | **15x** |
| FY2027E 合理价 | **$143** |
| 折现至当前（1.5Y @ 9%） | **~$126** |

> ⚠️ 此前版本出现了 $143 折现为 $120 和 $131 两个不同数字的计算不一致。修正后统一为 $143 / (1.09^1.5) ≈ $126。

**结论：合理价 ≈ $126（through-cycle 基准），vs 现价 +23% 溢价**

> PEG through-cycle 天然偏保守——它要求投资者等待 FY2027 trough 确认后再折现回来。对于愿意承受转型期波动的长期投资者，这个价格的参考价值有限。这也是给予 PEG 仅 15% 权重的原因。

## 六、关键验证节点

下一次最重要的验证不是 Apple 份额本身，而是：

1. 中国 Android 手机收入是否如承诺在 Q4 恢复双位数环比增长
2. QCT 利润率是否在 23-25% 见底
3. 价格调整能否覆盖晶圆、封装及内存成本
4. 库存能否从 $8.379B 开始下降
5. FY2027 数据中心收入是否真正按 $5B 路径确认
6. 回购和分红是否重新回到 FCF 覆盖范围内
7. 数据中心增长是否具备与手机芯片相近的利润率
