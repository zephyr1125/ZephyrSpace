# 中国财险估值分析（2026-08-28）

> 本次基于 2026H1 中期业绩更新估值。核心变化：归母净资产升至 3,036.88 亿元（BVPS ≈ 15.89 港元），股价已升至 15.98 港元（PB ≈ 1.0x）。合理价中枢上调至 **15.5 港元**，`valuation_certainty` 0.64。

## 结论

财险公司不适用传统自由现金流 DCF。以 2026H1 末净资产、正常化 ROE 12–13%、承保质量确认和跨周期投资收益为基础，采用剩余收益（P/B-ROE）与股息率交叉验证，对华夏银行联营投资显式保留折价后，取 **15.5 港元**为合理中枢，`valuation_certainty` **0.64**。**当前股价 15.98 港元已高于合理中枢，安全边际基本消失，属「已充分定价」而非「纪律买点」。**

## 为什么不是 PE 法

2026H1 净利润 322.84 亿元（+32%）包含承保改善与投资收益弹性。PE 无法区分准备金、资本占用和权益市场带来的当期收益，且 H2 强季节性使 H1 年化 EPS 严重失真。对财险公司，更合理的锚是「P/B-ROE 剩余收益 + 股息率 + PB 情景」。（对照 valuation SKILL 保险业框架：寿险常用 P/EV + NBV 倍数，但**非寿险 P&C 无内含价值/新业务价值概念**，故以 P/B-ROE 为主锚。）

## 剩余收益（P/B-ROE）框架

假设权益成本 11%，正常化 ROE 12–13%（2025 年 14.7% 为高基数，2026H1 未年化 10.9%，H2 季节性使全年中性 ROE 落在 12–13% 区间），保留收益支持保费增长与偿付能力，合理 PB 约 0.92–0.98 倍。

| 情景 | 正常化 ROE | 合理 PB | 每股价值（BVPS 15.89 港元）|
|---|---:|---:|---:|
| 承保恶化、投资回落 | 10% | 0.75x | 11.9 港元 |
| 承保稳定、投资常态化 | 12%–13% | 0.92–0.98x | 14.6–15.6 港元 |
| 车险效率延续、非车险修复 | 14%+ | 1.15x | 18.3 港元 |

2026H1 承保执行（CR 94.0%、费用率 -0.9pp、市占率 33.3%）小幅支持中性情景，但农业险 +4.2pp 恶化、责任险仍亏损、净利弹性依赖投资收益，这些使模型不把 H1 表现完全外推。基准中枢取中性情景上沿附近 ≈ 15.5 港元。

## 股息率视角（下限支撑）

- 2025 年 DPS 0.68 元（0.79 港元）→ 现价收益率 4.9%；
- 2026 中期股息 0.34 元（+41.7%），若全年 DPS 升至 0.75–0.80 元（0.87–0.93 港元），现价收益率 5.5%–5.8%；
- 以 6% 要求收益率、0.91 港元 DPS 反推 → 支撑价约 15.1 港元；以 5.5% 反推 → 16.5 港元。

股息率视角与 P/B-ROE 方向一致：**15–16 港元是合理区间，现价 15.98 已处于区间上沿。**

## 华夏银行折价处理

账面 518.61 亿元 vs 市值 163.79 亿元，折价约 355 亿元（对应每股约 1.6 元人民币、≈1.86 港元负贡献）。估值保留折价：即便华夏银行 VIU 测试通过，其市值持续低于账面意味着这部分资产的「公允价值」依赖管理层假设，不应按账面全额计价。折价在剩余收益框架中已通过「正常化 ROE 而非单年高投资收益」和「合理 PB ≤ 1.0x」体现。

## valuation_certainty 认定（0.64）

| 评估项 | 判断 |
|---|---|
| 盈利可预测性 | 承保端改善确认但 H2 季节性/巨灾不可控；投资收益波动大 → 中等 |
| 商业模式与资本强度 | 财险商业模式稳定，资本监管框架清晰 → 较高 |
| 资产负债表与融资需求 | 偿付能力 237.2%，无频繁再融资，清晰 → 较高 |
| 方法收敛度 | P/B-ROE / PB 情景 / 股息率收敛于 15–16 → 较高 |
| 尾部风险 | 农业巨灾、投资市场、监管、华夏银行减值 → 中等偏高 |

**闭合推导**：`0.5（基线）+ 0.06（H1 承保执行确认：CR 94.0%、费用率 -0.9pp 已兑现）+ 0.05（资产负债表清晰：偿付 237.2%、无频繁再融资）+ 0.03（估值方法收敛于 15–16 港元）− 0.00（尾部风险已通过正常化 ROE 与华夏折价内置）= 0.64`。

0.61 → **0.64**：2026H1 承保执行与分红信号小幅提高了合理中枢的可信度；但全年承保（H2 农业险）未验证、投资收益依赖度仍高、股价已到区间上沿，限制其上探更高档。

## 反证与验证

关键验证点是 **2026 全年业绩（2027 年 3 月）**：① 全年综合成本率能否守住 97% 以内；② 农业险 H2 是否重演 2025 年的巨灾亏损；③ 投资收益常态化后 ROE 能否保持 12%+；④ 华夏银行市值折价是否收敛。若承保利润持续扩张而投资收益回落，估值确定性上升；若利润仍主要来自行情或农业险亏损失控，目标价需下调。
