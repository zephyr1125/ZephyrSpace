## 三、多方法估值

### 方法一：PE（正常化盈利 × 周期中枢倍数）（权重 45%）

> 资源/周期股禁用纯 TTM/峰值 PE，改用正常化 EPS。天山为**行业成本曲线最左端 + 低负债 + 50% 派息承诺**的低成本龙头，给予周期中枢 PE 9–11x（商品制造中枢 8x 上浮至 10x）。

| 参数 | 值 |
|---|---|
| 正常化 EPS（基准） | 1.19 元（预测/推算，本报告模型） |
| 中枢 PE | 10x |
| 合理价 | 1.19 × 10 = **11.9 元** |

| 情景 | EPS | PE | 合理价 |
|---|---|---|---|
| 保守 | 0.97 | 9x | 8.7 |
| 基准 | 1.19 | 10x | 11.9 |
| 乐观 | 1.51 | 11x | 16.6 |

**结论：合理价 ≈ 11.9 元（-9% vs 现价 13.13）**

### 方法二：DDM（股利折现，严格 Gordon）（权重 30%）

| 参数 | 值 |
|---|---|
| 正常化 DPS（D0，按正常化 EPS 1.19 × 派息率 50%） | 0.60 元 |
| g（永续增长，产能受红线约束取低值） | 2.5% |
| Ke（A 股资源股） | 8.5%（区间 8.0–9.5%） |
| D1 = D0 × (1+g) | 0.615 元 |
| 合理价 = D1/(Ke−g) | 0.615 / (0.085−0.025) = **10.25 元** |

- 敏感性（D1=0.615）：Ke 9.5%/g2.5% → 8.8；Ke 8.0%/g2.5% → 11.2；Ke 8.5%/g3.0% → 11.2。DDM 区间约 **8.8–11.2 元**。
- 若按 2026 峰值盈利派息（DPS ~0.86，预测情景）则 DDM ≈ 12-13 元——但那隐含周期盈利永续假设，本报告不作主结果。

**结论：合理价 ≈ 10.3 元（-22% vs 现价）**（DDM 对周期股利最敏感，代表"以可持续股利贴现"的底线视角。）

### 方法三：FCF Yield（正常化自由现金流）（权重 25%）

| 参数 | 值 |
|---|---|
| 正常化 OCF（净利 55 亿 × 净现比 ~1.1） | ~60 亿 |
| 维护性 capex（近年 12–15 亿） | ~15 亿 |
| 正常化 FCF | ~45 亿（= 0.97 元/股） |
| 要求收益率（周期+未来印尼 capex 折让） | 8.0% |
| 合理价 | 0.97 / 0.08 = **12.1 元** |

- 口径说明：FCF 仅扣**维护性 capex**，印尼一期约 9-10 亿美元（~70 亿 RMB）为**价值创造型成长开支**，分 2027 后数年投放（约 0.35-0.40 元/股/年）；若将其视为纯消耗（无回报），FCF 锚相应降至 ~0.6 元 → 7.5-9 元。即 FCF 区间 **9–12 元**。

**结论：合理价 ≈ 12.1 元（-8% vs 现价）**

### 诊断方法（不进入加权）

**方法四：P/B–ROE（周期底线性验证）**

- 正常化 ROE ≈ 55 亿 / 平均净资产 ~310 亿 ≈ **17%**（预测/推算）。
- 合理 PB = (ROE−g)/(Ke−g) = (0.17−0.025)/(0.095−0.025) = 2.07x（Ke 9.5）至 2.6x（Ke 8.0/g2.5 → (0.145)/0.055=2.64）。
- 对应股价 = PB × BVPS 6.94 = **14.4–18.3 元**；当前 PB 1.89 对应 ROE≈15.5%（若市场要求 Ke9.5、g2.5）。诊断结论：若正常化 ROE 能守住 17%，PB 法显示当前未高估；分歧主要在对 ROE 可持续性与 Ke 的假设。

**方法五：逆向 DCF / PVGO（诊断，无正式权重）**

- 现价 13.13 元：Ke 9%、g=0 → 隐含永续 EPS = 13.13×0.09 = **1.18 元**；Ke 9%、g=2.5% → 隐含 EPS ≈ 0.85 元。
- 解读：**当前价格已隐含"正常化盈利（~1.19 元/股）零增长甚至含 2.5% 增长假设的较低档"的定价**——即市场**没有**为 140 万吨满产/印尼/深加工增长支付溢价，甚至对 2026H1 峰值盈利做了相当程度的均值回归折价。当前股价隐含预期并不贪婪，但也不便宜。
- 券商目标价 19-22 元隐含的是"2026E 峰值 86 亿 + PE 10-12x"，即**峰值盈利线性外推**口径；与本报告正常化口径（目标 11.4）差异根源在对铝价中枢与盈利可持续性的假设不同，属合理分歧、非数据错误。

## 四、综合加权 + 价格区间

### 方法独立性声明（强制）

| 方法 | 权重 | 独立性说明 |
|---|---|---|
| PE（正常化） | 45% | 与 DDM/FCF 共享正常化盈利假设（55 亿），但锚定"盈利 × 市场相对倍数"，角度不同 → **弱相关** |
| DDM | 30% | 由 DPS 折现，强依赖派息率假设；与 PE 共享盈利假设，额外引入 Ke/g → **弱-中相关** |
| FCF Yield | 25% | 由现金流折现，与盈利类方法同源（净利润/OCF），引入 capex 与折现率 → **弱相关** |

- **共享假设警示**：三个正式锚的盈利基数（正常化 55 亿 / EPS 1.19）同源，其"收敛"部分是同一假设的三种资本化，非三个独立验证。真正的分歧在倍数/折现率/派息/维护capex假设上，故加权结果本质是"给 55 亿正常化盈利找一个合理综合倍数（约 9.6x）"。敏感性矩阵已覆盖倍数区间。
- 诊断方法（P/B-ROE、逆向 DCF）不加权，仅作交叉验证。

### 加权合理价

| 方法 | 合理价 | 权重 | 加权贡献 |
|---|---|---|---|
| PE（正常化） | 11.9 | 45% | 5.36 |
| DDM | 10.3 | 30% | 3.09 |
| FCF Yield | 12.1 | 25% | 3.03 |
| **加权合理价** | | | **11.48 ≈ 11.5 元** |

- 因 DDM 强相关于派息/折现假设、FCF 依赖维护capex口径，且共享盈利基数，取**机械加权 11.5 元**作为中枢；对盈利正常化与倍数假设的敏感性见下节，故**合理价中枢定为 11.4 元**（考虑印尼成长capex 前置与 DDM 折价权重略作平滑，不做额外溢价/折价）。→ **合理价 = 11.4 元**

> 一致性校验：11.4 元 ≈ 正常化 EPS 1.19 × 9.6x ≈ 正常化 FCF 0.97 / 8.5%——与成本曲线最左端龙头的周期中枢定位自洽；对照现价 13.13 元（-13%）。

## 五、风险与催化剂

### 估值核心风险
1. **商品价格假设误差（最大变量）**：基准假设铝价中枢 2.1 万、氧化铝正常化。若铝价快速回落至 1.9 万以下或氧化铝重回 3,200+，正常化 EPS 下行至 0.9 以下，合理价中枢同步下修至 9-10 元。
2. **UFLPA 二元事件**：2026-08-03 生效，若下游供应链传导实质化或外资持续回避新疆标的，估值折价扩大（对应 PB 中枢下移 10-20%）。
3. **印尼 capex 回报**：一期约 9-10 亿美元（~70 亿 RMB）若投产推迟/回报低，侵蚀 FCF 与 ROIC。
4. **实控人减持/质押**：若出现第二轮实质减持或质押率上行，压制估值。

### 催化剂
1. 铝价维持高位 + 氧化铝价格受控 → 2026 全年实际净利落在 80 亿级（预测情景），短期 EPS 惊喜。
2. 印尼 200 万吨氧化铝/几内亚项目投产里程碑兑现，强化"资源自给 + 降本"叙事，可上修正常化盈利中枢。
3. 分红：2026 承诺 ≥50% 兑现 + 若提高频率，股息率视角支撑估值（当前静态股息率 4.2%）。
4. UFLPA 若出正式合规/溯源方案并获客户背书，折价修复。
