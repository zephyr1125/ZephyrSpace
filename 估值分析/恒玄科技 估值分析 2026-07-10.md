### 方法 5：PVGO（增长机会现值）（权重 10%）

**逻辑**：将股价拆分为"稳态价值"和"增长期权价值"，判断市场预期是否合理。

| 参数 | 值 |
|---|---|
| Normalized EPS（2026E） | ¥3.05 |
| Ke | 9.0% |
| SSV/股（稳态价值） | ¥3.05 / 0.09 = **¥33.89** |
| 当前股价 | ¥117.15 |
| PVGO/股 | ¥117.15 - ¥33.89 = **¥83.26** |
| 实际PVGO% | 83.26 / 117.15 = **71.1%** |

**PVGO%判断**：

| 项目 | 值 |
|---|---|
| ROIC vs WACC | ROIC≈ROE=8.4% < WACC≈9% — 当前资本回报低于成本 |
| 护城河 | ⭐⭐⭐ 中（品牌客户认证壁垒） |
| 合理PVGO%判断 | **50%**（ROIC<WACC应给予折价，但BES6100+AI眼镜期权价值支撑一定溢价） |
| 合理价 | SSV / (1-50%) = ¥33.89 / 0.5 = **¥67.78** |

**≈ ¥68（基准）**

> ⚠️ PVGO法给出极低的估值（¥68），核心原因是当前ROIC（8.4%）低于WACC（9%），导致理论上的"稳态价值"极低。这暴露了恒玄估值的核心矛盾：**71%的股价来自对未来价值创造的预期**——如果BES6100和AI眼镜不能兑现（提升ROIC至>WACC），当前股价将面临重大的"预期修正"风险。
>
> PVGO的合理价¥68是"如果公司永远保持当前ROIC"的理论价格，不代表目标价。正向解读：如果BES6100成功→ROIC升至15%+→合理PVGO%升至60-70%→合理价¥85-113。这恰恰说明了BES6100对估值的关键性。
