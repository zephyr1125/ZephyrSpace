# 华润万象生活估值分析（2026H1 更新 · 终审 40 港元）

> 关联公司页：[[01-公司/华润万象生活]]　关联深度分析：[[深度分析/华润万象生活 深度分析 79 2026-09-06]]　关联管理层档案：[[管理层档案/华润万象生活 管理层档案 77 2026-09-06]]
>
> **版次说明（强制）**：本版为 **2026H1 财报更新 · 终审修正版**。终审判定较当日初稿下调：**target 43→40 港元、certainty 0.62→0.55、机械买入价 33→30.28 港元**。下调原因：① 撤销对「长期（≥4 年）100% 分派」的过度认可（实际中期 100% 分派仅 2025/2026 两年，此前 28%-36%）；② 采用更完整的资产与资金口径——商誉 16.41 亿 + 客户关系无形 10.75 亿 + 租赁负债约 21.9 亿，现金非全部可即时支配，目标价不宜再按初稿 43 港元；③ 第三方收入分类边界（华润集团与第三方开发商）使商管质量的倍数支撑下修至 18x。方法由「PE45/DDM30/FCF25」改为 **Forward PE 60% + 正常化 FCF 40%，DDM 仅作敏感性、不入正式权重**。

## 估值结论

**合理价值：40 港元/股；估值确定性：0.55；机械买入价：30.28 港元。**

截至 2026-09-04 收盘价 **41.26 港元**，约为核心 FY2026E EPS 的 **18.7 倍**，**已高于 40 港元合理中枢约 +3%**。**结论：当前价不是买点；不建仓、不加仓。** 按纪律，跌至机械买入价 30.28 港元才进入建仓区（距现价约 −26.6%）。公司质量（B_GROWTH）仍值得跟踪。

## 0. 先统一口径（本版强制）

1. **货币**：财报人民币、交易港元。汇率取 **RMB1 ≈ HKD1.16**（公司 2026 中期股息换算中间价 0.8654 与即期 0.855 交叉；HKDCNY 2026-09-05 = 0.8545，yfinance）。汇率是股价级敏感项。
2. **股份数**：2,282,500,000 股（无摊薄）。FY2025 核心净利 39.50 亿 → FY2026E 核心按 +10% ≈ 43.5 亿元 → **核心 EPS ≈ 1.90 元 ≈ 2.21 港元**。
3. **股息口径（终审修正）**：中期股息 0.586 + 特别中期 0.391 = 0.977 元/股，= 中期核心净利 100% 分派。**但公司演示稿披露的中期派息历史为：2022=28%、2023=36%、2024=36%、2025=100%、2026=100%**——「中期即 100%」仅是近两年特征，此前中期只派 28-36%、缺口在末期补足。特别股息同样只有近两年的每期派发记录。**任何把高派息当作长期/永续承诺、并据此抬估值的做法，本次不再采纳。**
4. **FCF/现金口径（终审修正）**：① 无银行贷款属实，但租赁负债合计约 21.88 亿元（流动 1.48 亿 + 非流动 20.41 亿）、1H26 财务费用 0.54 亿即租赁利息；② 现金总额约 168 亿（公告，含受限制银行存款及理财存款）或演示稿「在手现金」171.3 亿（含定期存款 + 按公允价值计量金融资产）都**不是全部可即时自由支配**，且含已宣告未派发股息 19.4 亿；③ 计算可分配现金流时需扣租赁付款与少数股东股息。本文采用**整体股权口径**（PE/FCF 的盈利分母已含现金类收益），**不把 171 亿现金全额再加回**（避免双重计值）；正确的替代做法是「剔除对应投资收益后单独估值剩余现金」或「整体股权估值」，两者择一，不得叠加。
5. **不并入上市公司 FCF 的项目**：业主端租金 171 亿 / NOI 117 亿 / 商场零售额 1,485 亿是受托资产经营指标，只作商管能力验证，不按等额收入/利润计入（上市公司当期租赁类收入仅 4.86 亿元）。

## 1. 方法与权重（含独立性声明，强制）

| 方法 | 权重 | 本版定位 | 说明 |
|---|---:|---|---|
| 正常化 Forward PE | **60%** | 主锚 | 商业占分部经营溢利约 72.5%，以 EPS 表达；倍数 18x（终审判定，见 §2） |
| 正常化 FCF Yield | **40%** | 现金流交叉锚 | 以可分配 FCF 验证派息与价值基础；要求收益率 5.25%（见 §3） |
| DDM | — | **仅敏感性，0% 正式权重** | 高派息但历史短、特别股息可裁量；且 100% 派息下 DDM≈盈利资本化，与 PE 高度同源，不入权重 |

**独立性声明（强制）**：华润万象生活 ≈100% 分派核心净利的净现金服务公司，三个信号（PE / FCF / DDM）共享同一「核心盈利能力」驱动。PE 与 FCF 均以 2026E 核心 EPS 为分子基础，**并非相互独立**；**两种方法收敛不构成「独立证据叠加」，因而不提高确定性**（certainty 只给 0.55）。DDM 保留敏感性矩阵以暴露「特别股息假设」的敏感性，但不参与加权、更不作价值硬下限（特别股息若取消、留存现金用于有效投资，仍属股东价值，21 港元只是特定低派息低增长假设下的结果）。

## 2. 正常化 Forward PE：≈39.7 港元（权重 60%）

以 FY2026E 核心 EPS ≈1.90 元 = **2.21 港元** @1.16 为盈利基准。

| 情景 | 2026E 核心 EPS（元） | EPS（港元） | 合理 PE | 价值（港元） |
|---|---:|---:|---:|---:|
| 保守 | 1.85（+6%） | 2.15 | 16.5x | 35.5 |
| 基准 | 1.90（+10%） | 2.21 | **18x** | **39.7** |
| 乐观 | 2.00（+15%） | 2.32 | 20x | 46.4 |

**基准 18x 的支撑（终审判定）**：商业端毛利 66.9%、占分部经营溢利约七成，本可给商管 24x+；但须叠加四项下修：① 物业航道毛利率 18.3%（-0.5pt）与劳动密集；② **资产质量折扣**——商誉 16.41 亿 + 客户关系无形 10.75 亿（≈27 亿、≈归母净资产 17%）、2025 已现退出终止确认，隐含减值/整合风险高于纯轻资产同业；③ **「第三方」证据含华润集团内项目**，独立第三方深度未验证，商管溢价的可持续性证据被下修；④ 高派息（100% 分派）仅近两年、现金流需扣租赁付款与少数股东股息。四者合意：**集团整体 18x**（低于初稿 19.5x）。悲观情形 16.5x ≈35.5 港元。

## 3. 正常化 FCF Yield：≈39.0 港元（权重 40%）

### 3.1 以 2025 年报实际现金流重建转换率（终审提供，非公司指引）

用 2025 年报综合现金流量表重建「可分配 FCF」（人民币亿元）：

| 项目 | 金额 | 说明 |
|---|---:|---|
| 经营活动现金流量净额 | +40.81 | 含已收利息的处理见下 |
| ＋已收利息 | +0.41 | 还原到权益口径（核心净利含利息收入） |
| －设备及投资物业资本支出 | −1.92 | 轻资产模式下的维持/少量扩张性支出 |
| －无形资产支出 | −0.19 | 客户关系/系统类无形购买 |
| －租赁付款 | −2.49 | 经营所需的租赁本金偿还（IFRS16） |
| －少数股东股息 | −0.98 | 付给非控股股东 |
| **≈ 可分配 FCF** | **≈35.64** | ≈ 核心净利 39.50 的 **90.2%** |

（FY2025 实际转换率 ≈90.2%；终审以其为基准取 **90%–95% 正常化转换区间**，中值 **92.5%**——该区间能否持续实现取决于物业收缴/长账龄应收与并购，属研究假设而非保证。）

### 3.2 FCF 资本化

FY2026E 核心净利 43.5 亿元 × 92.5% ≈ **40.2 亿元 ≈ 46.7 亿港元**。考虑资产质量（商誉/无形/租赁）、商业消费与写字楼周期、第三方证据不足、控股股东结构，**要求收益率取 5.25%**（高于纯公用事业；若按 5.0% 会隐含对现金流确定度过高的信任）。

| 可分配 FCF（亿港元） | 要求收益率 | 权益价值（亿港元） | 每股（港元） |
|---:|---:|---:|---:|
| 45.2（×89.5%） | 5.25% | 861 | 37.7 |
| 46.7（×92.5%） | 5.25% | 889 | **39.0** |
| 47.6（×95%） | 5.25% | 907 | 39.7 |

中枢取 **≈39.0 港元**。此处 FCF 与 PE 共享「核心净利 ≈ 可分配现金」的近似——一旦收缴/应收恶化使 OCF 持续低于核心净利，两锚会**同步下修而非相互对冲**。

## 4. DDM（仅敏感性，正式权重 0%）

**为什么不入权重**：中期 100% 分派仅 2025/2026 两年、特别股息可裁量；且 100% 派息下 DDM 本质是盈利的资本化（与 PE 同源），独立信息有限。保留它只为量化「特别股息假设」的敏感度。

若按「总 DPS = 核心 EPS（100% 持续）」：D0=1.90 元，V = D0×1.16×(1+g)/(Ke−g)。

| Ke ＼ g | 3.5% | 4.0% | 4.5% |
|---|---:|---:|---:|
| 10.0% | 35.1 | 38.2 | 41.9 |
| 10.5% | 32.6 | 35.3 | 38.4 |
| 11.0% | 30.4 | 32.7 | 35.3 |

若按「仅固定 60% 长期派息、特别部分取消」：D0=1.14 元、g=3.5%、Ke=10.5% → V≈21 港元。

**解读（终审判定）**：**21 港元只是「低派息 + 低增长」特定假设下的结果，不能当作公司价值的硬下限**——特别股息若取消，留存现金用于有效投资仍属于股东价值；同样，「100% 派息持续」下的 35–42 港元也不能当硬上限，因为轻资产公司可以靠提效、提价、接管项目实现增长，并不需要「靠留存」才能增长。DDM 的结论是：**现价 41.26 无论按哪种股息假设都缺乏安全边际**。

## 5. 加权估值与情景区间

\[
39.67\times60\% + 38.95\times40\% = 23.80 + 15.58 = 39.38 \approx \mathbf{40\ 港元}
\]

| 情景 | 经营假设 | 每股价值区间（港元） |
|---|---|---|
| 保守 | 消费转弱、物业毛利率 <18%、长账龄应收恶化、商誉/无形减值或特别股息压缩 | 34–37 |
| 基准 | 商业中高个位数内生增长、非置地占比续升、物业毛利率企稳 | **37–42** |
| 乐观 | 商业高景气延续 + 写字楼金融机构放量 + 募资并购兑现正回报 | 45–48 |

**目标价取 40 港元（机械加权取整 39.38）**。不附加任何「确定性溢价」。它是基准经营下盈利中枢的资本化值，不是未来 12 个月价格预测。

## 6. 估值确定性：0.55（闭合计算）

**certainty = 0.5 + X − Y**（研究确信度，非统计概率）

正向因子 X（合计 +0.18）：
- 商业模式易理解、运营 KPI（零售额/出租率/收缴率/非置地占比/新签合同额）逐季可验证 → +0.07
- FY2025 OCF/核心净利 103.3%、1H26 覆盖同比改善；无银行贷款 → +0.05
- 现金厚实（公告口径现金总额约 168 亿，剔除受限/定期/理财与租赁负债后仍宽裕）→ +0.04
- 2025/2026 连续执行 100% 分派 + 特别股息，股东回报有近两年实绩 → +0.02

负向因子 Y（合计 −0.13）：
- 资产质量：商誉 16.41 亿 + 客户关系无形 10.75 亿 + 租赁负债约 21.9 亿；长账龄应收累积、拨备率上行 → −0.05
- 独立第三方证据不足（35.4% 含华润集团内项目）→ −0.03
- 54.9 亿待配置募资并购 ROIC 无历史 → −0.03
- 人民币/港元汇率、消费与写字楼周期、特别股息可裁量 → −0.02

\[
0.55 = 0.5 + 0.18 - 0.13
\]

**口径声明**：0.62→0.55 的下调源于撤销对「长期（≥4 年）100% 派息记录」的过度认可，并纳入商誉/无形资产/租赁负债与现金分层的完整口径；**中期资料经审阅（非全面审计）不单独扣分**。0.55 = 中等确定性：商业模式与 KPI 可验证性使其高于周期制造类，但资产质量、独立第三方与并购回报的不确定使其低于 0.60。

## 8. 敏感性：影响 target 的四个开关

1. **汇率**（RMB→HKD 1.10 / 1.1555 / 1.17）：EPS 2.09 / 2.20 / 2.22 港元 → 加权中枢约 37.8 / 39.8 / 40.2 港元（±6%）。
2. **FY2026E 核心增速**（+6%/+10%/+15%）：EPS 1.85/1.90/2.00 元 → 中枢约 37 / 40 / 42 港元。
3. **可分配 FCF 转换率**（89.5%/92.5%/95%）：FCF 锚 37.7 / 39.0 / 39.7 港元 → 加权 38.9 / 39.4 / 39.9 港元。
4. **特别股息假设**：全部延续（DDM 35–42，辅助参考）vs 取消只留固定 60%（DDM ≈21，但留存若有效再投资仍属股东价值，非硬下限）。

**自检（强检验）**：本版未将 Reverse DCF / PVGO / PEG 入正式权重；DDM 亦降为 0% 权重。PE 单锚 39.7 与 FCF 单锚 39.0 差距 <2%，加权 39.4 主要由两锚共同决定、对方法选择不敏感——target 可信度成立（两锚共享盈利假设，故确定性仍低）。

## 9. 估值可能错误的地方

1. 把商场零售总额高景气线性外推为长期；业主端 171 亿租金/117 亿 NOI 被误当上市公司收入；
2. 忽略物业端毛利率回落、长账龄应收与清欠走弱；
3. 把「中期 100% 分派（近两年）」误当长期/永续承诺抬升 DDM；
4. 忽视商誉 16.4 亿 + 客户关系无形 10.75 亿的减值/摊销与租赁负债 21.9 亿的真实负担；
5. 把「华润集团与第三方」35.4% 误读为独立第三方份额而抬高商管倍数；
6. 人民币/港元汇率反转；
7. 把 PE/FCF 两锚同源于核心盈利误当「独立双证」而高估确定性；
8. 把账上现金全额加回造成双重计值（本版采用整体股权口径、不加回）。
