### 方法 6：PVGO（增长机会现值）

**计算步骤**：

| 参数 | 值 |
|---|---|
| Normalized EPS (2026E) | 1.86 元 |
| Ke（权益成本） | 9.5% |
| SSV/股 = EPS/Ke | 1.86 / 9.5% ≈ **19.58 元** |
| 当前股价 | 170.46 元 |
| PVGO/股 = 170.46 - 19.58 | **150.88 元** |
| 实际 PVGO% = 150.88/170.46 | **88.5%** |
| 合理 PVGO% 判断 | **30-50%**（ROIC 11.6% > WACC ~8%，护城河真实但非不可逾越；合理增长预期在15-25%区间） |
| 合理价 = SSV / (1 - 合理PVGO%) | 19.58 / (1-40%) ≈ **32.63 元**（保守）/ 19.58/(1-30%) ≈ **27.97 元** |

**PVGO分析核心发现**：

```
股价170.46 元 = 19.58 元（稳态价值）+ 150.88 元（增长期权）

88.5%的股价来自于对未来价值创造的预期
仅11.5%来自当前盈利能力
```

| 对标 | PVGO% | 说明 |
|---|---|---|
| S&P 500 历史均值 | ~35% | Counterpoint Global / Morgan Stanley 2026 |
| 低PVGO%组合5年跑赢 | +260bp | 1990-2024美国市场 |
| 三环集团当前 | **88.5%** | 极端水平 |
| NVIDIA (可比高增长) | ~70-80% | AI芯片龙头 |
| 贵州茅台 | ~25-30% | 确定性溢价 |

**结论：合理价 ≈ 32.63 元（基于40%合理PVGO%，-80.9% vs 现价）**

> PVGO分析揭示了三环集团估值中最核心的矛盾：当前股价中接近90%是对"未来价值创造"的预期，而S&P 500历史均值仅35%。即使ROIC（11.6%）确实略高于WACC（~8%），40%的合理PVGO%已经非常慷慨。当前88.5%的PVGO%意味着市场预期三环将成为"下一个村田"——即全球MLCC市场份额从3%→30%+的跨越。
