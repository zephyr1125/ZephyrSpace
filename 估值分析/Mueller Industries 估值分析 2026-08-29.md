## 三、多方法估值

### 方法 1：PE 盈利法（主锚，权重 40%）

| 参数 | 值 |
|---|---|
| 2026E 正常化 EPS | **$3.8**（区间 $3.7–3.9；H1 报表 $2.21 翻倍为 $4.42，但需剔除铜价库存收益、一次性项，并反映 Piping 价差收窄，故取周期中位中枢 $3.8） |
| 合理 PE | **15–16x**（非普通周期股 10–12x，因 MLI 有：几乎无债务、净现金 $14 亿、FCF 长期为正、资本密度不高、产品组合多元、管理层穿越周期记录长、可逆周期并购） |
| **合理价** | **$58.9–$60.8，中枢约 $60**（悲观 3.4×13=$44.2；乐观 4.0×17=$68） |

> **正常化 EPS 说明（终审修订：$4.15 → $3.8）**：$4.15 本质仍是「从当前高景气利润向下调整一点」，不是真正跨周期中枢。H1 本身处于铜价 $6.16/lb、Piping 利润率较高、Bison 贡献、工业需求较强的环境。真正的正常化应建立在**周期中位加工利润模型**（不同铜价区间下的单位售价、单位金属成本、废料回收收益、Piping 单位加工利润、工业/Climate 正常利润、Bison 并购后正常贡献）之上；在该模型建立前，$3.8 是对正常化 EPS 的更稳健估计。

> ⚠️ **终审修订（避免净现金重复计价）**：若使用 FCFE（股权口径 FCF）÷ 收益率，得到的已是股权价值，**不应再额外加一次全部净现金**（除非该 FCF 明确是经营资产口径且现金收益完全剔除）。本版直接以股权口径 FCF 计算，**不重复加净现金**。$6.5 亿 / 5% = $130 亿 = $58.8；保守 $6.0 亿 = $120 亿 = $54.2。中枢约 $58。

| 加回净现金 | 约 $14 亿（含并购后余额） |
| **合理价** | **约 $55–$61，中枢约 $57** |

### 已降级/删除的方法

- **逆向 DCF**：仅诊断工具。当前价 $62.80 / 正常化 EPS $3.8 ≈ 16.5x，市场要求维持较高正常化利润；若铜价与建筑需求同时下行，估值将快速失去便宜感。不纳入加权。
- **PEG**：周期股不适用（盈利波动使 PEG 失真）。
- **DDM**：股息率约 1.1%（$0.70 年化 / $62.80），DDM 不反映资本配置灵活性，仅作辅助。

> **方法独立性说明（终审）**：FCF Yield 与 DCF **共享同一个 $6.0–6.5 亿正常化 FCF 核心输入**，不是两张完全独立的票——两者合计权重 45%，实际是同一现金流假设的两种资本化方式。PE 法（利润口径）与 EV/EBITDA（经营资产口径）相对独立。这降低了「四法收敛」的可信度，也是 certainty 下调的原因之一。

## 六、风险与催化剂

### 下行风险
1. **铜价回落**：COMEX $6.16/lb 高位（+30.6%），若回落 → 价差 + 库存收益双降，正常化 EPS 下修。
2. **Piping 价差收窄**：Q2 收入 +27.3%/经营利润 -0.8%，铜价急涨期传导不完整——当前环境下利润弹性很难线性预测。
3. **建筑下行**：住宅市场仍弱，商业/工业走强若转弱，Piping 销量承压。
4. **并购整合**：Bison/Chicago 周期高位并购，若 ROIC < WACC 或商誉减值。
5. **现金流质量**：H1 OCF/净利 59.7%，铜价剧烈变化时营运资本显著扰动。

### 上行催化剂
1. **价差企稳 + 量增**：铜价趋稳后价差修复，工业/电气终端放量。
2. **Bison/Chicago 协同**：产能整合 + 采购协同超预期，并购 ROIC 上修。
3. **住宅市场复苏**：管理层「乐观」若兑现，Piping 量增。
4. **股息/回购延续**：现金充沛（$14 亿），并购消化后回购可能恢复。

## 七、一句话结论

> Mueller Industries 当前价 **$62.80** 相对合理价值 **$60** 约 **+4.7%（略高于 fair）**，距机械买入价 **$45.42** 约 **38.3%**，**完全没有买入权限，不买**。MLI 仍然是值得长期放在 A_CORE 的高质量周期工业股，但 $62.80 已是在为正常化利润付合理甚至略高的价格。**真正有吸引力的位置更接近 $45 附近**——若届时恰逢铜价与美国住宅市场一起转弱，而公司资产负债表与加工价差能力仍未损坏，那才是最值得下手的场景。
