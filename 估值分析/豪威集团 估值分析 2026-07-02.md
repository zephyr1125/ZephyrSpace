## 四、多方法估值

### 方法 1：PE 分位法（权重 30%）

**逻辑**：用合理PE倍数 × 2026E/2027E一致预期EPS。

| 输入参数 | 值 |
|------|------|
| 2026E EPS | 3.49 元 |
| 2027E EPS | 4.39 元 |
| 合理 PE（考虑周期性和成长性） | 26-30x |
| 基准 PE | 28x |

豪威集团的PE估值面临半导体周期性问题——2023年PE高达100x+（盈利低谷），2021年PE仅15-20x（盈利高峰）。用TTM PE判断会严重失真。**改用forward PE + 跨周期正常化PE。**

| 情景 | PE倍数 | 锚定EPS | 合理价 |
|------|------|------|------|
| 保守 | 26x | 3.49（2026E） | 90.74 |
| 基准 | 28x | 70% 2026E + 30% 2027E = 3.76 | **105.28** |
| 乐观 | 30x | 4.39（2027E） | 131.70 |

> 2026E/2027E加权EPS = 0.7×3.49 + 0.3×4.39 = 3.76 元

**结论：合理价 ≈ 105 元（+8.2% vs 现价97.11）**

---

### 方法 2：PEG 法（权重 20%）

**逻辑**：PEG = Forward PE / EPS增速。半导体成长型公司公平 PEG ≈ 1.5。

| 输入参数 | 值 |
|------|------|
| 2025A EPS | 3.21 元 |
| 2027E EPS | 4.39 元 |
| 2Y CAGR | (4.39/3.21)^(1/2)-1 = 16.9% |
| 公平 PEG | 1.5 |
| 公平 Forward PE | 1.5 × 16.9 = 25.4x |

| 情景 | PEG | 对应PE | 合理价（锚定2026E EPS=3.49） |
|------|------|------|------|
| 保守 | 1.2 | 20.3x | 70.85 |
| 基准 | 1.5 | 25.4x | **88.65** |
| 乐观 | 1.8 | 30.4x | 106.10 |

> ⚠️ PEG法对增速假设高度敏感。若用2025A→2026E增速（仅5.4%），PEG=27.8/5.4=5.1→极度昂贵。此处用2Y CAGR（16.9%）是考虑到2026年增速受存储涨价临时压制，2027年恢复高增长。**需注意：若2027年增速不及预期，PEG估值将显著下修。**

**结论：合理价 ≈ 89 元（-8.6% vs 现价97.11）**

### 方法 4：逆向 DCF（权重 25%）

**逻辑**：从当前股价反推市场隐含的10年EPS CAGR，然后与合理预期对比。

| 输入参数 | 值 |
|------|------|
| 基准EPS | 3.76 元（2026E/2027E加权） |
| 折现率 | 9.5%（A股半导体，β偏高） |
| 成长期 | 10年 |
| 终值PE | 18x |
| 当前股价 | 97.11 元 |

**当前价格隐含 10年 EPS CAGR ≈ 10.5%**

| 情景 | 隐含g | 公平g | 合理价 | 判断 |
|------|------|------|------|------|
| 保守 | 10.5% | 7% | 70.15 | 当前偏贵 |
| 基准 | 10.5% | 8.5% | **84.33** | 当前溢价15% |
| 乐观 | 10.5% | 10% | 97.11 | 当前合理 |

**市场正在定价什么？**：在97.11元的价格上，市场隐含豪威未来10年EPS CAGR约10.5%。考虑到全球CIS市场CAGR约8-10%、豪威份额还有提升空间（13.7%→目标第二），10.5%的隐含增速**并非不合理，但安全边际不足**。

**结论：合理价 ≈ 84 元（-13.5% vs 现价97.11）**

## 六、风险与催化剂

### 上行催化剂
1. **2027年EPS加速**：若存储涨价影响消退+汽车CIS超预期，2027年EPS可能达到4.5-5.0元（乐观情景），对应114-130元
2. **AI视觉新场景爆发**：AR/VR/机器人CIS若在2027-2028年量产放量，可能推动估值重评（PE从28x→32x）
3. **H股资金高效使用**：48亿港元用于并购或产品线扩张，缩短与索尼的差距

### 下行风险
1. **半导体周期再次下行**：若2027年全球半导体需求转弱，EPS可能降至3.0元以下，对应股价<70元
2. **2026年增速仅5%**：短期业绩平淡可能导致估值收缩（PE从28x→22x），对应股价≈77元
3. **实控人继续减持/质押风险**：若虞仁荣质押率进一步上升或被迫平仓，可能造成非基本面驱动的股价下跌
4. **券商密集下调风险**：东方证券已将2026E EPS从4.49元大幅下调至3.23元，若更多券商跟进下调，一致预期可能进一步走低
