## 估值逻辑

### 行业适用性声明

Kinsale Capital为美国E&S(超额与剩余)财产险公司。按skills/valuation/SKILL.md行业专属框架：

- ✅ **P/B-ROE**：保险公司的核心估值方法——价值锚是BVPS和可持续ROE
- ✅ **PE历史分位**：有10年交易历史，盈利稳定
- ✅ **逆向DCF**：验证隐含预期
- ❌ **标准化FCF Yield**：保险禁用——保单现金流结构特殊，OCF不可简单视为可分配FCF
- ❌ **PVGO**：保险不适用——盈利需留存资本支撑承保扩张
- ❌ **DDM**：派息率仅3.4%，不适用

**选用方法**：P/B-ROE(核心, 25%) + PE历史分位(25%) + 逆向DCF(20%) + PEG(15%) + P/B-ROE周期调整(15%)

## 方法1：P/B-ROE 估值（核心方法，权重25%）

### 理论基础

保险公司的价值 = 净资产(BV) + 未来超额回报的现值(ROE - Ke的差异 × BV)。在均衡状态下：P/B = ROE / Ke。

### 参数设定

| 参数 | 值 | 依据 |
|------|-----|------|
| 当前BV/股 | $85.31 | 2025年报实际值 |
| 当前ROE(TTM) | 30.3% | 实际值 |
| 正常化ROE(软市场) | 22% | 基于2017-2018年上一轮软市场ROE(15.8-18.4%)+结构性改善(技术效率+费用率下降+品类扩展)。软市场ROE应高于上轮因为费用率从~22%→18.6%的结构性改善 |
| 正常化ROE(硬市场) | 28% | 基于2023-2024年硬市场ROE(31-33%)减去软市回归缓冲 |
| 权益成本Ke | 8.5% | 美股保险行业标准。Beta 0.89、无风险~4.25%、ERP~5% |
| 可持续ROE(加权) | 24% | 软市场概率50%×22% + 硬市场概率50%×28%，保守取近软端 |

### 计算

```
合理P/B = 可持续ROE / Ke = 24% / 8.5% = 2.82x
合理价(P/B-ROE) = BV/股 × 合理P/B = $85.31 × 2.82 = $240.57
```

### 敏感性分析

| | ROE=20% | ROE=22% | ROE=24% | ROE=26% | ROE=28% |
|------|---------|---------|---------|---------|---------|
| **Ke=7.5%** | $227 | $250 | $273 | $296 | $318 |
| **Ke=8.0%** | $213 | $235 | $256 | $277 | $299 |
| **Ke=8.5%** | $201 | $221 | **$241** | $261 | $281 |
| **Ke=9.0%** | $190 | $209 | $228 | $247 | $266 |
| **Ke=10.0%** | $171 | $188 | $205 | $222 | $239 |

> ⚠️ P/B-ROE方法给出的合理价($241)远低于现价($371)。这不一定意味着KNSL被高估——P/B-ROE框架假设"稳态"，而KNSL当前仍处于从E&S硬市场向软市场过渡的阶段，超额的ROE(30% vs 24%正常化)可能已经部分反映在当前的4.35x P/B中。

### 计算

```

P40(偏保守): $21.00 × 16 = $336

```

### 调整说明

## 方法3：逆向DCF（权重20%）

### 理论框架

从当前股价反推市场隐含的增长率，判断其合理性。

### 参数

| 参数 | 值 |
|------|-----|
| 基准FCFE | $21.00 (2026E EPS，保险业EPS≈可分配利润的合理代理) |
| 折现率Ke | 8.5% |
| 增长阶段 | 10年 explicit + 终端 |
| 终端增长率 | 3% |
| 当前股价 | $370.97 |

### 逆向求解

```
$370.97 = Σ(t=1 to 10) $21.00 × (1+g)^t / (1+8.5%)^t + Terminal
Terminal = $21.00 × (1+g)^10 × (1+3%) / (8.5%-3%) / (1+8.5%)^10
```

逆向求解 → 市场隐含的10年EPS CAGR ≈ **7-8%**

### 合理性判断

| 情景 | 隐含增速 | 判断 |
|------|---------|------|
| 保守 | 5% | E&S市场长期增速~5-6%(GDP+通胀+风险转移)，合理 |
| 基准 | 7% | 含技术效率改善+新产品线贡献，偏乐观但非不合理 |
| 市场隐含 | ~7.5% | 略高于保守但仍在合理范围 |
| 乐观 | 10%+ | 需硬市场持续+份额大幅扩张，当前不现实 |

KNSL过去5年EPS CAGR≈47%（从$6.88→$24.63），7%的隐含增速远低于历史水平——市场已经定价了显著的增速放缓。

**逆向DCF判断**：当前价格隐含的~7.5%增速处于合理偏乐观区间。如果软市场比预期更深/更长，EPS可能降至$18-19→隐含增速将不成立。

### 逆向DCF合理价

取10年CAGR 6%（含E&S结构性增长+效率改善，较保守）：
```
合理价(逆向DCF) ≈ $330-350
```

## 方法5：P/B-ROE 周期调整（权重15%）

### 理论

方法1(P/B-ROE)给出的$241是"永续稳态"估值，未考虑KNSL正处于周期过渡期——当前30% ROE高于正常化24%，但市场已经通过压缩P/B(从顶峰6-7x→4.35x)在定价这种回归。

### 三步周期调整

**步骤1：计算全周期平均ROE对应的合理P/B**
```
周期平均ROE ≈ 22% (含一轮完整软硬市场)
合理P/B = 22% / 8.5% = 2.59x
合理价 = $85.31 × 2.59 = $221
```
这对应的是"任何时候买入都不会太差"的极端保守价。

**步骤2：计算当前周期位置的ROE对应的P/B**
```
当前处于软市场初期(GWP-5%，费率-5.9%)
预期ROE从30%→~22-24%(软市场底部)
折中ROE = 24% → P/B = 2.82x → $241 (方法1)
```
这是"软市场底部"的估值。

**步骤3：计算硬市场回归后的ROE对应的P/B**
```
如果软市场在12-18个月内见底→硬市场回归
恢复后ROE ≈ 26-28% → P/B = 3.06-3.29x → $261-281
```
这是"18个月后"的估值。

### 周期调整估值

| 阶段 | ROE | P/B | 合理价 | 概率 | 加权 |
|------|-----|-----|--------|------|------|
| 软市场深度恶化 | 18% | 2.12x | $181 | 15% | $27 |
| 软市场(基准) | 22% | 2.59x | $221 | 40% | $88 |
| 软市场见底回暖 | 26% | 3.06x | $261 | 30% | $78 |
| 硬市场回归 | 30% | 3.53x | $301 | 15% | $45 |
| **预期值** | | | | | **$238** |

> ⚠️ P/B-ROE周期调整给出的$238仍然大幅低于现价$371——这与方法1一致。**P/B-ROE框架对保险公司的估值结果大幅低于市场交易价格是常态而非异常**，因为该框架基于历史BV和正常化ROE，未充分捕捉未来增长(新产品线、新州扩张)和技术护城河(费用率持续下降)的期权价值。这是P/B-ROE的固有局限性，而非KNSL特有的高估信号。

### 核心矛盾

**P/B-ROE说贵，PE分位说合理，逆向DCF说偏乐观但不过分。**

这是优质保险公司的经典估值悖论：
- P/B-ROE给出$241(=2.82x P/B) → 因为正常化ROE=24% vs Ke=8.5%，超额回报的现值只能支撑2.82x
- PE分位给出$357 → 因为当前15.1x PE处于历史低位(中位18x)，市场已经定价了软市场
- 市场给出$371(4.35x P/B) → 因为市场赋予KNSL的技术护城河+承保纪律+17年记录一个"质量溢价"

**KNSL当前的P/B(4.35x)远超"正常化ROE/Ke"(2.82x)——这个差距就是市场对"KNSL不是一家普通E&S保险公司"的投票。** 这个溢价能否持续取决于：①费用率能否继续下降(证明技术护城河在加深) ②软市场中的承保纪律能否维持(证明文化不随周期变) ③新产品线/新州扩张能否贡献增量(证明天花板未到)。

### 合理价认定

估值分析取$297为合理中枢，但承认市场赋予KNSL的质量溢价($371 vs $297 = +25%)可能部分合理——如果KNSL能在下一轮完整E&S周期(约5-7年)中维持ROE>20%的记录。在保险业，一个能穿越周期的低综合成本率比一个周期的超高ROE更值钱。
