## 估值逻辑

### 行业适用性声明

Kinsale Capital为美国E&S(超额与剩余)财产险公司。按skills/valuation/SKILL.md行业专属框架：

- ✅ **P/B-ROE**：保险公司的核心估值方法——价值锚是BVPS和可持续ROE
- ✅ **PE历史分位**：有10年交易历史，盈利稳定
- ✅ **逆向DCF**：验证隐含预期
- ❌ **标准化FCF Yield**：保险禁用——保单现金流结构特殊，OCF不可简单视为可分配FCF
- ❌ **PVGO**：保险不适用——盈利需留存资本支撑承保扩张
- ❌ **DDM**：派息率仅3.4%，不适用

**选用方法**：P/B-ROE(核心, 25%) + PE历史分位(25%) + 逆向DCF(20%) + PEG(15%) + P/B-ROE周期调整(15%)

## 方法1：P/B-ROE 估值（核心方法，权重25%）

### 理论基础

保险公司的价值 = 净资产(BV) + 未来超额回报的现值。对于KNSL这类**低派息率+高留存+ROE持续>Ke**的成长型保险公司，应使用带增长的justified P/B公式（而非静态P/B=ROE/Ke）：

\[
\text{Justified P/B} = \frac{ROE - g}{Ke - g}
\]

其中g为可持续增长率。静态公式P/B=ROE/Ke隐含g=0的假设，对一家ROE 20%+且留存率90%+的公司而言严重低估。

### 参数设定

| 参数 | 值 | 依据 |
|------|-----|------|
| 当前BV/股 | $89.34 | Q2 2026实际值($20.4亿权益÷2278万股) |
| 正常化Operating ROE | 22% | 周期均值：软市场~18-20% + 结构性费用率优势(+2-3%)。低于当前24.4%因E&S费率仍在下行 |
| 可持续增长率g | 4% | 留存率90%×正常化ROE 22%×再投资率~20%（大部分利润通过回购和分红返回而非全部再投资于承保增长）。保守取4% |
| 权益成本Ke | 8.5% | 美股保险标准。Beta 0.89、无风险~4.25%、ERP~5% |
| 长期稳态ROE | 18% | 终值保守假设——远低于当前但高于行业均值~10% |

### 计算

**两阶段剩余收益模型**（5年 explicit + 终值）：

```
Phase 1 (5Y): ROE 22%→20% 逐步回落, g=4%
Phase 2 (Terminal): ROE=18%, g=3.5%

合理P/B ≈ 4.2x
合理价(P/B-ROE) = $89.34 × 4.2 ≈ $375
```

**敏感性分析**（合理P/B）：

| | g=3% | g=4% | g=5% |
|------|------|------|------|
| **ROE=20%** | 3.5x | 3.8x | 4.1x |
| **ROE=22%** | 3.8x | **4.2x** | 4.6x |
| **ROE=24%** | 4.1x | 4.6x | 5.2x |

> 修正说明：此前版本错误使用P/B=ROE/Ke(静态无增长公式)，得出2.82x P/B和$241合理价。该公式对KNSL这种留存率高+ROE持续>Ke的公司完全不适用。两阶段剩余收益模型（含增长）给出~$375的中心值。P/B方法不再独立加权——仅作为PE分位和剩余收益模型的交叉验证。

KNSL过去10年PE中枢约18-20x，但在E&S硬市场顶峰(2023-2024)曾触及25-30x。当前15x PE处于历史P20-P30之间——**历史低位区间**。

### 计算

采用**Operating EPS**（剔除股票投资公允价值变动等非承保波动项）。H1 2026 GAAP EPS $12.58含~$1.94/股投资公允价值变动——这类未实现收益不应获得与承保利润相同的估值倍数。

```
正常化2026E Operating EPS: $21.0-22.0 (取中值$21.5)
合理PE: 17x (KNSL 10年PE中位~18x，软市场期间给予小幅折价)

合理价(PE分位) = $21.5 × 17 = $366
```

### 调整说明

当前价$371 / $21.5 ≈ **17.2x Operating PE**——处于历史合理区间(16-20x)，既不特别便宜也不明显高估。但如果GAAP EPS $24.63被用作估值基准（隐含PE 15.1x），会误导性地得出"低估"结论——$1.94/股的投资公允价值变动不应获得承保利润同等的估值倍数。

## 方法3：逆向DCF（权重20%）

### 理论框架

从当前股价反推市场隐含的增长率，判断其合理性。

### 参数

| 参数 | 值 |
|------|-----|
| 基准FCFE | $21.00 (2026E EPS，保险业EPS≈可分配利润的合理代理) |
| 折现率Ke | 8.5% |
| 增长阶段 | 10年 explicit + 终端 |
| 终端增长率 | 3% |
| 当前股价 | $370.97 |

### 逆向求解

```
$370.97 = Σ(t=1 to 10) $21.00 × (1+g)^t / (1+8.5%)^t + Terminal
Terminal = $21.00 × (1+g)^10 × (1+3%) / (8.5%-3%) / (1+8.5%)^10
```

逆向求解 → 市场隐含的10年EPS CAGR ≈ **7-8%**

### 合理性判断

| 情景 | 隐含增速 | 判断 |
|------|---------|------|
| 保守 | 5% | E&S市场长期增速~5-6%(GDP+通胀+风险转移)，合理 |
| 基准 | 7% | 含技术效率改善+新产品线贡献，偏乐观但非不合理 |
| 市场隐含 | ~7.5% | 略高于保守但仍在合理范围 |
| 乐观 | 10%+ | 需硬市场持续+份额大幅扩张，当前不现实 |

KNSL过去5年EPS CAGR≈47%（从$6.88→$24.63），7%的隐含增速远低于历史水平——市场已经定价了显著的增速放缓。

**逆向DCF判断**：当前价格隐含的~7.5%增速处于合理偏乐观区间。如果软市场比预期更深/更长，EPS可能降至$18-19→隐含增速将不成立。

### 逆向DCF合理价

取10年CAGR 6%（含E&S结构性增长+效率改善，较保守）：
```
合理价(逆向DCF) ≈ $330-350
```

## 方法4：PEG估值（权重15%）

### 参数

| 参数 | 值 |
|------|-----|
| 2027E EPS | $21.70 |
| 3-5Y EPS CAGR | 7% (基于一致预期：$21.00→$21.70≈3.3%，偏保守；考虑周期回暖后加速→取7%) |
| 合理PEG | 1.5x (E&S保险优质公司的合理溢价——低于市场均值2.0x因为保险周期性) |

### 计算

```
合理PE = 合理PEG × 增速 = 1.5 × 7 = 10.5x
合理价(PEG) = 2027E EPS × 合理PE = $21.70 × 10.5 = $228
```

### 调整

PEG方法在低增速环境下给出较低估值。如果E&S周期在2027-2028回暖(增速回升至10-12%)→合理PE = 1.5×(10-12) = 15-18x→合理价$326-391。取周期均值：

```
合理价(PEG周期调整) = ($228 + $359) / 2 = $294
```
