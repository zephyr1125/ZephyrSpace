## 估值方法（方法同源去重）

> **方法独立性声明**：五种常见方法中，PE、PEG、剔除现金PE本质都是"盈利×倍数"（PE家族），属同一信息来源的重复投票。真正独立的方法只有 **FCF（现金流锚）** 与 **DDM（股息锚）**。本稿以 **正常化PE**（盈利锚）与 **正常化FCF Yield**（现金流锚）为两大独立核心，DDM 为股息锚辅助，剔除现金PE 降为上行参考（不正式加权）。

### 方法1：正常化PE法（权重 35%）——盈利锚

**逻辑**：TTM EPS 1.54、2026E EPS 1.63。考虑①收入~14%增长、②税率已正常化、③肾科集中度75%、④核心产品存在明确集采尾部风险、⑤公司市值与流动性均较小，正常化PE给 **12-13x**（12x=19.56，13x=21.19）。

| PE倍数 | 对应股价(HKD，基于2026E EPS 1.63) | 含义 |
|--------|-------------|------|
| 10x（深度低估） | 16.3 | 接近当前位 |
| 12x（保守合理） | 19.6 | 正常化下限 |
| 12.5x（中性） | 20.4 | 本方法取用 |
| 13x（乐观合理） | 21.2 | 正常化上限 |

**合理PE**：**12.5x**（中性。**PEG不单独加权**——PEG本质是PE×增长率，与PE同源；12-14%增长对应12-14x，作为本方法的交叉验证而非独立信号）

**合理价**：HKD 1.63 × 12.5 = **HKD 20.4 → 20.0**

### 方法2：正常化FCF Yield法（权重 35%）——现金流锚

**逻辑**：H1 OCF 7.81亿确实漂亮，但**不能直接年化**——报告已指出应付账款周转天数从~50天升至70.6天，即一部分OCF提升来自**延长供应商账期**（营运资本释放）。这是真现金，但不是每年可重复的增长来源。正常化FCF取 **RMB 9.5-10.5亿**（考虑净利12.4亿、长期OCF转换优秀、研发投入快速增加、营运资本释放不可全外推），且**不能同时用偏高FCF和偏低yield两层乐观**。

- 正常化FCF：RMB 9.5-10.5亿 ≈ HKD 10.5-11.6亿
- FCF/股：**HKD 1.25-1.38**
- Required yield **6.5%-7%**：→ 17.9 - 21.2，中枢 **19.5**

| FCF Yield | 对应股价(HKD，基于FCF/股~1.31) | 含义 |
|-----------|-------------|------|
| 8.8%（当前） | 14.93 | 当前FCF/股口径的收益率 |
| 7%（保守） | ~18.7 | 正常化下限 |
| 6.7%（中性） | ~19.6 | 本方法取用 |
| 6.5%（乐观） | ~20.2 | 正常化上限 |

**合理FCF Yield**：**6.7%**（FCF/股取1.31 HKD，对应中枢值）

**合理价**：HKD 1.31 / 0.067 = **HKD 19.6 → 19.5**

### 方法3：股息贴现法（DDM，权重 20%）——股息锚

**逻辑**：康臣是少数值得保留DDM作为正式辅助的公司——长期分红（连续13年）、派息率稳定提高（30%→46-50%）、回购持续。DPS TTM 0.78 HKD（2025末期0.40+2026中期0.38），中期增长5%、长期3%，要求回报率8%。

两阶段DDM（未来5年DPS增长5%，其后3%永续）：
- 第1-5年DPS折现：0.76+0.74+0.71+0.69+0.68 = **3.58**
- 第5年终值折现：0.82×1.05⁴×1.03/(0.08−0.03) ÷ 1.08⁵ ≈ **14.0**
- 合计：**HKD 17.6**

**合理价**：**HKD 18.0**（DDM 17.5-19 区间中值）。DDM说明：即使不给成长太多价值，当前15港元附近已开始具有收益型资产吸引力——**但不能把高分红当作保证**，集采冲击利润后DPS同样会下降。

### 方法4：剔除现金PE（上行参考，权重 10%）——资产保护锚

**逻辑**：现金及类现金金融资产48.15亿RMB（≈HKD 53亿，占市值42%）。为严谨，经营净利剔除利息及理财收益（2026H1利息4,071万+理财737万≈0.48亿RMB，TTM税后约0.84亿RMB≈0.92亿HKD）。

- 净现金及类现金：~HKD 53.0亿
- 经营净利（归母TTM 11.75亿RMB − 利息及理财税后~0.84亿）≈ **RMB 10.9亿 ≈ HKD 12.0亿**
- 合理经营资产PE：**14x**（ROE ~25%经营资产合理定价）→ 12.0×14 + 53.0 = **HKD 221亿** → 股价 **HKD 26.3 → 26.0**

**合理价**：**HKD 26.0**。⚠️ **仅作上行参考，不作独立正式加权**——26元同时假设：①所有现金接近1:1值钱；②经营业务值得14x；③现金会有效返还或高ROIC再投资。而当前最重要的问题恰恰是**第二增长曲线尚未形成**。26元的含义是"资产负债表提供较强保护"，不是中心估值。

## 估值确定性评估

| 因素 | 评估 | 对确定性的影响 |
|------|------|--------------|
| 盈利可预测性 | 高（慢性病+独家品种+高复购） | ✅ 正面 |
| 现金流质量 | 极高（OCF/NI 131.3%，零负债） | ✅ 正面 |
| 管理层可信度 | 高（管档82分，增派息+回购持续兑现） | ✅ 正面 |
| 业绩兑现 | 2026H1超预期+中期息+15.2%增派 | ✅ 正面 |
| 高现金+高分红 | 现金及类现金占市值42%，股息率5.2% | ✅ 正面 |
| **集采jump risk** | **一个政策事件可直接击中占收入~75%的业务，风险非线性** | ❌ 负面（核心） |
| 单品集中度 | 高（肾科74.8%） | ❌ 负面 |
| 新管线第二支柱 | 未形成（新增长曲线未兑现） | ❌ 负面 |
| 税率正常化（残余） | 已计入EPS预测与PE倍数，此处仅记残余不确定 | ❌ 负面（小） |

**valuation_certainty 计算（闭合）**：
```
certainty = 0.5 + X − Y
X = 盈利可预测性0.05 + 现金流质量0.05 + 管理层可信0.05 + 业绩兑现0.02 + 高现金高分红0.03 = 0.20
Y = 集采jump risk 0.08 + 单品集中0.05 + 新管线无第二支柱0.04 + 税率残余0.03 = 0.20
certainty = 0.5 + 0.20 − 0.20 = 0.50
```
> **不因PE打折而抬高确定性**：集采尾部风险不能在PE倍数里打折后就认为估值确定性很高——这种风险是**非线性**的，一旦落地可能击穿基于正常化盈利的一切估值锚。新管线未形成第二支柱进一步压制确定性。

**valuation_certainty：0.50**（较上期0.52持平偏保守——集采jump risk是确定性天花板）

### 机械买入价计算

```
buy_price = target_price × (0.68 + 0.14 × valuation_certainty)
         = 20.0 × (0.68 + 0.14 × 0.50)
         = 20.0 × 0.75
         = HKD 15.00
```

> 机械买入价 **HKD 15.00**。当前价 HKD 14.93 仅低于机械线 **0.47%**——**刚刚触发，而非"明显低于买线的强买"**。这是"可以下第一档建仓"的位置，不是"砸出巨大安全边际应积极重仓"的位置。

## 综合结论

**合理价中枢：HKD 20.0**
**当前价：HKD 14.93**
**上行空间：34.0%**
**估值确定性：0.50（中等）**
**机械买入价：HKD 15.00（当前价仅低0.47%，刚刚触发）**

康臣药业2026H1业绩（收入+13.8%、净利+19.5%、毛利率81.4%、OCF/NI 131.3%、中期息+15.2%增派）再次验证了其盈利质量与股东回报能力。当前PE TTM 9.7x、2026E PE ~9.2x，股息率5.2%，现金及类现金占市值42%，处于港股中小市值医药板块的估值洼地。

**本次更新最重要的判断（终审修订）**：
1. **方法同源去重**：PE/PEG/剔现金PE同属"盈利×倍数"家族，五个方法看似独立实则重复。真正独立的是 **正常化PE（20.0）** 与 **正常化FCF Yield（19.5）**——两者高度收敛于 ~19.5-20，这才是估值中枢。初稿21.5的虚高来自同源方法对同一份优质盈利和现金资产的重复投票。
2. **FCF必须正常化**：H1 OCF 7.81亿含营运资本释放（应付账期50→70.6天），不可直接年化。正常化FCF取9.5-10.5亿RMB，FCF Yield 6.5-7% → 17.9-21.2，中枢19.5。
3. **剔现金PE 26元只能当上行情景**：它同时假设"现金1:1值钱+经营14x+现金有效返还"，而第二增长曲线尚未形成。26元的含义是"资产负债表保护强"，不是中心估值。
4. **每股6.29 HKD是"现金及类现金金融资产"而非绝对硬底**：还有2.17亿贷款、6.65亿资本承诺和日常营运需求。

**操作含义**：14.93 HKD处于强买区下沿，且**刚刚触发机械买入线15.00（低0.47%）**——符合"好公司+低于机械买线"的建仓条件，**可以下第一档建仓**。但这不是"确定性上行空间44%的强买"，而是"刚刚够便宜、可以下第一档"的位置。真正决定后续是否越跌越买的，不是再看PE，而是盯住三个变量：
- **尿毒清集采进展**（一旦进入全国集采，利润可能阶跃式下修）
- **新肾科管线收入占比**（何时突破30%形成第二支柱）
- **库存股最终处置**（注销/合理激励 vs 低价授予管理层形成实质稀释）

**仓位纪律**：这类"高现金+高分红+低估值，但单品集中度74.8%+集采jump risk"的公司，适合**低估时买、但必须控制单股最终权重**——不能因低PE/高现金/5%股息/高ROE的"平时看起来非常安全"而重仓。
