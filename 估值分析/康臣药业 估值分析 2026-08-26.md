## 估值方法

### 方法1：PE 分位法（权重 30%）

**逻辑**：康臣药业历史上PE在8-18x区间波动，当前9.7x处于历史最低分位。合理PE应反映其ROE ~25%+零负债+稳定增长的基本面，同时考虑税率正常化（净利增速下移至~15%）与单品依赖74.8%的折价。

| PE情景 | 对应股价(HKD) | 含义 |
|--------|-------------|------|
| 9x（深度低估） | 13.8 | 接近当前位 |
| 12x（保守合理） | 18.5 | TTM EPS 1.54 × 12 |
| 13x（中性合理） | 20.0 | 考虑税率正常化的折中 |
| 15x（乐观合理） | 23.1 | 集采不发生+新管线放量 |

**合理PE**：**13x**（中性，兼顾ROE 25%基本面与税率正常化/单品依赖折价）

**合理价**：HKD 1.54 × 13 = **HKD 20.0**

### 方法2：FCF Yield 法（权重 25%）

**逻辑**：以5-7%的FCF收益率作为合理估值锚点。康臣药业FCF质量极高（OCF/NI 131.3%），值得较低的FCF Yield（即较高估值）。但2026H1 OCF高增含营运资本改善成分（客户现付比例提高+供应商账期延长），正常化FCF按~RMB 11-12亿计。

| FCF Yield | 对应股价(HKD) | 含义 |
|-----------|-------------|------|
| 9.5%（当前） | 14.93 | 当前FCF/股~1.44 HKD |
| 7%（保守） | ~20.6 | 仍属高收益率 |
| 6.5%（中性） | ~22.2 | 与低风险资产合理风险溢价 |
| 5.5%（乐观） | ~26.2 | 顶级防御资产估值 |

**合理FCF Yield**：**6.5%**（零负债+高OCF质量，但正常化FCF需保守）

**合理价**：HKD 1.44 / 0.065 = **HKD 22.2**

### 方法3：PEG 法（权重 15%）

**逻辑**：PEG=1为合理。税率正常化后未来3年净利润CAGR约14-16%（2025 +18.4%、2026E +15-17%），较此前假设的15-18%下移。

| 增长假设 | 合理PE（PEG=1） | 股价(HKD) |
|---------|---------------|-----------|
| 12%（保守） | 12x | 18.5 |
| 14%（中性） | 14x | 21.5 |
| 16%（乐观） | 16x | 24.6 |

**合理PE**：**14x**（对应14% CAGR，考虑税率正常化的中性假设）

**合理价**：**HKD 21.5**

### 方法4：股息贴现法（DDM，权重 15%）

**逻辑**：康臣药业是港股少有的"分红+回购"双驱动公司。DPS TTM升至0.78 HKD（2025末期0.40 + 2026中期0.38），中期增长5%、长期3%，要求回报率8%。

两阶段DDM（未来5年DPS增长5%，其后3%永续）：
- 第1-5年DPS折现：0.76+0.74+0.71+0.69+0.68 = **3.58**
- 第5年终值折现：0.82×1.05⁴×1.03/(0.08−0.03) ÷ 1.08⁵ ≈ **14.0**
- 合计：**HKD 17.6**

**合理价**：**HKD 17.5**（取整，DDM作为安全边际参考）

### 方法5：剔除现金后的PE估值（权重 15%）

**逻辑**：康臣账上现金及类现金（含定期存款、受限制现金、理财）48.15亿RMB（≈HKD 53亿，占市值42%）。这部分按1:1单独估值，经营业务按PE估值。为严谨，经营净利需剔除利息及理财收益（**2026H1现金利息收入4,071万 + 理财净收益737万 = 4,808万RMB ≈ 0.48亿**，TTM约税后RMB 0.84亿 ≈ HKD 0.92亿）。

- 净现金：~HKD 53.0亿

**合理价**：**HKD 26.0**（此方法将巨额现金按1:1估值并叠加优质经营资产，是估值上沿参考——显示当前价对"现金+经营"组合的深度折价）

## 估值确定性评估

| 因素 | 评估 | 对确定性的影响 |
|------|------|--------------|
| 盈利可预测性 | 高（慢性病+独家品种+高复购） | ✅ 正面 |
| 现金流质量 | 极高（OCF/NI 131.3%，零负债） | ✅ 正面 |
| 管理层可信度 | 高（管档78分，增派息+回购持续兑现） | ✅ 正面 |
| 业绩兑现 | 2026H1超预期+中期息+15.2%增派 | ✅ 正面 |
| 税率正常化（残余） | 已计入EPS预测与PE倍数，此处仅记税率未来稳定性的残余不确定 | ❌ 负面（小） |
| 集采风险 | 中高（时间不确定，降幅不确定） | ❌ 负面 |
| 单品集中度 | 高（肾科74.8%，较~70%加深；已在PE倍数折价） | ❌ 负面 |
| 新管线不确定性 | 中（放量时间/规模不确定） | ➖ 中性 |

**valuation_certainty 计算（闭合）**：
```
certainty = 0.5 + X − Y
X = 盈利可预测性0.05 + 现金流质量0.05 + 管理层可信0.05 + 业绩兑现0.02 = 0.17
Y = 税率残余不确定0.02 + 集采风险0.05 + 单品集中0.04 + 新管线0.02 = 0.13
certainty = 0.5 + 0.17 − 0.13 = 0.54
```
> 税率正常化与单品集中度已在 EPS 预测与 PE 倍数中计入（避免三重叠加），此处仅记残余不确定。

**valuation_certainty：0.54**（较上期0.52小幅上调——业绩超预期+OCF/NI 131.3%现金流强化，抵消了税率正常化的盈利弹性下修）

## 综合结论

**合理价中枢：HKD 21.5**
**当前价：HKD 14.93**
**上行空间：44.0%**
**估值确定性：0.54（中等）**

康臣药业2026H1业绩（收入+13.8%、净利+19.5%、毛利率81.4%、OCF/NI 131.3%、中期息+15.2%增派）再次验证了其盈利质量与股东回报能力。当前PE TTM 9.7x、2026E PE ~9.2x，股息率5.2%，每股净现金6.29 HKD（占股价42%），仍处于港股中小市值医药板块的估值洼地。

**本次更新的两个新变量**：
1. **税率正常化**（6.1%→14.3%）：2025年低税率红利消失，净利增速从~20%下移至~15-17%。已计入2026E EPS预测与PE倍数（13x而非15x），是盈利弹性下修而非逻辑破坏。毛利率+4.3pct对冲了大部分影响。
2. **业绩超预期+增派息**：验证了管理层的兑现能力，叠加OCF/NI 131.3%的现金流强化，估值确定性从0.52小幅上调至0.54。

**核心建议**：当前价处于强买区（<18），且低于机械买入线16.25约8.8%，适合按B_GROWTH档位（单品风险控制）分批建仓。合理价21.5对应44%上行空间，下行有每股6.29 HKD净现金（占股价42%）提供较强硬底。税率正常化是温和的盈利下修而非逻辑破坏——高现金+高分红+低估值的防御价值未变。
