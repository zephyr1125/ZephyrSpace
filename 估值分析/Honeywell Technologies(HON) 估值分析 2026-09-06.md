## 3. 估值方法选择与计算

**方法选择逻辑**：HON = 多元化工业自动化纯-play（楼宇/过程/工业离散），净债务低、资本开支轻、真实分红；但有机增长温和（3-4%）、分拆初期数据缺口多、且不是高派息股。选用 **Forward PE（主锚）+ EV/EBITDA + FCF Yield + 股东回报锚（股息率/DDM 合并，低权重）**；PE 历史分位不适用（无纯自动化历史）；PEG 仅辅助（FY26 增速含结构成分，不可作主锚）；逆向 DCF / PVGO 仅诊断；不做 SOTP 正式加权（Quantinuum 股权单列说明）。

**口径注（EV/EBITDA 为何非 10.8x）**：stockanalysis 的 EV/EBITDA 10.8x 用含 Aero 的 6/30 净债务（$24.8B）与含 Aero+一次性利得的 TTM EBITDA（~$8.5B）错配计算。正确自动化口径：EV = 市值 $66.4B + 自动化净债务 $9.5B ≈ **$75.9B**；EBITDA = 自动化调整后净利 ~$2.6B + 利息 + 税 + D&A ≈ **$4.3-4.7B**（DBRS 预测 FY26 <$4.5B）→ **EV/EBITDA ≈ 16.5-17.6x**（对应自动化同业 18-24x 的中下沿，含分拆初期折价）。

### 诊断方法（不进入加权）

- **逆向 DCF**：现价 $209.61、FY27E EPS $9.95、Ke=9% → 隐含永续 EPS 增速 ≈ 9.95/209.61 − 0.09 ≈ **4.2%**。对"中期 4-6% 有机 + margin 扩张 + 股本每年 -1%"的公司属**温和、非激进**的市场预期——市场未对 autonomy/AI 叙事定价明显溢价，也非明显低估。
- **Quantinuum 股权 SOTP 说明**：~48% 权益（账面 $7.26B，≈$23/股）为独立于经营的非经营资产（亏损中、波动大）。若剥离看待，核心自动化业务隐含价格 ≈ $209.6 − $23 ≈ $187 → 对应 FY27 经营 PE ≈ 18.8x。**本估值不给 Quantinuum 额外溢价**（亏损 + 流动性差 + 管理层双重角色），仅记录其作为上行期权与报表波动源。

### 方法独立性声明（强制）

| 方法 | 权重 | 独立性说明 |
|---|---|---|
| Forward PE（FY27E） | 35% | 基于一致预期 EPS，切入"市场相对增长给多少倍"——与 EV/EBITDA 共享盈利预期但锚定口径不同（权益 vs EV），弱相关 |
| EV/EBITDA | 25% | 基于 EBITDA+净债务（含折旧口径），与 PE 共享经营盈利但引入资本结构/资产视角，弱相关 |
| FCF Yield | 25% | 基于现金流（OCF−capex）而非盈利，与 PE/EBITDA 驱动因素部分重叠但现金流切入独立，弱相关 |
| 股东回报锚（股息率/DDM） | 15% | DDM 与股息率**同源**（均基于 DPS），已合并为单一股东回报锚并压至 15% 低权重（派息率仅 34%，DDM 对留存增长假设敏感，故不给高权重） |

> 结论声明：4 法可归为 3 类信号（相对盈利估值 / 现金流估值 / 股东回报），已控制同源权重；诊断法（逆向 DCF、Quantinuum SOTP）不进入加权。加权中枢可信度中等偏低（见 certainty 认定）。

## 6. 风险与催化剂

### 上行催化剂
- 2026 Q3/Q4 分部利润率兑现 20.1-20.5% + H2 有机 4-6%（10-22 Q3 财报）
- 2027 三年框架首年指引（EPS +~15%、FCF conversion >90%）超预期
- 数据中心（楼宇 + 现场发电/液冷）、LNG 订单持续入 backlog；JM Catalyst 整合超预期
- Quantinuum 股价上行或部分退出（释放 $7.26B 股权价值）

### 下行风险
- FY26/27 margin-EPS 兑现不及（量端弱 + 结构性贡献退坡）
- goodwill 进一步减值（IA/PA&T 未达框架）
- Quantinuum 公允价值下修（直接冲击 GAAP 权益/盈利）
- 真实 post-spin 资产负债表劣于 pro forma；评级下修
- 全球工业/楼宇资本开支转弱、LNG 项目延迟
