## 三、多方法估值

### 方法1：PE历史分位法（权重20%）

**逻辑**：用正常化EPS × 合理PE倍数。合理PE取3Y历史中枢折扣（周期高峰应低于历史中位数）。

| 参数 | 值 | 说明 |
|---|---|---|
| 2026E EPS | 2.90元 | 770亿÷265.9亿股 |
| 正常化EPS（mid-cycle）| 1.75元 | 465亿÷265.9亿股（约FY2024水平）|
| 混合EPS | 2.44元 | 60%×2026E + 40%×mid-cycle |
| 3Y PE中位数 | 17.50x | 理杏仁200样本 |
| 合理PE（cycle-adjusted）| 12-14x | 周期高峰折扣20-30% vs 中位数 |

| 情景 | PE | EPS | 合理价 |
|---|---|---|---|
| 保守 | 11x | 2.44 | **26.84元** |
| 基准 | 13x | 2.44 | **31.72元** |
| 乐观 | 15x | 2.44 | **36.60元** |

**加权合理价：31.23元**（保守30%+基准50%+乐观20%）

---

### 方法2：FCF Yield标准化（权重20%）

**逻辑**：矿业公司重资产+强现金流，FCF Yield是最干净的估值锚。取正常化FCF（去除扩张性capex）+合理收益率。

| 参数 | 值 | 说明 |
|---|---|---|
| OCF（正常化）| 600亿 | FY2024 488亿 + FY2025 753亿均值≈620，取保守600 |
| 维护性capex | 200亿 | 矿山维持+安全环保，总capex~450亿中约45%为维护性 |
| 正常化FCF | **400亿** | OCF 600 - 维护capex 200 |
| 扩张性FCF（peak）| **550亿** | OCF 753 - 维护capex 200（FY2025水平）|
| 混合FCF | **475亿** | 正常化50% + peak 50%（给予近期可见度一半权重）|

| 情景 | FCF Yield | 合理MC | 合理价 |
|---|---|---|---|
| 保守 | 7.5% | 6,333亿 | **23.82元** |
| 基准 | 6.5% | 7,308亿 | **27.49元** |
| 乐观 | 5.5% | 8,636亿 | **32.48元** |

**加权合理价：27.39元**

### 方法3：EV/EBITDA（权重15%）

**逻辑**：EV/EBITDA排除资本结构影响，是国际矿业公司估值标准。

| 参数 | 值 | 说明 |
|---|---|---|
| 2026E EBITDA | ~1,200亿 | 净利770+折旧250+利息80+税100 |
| 正常化EBITDA | ~800亿 | mid-cycle净利465+折旧220+利息60+税55 |
| 混合EBITDA | **1,000亿** | peak 50% + 正常化 50% |
| 净债务 | ~1,000亿 | 总负债~3,000-现金~300 = ~2,700（含少数股东），简化取1,000 |
| EV（当前）| ~8,371亿 | MC 7,371 + 净债务 1,000 |
| EV/EBITDA（混合）| 8.4x | 8,371/1,000——当前估值 |

| 情景 | EV/EBITDA | EV | MC | 合理价 |
|---|---|---|---|---|
| 保守 | 7.0x | 7,000亿 | 6,000亿 | **22.57元** |
| 基准 | 8.5x | 8,500亿 | 7,500亿 | **28.21元** |
| 乐观 | 10.0x | 10,000亿 | 9,000亿 | **33.85元** |

**加权合理价：27.64元**

> 全球铜金矿业同行EV/EBITDA：Freeport-McMoRan ~8.5x，Newmont ~9x，Barrick ~7.5x。紫金8.4x处于合理区间。

### 方法4：PB-ROE（权重15%）

**逻辑**：周期股用PB估值比PE更稳定。PB = (ROE - g)/(Ke - g)。

| 参数 | 值 | 说明 |
|---|---|---|
| BVPS | 7.04元 | MC 7,371亿÷PB 3.94÷265.9亿股 |
| 可持续ROE | 25% | 介于FY2024 26%和假设下行周期20%之间 |
| 长期增长率g | 4% | 铜需求结构性增长+产量扩张 |
| Ke（权益成本）| 9.5% | A股矿业，相对高β |
| 理论PB（可持续）| **3.82x** | (25%-4%)/(9.5%-4%) |

| 情景 | ROE假设 | PB | 合理价 |
|---|---|---|---|
| 保守 | 20%（下行周期）| 2.91x | **20.49元** |
| 基准 | 25%（mid-cycle）| 3.82x | **26.89元** |
| 乐观 | 33%（FY2025水平）| 5.27x | **37.12元** |

**加权合理价：30.98元**（保守30%+基准50%+乐观20%）

> 当前PB 3.94x已低于基准理论PB 3.82x，安全边际初现。

### 方法5：逆向DCF（权重15%）

**逻辑**：从当前股价反推市场在定价什么样的未来增速。

| 参数 | 值 |
|---|---|
| 起始FCF | 400亿（正常化）|
| 折现率 | 9.5% |
| 成长期 | 10年 |
| 终值PE | 15x |
| 当前EV | ~8,371亿 |

**反推结果**：

| 隐含g | 对应情景 | 判断 |
|---|---|---|
| **~4.5%** | 铜需求增长~3% + 产量扩张~1.5% | 🟢 合理偏低——仅需行业平均增速 |
| 5.5% | 铜需求+产量扩张+小幅份额提升 | 🟢 可实现 |
| 7.0% | 需要超预期增长或商品价格持续上涨 | 🟡 偏乐观 |

| 情景 | g假设 | EV | MC | 合理价 |
|---|---|---|---|---|
| 保守 | 3.5% | 7,500亿 | 6,500亿 | **24.45元** |
| 基准 | 5.0% | 8,400亿 | 7,400亿 | **27.83元** |
| 乐观 | 6.5% | 9,600亿 | 8,600亿 | **32.35元** |

**加权合理价：28.21元**

**关键发现**：当前股价隐含FCF增速仅~4.5%，远低于公司过去5年实际增速（FCF CAGR ~40%+）和1H26的+68%利润增速。市场在定价"均值回归"——即使只假设5%的温和增长，当前价已有安全边际。

## 七、结论与建议

### 估值结论

| 要素 | 结论 |
|---|---|
| 多方法加权合理价 | **29.70元** |
| vs 现价（27.72元）| **+7.1%** |
| 当前区间 | 🟢 **较好区**（25.00-29.70） |
| 估值判断 | **合理偏低**——市场对周期顶部的恐惧已大部分price in |
| 最佳买入区间 | **<25.00元**（低估区，PE blended <10x） |
| 建议仓位上限 | **10-12%**（周期股天然不适合超配） |

### 核心矛盾

**多方逻辑**：PE 11.95x处于3年极端低位（P5），PB从82%分位急降至5%分位；1H26利润391亿+68%确认高增长；零息CB+La Arena提供未来增长期权；成本领先意味着即使价格下跌仍盈利。

**空方逻辑**：利润处于历史最高峰，铜金价格任何一方下跌20%+即显著压缩EPS；PE低是周期顶部特征而非低估证据——如果2027年EPS腰斩，当前PE实际上可能是20x+；15年商品超级熊市（2011-2015紫金利润-80%）不是不可能重演。

**个人判断**：当前价位（27.72元）已反映较多悲观预期，但距离真正的安全边际（<25元）还有约10%的距离。建议**等待更好买点或轻仓分批介入**，初始仓位5%以内，若回调至25元以下可加至10%。

### 退出条件

- 铜价 <$7,000/t **且** 金价 <$2,400/oz 同时出现 → 减仓50%
- 单季度净利同比转负 → 重新评估
- 海外主力矿山（卡莫阿/Timok/La Arena）许可证被冻结 → 立即退出
- 管理层再次出现2010年级别的信披违规 → 立即退出
