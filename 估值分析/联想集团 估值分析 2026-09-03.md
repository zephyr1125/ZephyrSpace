## 3. 方法选择与适用性

联想=硬件制造(PC/AI服务器)+IT服务，非金融。盈利处爆发拐点 + 周期属性 + 服务化转型，估值**不能依赖单一 PE 或 PEG**。选择：

| 方法 | 适用性判断 | 权重建议 |
|---|---|---|
| **Forward PE（经调整）** | 盈利拐点已确立、有 2-3 年一致预期 → 主锚 | 30% |
| **SOTP 分部估值** | 三大业务成长/利润率差异大 → 高适用 | 25% |
| **PEG** | ⚠️ 利润拐点期增速失真(+176%低基数)，仅辅助 | 10% |
| **DDM** | 派息率~35% 中低 → 低权但可用 | 10% |
| **逆向 DCF** | 诊断当前价隐含增速，不独立计权 | 0%（诊断） |
| **EV/EBITDA** | ISG 重资产/AI资本开支大，EV/EBITDA 部分适用 | 15% |
| **PS（分部）** | 高增长 ISG 可辅助 | 10% |

### 方法独立性声明

- Forward PE / PEG / DDM 共享 EPS/盈利假设 → **同源，合并权重上限 40%**（PE30+PEG10，DDM 并入）
- SOTP 与 EV/EBITDA 基于分部盈利+净债务，**与盈利倍数类弱相关**
- 逆向 DCF 仅诊断不赋权
- 结论：7 法可归为 4 类信号（盈利倍数/分部加总/股利折现/现金流倍数），已控制同源权重。

## 4. 多方法估值

### 方法 1：Forward PE（经调整，主锚）

**输入**：FY2027E 经调整净利 30–44亿美元；市值取基础股本 486亿美元（对应现价30.54）。
**目标 PE 区间**：联想历史 PE（盈利正常年）约 8-18x；考虑 ISG 高增长重估+服务化，给 **12–15x（FY2027E）** 合理（对标 Dell/HP 转型 AI 的估值上移，花旗给 16.1x FY28E、高盛 18.5x CY27E、JPM 18x FY27 前向——外资目标价隐含估值已抬至 16-18x）。

| 情景 | FY27E净利 | PE | 合理价(HKD) |
|---|---|---|---|
| 保守 | 30亿美元 | 12x | 30.54×(30/44)×(12/14)≈**17.8** |
| 基准 | 40亿美元 | 14x | **35.2** |
| 乐观 | 44亿美元 | 16x | **50.3** |

**测算（基准）**：合理市值 = 40亿×14 = 560亿美元 = 4,368亿港元 ÷ 124亿股 = **35.2港元**
**结论：合理价 ≈ 35.2港元（+15% vs 现价 30.54）**

> ⚠️ 说明：PE 倍数给 14x 隐含对"FY27E 盈利可持续到 FY28+"的信心。现价 30.54 对应基础股本前向 PE ~12.5x（按40亿），若市场担心 ISG 利润率回落/PC 下行，可回落至 30 亿盈利×12x=17.8港元支撑区。

### 方法 2：SOTP 分部估值

采用经调整经营利润口径（参考花旗 SOTP 逻辑，拆分三集团）：

| 分部 | FY27E 收入(亿美元) | 目标 EV/收入或PE | 估值(亿美元) |
|---|---|---|---|
| IDG（PC/手机，利润率~7%） | ~700 | 8x PE ≈ 净利~26亿 → 208亿 | ~208 |
| ISG（AI服务器，高增长） | ~437 | 18.9x PE（花旗）≈ 净利~18亿 → 340亿 | ~340 |
| SSG（服务，利润率24%） | ~120 | 10x PE ≈ 净利~12亿 → 120亿 | ~120 |

**分部合计** ≈ 668亿美元
**减净债务**：联想有息负债以 CB 为主（Alat 20亿+2033 CB 20亿+2029 CB 4.5亿≈44.5亿），现金约50亿美元 → **净现金 +约5亿美元**，加回 ≈ 5亿
**完全摊薄股数调整**：上述分部盈利基于现有业务，若考虑 Alat CB/权证潜在摊薄至 ~151亿股 → 每股 = (668+5)亿美元×7.8 ÷ 151亿 = 5,249 ÷ 151 = **34.8港元**

| 情景 | 假设 | 合理价(HKD) |
|---|---|---|
| 保守 | ISG 用 12x（担忧利润率回落） | ~26 |
| 基准 | ISG 18.9x（花旗口径） | **34.8** |
| 乐观 | ISG 22x + SSG 12x | ~40 |

**结论：SOTP 基准合理价 ≈ 34.8港元（完全摊薄口径；基础股本口径约42港元）**

### 方法 3：PEG（辅助）

- FY27E 增速 +100%（低基数，非可持续）；FY28E 一致预期 +27%（花旗 40→ ~50美分），用 FY27A→FY28E 增速 ~27%
- PEG = Forward PE(12.5x) / 27 ≈ 0.46（<1 → 低估）
- 合理 PEG 1.0 → PE 27x 明显过高；联想为周期成长，合理 PEG 0.8-1.0 应用于 FY28E 增速更稳健
- **PEG 结论**：以 FY28E 增速 25-30% 计，给 FY27E 12-15x 已合理消化，不额外上修。参考值 ≈ 当前价基本合理。

> ⚠️ 利润拐点期 PEG 失真警示：FY27E 因低基数净利+176%，直接 PEG 会把合理价推高到失真水平，仅取 FY28E 增速交叉验证，不给正式权重加码。

### 方法 4：DDM（低权）

- FY2026 DPS 0.422港元，派息率约35%（经调整口径）
- 若 FY27E 净利40亿 → EPS ~0.40美元(基础) → DPS ~0.14美元 ≈ 1.09港元(派息率35%)
- g（长期股息增长）：盈利增速向成熟收敛，取 8-10%（AI 服务器资本回报若能兑现）；Ke 港股 11%
- P = D1/(Ke-g) = 1.09×1.09 / (0.11-0.10) → g=10% 时极高；g 需谨慎

| g | 合理价(HKD) |
|---|---|
| 8% | 1.09×(1.08)/(0.11-0.08) = **39.2** |
| 9% | 1.09×1.09/(0.11-0.09) = **59.4** |
| 6% | 1.09×1.06/(0.11-0.06) = **23.1** |

**DDM 结论**：对 g 极敏感。联想当前派息率 35% 属中低，DDM 本身低估留存价值，合理价参考区间 23–39港元，中枢约 30。**低权使用（g=8% → 39 偏乐观，g=6% → 23 偏保守）。**

### 方法 5：EV/EBITDA（部分适用）

- FY2027E EBITDA：经调整经营利润 ~40亿美元 + D&A ~15亿美元 ≈ 55亿美元（估算，AI capex 放大 D&A）
- 净现金 ~5亿美元 → EV ≈ 486-5 = 481亿美元
- EV/EBITDA = 481/55 ≈ **8.7x**
- 参考：Dell EV/EBITDA ~10-12x（AI 服务器业务被高估），HPE ~8-10x
- 给联想 10-11x（AI 服务器+服务转型溢价）→ 合理 EV 550-605亿美元
- 合理价 = (550~605 + 5)亿 ×7.8 / 124亿股 = 4,330-4,760亿 /124 = **34.9–38.4港元**

**结论：EV/EBITDA 合理价 ≈ 35–38港元**

### 方法 6：逆向 DCF（诊断，不赋权）

- 现价 30.54港元 → 市值 486亿美元
- 假设 Ke 11%，终值 PE 15x，10 年成长期
- 反推隐含 FY27-FY36 EPS CAGR：当前 FY27E EPS ~0.32美元，市值隐含要求未来 10 年净利 CAGR ≈ **18-20%**（若净利率升至 5-6% 且收入 CAGR 12-15%，可支撑）
- 判断：现价隐含预期**非极端**——ISG 订单管道540亿美元 + 利润结构改善若能持续，18-20% 净利 CAGR 在 AI 周期内有现实基础；但若 ISG 利润率回落至 <5%，隐含增速不达标，估值有下修压力

**逆向 DCF 结论：当前价隐含 18-20% 净利 CAGR，属于"乐观但非泡沫"预期，需 ISG 盈利兑现支撑。**

## 5. 综合加权 + 价格区间

### 加权合理价

**正式权重只采用四个可靠锚**（PEG/逆向DCF/PS 列辅助诊断，不赋正式权；记忆纪律：PEG 仅辅助、低派息股 DDM 降权、FCF/现金流倍数与盈利倍数保持信号分离）：

| 方法 | 基准合理价(港元) | 权重 | 独立性 |
|---|---|---|---|
| Forward PE（经调整） | 35.2 | 35% | 盈利倍数主锚 |
| SOTP 分部 | 34.8 | 30% | 分部加总（IDG/ISG/SSG 成长与利润率差异大） |
| EV/EBITDA | 36.5 | 20% | 现金流/重资产口径，与盈利倍数弱相关 |
| DDM | 30.0（中枢） | 15% | 股东回报锚（低派息35%→降权至15%） |
| PEG / 逆向DCF / PS | ~30 / 诊断 / ~32 | 0% | 辅助诊断，仅交叉验证不赋正式权 |
| **加权合理价** | | **100%** | |

**加权计算**：
35.2×0.35 + 34.8×0.30 + 36.5×0.20 + 30.0×0.15
= 12.32 + 10.44 + 7.30 + 4.50
= **34.6港元**

> ⚠️ 方法独立性说明：四锚分两类信号——PE+DDM 共享经调整盈利假设（合计50%），SOTP+EV/EBITDA 基于分部盈利与现金流（合计50%），两类信号来源不同、加权可信。但需注意 **SOTP 的 ISG 18.9x 与 PE 的 14x 共享"ISG 盈利兑现"假设**——若 AI 服务器利润率回落（ISG<5%），两类估值同步下修，合理价中枢或下移至 25 港元。机械加权取整后 target_price 采用 **34.6 港元**。

### 目标价修正：对现价与"已含 ISG 兑现预期"的再校准

加权合理价 34.6港元 > 现价 30.54（约+13%）。与五家外资行目标价（46-66港元，均值~50）仍差距大，主因：
1. **我的倍数更保守**：外资行普遍给 16-18.5x forward（隐含对 ISG 兑现的高置信），我给 12-15x，考虑联想 85% 高杠杆 + 报表失真 + 历史并购兑现慢。
2. **摊薄处理更审慎**：SOTP 采用完全摊薄股本（151亿股），外资行多用基础股本或部分摊薄。
3. **盈利取中枢下沿偏谨慎**：以 38-44亿美元经调整净利为主线，但给保守情景 30亿美元足够权重。

**裁决**：审慎合理中枢 **34.6港元**（现价 30.54 处于中枢下方约12%）。**现价接近但不具备机械买入安全边际**——按估值纪律 buy_price = 34.6 × (0.68 + 0.14×0.48) ≈ 34.6 × 0.747 ≈ **25.8港元**，现价高于买入点约18%，故观望为主，回落至 25-28 港元分批建仓。

## 7. 风险与催化剂

2. ISG 利润率连续 4 季维持 ≥7%，坐实结构性盈利。
