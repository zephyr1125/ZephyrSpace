## 四、多方法估值

### 方法1：PE历史分位（权重25%）

> 核心思路：以2026E EPS为锚，参照历史PE分位给出合理Forward PE区间。TTM PE 63.89x处于历史P50以上，但Forward PE才是成长股的正确锚点。

| 参数 | 值 |
|---|---|
| 2026E EPS（一致预期） | ¥3.37 |
| 2027E EPS（中泰证券） | ¥4.55 |
| 历史PE分位参照（TTM） | 5Y P20~35x / P50~48x / P80~75x |
| 当前TTM PE | 63.89x（高于P50，约P65-P70分位） |
| 当前Forward PE（2026E） | 31.03x |
| 当前Forward PE（2027E） | 22.98x |

**分析**：TTM PE 63.89x处于5年P65-70分位，看起来偏贵。但换到Forward PE视角：31x（2026E）→ 23x（2027E），对于一个62%增速的Fabless半导体公司而言处于合理偏低区间。

A股可比公司（瑞芯微、恒玄科技、乐鑫科技）在增速>50%阶段通常享受40-60x Forward PE。晶晨31x的Forward PE隐含了市场对其OCF/存货问题的折价。

| 情景 | 2026E PE | 合理价 | 逻辑 |
|---|---|---|---|
| 保守 | 25x | **¥84.25** | OCF持续恶化，H1 2026净利继续下滑，全年增速miss |

| 乐观 | 40x | **¥134.80** | 2026E完全兑现甚至超预期（6nm放量+WiFi6爆发） |

**基准合理价：¥108（+3.1% vs 现价）**

> 备注：如果使用2027E EPS ¥4.55锚定，保守20x=¥91，基准28x=¥127，乐观35x=¥159。2027E视角估值明显更乐观——关键是2026→2027的增长路径可信度。

### 方法2：PEG（权重25%）

> 核心思路：成长型公司用PEG锚定估值，PEG=Forward PE/增速。PEG<1视为低估，但需警惕"增速陷阱"——基数效应消退后增速骤降。

| 参数 | 值 |
|---|---|
| 2025A 归母净利 | ¥8.73亿 |
| 2026E 归母净利（一致预期） | ¥14.17亿 |
| 2026E 增速 | **+62.35%** |
| 2027E 归母净利（中泰） | ¥19.14亿 |
| 2027E 增速（vs 2026E） | **+35.0%** |
| 2Y CAGR（2025→2027E） | **48.1%** |
| 2026E EPS | ¥3.37 |
| 2027E EPS | ¥4.55 |
| 当前Forward PE（2026E） | 31.03x |
| PEG（1Y，2026E基准） | **0.50** |
| PEG（2Y CAGR基准） | **0.64** |

**分析**：PEG=0.50在A股半导体中属于罕见的"便宜"信号（同类成长芯片公司PEG通常在0.8-1.5）。但需大幅打折的原因：

1. **Q1 2026净利-7.95%**：全年62%的增长严重依赖H2爆发，Q1已经miss了——2026E存在下修风险
2. **OCF已持续为负**：利润的现金含量存疑（存货堆出来的"账面利润"）
3. **基数效应**：2023年低谷→2024年反弹→2025年温和增长→2026年预期暴增，增速脉冲特征明显
4. **费用端异常**：Q1 2026营收+24%但净利-8%，费用率攀升侵蚀利润

因此采用PEG=0.6-0.8作为合理区间（而非标准的0.8-1.2），对增速质量和OCF风险打折。

| 情景 | 合理PEG | 隐含PE | 合理价 | 逻辑 |
|---|---|---|---|---|
| 保守 | 0.50 | 24x（用48%CAGR） | **¥80.96** | 2026E增速腰斩至30%（存货减值+费用继续扩张） |
| 基准 | 0.65 | 31x（用48%CAGR） | **¥105.24** | PEG=0.65仅略低于1.0，对OCF和Q1 miss打折 |
| 乐观 | 0.85 | 41x（用48%CAGR） | **¥137.69** | H2放量完美兑现，OCF随存货消化转正，PEG修复至0.85 |

**基准合理价：¥105（+0.6% vs 现价）**

> 交叉检验（用2027E）：2027E EPS 4.55，增速35%。PEG=0.65→PE=22.8x→¥104；PEG=1.0→PE=35x→¥159。当前价¥104.56恰好对应2027E PEG=0.66，与基准情景一致。

### 方法4：PVGO 增长机会现值（权重15%）

> 核心思路：将股价拆解为稳态价值+增长期权价值，判断市场对未来价值创造的预期是否合理。

| 参数 | 值 |
|---|---|
| Normalized EPS（2026E） | ¥3.37 |
| 替代Normalized EPS（2027E） | ¥4.55 |
| Ke（A股权益成本） | 9.0% |
| SSV/股（基于2026E） | 3.37 ÷ 0.09 = **¥37.44** |
| SSV/股（基于2027E） | 4.55 ÷ 0.09 = **¥50.56** |
| 当前股价 | ¥104.56 |
| 实际PVGO%（基于2026E） | (104.56-37.44) ÷ 104.56 = **64.2%** |
| 实际PVGO%（基于2027E） | (104.56-50.56) ÷ 104.56 = **51.6%** |

**合理PVGO%判断**：

| 维度 | 评估 | 对PVGO的影响 |
|---|---|---|
| ROIC vs WACC | ROE 11.88%（2025），趋势下行；WACC ≈ Ke = 9%；ROIC略高于WACC但差距收窄 | 不支持高PVGO% |
| 竞争护城河 | 深度分析评分12/20（60%），中等 | 不支持高PVGO% |
| 增长可见性 | 6nm+WiFi6放量是结构性机会，但OCF问题削弱信心 | 支撑中等PVGO% |
| 管理层质量 | 79/100，创始人技术驱动型 | 支撑中等偏上PVGO% |

**综合判断**：合理PVGO%区间 **30-40%**（ROIC>WACC但护城河一般，增长可见性中等）。

| 情景 | 合理PVGO% | 合理价（2026E SSV） | 合理价（2027E SSV） | 逻辑 |
|---|---|---|---|---|
| 保守 | 25% | ¥49.92 | ¥67.41 | OCF持续恶化，市场下调增长预期 |
| 基准 | 35% | **¥57.60** | **¥77.78** | 2026E部分兑现，OCF改善但未完全消化 |
| 乐观 | 45% | ¥68.07 | ¥91.93 | 6nm+WiFi6暴发，OCF转正，PVGO修复 |

**基准合理价（取2027E SSV）：¥78（-25.5% vs 现价）**

> ⚠️ PVGO给出最低的估值——因为假设"稳态盈利"仅为2026E/2027E水平，而市场定价中包含了远远超过这一水平的增长预期。PVGO% 51-64%远高于S&P 500历史均值35%，也高于多数A股半导体公司（通常40-50%）。这是逆向DCF之外的第二个"市场预期偏高"信号。

**PVGO vs 逆向DCF互补解读**：

| | PVGO | 逆向DCF |
|---|---|---|
| 发现 | 股价中52-64%来自对未来增长的预期 | 隐含10年EPS CAGR 16.7%（从2025A）或10.4%（从2026E） |
| 含义 | 预期占比偏高（S&P 500均值35%） | 增速假设并不离谱（半导体行业长期CAGR ~12-15%） |
| 综合解读 | **市场对"增长的质量"定价很高，但对"增长的幅度"定价尚可。核心赌注不是"能不能增长"，而是"增长能不能兑现为现金"。** |

### 方法6：标准化FCF Yield（权重5%）

> 核心思路：OCF为负是核心硬伤，但需区分"永久性问题"还是"存货周期的暂时扭曲"。用正常化FCF计算隐含合理市值。

| 参数 | 值 |
|---|---|
| 2022 OCF | +5.33亿 |
| 2023 OCF | +9.48亿 |
| 2024 OCF | +10.42亿（最佳年份） |
| 2025 OCF | **-2.30亿** |
| **3Y平均OCF（2022-2024）** | **+8.41亿** |
| **含2025的4Y平均** | **+5.73亿** |
| 维护性Capex（Fabless，~1-2亿/年） | ~1.5亿 |
| **正常化FCF（3Y去极值）** | 8.41 - 1.5 = **~6.9亿** |
| **悲观正常化FCF（含2025）** | 5.73 - 1.5 = **~4.2亿** |

> 正常化逻辑：2025年OCF为负主因存货从10.7亿暴增至25.3亿（+14.6亿营运资金占用）——属于扩张性而非经营性恶化。若2026年存货消化（出货放量），OCF有望修复至5-10亿区间。但Q1 2026 OCF=-4.82亿说明消化尚未开始。
