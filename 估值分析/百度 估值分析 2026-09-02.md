```
          = 74.366 ≈ 74.4 HKD
```

## 风险与催化剂

### 风险
1. **搜索广告止血失败**：传统广告连 8 季下滑，若 AI 答案分流持续，FY27 恢复假设（NI 175 亿）证伪 → 目标价下移至 PE27 10x（~70 HKD）。
2. **AI 云盈利拐点推迟**：capex 折旧前置，若 GPU 云高增不转化为分部利润，EV/EBITDA 与 SOTP 的 AI 云假设同步下修。
3. **净现金口径/可动用性**：若大额现金受汇出/用途限制或加速烧钱，SOTP 下沿（~104）失守。
4. **萝卜牌照冻结持续**：Q2 订单骤降若成常态，期权价值归零风险。
5. **地缘升级**：1260H 升级为实际制裁 / 芯片管制加码。
6. **昆仑芯分拆估值倒挂 + 绑定配售**：若 IPO 定价远低于传闻，损害母公司价值显性化叙事。

### 催化剂
1. **在线营销同比止血**（单季不再双位数下滑）→ 直接修复「现金牛失血」这一核心担忧。
2. **AI 云分部利润转正**或披露 EBITDA 拐点 → certainty 上移。
3. **昆仑芯 IPO 落地**（若定价合理 + 移出绑定条款）→ 价值显性化 + 资金回流。
4. **萝卜牌照解冻 + 周订单回到 30 万+** → 期权价值回归。
5. **纳入港股通 + 南向流入**（大摩估 2026-09 纳入，6-12 个月流入 $3-6.8B）→ 短期资金面支撑。
6. **回购/首次股息落地** → 股东回报底部确认。

## 一句话结论

> 百度是「深价值 + 转型期权」标的而非质量标的（深分 60 < 70、NONE 档）：现价 HK$92.35 的 ~44-54% 是净现金/上市股权（~40-50 HKD），经营盘（搜索 + AI 云）仅被定价约 4-5x EV/EBITDA——市场已对「搜索不可逆下滑」充分悲观、对「AI 云转盈 + 昆仑芯 + 萝卜」几乎未付费（隐含长期增速仅 ~3%）。**合理价 HK$103（现价低于 fair 约 10%），certainty 0.30（低，误差带极宽），机械买入 HK$74.4——当前无买入权限**。买点=等它跌到 74 港元附近（安全边际），或等「搜索止血 / AI 云转盈 / 昆仑芯落地」任一拐点让 certainty 与买入线自行抬升。
