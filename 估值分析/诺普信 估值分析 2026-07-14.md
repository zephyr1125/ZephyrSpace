## 三、多方法估值

### 方法选择矩阵

诺普信特征：农药+蓝莓双轮驱动，蓝莓处于重资本投入期（高CAPEX/低FCF），2026E盈利跳升67.7%，高杠杆（D/E 63%），治理有红旗。

| 方法 | 适用性 | 权重 | 说明 |
|---|---|---|---|
| **PE 历史分位** | 适用——盈利已稳定，2026E EPS跳升需作为主锚 | **25%** | 以2026E EPS为主，2025A EPS交叉验证 |
| **PEG** | 适用——2026E增速67.7%极高，需用3Y可持续增速校准 | **15%** | 增速从67%→25%快速回落，PEG=1非合理锚 |
| **EV/EBITDA** | 适用——有息负债34.81亿，D/E 63%，需用企业价值法 | **15%** | 制造业+农业属性，负债纳入估值 |
| **标准化FCF Yield** | 核心——报表FCF（1.78亿）被CAPEX吞噬，必须标准化 | **20%** | OCF 14.75亿强劲，维护性CAPEX仅~3亿 |
| **逆向DCF** | 适用——验证市场对蓝莓增长的隐含预期 | **15%** | 以2025A EPS为基准，两阶段增长模型 |
| **SOTP分部估值** | 辅助——蓝莓vs农药商业模式差异大 | **10%** | 分部PE法，蓝莓高增长高PE/农药低增长低PE |

### 方法独立性声明

| 方法 | 权重 | 独立性说明 |
|---|---|---|
| PE分位 | 25% | 与PEG共享EPS/盈利预期，但切入角度不同（市场相对历史 vs 增长定价），**弱相关** |
| PEG | 15% | 与PE分位共享EPS，但引入了增速维度，**部分重叠**（PE+PEG合计40%属合理） |
| EV/EBITDA | 15% | 与盈利类方法共享EBITDA底层，但引入负债/企业价值视角，**弱相关** |
| 标准化FCF Yield | 20% | 与盈利类方法同源（基于净利润→现金转化），但切入口不同（现金回报 vs 会计利润），**弱相关** |
| 逆向DCF | 15% | 与其他方法共享EPS但验证隐含增速，**部分重叠** |
| SOTP | 10% | 分部独立估值，与整体法切入角度不同，**基本独立** |

> 结论：本次6法可归为3类信号（相对估值PE/PEG / 企业价值EV+SOTP / 现金流FCF+逆向DCF），已控制同源权重，加权中枢可信。

### 方法 4：标准化FCF Yield（权重 20%）⭐ 核心方法

| 输入参数 | 值 |
|---|---|
| 2025A OCF | **14.75亿** |
| 2025A CAPEX | **9.98亿** |
| 维护性CAPEX（估算） | **~3亿**（占总CAPEX约30%；农药产能维护+蓝莓老园区维护） |
| 扩张性CAPEX（估算） | **~7亿**（蓝莓新增种植面积+老挝基地） |
| 标准化FCF | **11.75亿**（OCF 14.75 - 维护性CAPEX 3.00） |
| 标准化FCF/股 | **1.17元**（11.75 / 10.05亿股） |
| 报表FCF | **1.78亿**（已发布，被CAPEX吞噬） |
| 当前标准化FCF Yield | **13.2%**（11.75 / 89） |

> **为什么必须标准化？** 报表FCF 1.78亿（FCF Yield 2.0%）严重失真——公司正处于蓝莓重资本投入期，~7亿CAPEX是"可选"的增长投入而非维持运营所必需。一旦蓝莓投产高峰期过去（预计2027-2028），CAPEX将回落至维护水平，FCF将释放。

| 情景 | FCF Yield | 合理市值（亿） | 合理价（元） |
|---|---|---|---|
| 保守（10%，农业高杠杆折价） | 10% | 117.5 | **11.69** |
| 基准（8%，蓝莓品种权+农药现金流） | 8% | 146.9 | **14.62** |
| 乐观（6.5%，CAPEX触顶回落FCF释放） | 6.5% | 180.8 | **17.99** |

**结论：合理价 ≈ 14.00元（基准8.5% FCF Yield，介于保守和基准之间），vs 8.86元 = +58.0% 低估**

> 标准化FCF Yield 13.2%意味着当前市场愿意为每1元可分配现金流仅支付7.6x——对于一个OCF/净利227%的公司，这是极端便宜的定价。核心前提：蓝莓CAPEX是增长性而非维持性，这一判断成立则低估显著。

### 方法 5：逆向DCF（权重 15%）

**核心问题：当前8.86元的股价隐含多高的EPS增长率？这个增长率是否合理？**

| 参数 | 值 |
|---|---|
| 基准EPS | **0.65元**（2025A，实际值） |
| 折现率（WACC） | **9.5%**（A股一般水平 + 杠杆折价，高于标准9%） |
| 成长期 | **10年** |
| 终值PE | **15x**（农业+制造，品牌弱） |

**两阶段增长模型**：
- 阶段1（Y1-3）：受益于蓝莓投产放量+农药底部修复，增速较高
- 阶段2（Y4-10）：蓝莓进入稳态，增速回归农业公司常态

**逆向求解**：市场隐含 10Y EPS CAGR ≈ **5-6%**

| 市场隐含增速 | 判断 |
|---|---|
| **5-6%**（当前价8.86元） | 市场预期蓝莓品种权壁垒无法阻挡供给暴增，利润增长极为温和 |
| **10%**（券商一致预期下限对应增速） | 2027E 1.36 → 3.5Y CAGR ≈ 20%，10Y远低于此因终值回归 |
| **25%**（2026→2027券商增速） | 仅适用于阶段1，不可持续 |

| 情景 | 阶段1增速(3Y) | 阶段2增速(7Y) | 合理价 |
|---|---|---|---|
| 保守（蓝莓价格彻底"阳光玫瑰化"） | 15% | 3% | **8.50元** |
| 基准（蓝莓品种权壁垒有效，增速放缓但为正） | 25% | 6% | **11.50元** |
| 乐观（蓝莓价格企稳+东南亚出口+农药恢复） | 35% | 8% | **14.80元** |

**结论：逆向DCF合理价 ≈ 11.50元（基准），vs 8.86元 = +29.8% 低估**

> 逆向DCF是6法中最保守的之一，因为它用2025A EPS(0.65)为基准而非2026E(1.09)。这更谨慎，但可能过于悲观——如果2026H1蓝莓价格没有进一步崩盘，2026E EPS有较大可能落在0.90-1.10区间。

### 方法 6：SOTP 分部估值（权重 10%）

诺普信的蓝莓和农药是两个商业模式差异显著的业务，适合分部估值。

| 分部 | 2025营收（亿） | 估算净利（亿） | 合理PE | 分部价值（亿） | 依据 |
|---|---|---|---|---|---|
| 蓝莓 | 26.57 | **4.0** | **16x** | **64** | 品种权壁垒+促早技术+高增长，给成长溢价 |
| 农药制剂 | 24.82 | **2.0** | **12x** | **24** | 成熟现金牛，农药行业中性PE |
| 控股经销商 | 6.44 | **0.5** | **8x** | **4** | 低毛利渠道业务，折价 |
| **合计** | **57.83** | **6.50** | — | **92** | — |

| 项目 | 金额（亿） |
|---|---|
| 分部价值合计 | 92 |
| 减：净债务（~20亿估算） | -20 |
| **股权价值** | **72** |
| **每股价值** | **7.17元** |

| 情景 | 蓝莓PE | 农药PE | 每股价值 |
|---|---|---|---|
| 保守（蓝莓跌价预期压低估值） | 12x | 10x | **5.67元** |
| 基准 | 16x | 12x | **7.17元** |
| 乐观（蓝莓价格企稳+出口放量） | 20x | 15x | **9.55元** |

**结论：合理价 ≈ 7.50元（基准偏乐观，蓝莓18x/农药13x），vs 8.86元 = -15.3% 高估**

> SOTP是6法中唯一给出"当前偏高"结论的方法。原因：净债务~20亿吃掉大量分部价值。但也存在向上重估空间——如果蓝莓利润占比从62%继续提升（2026E），蓝莓分部PE上调将拉动整体估值。SOTP对净债务假设敏感：若实际净债务低于20亿，估值将上调。

### 复核讨论

SOTP给出7.50元、PEG给出15.50元——6法极差~8元，是本次估值的核心张力：
- **悲观端（SOTP 7.50/EV-EBITDA 9.65）**：基于存量资产+净债务负担定价，反映"蓝莓=普通农业资产"视角
- **乐观端（PEG 15.50/标准化FCF 14.00）**：基于盈利增长+现金流释放定价，反映"蓝莓=品种权壁垒资产"视角

**合理价中枢选择**：取逆向DCF(11.50)和PE分位(13.08)的均值偏保守位 **≈ 12.50元**，对应2026E PE约11.5x、2025A PE约19.2x。这个估值：
- 认可蓝莓品种权+促早技术有一定壁垒（不是普通农业资产）
- 但为高杠杆+治理红旗+蓝莓供给风险保留了折价
- 较当前8.86元有约41%上行空间

> **⚠️ 关键假设**：2026E EPS 1.09元能基本兑现（±15%）。若蓝莓价格在2026H2加速下行导致一致预期下修至0.80元以下，合理价中枢将下移至9-10元区间。
