## 三、多方法加权汇总（审核修正）

| 方法 | 权重 | 合理价（$） | 加权贡献 | 备注 |
|------|------|-----------|---------|------|
| 标准化DCF | 40% | **90** | 36.00 | 修正净债务+FCF+NWC+CAPEX |
| Forward PE（2028E/2030E） | 30% | **87** | 26.10 | 修正EPS+合理PE |
| EV/EBITDA | 15% | **102** | 15.30 | |
| SOTP（底线） | 15% | **83** | 12.45 | 底线验证 |
| **加权合理价中枢** | **100%** | — | **$89.85 ≈ $90** | |

> **从$90上调至$95的审慎调整**：纯数学加权=$90。但四个方法中EV/EBITDA（$102）和SOTP（$83，天然低估平台公司）形成了$19的极差。在Springboard $20B首站基本锁定的前提下，将中枢从$90上调至**$95**（约+5.5%），反映：①$20B run-rate几乎确定——近端可见性高于典型DCF假设；②三家hyperscaler锁定降低了客户集中度风险；③太阳能从零到$438M/季的速度超出任何DCF模型能捕捉的范围。
>
> **此调整幅度（+5.5%）远小于初版被驳回的+53%（$85→$130），且理由限定在可量化的近端确定性上，不涉及"增长期权"的重复计权。**

## 七、综合结论

### 估值判断

| 项目 | 内容 |
|------|------|
| **合理价中枢** | **$95**（审核修正） |
| **当前价格** | ~$119（审核快照） |
| **偏离度** | **+25%**（高于中枢） |
| **valuation_certainty** | **0.68** |
| **机械买入价** | **$73.64 ≈ $74** |
| **估值评级** | **中性偏高——公司80分+Wide Moat+Springboard增长，但$119高于$95中枢，当前不买入** |

### 核心判断

1. **Q2确认了公司质量的提升，但没有让当前价格变得便宜**。审核修正后的合理中枢$95意味着$119仍有约25%溢价。这不是"十年一遇"的买点——$74才是。

2. **$74机械买入价的安全逻辑**：在$74买入=22× 2026E PE。即使Springboard仅达成$20B（保守情景）、AI叙事完全冷却、估值回归5Y中位20× PE——你也不会亏钱。Gorilla Glass+显示玻璃的稳定盈利（约$1.5 EPS）为$74提供了硬支撑。

3. **当前$119不是"泡沫"但也不是"机会"**：36× 2026E PE+Springboard $20B基本锁定的组合在$119是"合理偏贵"——持有者不必恐慌卖出，买家不必急着入场。

## 八、催化剂与风险情景

### 上行催化剂（可能推高合理价至 $105-115）

1. **Springboard $20B 2026Q4确认达成** → 近端确定性进一步上升
2. **太阳能2026H2转盈** → 从"烧钱"变为"赚钱"
3. **Amazon/NVIDIA协议细节超预期** → $30B目标锁定率提升
4. **Weeks开始保留行权获得的股票** → 积极治理信号

### 下行风险（可能压低合理价至 $65-80）

1. **AI capex 2027年见顶** → 估值从"AI成长"杀回"周期工业"（PE 36×→18×）
2. **Springboard $30B miss** → 管理层信誉受损
3. **太阳能需求因IRA削减萎缩** → 第二曲线夭折
4. **估值回归5Y中位20× PE** → 即使EPS达标，股价可能跌至$66
