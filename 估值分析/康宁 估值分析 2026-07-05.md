## 二、多方法估值

### 方法 1：5年 DCF（权重 35%）

**逻辑**：Corning的Springboard计划给出了到2028年的量化增长目标，适合用DCF估算合理价值。

| 参数 | 数值 | 依据 |
|------|------|------|
| 2025基准FCF | ~$1.72B | 实际值 |
| 2026-2028 FCF增速 | 15-25% | Springboard计划路径 |
| 2029-2030 FCF增速 | 10-15% | Springboard延伸+增速自然放缓 |
| 终端增速 | 3% | 名义GDP匹配 |
| WACC | 9% | 美股工业股标准 |
| 终端FCF倍数 | 20× | 优质工业股+Wide Moat溢价 |

**DCF情景分析**：

| 情景 | 假设 | 合理市值($B) | 合理股价 |
|------|------|------------|---------|
| 保守 | Springboard达成70% ($7.7B增量), 终端PE 15× | ~$1,200 | **$140** |
| 基准 | Springboard达成90% ($10B增量), 终端PE 18× | ~$1,590 | **$185** |
| 乐观 | Springboard达成100% ($11B), 终端PE 20× | ~$1,850 | **$215** |
| 极度乐观 | Springboard超预期到$13B, 终端PE 22× | ~$2,200 | **$256** |

**本方法合理价：$185**（基准情景）

### 方法 2：Forward PE 目标估值（权重 25%）

**逻辑**：用2027E/2028E的EPS × 合理的远期PE，反推当前合理价。

| 情景 | 目标年份 | 目标PE | 目标股价 | 折现至2026（9%） | 
|------|---------|--------|---------|-----------------|
| 保守 | 2028E EPS $5.69 | 20× | $113.80 | $95.78 |
| 基准 | 2028E EPS $5.69 | 25× | $142.25 | **$119.72** |
| 乐观 | 2028E EPS $5.69 | 30× | $170.70 | $143.67 |
| 当前叙事 | 2028E EPS $5.69 | 34× | $193.46 | $162.82 |

> 折现率9%，2年折现（2028→2026）

**核心问题**：即使是乐观情景（30× 2028E PE），折现后的当前合理价仅$144，远低于$196。当前$196需要2028E PE 34×才能支撑——这意味着市场定价的是"Springboard完美执行+AI叙事持续+高估值不回落"三重乐观假设同时成立。

**本方法合理价：$120**（基准情景——25× 2028E PE，这对Wide Moat工业股已属合理偏高）

> 但此方法可能在"大牛市"中过于保守——当AI叙事正热时，市场可能给予更高PE。故在实际权重中适度上调。

### 方法 4：逆向DCF（权重 15%）

**逻辑**：从当前$196反推市场隐含的FCF增速。

| 参数 | 数值 |
|------|------|
| 当前FCF | $1.72B |
| 隐含10年FCF CAGR | **~14%** |
| 终端FCF倍数 | 18× |

**判断**：10年FCF CAGR 14% → 10年后FCF = $1.72B × 1.14^10 = $6.2B → 终端EV = $6.2B × 18 = $112B → 加上期间FCF → 与当前$168B市值基本吻合。

14% FCF CAGR在AI驱动的光通信高增长阶段（2025-2028年+25-35%）可能实现，但在2029-2035年的"稳态"阶段难以维持（工业公司长期FCF增速通常为5-8%）。

**本方法判断**：当前价格隐含的预期偏高（14% FCF CAGR是工业公司中极少见的长期增速），市场定价偏乐观。

### 方法 5：PEG（权重 5%）

| 参数 | 数值 |
|------|------|
| 2026E PE | 61× |
| 2026E→2028E EPS CAGR | 33% |
| PEG = 61 / 33 | **1.85×** |

PEG > 1.5× 通常被视为偏贵。但若用2025A→2028E CAGR（$2.52→$5.69=31%）：PEG = 61/31 = 1.97× → **偏贵**。

## 五、催化剂与风险情景

### 上行催化剂（可能推高合理价至 $220-250）

1. **Springboard $11B目标提前一年达成**（2027年而非2028年）→ 2028E EPS从$5.69上调至$6.50+
2. **第三个Meta级hyperscaler大单落地**（如Google/Amazon）→ 光通信增速维持+40%
3. **Gorilla Glass进入汽车玻璃市场**（如全玻璃车顶/AR-HUD）→ 打开新$5B+ TAM
4. **AI叙事升级为"AGI基建"** → 市场将Corning从"工业股"永久重定价为"AI基础设施股"

### 下行风险（可能压低合理价至 $100-140）

1. **AI capex周期见顶**（2027年hyperscaler开始削减资本开支）→ 光通信增速从+35%降至+5%
2. **Springboard目标miss** → $11B最终仅达$7-8B → 市场重新定价为"管理层承诺过度"
3. **EU反垄断判罚+排他协议被禁** → Gorilla Glass面临中国竞争者的价格战
4. **Weeks退休/减持加速** → 关键人物风险+信心信号恶化
5. **估值回归均值** → Forward PE从61×回落至30×（历史中位仍远低于此）→ 即使EPS达标，股价仍可能下跌30%+

## 六、综合结论

### 估值判断

| 项目 | 内容 |
|------|------|
| **合理价中枢** | **$170**（多方法加权调整后） |
| **当前价格** | $196（2026-07-01） |
| **偏离度** | +15%（高于中枢） |
| **估值评级** | **中性偏高——长期优质但短期估值已透支大部分Springboard叙事** |
| **对应 2028E PE** | 当前$196对应34× vs 合理中枢$170对应30× |
| **核心不确定性** | AI capex可持续性（决定β）+ Springboard执行完美度（决定α） |

### 关键判断

1. **好公司 ≠ 好价格**。Corning 80分+Wide Moat+Springboard执行力都是真实的——但$196的价格已经将大部分好消息计入了。2028E EPS $5.69 × 34× PE = $193——你现在付的价格大致等于"所有事情都完美执行"后的两年后合理价值。相当于两年"免费等待"——如果一切完美执行，年化回报 ≈ 0-5%；如果执行有瑕疵，年化回报可能为-20%+。

2. **估值的最乐观情景：$220-250**（需Springboard超预期+AI叙事不破+市场不杀估值三重条件）vs **最悲观情景：$80-100**（Springboard miss+AI capex见顶+估值回归均值）。Risk/Reward比在$196位置约为 1:2.5（上行$54 vs 下行$96），不对称地偏向下行。

3. **$100-140区间是真正的"安全边际"区域**——届时无论AI叙事如何演变，Gorilla Glass+显示玻璃的稳定盈利（约$1.5 EPS）本身就能支撑$100+的估值。在$100以下买Corning等于"白送光通信的AI期权"。

### 操作建议

- **当前价位（$196）**：不建议新建仓位。已持有者可部分减仓（减至半仓）
- **理想买入区间（$120-150）**：Springboard部分定价、AI叙事有冷却、估值回归至较合理水平——可分批建仓至重仓
- **极度低估区间（≤$100）**：大概率伴随AI叙事危机或市场系统性恐慌——届时应大幅加仓（这是Corning的"十年一遇"买点）
- **减仓/清仓区间（≥$250）**：估值进入极端乐观区间，Springboard即使达成也已充分定价
