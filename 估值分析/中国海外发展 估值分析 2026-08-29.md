## 三、估值方法选择与执行

**公司特征**：周期底部的央企地产龙头。盈利下滑、毛利率底部未确认、但资产负债表行业最稳健、市占率逆势提升。**强周期+重资产 → 以 PB 为主线，辅以正常化 PE、股息率、NAV 交叉验证。**

> ⚠️ PEG 不适用（周期股盈利处于底部，增速失真）；逆向 DCF 仅作诊断（与 PE 同源，不重复计分）。

### 方法 1：P/B 历史分位法（核心）

| 参数 | 值 |
|---|---|
| 当前 PB | 0.333x |
| 3 年 PB 中位数 | 0.37x |
| 3 年 PB 区间 | 0.26x – 0.51x |
| 合理 PB（底部周期央企龙头，中位数+质量溢价） | **0.38x** |
| 每股净资产（BVPS） | 39.6 港元（归母权益约 3,900 亿人民币 ×1.11 / 109.45 亿股） |
| **合理价** | 0.38 × 39.6 ≈ **15.0 港元** |

> 逻辑：PB 中位数 0.37x 反映正常化 ROE ~7% 的合理定价；当前 ROE 3.6%（周期底部）理应按 PB 0.25-0.35x 交易，但央企龙头质量溢价+市占率逆势提升+资产负债表极稳，给予 0.38x（中位数上沿）作为**周期底部估值锚**——隐含市场对未来 2-3 年 ROE 修复的合理定价。

### 方法 2：正常化 PE 法

| 参数 | 值 |
|---|---|
| 正常化 EPS（用 2027E 一致预期，隐含毛利修复） | 1.21 元人民币 ≈ 1.34 港元 |
| 周期底部合理 PE | **10.0x**（港地产周期股底部 8-11x） |
| **合理价** | 1.34 × 10.0 ≈ **13.4 港元** |
| 参考：FY2025 核心 EPS | 1.32 港元 × 10.2x ≈ 13.5 港元 |

> 逻辑：一致预期 2027E 净利 ~132 亿元（较 2025 年 +4%），隐含毛利率小幅修复；10x PE 为底部周期央企合理倍数（大摩悲观 8.6x、美银给 2027 年 11x）。**用 forward EPS 而非历史 EPS**（TTM 历史 PE 不得乘 forward EPS）。

### 方法 3：股息率 / DDM（股东回报锚）

| 参数 | 值 |
|---|---|
| 2027E DPS | ≈0.50 港元（一致预期 0.45 元人民币） |
| 合理股息率（央企蓝筹稳定回报） | **4.0%** |
| **合理价** | 0.50 / 0.040 ≈ **12.5 港元** |
| 当前股息率 | 3.6%（13.82 港元） |

> 逻辑：DPS 从 1.21 降至 0.50 后已趋稳（H1 2026 中期息 0.23 环比持平），派息率 38.6% 稳定。按 4.0% 合理股息率，当前 3.6% 的收益率偏低——**股息视角偏谨慎**（市场在定价盈利修复而非当前分红）。DDM 与股息率同源，合并为单一股东回报锚。

### 方法 4：NAV 法（交叉验证）

| 参数 | 值 |
|---|---|
| 每股 NAV 估计 | ≈45 港元（BVPS 40 港元 + 核心城市土储/商业物业重估溢价，粗略估算） |
| 央企龙头合理折价率（周期底部） | 0.42x（底部 0.3-0.4x，修复期 0.5x+） |
| **合理价** | 45 × 0.42 ≈ **18.9 港元** |
| 现价 P/NAV | 13.82 / 45 ≈ 0.31x |

> ⚠️ NAV 为粗略估算（无逐项目重估模型），置信度低，仅作上界参考，低权重。国泰海通按 2026 年 PB 0.5x 给 20.3 港元目标价（与本方法量级一致）。

## 六、风险与催化剂

### 主要风险

1. **毛利率继续下滑**（重大）：若结转项目毛利率跌破 15%，2026-2027 盈利将低于一致预期（悲观情景合理价 9-11 港元）
2. **楼市量价双弱**（重大）：一线城市成交回落/二手价下跌 → 销售复苏证伪 + 土储减值
3. **拿地激进反噬**：2023-2025 连续三年拿地行业第一（权益 924 亿/2025），若新拿地项目毛利率不达预期，逆势扩储将转为负担
4. **汇率**：人民币贬值侵蚀 HKD 计价 EPS/股息

### 催化剂

1. **毛利率企稳回升**：H1 2026 16.1%（环比回升），若连续两季确认 ≥17%，盈利拐点确立
2. **合约销售持续双位数**：H1 2026 +11.8% 权益第一，若全年维持，结转收入将回升（H1 收入已 +17.3%）
3. **商业 REITs/经营性业务重估**：商业收入 72 亿已覆盖利息，REITs 上市打开重估空间（国泰海通核心逻辑）
4. **政策加码**：稳地产+城市更新+现房销售改革推进
5. **分红稳定**：派息率 38.6%，若利润企稳 DPS 止跌（H1 中期息已环比持平）
