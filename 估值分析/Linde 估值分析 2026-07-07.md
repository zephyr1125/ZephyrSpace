## 四、多方法估值

### 方法 1：PE 历史分位法（权重 30%）

**逻辑**：以2026E EPS为锚，参考3Y/5Y PE分位设定合理PE倍数。

| 参数 | 值 |
|---|---|
| 2026E EPS | $17.85（指引中位） |
| 3Y平均PE (2023-2025) | ~31x |
| 5Y P50 PE | ~35x |
| 5Y P20 PE | ~32.5x |
| **合理PE（判断）** | **30x**（接近3Y均值、略低于5Y中位、给予利率环境上升的折扣） |

| 情景 | PE | 合理价 | vs现价 |
|---|---|---|---|
| 保守 | 28x | $500 | -7.4% |
| 基准 | 30x | **$536** | -0.8% |
| 乐观 | 33x | $589 | +9.0% |

**结论：合理价 ≈ $536（+/- 8% vs 现价$540）**

> 💡 为什么不用5Y中位35x？5Y数据包含2020-2021年的COVID时期异常高估值（PE高达47-63x），拉高了5Y中位。当前利率环境（10Y 4.3%）不支持35x作为"正常"估值。30x更接近近3年的实际交易均值。

---

### 方法 2：PEG 法（权重 10%）

**逻辑**：PEG = Forward PE / EPS增长率。对Linde这种高质量复利型公司，PEG 2.5–3.0x可接受。

| 参数 | 值 |
|---|---|
| 2026E EPS增长 | 8.5%（$16.46→$17.85） |
| LT EPS增长（共识） | ~9% |
| 合理PEG | 2.8x（高质量复利型，非高速成长型） |
| **合理Forward PE** | **2.8 × 9 = 25.2x** |

| 情景 | PEG | 合理Forward PE | 合理价 |
|---|---|---|---|
| 保守 | 2.5x | 22.5x | $402 |
| 基准 | 2.8x | 25.2x | **$450** |
| 乐观 | 3.2x | 28.8x | $514 |

**结论：合理价 ≈ $450（-16.7% vs 现价）**

> ⚠️ PEG法对Linde适用性有限：PEG更适合成长型公司（增速>15%），对一个增速仅9%的成熟工业公司用PEG，结果偏保守。故权重仅10%。

### 方法 4：标准化 FCF Yield 法（权重 25%）

**逻辑**：FCF是股东最终能拿到的真金白银。用标准化FCF（平滑Capex周期波动）和合理FCF Yield倒推公允价值。

| 参数 | 值 |
|---|---|
| TTM OCF | ~$103.5亿 |
| 标准化维护Capex | ~$35亿（≈折旧$36亿） |
| 增长Capex（保留在FCF中） | ~$18亿 |
| **标准化FCF** | ~$50亿（$103.5–$35–$18≈$50.5亿，四舍五入） |
| **每股标准化FCF** | ~$10.82（$50亿/4.62亿股） |
| 历史FCF Yield区间 | 2.5–3.8% |
| 当前FCF Yield | 2.04%（历史最低） |
| **合理FCF Yield** | **2.5%**（历史区间下沿，给予质量溢价） |

| 情景 | FCF Yield | 合理价 |
|---|---|---|
| 保守 | 3.0%（历史中位） | $361 |
| 基准 | 2.5%（历史区间下沿） | **$433** |
| 乐观 | 2.0%（极低——当前水平） | $541 |

**结论：合理价 ≈ $433（-19.8% vs 现价）**

> ⚠️ FCF Yield法给出的估值最低，因为当前$540隐含的FCF Yield(2.04%)确实处于历史极端水平。但Linde目前处于"增长Capex周期"——FCF被暂时压低（因为大规模氢能投资），未来Capex正常化后FCF将回升。这是"结构性的低FCF Yield"而非"永久性的低FCF Yield"——因此用"标准化FCF"（即假设增长Capex周期结束后的正常化FCF）来计算。

### 方法 5：逆向 DCF（权重 20%）

**逻辑**：从当前股价反推市场在定价什么样的未来增长，然后判断这个增长假设是否合理。

| 参数 | 值 |
|---|---|
| TTM调整后EPS | ~$16.50 |
| 折现率 | 9%（美股工业股） |
| 成长期 | 10年 |
| 终值PE | 18x（工业龙头） |

| 隐含10年EPS CAGR | 合理价判断 |
|---|---|
| **当前$540隐含** | **~10.5%** |
| 若实际增长9%（共识） | ~$486（-10%） |
| 若实际增长8%（保守） | ~$438（-19%） |
| 若实际增长12%（氢能超预期） | ~$610（+13%） |

**结论**：当前$540隐含~10.5%的10年EPS CAGR。这**高于**共识的9%——市场在为Linde定价一个"超预期"的未来。如果氢能/航天/电子气体三重引擎全部兑现且超预期，10.5%可以做到。但如果任何一个引擎miss，估值会向$486（9%增长情景）收敛。

**逆向DCF合理价**：取共识增长(9%)情景=$486，给予氢能期权溢价+$54(到$540)。**基准合理价=$500**（10% CAGR折中）。

> 加权合理价 ≈ **$484**。较现价$540低10.4%。这意味着按多方法加权，Linde当前约有10%的高估。

### ⚠️ 方法分歧与处理

FCF Yield和EV/EBITDA给出的估值显著偏低（$433/$467），PE分位法给出的估值接近现价($536)。这个分歧的根源是：
- **PE分位法**用"市场已经给予Linde的倍数"来估值（接受现状）
- **FCF Yield和EV/EBITDA**用"市场应该给予Linde的倍数"来估值（向历史均值回归）

**我的处理**：不简单取平均。对于一个ROIC 24%、34年增息、寡头格局、三重增长引擎的卓越公司——市场确实应该给予溢价。但溢价不应是无上限的。30x Forward PE（基准PE分位）已经包含了显著的品质溢价。因此最终合理价中枢定在**$509**，取PE分位基准($536)和绝对估值法均值(~$480)的中间偏上。
