## 四、多方法估值

### 方法 1：PE 历史分位法（权重 30%）

**逻辑**：以2026E EPS为锚，参考周期中位PE设定合理倍数。

| 参数 | 值 |
|---|---|
| 2026E EPS | 0.85元（正常化基准，券商预期范围为0.83-0.93元） |
| 3Y PE中位 | ~20x |
| 5Y PE中位 | ~18x |
| 周期底部合理PE | **15x**（周期底部+治理折价+竞争格局折价） |

| 情景 | PE | 合理价 |
|---|---|---|
| 保守（周期不复苏） | 12x | 10.2元 |
| 基准（温和复苏） | 15x | **12.8元** |
| 乐观（景气回升+出口超预期） | 18x | 15.3元 |

**结论：合理价 ≈ 12.8元（-9.2% vs 现价14.09元）**

> 💡 15x基准PE已反映东方红品牌+核心零部件自制体系+出口增长等品质溢价；同时扣除低毛利、强周期、治理折价和竞争格局（CR2仅37%）的合理折扣。

### 方法 4：逆向 DCF（权重 20%）

**逻辑**：从当前股价反推市场在定价什么样的未来增长。

| 参数 | 值 |
|---|---|
| TTM EPS | ~0.72元 |
| 折现率 | 10%（A股工业股+治理风险溢价） |
| 成长期 | 8年 |
| 终值PE | 12x（周期股终值不应用高PE） |

| 隐含8年EPS CAGR | 合理价判断 |
|---|---|
| **当前14.09元隐含** | **~8%** |
| 若实际增长5%（保守：仅出口驱动） | ~11.0元（-22%） |
| 若实际增长8%（基准：温和复苏+出口） | **~14.1元**（≈现价） |
| 若实际增长12%（乐观：景气回升+出口+产品升级） | ~18.5元（+31%） |

**结论**：当前14.09元隐含~8%的8年EPS CAGR。这个假设要求出口持续30%+增长+国内温和复苏——**现实但非保守**。逆向DCF基准合理价≈**14.0元**。

## 八、一句话结论

> **一拖是农机整机领域中相对不错的公司（69/100），但未达到正式Watchlist资格（cScore 69+mScore 70=139<150）。当前14.09元高于合理价值13元——公司质量尚可但价格没有低估。不是农机智能化中高毛利核心受益者，护城河被此前分析高估（CR2仅37%、自制率无官方定量出处、智能化仍在早期）。真正值得等待的不是股价跌到10元，而是公司质量出现结构性提升：出口收入占比明显提高、智能产品形成可验证收入和毛利、国内市场集中度真正上升，以及新管理层连续两年以上保持干净治理记录。**
