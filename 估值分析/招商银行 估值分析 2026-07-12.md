## 三、多方法估值

### 方法 1：PB 历史分位回归（权重 35%）

### 方法 2：PB-ROE 内在价值（权重 15%， sanity check）

银行内在 PB ≈ (ROE − g) / (r − g)，取 ROE=13.4%、CoE r=9.5%、永续增长 g=4%：
- 理论 PB = (13.4−4)/(9.5−4) = 9.4/5.5 = **1.71x** → 隐含价 ≈ 75 元
- 保守（r=10%、g=3%）= (13.4−3)/(10−3) = 10.4/7 = **1.49x** → 隐含价 ≈ 65 元

> ⚠️ 该"理论 PB"显著高于市场实际交易价（0.84x），反映市场对 NIM 持续下行 + 零售资产质量的极端悲观定价。它说明：**若 ROE 13%+ 可持续，当前价被严重低估**；但银行板块整体 PB<1 是系统性现象，故仅作上限 sanity check，不直接用于定价。

### 方法 3：DDM 股利折现（权重 25%）

- DPS₀ = 2.016 元；派息率 34%，留存 66% × ROE 13.4% 暗示高增长，但成熟银行实际 g 取 **3–5%**
- r（权益成本）= 9%
- g=4%：P = 2.016×1.04 / (0.09−0.04) = **41.9 元**
- g=3%：P = 2.016×1.03 / 0.06 = **34.6 元**
- g=5%：P = 2.016×1.05 / 0.04 = **52.9 元**（乐观）

**结论：DDM 合理价中枢 ≈ 39–42 元（g=4% 基准）。**

### 方法 4：PE 绝对 / 历史（权重 15%）

- 当前 PE_TTM 6.17x（EPS_TTM 5.98）
- 2026E EPS ≈ 6.1（低单位数增长）；银行合理 PE 7–8x（历史中位）
- 7x × 6.1 = **42.7 元**；8x × 6.1 = **48.8 元**

**结论：PE 视角合理价 ≈ 43–49 元。**

### 方法 5：逆向 DCF（权重 5%，隐含预期检验）

当前价 36.88、EPS 5.98、r=9%：
- 解 PE = (1+g)/(r−g) → 6.17 = (1+g)/(0.09−g) → g ≈ **−6.2%**
- **市场隐含假设：招行盈利将永久以 ~6%/年 衰退。** 这一极端悲观预期只需被"盈利持平/微增"证伪即可释放估值修复。

### 方法 6：PVGO 增长机会现值（权重 5%，预期结构检验）

- SSV/股 = EPS / Ke = 5.98 / 0.095 = **62.9 元**（假设盈利永续不变）
- 当前股价 36.88 < SSV → **PVGO 为负（≈ −26 元，−70%）**
- 含义：市场不仅不给增长溢价，反而对账面净资产打折定价——典型的周期底部 + 恐慌定价，与逆向 DCF 互为印证。

## 五、风险与催化剂

**风险（压制估值的核心变量）**：
1. **NIM 未触底**：若 2026 半年报 NIM 跌破 1.85% 警戒线，ROE 承压，PB 折价可能加深。
2. **零售资产质量**：按揭 / 消费贷 NPL 若快速上行（房价持续下跌 + 断供），拨备消耗、盈利下修。
3. **财富管理竞争**：中间业务收入若连续下滑，轻资本增长引擎熄火。

**催化剂（释放估值修复）**：
1. **2026-08-31 半年报**：确认 NIM 触底、营收增速可持续、NPL 稳定 → 直接修复 PB 折价。
2. **货币政策宽松**：降准降息落地，信贷需求复苏，信用周期底部确认。
3. **国资委市值管理考核**：若要求央企提升分红率，招行派息率由 34% 向 35%+ 上调 → 股息率安全垫进一步增厚。
4. **市场风格切换**：高股息 / 红利资产重估，银行 PB 系统性修复。
