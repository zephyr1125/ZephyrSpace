## 四、交叉验证方法

### 方法 1：PE 分位（辅助验证）

- PE_TTM 10.29x 处于 3 年分位 3.5%、5 年分位 4.7%（理杏仁）——历史极低分位
- 2026E 调整净利 20.03 亿人民币 -> 2026E EPS = 1.46 元 RMB = 1.59 港元
- 现价 24.84 -> 2026E PE = 15.6x
- 参考：金山软件历史 PE 中枢 20-30x（2019-2023）；若给 18x（成长）-> 28.6 港元；20x -> 31.8 港元
- 结论：按调整后盈利，现价对应 15.6x PE 已处历史低位，18-20x 对应 28.6-31.8 港元，与 SOTP 基准（31.2）收敛

### 方法 2：PVGO（增长机会现值）

| 参数 | 值 |
|---|---|
| 2026E 调整后 EPS | 1.59 港元 |
| Ke（港股） | 10% |
| SSV/股 | 15.9 港元 |
| 当前股价 | 24.84 港元 |
| 实际 PVGO% | 36% |
| 合理 PVGO% | 35-45%（办公 ROIC 高 + AI/游戏期权） |
| 合理价 | SSV/(1-PVGO)：35% -> 24.5；45% -> 28.9 港元 |

**结论**：PVGO 法合理价 24.5-28.9 港元，中枢 26.7。现价已充分反映「无增长稳态 + 中等期权」，向上弹性来自 PVGO 扩张（游戏拐点/AI 变现）。

### 方法 3：净现金-市值扣除法（极端保守验证）

- 当前市值 341 亿港元（313 亿人民币）
- 减归属净现金 208 亿人民币 -> 扣除现金后市值仅 105 亿人民币（115 亿港元）
- 该 115 亿港元购买的是：金山办公 51.38%（市值 666 亿港元）+ 金山云 35.59%（97.5 亿）+ 西山居（80 亿）约 840 亿港元资产（月之暗面持股未核实不计入）-> 隐含折价率 86%
- 即使对金山办公按盈利法（花旗 20x 2026E：168 亿港元）+ 西山居 52 亿 + 金山云 78 亿 + 现金 227 亿 = 525 亿港元 -> 扣除现金后市值 115 亿 vs 资产 300 亿 -> 仍折价 62%

**结论**：无论用市值法还是盈利法，当前价格对集团资产折价都极端（62-87%），安全边际充足，但折价收敛需要催化剂（游戏拐点/AI 资产显性化）。

> 声明：本次 4 法实际归为 **2.5 类信号**——① 资产法（SOTP 60% + 净现金扣除 10% = 70%，均依赖分部价值，同源已克制）；② 盈利倍数法（PE 15% + PVGO 15% = 30%，**二者共享同一花旗 2026E 调整 EPS 1.59 港元假设，严格同源**，合计权重 30% 未重复夸大）。因此"三法收敛于 27-32"（SOTP 31.2 / PE 28.6-31.8 / PVGO 26.7）中，PE 与 PVGO 的收敛部分由共享 EPS 假设人为增强，实际独立证据为"资产法 31.2 vs 盈利法 26.7-31.8"，两者仍收敛于 27-32，加权中枢可信但独立性弱于初版表述。

## 八、风险与催化剂

### 主要风险（下行）

1. 游戏拐点再次落空：鹅鸭杀商业化爬坡慢 + 新游（愤怒的小鸟/星砂岛）上线失败 -> 游戏收入 2027 继续负增长，SOTP 中西山居价值归零化

5. 雷军退出/邹涛权力集中风险：治理关注项
