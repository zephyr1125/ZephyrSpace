# 乐歌股份 估值分析

## 结论

**停止正式估值（维持）。** 2026H1 更新后公司质量 **63 分**，仍低于正式估值的 70 分底线；`target_price` 与 `valuation_certainty` 均为 `null`，不计算机械买入价，也不设正式价格分区。2026-08-28 收盘价 10.42 元、总股本 3.42 亿股、市值约 35.6 亿元、PB 约 0.99x、TTM 股息率约 2.9%（2025 年度 0.30 元/股）仅作参考，不构成交易判断。

## 暂停原因（基于 2026H1 复核）

| 未满足的前提 | H1 2026 实际状态 |
|---|---|
| 增量ROIC可验证 | 仍未披露单仓投资、利用率、单位 EBIT 与税后 ROIC；美国仓主体 Lecangs 资产 51.78 亿、H1 净利仅 122 万。 |
| 自由现金流持续为正 | 简化 FCF = OCF 2.47 亿 - capex 3.09 亿 = **-0.62 亿**（负值收窄但仍为负）。 |
| 正常化利润可判断 | 扣非净利 296 万（-96.23%），汇兑损失 7,784 万与销售费用高增使正常化盈利中枢无法确定。 |
| 增长可持续 | 仓储物流服务收入 **-1.27%**（多年高增后首次转负），增长引擎失速。 |
| 偿债能力无忧 | 利息保障倍数 1.27x（上年 2.53x），乐歌转债 1.42 亿 2026-11 到期，债务滚动依赖经营现金流+再融资。 |

## 重新启动正式估值的条件

1. 仓储物流收入重回正增长，且连续两个半年度披露海外仓项目级 ROIC、利用率和单位经济性。
2. 正常化汇兑损益得到验证（套保 19.3 亿名义下的净汇兑损失显著收敛），币种错配不再显著吞噬经营利润。
3. 经营现金流扣除资本开支后连续两个季度转正，利息保障倍数回升至 2x 以上。
4. Ellabell/Apple Valley 投产后实际折旧+利息成本与"1/3-1/2 租金"承诺吻合，自建仓单仓回报明确覆盖资本成本。
5. 美国线下渠道（如有投入）实现盈亏平衡，扣非利润连续转正。

价格下跌本身不构成纳入 Watchlist 的理由。只有公司页列明的基本面触发条件满足后，才重新开展正式估值。
