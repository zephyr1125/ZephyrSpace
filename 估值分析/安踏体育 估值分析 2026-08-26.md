## 方法 1：PE历史分位+可比公司

**安踏19年PE历史（TTM）**：
- 5年低位：~10x（2022年消费寒冬）
- 5年中位：~20x
- 5年高位：~35x（2021年消费顶峰）
- **当前**：13.5x（FY2026E核心）——处于5年低位区间

**可比公司**：

| 公司 | FY2026E PE | 营收增速 | OP Margin | 备注 |
|---|---|---|---|---|
| Nike | ~22x | 低个位 | ~13% | 全球第一，品牌溢价 |
| Adidas | ~20x | 中个位 | ~10% | 全球第二 |
| 李宁 | ~15x | 低个位 | ~15% | 国产品牌第二 |
| **安踏** | **13.5x** | **+10%** | **~27%** | **增速+利润率均优于李宁，但PE更低** |

**PE估值**（FY2026E核心EPS HKD 5.83）：
- 保守：16x → 5.83×16 = **HKD 93**
- 中枢：17.5x → 5.83×17.5 = **HKD 102**（品牌矩阵质量+净现金391亿+第三增长极成型；16–18x区间中枢偏上）
- 乐观：18x → 5.83×18 = **HKD 105**

**结论：PE合理价区间 HK$93–105，中枢取 HK$102。**

## 方法 2：FCF Yield（独立信号）

**经营自由现金流（normalized）**：
| 参数 | 值 |
|---|---|
| 2026H1 FCF | 116.3亿元（实际，+54.2%） |
| FY2026E normalized FCF | **175亿元**（中枢；区间170–185，剔除简单年化232.6亿的过度乐观与扣PUMA后160亿的过度保守） |
| 每股FCF（27.7亿股） | CNY 6.32 → HKD ~6.82（~1.08换算） |
| 当前FCF Yield | 6.82/78.75 = **8.7%** |

**FCF Yield估值**（合理收益率6.5%–7.0%，含品牌扩张再投资需求）：
- 6.5% → 6.82/0.065 = **HKD 105**
- 6.7%（中枢） → 6.82/0.067 = **HKD 102**
- 7.0% → 6.82/0.07 = **HKD 97**

**结论：FCF Yield合理价区间 HK$97–105，中枢取 HK$102。**

## 方法 4：Reverse DCF（仅诊断，不正式加权）

**参数**：WACC=8.5%，成长期10年，终值PE=15x，含分红/回购现金流。

当前HKD 78.75隐含的10年FCF CAGR ≈ **3-4%**——市场预期安踏未来长期近乎无增长。

**诊断价值**：这个信息本身很重要——当前价已计入"几乎无增长"的悲观假设，为价值提供安全边际。但完成诊断后，不自行假设5%增长推回一个"合理价"再给正式权重（否则就是第二份人工增长假设的估值票）。Reverse DCF在本模型中**仅作诊断**。

## 估值确定性评估

| 维度 | 判断 | 影响 |
|---|---|---|
| 盈利可预测性 | 高——三品牌群均增长+指引全兑现+H1核心+12.9% | +0.14 |
| 商业模式稳定性 | 高——多品牌矩阵分散风险，第三增长极成型，不依赖单一FILA | +0.05 |
| 资产负债表清晰度 | 高——净现金391亿，无隐藏风险 | +0.05 |
| 方法收敛性 | 高——PE/FCF双锚独立收敛于102 | +0.04 |
| 尾部风险 | 中——中国消费周期+FILA生命周期+PUMA投资回报+品牌半径+家族治理 | -0.08 |

**valuation_certainty = 0.50 + 0.14 + 0.05 + 0.05 + 0.04 - 0.08 = 0.70**（较高）

> 较前次（0.66）上调，主因：三品牌群全部增长（不依赖单一FILA）、2026指引全兑现、FCF极强、净现金391亿、长期资本配置记录强。但中国消费周期、FILA生命周期、PUMA投资回报、品牌管理半径与家族治理仍是真实尾部风险，故停在0.70，**不升至0.75以上**（明显低于S_STRATEGIC所需0.80）。

```
buy_price = 102 × (0.68 + 0.14 × 0.70) = 102 × 0.778 = HK$79.36
```

**当前HKD 78.75 已低于机械买入线 HK$79.36（约-0.8%），机械建仓条件正式触发。**

## 风险与催化剂

**上行催化剂**：①PUMA持股战略明朗化（29.06%产生协同/回报）；②Amer Sports盈利持续改善；③其他品牌（Descente/Kolon/狼爪）延续+44%高增；④Nike中国收缩→安踏蚕食份额

**下行风险**：①PUMA 29.06%投资回报不及预期；②FILA增速<5%；③消费持续低迷；④丁世忠继任不确定性

## 一句话结论

**HKD 78.75较102港元合理价折让23%，已跌破机械买入线79.36港元（约-0.8%），机械建仓条件正式触发——可执行第一档仓位，后续下跌按阶梯规则扩大仓位。** 安踏是中国消费股中质量最强的标的之一：多品牌矩阵+2026H1 FCF+54.2%+净现金391亿+19年零减持+资本配置记录被反复验证。核心不确定性集中在：PUMA 29.06%这笔现实投资的最终ROIC、FILA生命周期、以及多品牌管理半径是否继续出现品牌事故。估值确定性0.70（较高），目标价102港元由PE与FCF两个独立锚收敛得出。
