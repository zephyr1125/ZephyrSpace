# 中国巨石 估值分析

## 关键参数

| 参数 | 数值 |
|------|------|
| 周期底部PE | 15-25x |
| 周期顶部PE | 8-12x（EPS虚高，PE失真） |
| PB | ~1.0-1.5x（底部） |
| 股息率 | ~2-3%（当前） |
| ROE(底部) | ~5-8% |
| ROE(顶部) | ~20-25% |

## 估值方法

### PB-ROE法（权重40%）
- BVPS ~6-7元，合理PB = ROE/COE = 8%/10% = 0.8x(底部)
- **底部合理价 ~5-6元** / **中部合理价 ~8-12元**

### PE周期调整法（权重30%）
- 周期底部给予PE 20-25x → **合理价 8-12元**

### EV-EBITDA法（权重30%）
- 全球玻纤龙头EV/EBITDA 7-10x
- **合理市值 ~400-600亿**

## 综合结论

**合理价中枢：8-12元（周期底部）。当前价格若低于8元进入低估区间。**

> ⚠️ 玻纤是强周期行业——估值锚的核心不是"合理PE"，而是"我们在周期的什么位置"。
