# A/H 双重上市公司的自动市场选择

适用于未来新启动的三件套估值、整套更新和修复。用户要求综合折价、股息税及其他实际因素，自动决定选A还是选H；作者给出结论，双复核检查，裁决确认，主Agent统一落页和Watchlist。只有A/H同一发行人且股份经济权益可比时使用；不可将母子公司或不同权益证券直接相比。

## 投资者假设与数据

- 用户已于2026-09-17确认默认比较口径：内地个人、A股持有超过一年、H股经港股通。后续直接沿用，不逐家公司重复询问；用户另行指定时覆盖。基准持有五年并检验三年及十年属于分析假设，不冒充用户已承诺的持有期限；费用优先采用用户实际渠道数据。
- 基准股息税假设为A股0%、港股通H股20%，每次执行须核验截止日有效规定和适用性。A股较短持有期、境外券商渠道或其他税务身份按对应规则重算；不能把券商预扣率等同最终有效税率，也不能把所有H股渠道一律视为20%。
- 获取同一可比交易日A/H未复权收盘价、证券代码、币种和汇率（定义 `x = 人民币/港元`），核实权益比例、除息时点、现金分红权利及交易可达性。不同除息状态须调整或另取可比日期，不能把除息落差算成折价。
- 收集同一期间每股税前现金股息、普通/特别股息拆分及可持续派息预测；TTM、已宣告未支付和预测分列。行情、汇率、税率、手续费与港股通资格均注明来源和日期，未知费用注明假设并做敏感性，不默认零成本。

税务基础来源（2026-09-17核验；不替代执行时的有效性检查）：[财税〔2014〕81号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5204006/content.html)、[财税〔2015〕101号](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)。

## 比较方法与自动决策

1. **先统一口径**：一股A与一股H权益等同的情况下，`H股折价 = 1 - P_H × x / P_A`。非一比一权益先换算。报告分别列税前及税后股息率：`y_A = D_A × (1-t_A) / P_A`，`y_H = D_H_HKD × (1-t_H) / P_H`。费后股息回报另扣适用费用。折价有利于H，额外股息税构成H的不利因素，但最终比较实际税后结果，不能仅因高股息选A。
2. **用同一经营预测比较投资者回报**：复用两个主估值模型及三情景，不新增一套公司研究。A/H分别以买入价加买入费用作为初始流出，以税后股息减相关费用、期末出售净所得作为流入，统一人民币口径计算基准五年年化IRR；列出税费、汇率及退出价格假设。退出价依据对应未来年度盈利/净资产等与有来源的估值假设确定，不能将今天的目标价机械当作五年后价格；股息和终值不得重复计入同一现金流。
3. **不预设价差收敛**：基准须包含A/H相对折价持续的情形，并检验折价扩大与缩小、股息削减、汇率变化及三年/十年持有期限。没有充分依据，不把A/H完全同价作为基准收益来源。若同公司经营增长和股息相同、折价持续且H税后股息率更低，不能仅凭H绝对买价低就宣称回报更高。需说明折价带来的价值缓冲与实现回报的条件。
4. **给出单一选择**：先排除用户渠道不可交易或流动性无法满足需求的一侧；在可交易者中以基准税后费后年化回报较高者为首选，再检查悲观损失、流动性、价差/成交成本、汇率及结论敏感性。若基准优势被合理假设扰动轻易逆转，优先悲观情景回报更好者，再比较交易成本和流动性；仍无法区分时，既有记录保留当前市场，新候选默认A并说明优势不显著。非量化因素改变首选时须写明具体事实，不编造精确权重或修改公司/管理层评分。
5. **说明切换条件**：给出使选择逆转的可计算条件，例如临界H/A价格比、折价率或税后回报差，说明其余假设不变；数值不可求或关键数据不足时如实说明。关键价格/税务/权益事实未核实不能强行下最终结论或换码，保留原记录并标注待补证。一般预测不确定性以明确假设及敏感性处理，不因此把所有决策交回用户。

辅助检查：仅在每股税前分红等同、忽略费用且汇率一致时，H税后股息率高于A的条件是 `P_H × x / P_A < (1-t_H)/(1-t_A)`；0%对20%的假设对应H折价超过20%。这只是股息率临界值，不是总回报或自动选H的固定阈值。股息税影响分红现金流，不能把公司整体价值或目标价直接打八折。

## 估值报告与落库

- 报告增加“A/H自动选择”区块：首句明确“选择A股/H股（代码、交易币种）”，列双边行情、同币种折价、税前/税后股息率、税费及渠道假设、三情景回报、主要风险、选择理由和切换条件。保留另一侧对照供复核；封面摘要、最终合理价、机械买入价和价格分区只以选定股份为主表达。
- 合理价仍由选定股份适用的两个主模型加权得到。明确公司经济价值到选定股份价格的币种/权益桥接，以及有依据的市场风险调整；不得将观察到的市场折价机械乘入内在价值形成循环论证。税负若已进入DDM等现金流，不再重复扣税。
- 主Agent经完整流程验收后，同步更新同一公司的 `code`、`board`、`target_price`、`valuation_certainty`、`dv_ttm`；A股价格用人民币，H股用港元。机械买入价沿用统一公式，不新增Watchlist字段。`dv_ttm`保留选定股份的税前TTM百分数口径，税后数值放估值文档，不偷换现有字段含义。
- 同一公司只保留一个研究选择条目；检索所有现有等级文件，按公司身份及A/H代码匹配，不能因换码重复新增。市场切换本身不改变研究等级，名称和公司页路径保持稳定，比较理由与旧/新代码记在新报告及公司页；旧报告保留。公司页、索引和最终反馈以选定市场表达。
- 该选择针对后续配置偏好，不等于自动卖出已有另一侧持仓；不改真实持仓或交易记录。换码时核查消费端按代码识别持仓的影响，如会丢失另一侧真实持仓跟踪，须明确记录并解决兼容问题后同步，不能伪称已换仓或静默丢失跟踪。
- 写入后按现有规则运行Watchlist验证与同步。完整报告未验收或仍有P0/P1不写入。本规则不要求本次追溯批量重算现有公司，后续逐家公司执行。
