# 美股质量价值候选刷新

使用 `scripts/us_quality_value_refresh.py --date YYYY-MM-DD` 刷新研究候选。
凭据仅从工作区 `.env` 加载，不进入结果。

流程为 Tiger 价格/流通市值/PE/52周高点初筛，筛选15%—45%回撤，然后以 Yahoo 补充公司身份和财务报表。
原始证券、初筛、二筛、异常与独立池分别写入 `data/screens/`，不改 Watchlist。
金融、REIT、BDC排除；资源和航运独立；证券身份或跨源价格异常进入隔离。

增长使用真实报告日期及有效端点；不把可得3—4年增长率称为5年增长。
季度只计算同季同比；资产负债率使用总负债/资产；ROE使用平均权益。
自由现金流代理为年OCF减资本支出绝对值。机场等特许经营公司须人工纳入特许资产改善、大修等现金支出。
年报财务指标不等于最新季报指标，发生重大并购后必须重新核算。

代理条件为可得周期营收/净利CAGR>=5%、毛利率>=25%、营业利润率>=10%、ROE>=12%、负债率<=65%、OCF及FCF正数、可得季度营收和净利同比非负。
缺失条件不计为通过；未观察到失败条件仅进入“待补证候选”，并降低数据置信度。
必须另外核实五年增长、最新财报原件、正常化利润、SBC与治理事件，才能认定完整条件通过。
评分权重为增长25%、盈利25%、现金流与杠杆20%、估值回撤20%、数据可信度10%，另扣异常。
该分数只用于研究排序，不能作为公司质量分或入库依据。

`--repair-cache` 仅重新取数复核已有待补证候选，不重新扫描市场。
财务数据缺失恢复时应完整刷新，以免只复核已有候选遗漏被初轮排除的标的。
同日重复运行会刷新同日CSV；跨日结果保留历史。

新旧筛选规则、字段口径或排除范围不同，排名和分数不可作为同口径趋势。
人工优先级需解释一次性收益、并购、低基数、汇率、监管和特殊资本开支，优先推荐下一批3家研究。
筛选本身不宣称完成三件套，也不生成未经估值验证的目标价、买入价和仓位。
