# 2026-09-19 三件套实跑复盘：耐克与中国民航信息网络

结论：新版降低了部分规则加载和初次复核的负担，但尚未实现端到端节省或可靠收敛。耐克任务比当日中国食品基线更长、实测token更多；不同公司的复杂度和数据可得性不同，不能把全部增量归因于新流程。两次未完成既有真实缺证，也有修复引入错误、已核内容丢失及验收分级/终局处理缺陷，不能仅用“信息复杂”解释。

本次是流程复盘，不重新给公司评分、估值或启动完整研究。中国民航信息网络已被用户明确指定暂缓，本次保持该处置；历史过程稿、评分状态及Watchlist未改动。

中国民航信息网络截至第二个研究回合结束（UTC 12:57:42.420，不含随后暂缓登记追问）的累计总token为48,925,408，非缓存输入2,510,648，输出213,160。两个主研究回合duration_ms合计83.78分钟；中间有用量限制/暂停形成的长空档，不能把跨越约8.5小时的墙钟视为模型连续工作时间，也不能简单与耐克88分钟作因果比较。

## 局部改善被返工抵消

按model-routing调度时钟，耐克初次全文双复核4.77分钟，旧中国食品6.19分钟；首次裁决8.98分钟，旧基线14.01分钟。两个局部阶段变短，但并非同一冻结证据的配对试验，不能宣称全由优化造成。

耐克证据17.77分钟、撰稿10.62分钟，首次修复13.13分钟、首次定向复查8.24分钟，例外裁决11.63分钟、例外修复6.98分钟、最终复查5.14分钟。首次审核后约54分钟仍用于裁决/修复/复查。真正瓶颈是初稿质量和修复稳定性，继续压缩模板不足以解决。

耐克作者累计输出81,232 token，中国食品作者49,715；作者非缓存输入365,860，对照218,365。两路审核、裁决的非缓存输入也都上升。现阶段不应再以“文件体积减少47%”代称实际token下降；上一轮修改的收益预期未通过实跑验证。

## 耐克为何未闭合

直接证据：`data/reviews/nike-2026-09-19/{adjudication-v2.json,sol/recheck-v2.json,astra/recheck-v2.json,writer/workpaper-v1.json,writer/workpaper-v2.json,writer/workpaper-v3.json,writer/check-v3.json}`。

1. **实质错误仍在**：预测期末股数被当作年度加权股数，回购只减分母但资金/时点桥不充分，SBC经济扣除与股份稀释边界仍有争议；PE独立锚及正常化口径未被两路共同确认。不能因公式能算出数就发布最终合理价。
2. **修复回退可直接复现**：v1/v2公司25个评分项各有25条不同理由，管理层7项各有7条；v3分别退化成1条相同占位理由，来源指回“最终报告”。原来可追溯的逐项判断变成循环引用。旧程序只查字符串非空、加总和表格一致，所以仍返回mechanical_checks_passed。这是我们上一轮防护不足，不是公司天然无法研究。
3. **“全关闭”声明不等于验收**：最后关闭表用泛指补充稿/底稿覆盖全部条件，两路仍发现已核控制权、人事、激励细节被删。局部修复约定没有用差异检查落实。
4. **审核分级存在分歧**：G09-segments，Sol因未单列同比百分比列P1未关；Astra确认绝对额、合计和趋势均正确，认为仅展示缺口。现金税与承诺覆盖等也有通过/不通过分歧。不能把两路fail简单取并集便当最终裁决，也不能因存在分歧就假定所有P1无效。
5. **收尾缺出口**：原流程的最后一步是“例外后有P1→全部未完成”，没有一次只裁既有材料的终局处置，也没有逐字段撤回、保留已验收结论并给明确暂缓原因的统一格式。

本次不重新裁定这些公司的具体争议，也不认可过程稿里的72.5/68或任何价格为最终值。当前明确处置是：暂不入库，原因包含研究执行错误；不能由此认定耐克属于低质量公司。

## 本轮已落实的修正

- **防回退**：修复检查必须给上一冻结底稿；未变评分项完整保留，变更须对应裁决ID/证据；同一句理由替换多个分项直接失败。正文按二级章节比较，未声明重写/删除失败，删章节必须指向保留其内容的新章节。机器仍不评估证据真假，不能替代双复核。
- **验收分级**：P1写实际影响和最小充分证据；正确且可直接复算的展示项不机械升级；真正错误必须修正或撤回，不能包装成条件性诊断。
- **明确出口**：decision分eligible/reject/defer，research_status单独保留；缺证、固有未知与执行失败不同。可保留已确认分项，必要时给有据区间；没有可信价格就明确暂不定价，不凑第二模型。
- **终局处置**：最后实质分歧由原裁决员只核既有材料并决定使用/撤回哪些结论，不再补证、建模或派第三轮修复；角色不可用则保守暂缓，绝不冒充通过。
- **实测用量**：新增只读日志汇总工具，将累计、缓存、非缓存输入和输出分开；后续收尾可直接引用真实计量，不再长期留空或凭文件大小估计。

规则入口：`docs/three-report-closeout.md`；新增防回退回归和计量去重测试。没有重跑两家完整三件套，也没有进行同一冻结证据的新旧流程对照；修正有效性限于针对已观察故障的回归测试，后续仍需实跑验证。可保证流程要求交代明确处置，不能保证所有公司都得到精确评分/价格，也不能保证数据源或模型运行永不失败。

本轮验证：28项测试全部通过，唯一技能入口、迁移原文哈希、技能格式检查通过。对耐克原始底稿作只读重放：v1/v2通过机械检查，v3因重复占位评分理由失败；结果留存在 `data/reviews/process-audit-2026-09-19/regression-replay.json`。这只证明新防护能拦住该已知回退，不证明v1/v2事实或模型正确，也不改变历史验收状态。
