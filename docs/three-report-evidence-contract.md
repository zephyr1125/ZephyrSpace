# 三件套共享证据与数据源规范

适用于ZephyrSpace完整三件套及相关skill在本项目的数据获取。调度、准入与复核轮次以 [三件套经济组合调度](three-report-economy-routing.md) 为准。本文件定义共同输入，不替代原始披露或审核员的独立判断。

## 一份证据包，多角色复用

Terra统一整理到 `data/reviews/<run-id>/`，已有原件直接引用，避免复制整份财报：

| 产物 | 必需内容 |
|---|---|
| `evidence-index.md` | 证券身份、经济本质、资料截止日、证据版本、来源列表、报告期覆盖、检索范围及时间、缺口/冲突、归档路径；通过准入后须覆盖至少三年或可得完整周期，适用skill要求更长周期时沿用 |
| `facts.json` | 事实ID、指标/事件、原值与原单位、规范化值/单位、币种、报告期、披露日、合并/母公司、归母/少数股东、年度/单季/累计/TTM口径、实际/预测/推算标记、来源ID、原件页码/行号/章节及计算桥 |
| `sources.json` | 来源ID、URL、可访问原件路径、获取日期、文件哈希或可用版本标识；网页/API原始响应按需保存，禁止保存令牌或鉴权请求头 |
| `market-snapshot.json` | 同一截止时点的收盘价、交易日、市场、币种、股数及股数日期/类别；标明是否复权及ADR/普通股换算，市值与每股估值分母保持一致 |
| 原件与必要摘录 | 最新及必要历史财报、审计/附注、治理公告；摘录保留上下文、限定词与来源定位 |

闸门阶段只填写决定性事实，行情与完整历史包可在proceed后补齐。无法取得的值用null并给出缺口，不生成伪数据。事实表不夹带作者评分、目标价、gate评价或审核意见。

财报和MinerU产物沿用项目 `财报/[公司名]/` 归档及命名规则；图片与可复核辅助产物必须保留。无MD时可用可访问PDF/HTML原文；是否运行转换取决于原件可读性，不把“无MD”当作缺少披露。

证据交接前在现有索引中确认决定性来源可访问，并将关键事实定位到Markdown章节/行号及可得的原件页码；表格摘录保留表头、单位和必要附注，不能只摘数字。复用可访问的原件与索引，不另造一份完整财报副本。读取先检索再按章节取必要上下文；遇到截断应补读，不能把工具的截断输出当作全文已核。原件中不在索引的风险章节仍按下文要求独立检查。

2026-09-19后新任务：核心内容模块的接口示例和历史案例已拆为按需附件，Terra只读与实际缺口相关的数据获取章节，不为收证读完整作者模板。交接列事实ID、原件位置、未解冲突和证据版本，不重复生成一份同义事实长文；财务历史长度遵守适用模块（公司财务5–7年、估值近5年或可得完整周期，战略执行连续3年），不因拆分而缩短覆盖。作者的评分/估值底稿单独保存在作者目录，绝不并入中性包或提前交盲审。共享同一摘录不算两个独立来源；决定性事实和索引外风险的独立核验不减少。

## 数据源与冲突处理

### 财报数据优先查本地 Markdown

三件套证据整理、撰写及复核需要财报数据时，先检索 Vault `财报/`，优先读取 `财报/[公司名]/` 中已有的 Markdown 财报；按公司名、证券代码或别名定位，核对正文中的公司身份、报告期、合并口径及来源，不只凭文件名判断。该优先级适用于财报数据与附注，不替代行情刷新和新增治理事件检索。

- 本地 Markdown 覆盖所需期别和内容且来源可追溯时，直接复用并记录 Vault 路径、章节/行号及对应原件定位，不为获取相同数据重复联网下载或调用 API。
- 本地文件缺失、期别不足、内容缺漏、来源不明或存在冲突时，按下表定向补查；不能把“本地最新文件”等同于“截至资料截止日最新披露”，仍须确认有无更新报告或更正/重述。
- Markdown 是原披露的阅读与检索版本，不提升其证据等级；决定性事实仍按下文独立核验要求回看原件，优先使用本地归档原件。表格错位、单位/正负号异常或 OCR 疑点须核对 PDF 对应页，必要时再查官方披露。

| 用途 | 首选与回退 |
|---|---|
| 法定事实、审计、附注、治理结论 | 公司IR、交易所、监管机构披露；A股巨潮/上交所/深交所，港股披露易，美股SEC/IR。官方原件是最终依据 |
| 结构化财务/行情/历史分位 | 财报数据先按上述规则复用本地Markdown；需补充结构化财务、行情或历史分位时，以理杏仁适用市场和行业端点为主，按lixinger-query核字段与期别；不要求各角色重新拉取 |
| A股期别/延迟验证 | 东方财富已知接口校验QDATE/REPORTDATE；密集披露期或主源期别落后时核验公司公告。不能由API为空推断未披露 |
| 主源不覆盖的港美股/字段 | 官方披露补足财务，已有可靠行情工具或StockAnalysis等补充；必须标注来源，不能硬套A股端点或反复调用不支持市场 |
| 自由文本红旗/重大事件 | Tavily检索，最终判断回到公司公告/监管记录；“未发现”仅限已记录的日期与检索范围 |
| 管理层声音/卖方预测 | 官方电话会/IR优先；智堡作补充与发现入口，按需取详情；一致预期注明供应方、覆盖期、采集日，单篇研报不称一致预期 |

同一请求主源成功且覆盖完整后不全平台重复拉取。若理杏仁与东方财富同口径仍冲突，先以东方财富作临时校验值、保留两者差异，再核官方原件；官方值优先，决定性冲突未解不进入正式估值/排除。OCR疑点回看PDF对应页。CNINFO结构化API是补充，官方披露与其标准化接口的优先级不可混为一谈。新流程不再要求Tushare。

“最新”指截至资料截止日已正式披露的最新信息集：最新年报提供完整年度基础，更新的中期/季报必须纳入；历史期数字允许用于趋势与正常化，预测允许用于模型但须单列。不得用旧年报优先规则屏蔽新季报，也不得将当期累计数据充作全年。下一财报具体日期只认官方公告，未确认则null。

## 复用与独立核验边界

A/H双重上市适用 `docs/ah-share-selection.md`：证据包一次收齐两地可比行情、汇率、权益/除息口径、分红、税务渠道及交易条件；作者自动选择市场，双复核核对税后比较、退出假设、选择理由及最终代码/币种一致性。两地复用同一公司经营证据，不重复完整研究。

- 作者和两位审核员复用相同事实表与定位；不重复抓取已冻结的同源资料。原件必须可访问，不能只提供Terra摘要。
- 两路审核都须回看决定性事实原件：审计/红线、影响分数与档位的主张、关键估值输入、现金/负债归属、股数/币种；独立推导关键计算，不只信任Terra或作者的计算输出。
- 其余事实做按风险抽样，并记录抽样范围。每路至少检查一处从原件章节出发的遗漏风险（如关联交易、资本承诺、或有负债等适用章节），避免共享索引漏项导致两路同盲；发现同类错误扩大核验。
- 复查时只读变化及必要上下文，核对跨报告联动；无新证据不重写完整事实表。审核员可定向补查，记录检索原因和原件，不能靠省检索跳过决定性事实。
- 初稿/证据包冻结后，补证进入新版本，保留旧版本标识与差异。新增原证据中性内容可分别发两路，审核意见保持隔离。
- 整套更新复用未改变的历史证据，检查是否有重述；行情刷新到共同截止日，治理检索从上次截止日连续覆盖至本次。新增事件不因缓存或API空结果被跳过。
- 管理层数据收集以覆盖事项为验收标准：控制结构、人事时间线、言行兑现、资本配置、回报、监管和行业合规。无需每次重复拉全部CNINFO/理杏仁/智堡端点。投资评级、全部互动问答及全部新闻详情按证据缺口调用。

## 准入判断的最小质量约束

Terra只整理事实，Sol核原件并判断规则适用性。财经新闻、搜索摘要、过期审计记录、缺失值或不适用行业指标均不能单独作为排除依据。决定性材料不足时，保留unknown并集中补证；不得把“未完成研究”写成公司已经触发红线。
