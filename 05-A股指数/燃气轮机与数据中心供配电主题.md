# 燃气轮机与数据中心供配电主题

> **核心逻辑**：AI 数据中心的爆发式扩张对供电可靠性要求极高。燃气轮机作为基荷/调峰电源，能在 10 分钟内启动并提供百兆瓦级连续供电，天然契合数据中心"7×24 不断电"需求；数据中心内部供配电（HVDC/UPS/高效变压器/储能逆变）则决定 PUE（电源使用效率），是降本增效的核心环节。两条链路共同构成 AI 算力基础设施的**电力护城河**。

---

## 主题简介

### 燃气轮机产业链层级

```
整机制造（F/H级大型GT）  →  东方电气（GE合作）/ 上海电气（西门子合作）
移动式/中小型GT整机      →  杰瑞股份 / 金通灵（*ST，已出局）
热端核心部件（叶片/涡盘）→  应流股份 / 图南股份
高温合金材料             →  钢研高纳 / 派克新材（锻件）
大型锻件/压力容器        →  中国一重 / 兰石重装
仪控配套                 →  川仪股份
```

> ⚠️ 东方电气、上海电气、中国一重、大连重工均为多业务集团，**燃气轮机仅为部分业务**，
> 核电/风电/火电同等或更大权重，投资时需注意业务分散风险。

### 数据中心供配电产业链层级

```
HVDC / UPS 系统          →  科华数据 / 科士达
中高压变配电设备          →  金盘科技（⚠️ 与931994电网指数重叠）
储能 + 工商业逆变         →  阳光电源 / 固德威
车载/工业电源（延伸）     →  威迈斯（注意代码：688612.SH，非688162）
散热/液冷（交叉主题）     →  隆华科技（注意代码：002263.SZ，非002363）
```

## 板块风险提示

### 燃气轮机特有风险

1. **国产化进度不确定**：F/H 级大型燃气轮机核心部件（热端叶片、控制系统）仍依赖 GE/西门子技术授权，国产替代时间表存在不确定性。
2. **需求集中于电力主机厂**：核心客户东方电气/上海电气采购节奏对零部件厂商影响巨大，订单波动性高。
3. **高温合金材料盈利困难**：应流/图南/钢研高纳当前 ROE 均在 3%–8%，行业整体处于技术爬坡期，规模效应尚未释放。
4. **\*ST 金灵警示**：金通灵（300091）已退化为 ST，是小型工业燃机自主研发路线的风险实例。

### 数据中心供配电特有风险

1. **AI 资本开支周期风险**：数据中心建设高峰若提前结束，订单增速将从 >20% 快速下行，科士达/金盘科技受影响最直接。
2. **价格竞争加剧**：UPS/变压器赛道进入壁垒有限，海外和国内新玩家涌入压缩毛利率，注意科华数据 ROE 已下滑至 7.5%。
3. **固德威盈利陷阱**：PE 超过 2000x 意味着利润极薄，逆变器价格战持续冲击盈利，不满足质量门槛。
4. **代码核查提醒**：688162（巨一科技）和 002363（隆基机械）疑似代码输入有误，**威迈斯应为 688612.SH，隆华科技应为 002263.SZ**，后续分析前需先确认。

### 通用风险

- 估值普遍偏高（PE 40x–140x），数据中心主题溢价显著，安全边际薄弱
- 美联储利率政策和国内经济复苏节奏影响资本开支预算
- 国产化验证周期（叶片/合金类）可能拖长到 2027–2028 年
