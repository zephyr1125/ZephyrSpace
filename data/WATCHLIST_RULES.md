# Watchlist 分层规则

> **重要：任何 AI 在修改 watchlist 文件之前，必须先完整阅读本文件。**

本文件是 Watchlist 三层研究分级及未入池保留机制的配套规则。研究等级与实际持仓状态相互独立。

---

## 整体原则

- **只收录已完成完整 PreBuy 分析的公司**（对应 `01-公司/` 下存在完整模板页面）。
- 研究等级依次为 `S_STRATEGIC`、`A_CORE`、`B_GROWTH`；不满足者写入 `NONE`，保留研究与持仓跟踪入口。
- 每次新增或更新公司，必须先检查重大红线，再按最高满足等级归档。
- `watchlistLevel` 只表达公司研究质量，不代表当前价格、仓位权限或实际持仓。
- `trackingStatus` 与研究等级独立；真实持仓由 Finance 核算表动态识别。
- **档位（core/growth）由公司基本面质量决定，与当前股价无关。** Watchlist 只保留估值报告的加权合理估值 `target_price` 与估值确信度 `valuation_certainty`；实时行情和价格带不再存入 Watchlist。`NONE`若因质量门槛停止正式估值，两个估值字段可同时为`null`。

## 三层分级定义

### 🟣 战略核心 `S_STRATEGIC`

必须同时满足：双评分合计≥170、两项均≥82、`valuation_certainty`≥0.80、现金流质量通过、盈利稳定性通过、无重大治理/财务/逻辑证伪红线。

S级必须填写 `strategicCoreType`。红线复核超过90天提示待复核，超过180天标记资料过期，但不自动降级。

### 🟢 核心关注 `A_CORE`

硬门槛：双评分合计≥160，且两项均≥76。估值确定性展示但不作为A级硬门槛。

A级不额外增加现金流、估值确定性或行业类型硬门槛；这些信息继续展示和监控。

### 🔵 成长关注 `B_GROWTH`

硬门槛：双评分合计≥150，且两项均≥70。估值确定性展示但不作为B级硬门槛。

B级不额外增加现金流、估值确定性或行业类型硬门槛；这些信息继续展示和监控。

### ⚪ 未入池 `NONE`

不满足三层门槛的公司移出新增建仓候选，但不得删除研究数据。若公司仍持仓，必须继续输出 `trackingStatus=HOLDING` 并保留跟踪与退出条件。

### 红线优先规则

- 财务造假、非标审计、异常关联交易、资金占用、严重侵害中小股东、核心管理层异常集中离职、重大资本配置失败或投资逻辑被证伪，可直接判定为 `NONE`。
- S级的现金流质量、盈利稳定性和估值确定性门槛只用于S级；未通过时仍可按双评分进入A或B。
- 不得仅依赖理杏仁判断无减持；红线复核必须同时使用 Tavily、公司公告或监管披露。

### 🟡 已废弃的雷达池 `radar`（历史规则，不得再使用）

> Radar 档及 `watchlist_radar.json` 已于 2026-07-15 删除。本节仅保留历史解释；任何新公司若不满足 core/growth，均只记录在研究页或指数专题页，不写入 watchlist。

**定位**：有关注价值，但存在较多不确定性。只跟踪，不主动买入。出现明确信号后再考虑是否升档。

**进入条件（三层，缺一不可）**：

**前置质量门槛（新增，优先判断）**

> ⚠️ **必须先通过粗筛才有资格进入 Radar。** 粗筛未通过（ROE 低于行业门槛×80%）的公司不入 watchlist 任何档位，只记录在对应指数专题页的成分股表中。
>
> 粗筛边界（⚠️）内的公司（ROE 在行业门槛 80%~100%，即偏离≤20%），**额外需满足两项**：
> 1. `entry_trigger` 中必须包含明确的 ROE 相关改善条件（净利率回升、ROE 绝对值达到某水平等），**不允许仅凭价格触发**；
> 2. ROE 必须处于**稳定或改善趋势**。若 ROE 连续 2 年持续下行且无明确拐点，则视为结构性退化，**不入 watchlist**，仅记录指数专题页。

**第一层：满足以下任一情形**

| 情形 | 说明 |
|---|---|
| 逻辑未完全验证 | 成长故事有说服力，但缺乏足够的历史业绩印证；或处于行业周期底部，反转拐点不明 |
| 红旗较多 | PreBuy 报告中有 ≥ 3 条主要红旗，或有 1 条治理/结构性红旗 |
| 竞争格局不清 | 行业竞争激烈，公司护城河存疑，胜出概率尚不确定 |
| 主题纯度工具 | 用于跟踪特定行业主题景气度，但公司自身不是该主题的最优受益者 |
| 困境反转型 | 当前业绩较差，押注未来改善，不确定性高 |

**第二层：必须同时具备至少一个具体的、可量化的入场触发器**

> 触发器示例：股价跌至 X 元（对应 DY≥Y% 或 PE≤Zx）、某季报净利同比由负转正、某产能/项目投产落地、行业政策明确落地。
>
> **不符合要求的触发器**："等基本面改善"、"等市场情绪好转"——这类描述过于模糊，不具操作性。
>
> **没有具体触发器的公司，记录在对应指数专题页的成分股表中即可，不进入 watchlist。**

触发器写入 JSON 的 `entry_trigger` 字段（**radar 专属必填字段**），格式为一句话，包含具体条件和数字。

**操作含义**：只读不买。持续跟踪季报和行业动态；触发器条件达成后评估是否升档；若逻辑持续验证（连续 2 个季度超预期 + 红旗消除），升档至 growth；若逻辑证伪，移出 watchlist。

**退出条件**：
- 升档至 growth：核心红旗消除，成长逻辑获得业绩印证，可升至 growth
- 移出 watchlist：跟踪满 2 年无改善信号，或原有关注理由不再成立

### 🔴 不入出口 `excluded`

**定位**：完成了 PreBuy 分析，但存在结构性缺陷，不具备进入 watchlist 任何档位的条件。记录结论供备查，不写入 JSON。

**判定标准（满足以下任意 2 条即直接排除）**：

| 标准 | 说明 | 典型例子 |
|---|---|---|
| ① OCF 与利润严重背离 | 净利润正增长但经营现金流持续背离（OCF/净利 < 20%，或非经常性损益占净利 > 60%） | 中科蓝讯：11.5亿非经常性损益使表观净利暴增，OCF/净利仅4%（背离率96%） |
| ② 无明确有时限的修复路径 | `entry_trigger` 本质是"等主业好转"——无法确定扣非净利/现金流何时恢复；若修复时间线超过 3 年或完全不可预期则触发 | 中科蓝讯：TWS市场饱和+主业增速+1.2%，无法预期扣非何时改善 |
| ③ 结构性治理或合规风险 | 外资母公司持股 > 50% 且叠加出口管制风险；或审计意见非标；或存在持续关联交易掩盖利润转移 | 盛美上海：ACMR持股74.5% + 美国出口管制双重叠加 |

**与普通观察对象的区别**：普通观察对象可以保留研究页等待验证，但不写入 watchlist；结构性问题公司则明确标记“不入”。

**操作说明**：
1. 在对应公司页面的 `## PreBuy 结论` 中注明"**不入 watchlist**，原因：[触发的标准+具体数据]"
2. 在对应指数专题页的成分股表中，将该公司状态标记为"❌ 不入"
3. **不写入** `watchlist_core.json` 或 `watchlist_growth.json`

## 分层决策树

收到一家新公司的 PreBuy 报告后，按以下步骤判断档位：

```
1. 是否完成完整 PreBuy 分析？
   → 否 → 不得加入 watchlist

2. 是否触发"不入"出口？（满足以下任意 2 条）
   ① OCF/净利 < 20% 且非经常性损益 > 60% 净利
   ② 无明确有时限修复路径（修复时间 > 3 年或完全不可预期）
   ③ 结构性治理/合规风险（外资持股>50%+出口管制叠加、非标审计等）
   → 触发 2 条及以上 → ❌ 不入 watchlist（在公司页和指数专题页注明，不写入 JSON）

3. PreBuy 结论是否支持"可以布局/可以买"（而非"纯观察"）？
   → 否（纯观察/逻辑未验证） → 只记录在公司页或指数专题页，不进 watchlist

4. 护城河是否为垄断/极强级别？净现比 > 90%？ROE 稳定 > 15%？红旗 ≤ 2？
   → 是 → core

5. 基本面优秀但估值偏贵，或有成长验证点待确认？净现比 > 80%？ROE > 15%？红旗 ≤ 3 且无治理问题？
   → 是 → growth

6. 以上都不满足（红旗多/逻辑存疑/周期不明/纯主题工具）
   → 不进 watchlist，记录在公司页或指数专题页即可
```

## 字段填写规范

Watchlist 条目只保留公司身份、质量评分、研究文件定位、财报跟踪、周期状态和精简估值参数。完整字段规范以 `data/WATCHLIST_SCHEMA.md` 为准。

新增或更新记录时，估值字段必须满足：

- `target_price`：`S_STRATEGIC`、`A_CORE`、`B_GROWTH`直接取最新估值报告的最终“加权合理估值”，为正数，币种跟随交易市场。`NONE`若明确停止正式估值，可为`null`。
- `valuation_certainty`：衡量 `target_price` 的可靠程度，范围 `0.00–1.00`，最多两位小数；只评估目标价误差范围，不评价公司质量或管理层质量。`NONE`停止正式估值时须与`target_price`同时为`null`。
- 认定维度：盈利与现金流可预测性、商业模式与资本强度、资产负债表与融资需求、估值方法收敛度、周期/客户/监管/技术/商品/临床/资本开支等尾部风险。
- 参考区间：`0.80–0.90` 极高、`0.70–0.79` 较高、`0.60–0.69` 中等、`0.50–0.59` 中低、`0.40–0.49` 较低、`<0.40` 很低。
- 存在有效估值时，买入价自动计算：`buy_price = target_price × (0.68 + 0.14 × valuation_certainty)`；`buy_price` 不写入 Watchlist。`NONE`停止正式估值时不计算买入价，不设置正式价格分区。
- 财报、商业模式、资本结构或主要估值假设变化时，必须重新评估；不得因偏好公司而主观上调。
- 不得保留 `targetPrice`，避免同一记录存在两个目标价。
- 不得保留 `buyPrice`、`maxWeight`、`entry_trigger`、entry 级 `tier`、`deep_rating`、`deep_score`、`mgmt_score`、entry 级 `last_updated` 或 `market`。
- 不得保留 `deep_analysis` 或 `mgmt_archive`；研究文件由公司名和目录规则定位。
- 不再写入持仓角色、来源 ETF、跟踪理由、当前价格、价格日期、价格带、估值锚、风险列表和 PreBuy 摘要；这些信息回归公司页与估值报告。

### `next_earnings_date` / `next_earnings_type` 规则（强制）

> 🔴 **null 就是 null，不是"填个大概日期"。** 未获得公司官方公告确认的财报日期，两个字段必须同时为 `null`，不得以下列值填充：
> - 交易所法定截止日（A 股 `08-31`/`04-30`/`10-31`、港股 `08-31`/`03-31`）
> - 平台默认显示或历史规律推算
> - 基于 A 股日期推测的 H 股日期
>
> 写入前必须用 Tavily 搜索确认日期来自公司公告（董事会会议通知等）；搜不到 → 写 `null`。
