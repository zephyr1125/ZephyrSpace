# 公司质量：评分与研究核心规则

仅作为 `skills/company-triplet/SKILL.md` 的仓库内部模块，不单独安装或启动。完整流程以 `docs/three-report-economy-routing.md` 为唯一调度真源，数据源以 `docs/three-report-evidence-contract.md` 为准；旧段落中的独立审核、全源拉取、提交及回写指令不执行。评分标准、研究内容、行业约束及原件核验要求不变。

总分展示遵守 `docs/three-report-closeout.md` 的整数规则；分项、原始总分与门槛不变。

## 按需读取

- 作者和两位审核员必读本文件全部评分与内容规则；不得只读总分表。
- 作者首次撰稿、涉及结构修复时读 [报告格式](references/report-format.md)；审核员核验结构时按需读取。
- Terra 或补证角色遇到接口/来源缺口时读 [数据获取](references/data-access.md) 对应章节；不按示例全量调用。该附件中的 E 维度 5–7 年或可得完整周期要求仍适用，D2 保留连续 3 年战略执行对照。
- [历史坑例](references/pitfalls.md)按触发点读取：接口异常看坑1–4；执行脚本问题看坑5；IPO看坑6；分部/主体看坑7/12/13；FCF看坑8；监管看坑9/18；审计看坑10；评分及修复看坑11/15；融资看坑14；合并OCF看坑16；人事看坑17。触发时相应作者/审核员必须读取，不能以附件为由豁免检查。
- 本文件的通用约束和完整性清单始终必读。历史附件中的“每次执行前必读”改按上述触发路由；事实修复必须同步重评相关分项，分数不变也说明原因，不能把模型资料缺失直接认定为公司治理缺陷。
- 旧入口定位与提交步骤仅留在 [历史上下文](references/legacy-context.md)，不加载执行。

## 核心工作原则

1. **事实 / 推断 / 未知三分法**：每条结论必须明确标注来源；无法核实的标为「待补证据」并降低置信度。
2. **数据源优先级**：
   - **结构化财务数据**：理杏仁适用端点为主，东方财富校验A股期别/延迟；CNINFO接口按缺口补充。冲突回到法定披露原件，不能以API优先级推翻官方值。完整三件套复用共享证据，不重复拉全平台。
   - **叙事 / 定性内容**（MD&A、附注、审计意见、高管名单、战略目标）：`财报/[公司名]/*.md`（MinerU 转换的年报/半年报结构化 Markdown）
   - **卖方深度分析**（投行研报摘要、电话会纪要、企业研究）：**智堡 API**（`scripts/wisburg_api.py`），优先于 Tavily——卖方研报的结构化摘要（含观点、事实依据、关键数据、估值表）质量远高于搜索引擎碎片化结果
   - **交叉验证**：API 数字可疑时，回到 MD 文件核对附注原文；MD 表格数字有 OCR 疑问时，用 API 验证；管理层指引一致性用智堡电话会纪要纵向对比
   - **兜底**：Tavily 搜索（仅用于卖方研报未覆盖的领域——红旗排查、治理事件、小众公司）
3. **反证驱动**：不只找支持结论的证据，必须同步列出使这个公司"变差"的条件和证据。
4. **历史先于预测**：先弄清楚公司过去 5–10 年实际发生了什么，再判断未来。
5. **AI 不编造**：没有可靠来源的字段一律留空并标注「未核实」，禁止推测填充。
6. **数据日期与真实性标注（强制）**：
   - **采用截至截止日最新披露信息集**：年度基础与更新中期/季报同时纳入，历史期用于趋势，预测用于假设并单列标记；不以旧年报优先屏蔽新季报。禁止旧分析或记忆冒充当前值。
   - **必须列明「数据日期」与「实际值/预测值」**：每条数据须带 `(数据日期：YYYY-MM-DD/YYYYQn)` 与 `(实际值，已发布)` 或 `(预测/推算，来源：xxx)` 两个标签。未标注的财务数字视为 P1（数据不完整）。
   - **年报密集期特别处理**：若分析日处于 4–5 月且目标公司年报尚未发布，须显式标注所用数据仍来自上一年报/三季报，不得擅用未发布预测值冒充"实际值"，并注明审计报告签发日期（如"2025年报 2026-04-15 标准无保留"）。
   - 银行/保险/券商/资源股等非通用行业，估值与财务解读须遵循 `skills/valuation/SKILL.md` 的**行业专属框架**（如银行禁用普通 FCF Yield 与 EPS/Ke 式 PVGO、资源股须做商品价格敏感性）。
7. **MD 年报文件读取规范**：若 `财报/[公司名]/` 下存在 MinerU 转换的年报/半年报 Markdown，**必须优先读取**以获取以下独占内容：审计意见与审计机构（防坑10）、管理层名单（防坑17）、MD&A 经营讨论与战略表述（D维度）、财务报表附注（E5资产质量）、分部收入明细（B1）、关联交易（F3）。读取时注意：年报正文极长（~4200行），使用 offset/limit 分段定位到目标章节；表格为 HTML 格式，数字可直接引用但要标明来源行。若未找到对应的 MD 文件，回退到巨潮资讯在线查询。
  8. **业务分部数字必须逐项来自年报分部披露**：填写 B1 业务板块时，每个数字都必须能指向年报中对应分部的具体披露（如"VAS 3,692.81亿 = 腾讯2025年报 Revenues by Segment"）。严禁将父分部的合计值直接作为某子分部的收入填写（如把"VAS 3693亿"误写成"游戏 3500亿"）。
8. **FCF 口径：有官方定义时以官方为准**：若公司在年报或业绩演示文稿中披露了明确的 FCF 定义，必须以官方口径为准，不得用简化公式（OCF - Capex paid）替代。若两者差异 > 5%，须在报告中注明两种口径的差异及原因（例如腾讯官方 FCF 还扣除 media content payments 和 lease liabilities payments，官方值 1826亿 vs 简化值 2150亿，差 ~330亿）。
9. **监管处罚必须精确还原每次事件**：多次独立监管事件不得合并为一条笼统描述。每条处罚记录必须包含：年份、处罚机构、处罚金额（精确到单位：元/万元/亿元不可混淆）、主要原因、处置状态。事后回顾时，记忆中的"50亿"与档案中的"50万元"差距4个数量级——所有监管处罚记录必须溯源核实，禁止依赖记忆。

> ⚠️ **监管处罚分级说明**（来自腾讯2026-05分析经验）：
>
> 不是所有处罚都触发一票否决，必须区分：
> - **一票否决**：核心业务被责令停业 / 主要金融牌照被吊销 / 强制业务剥离
> - **黄旗（继续分析但须在报告中如实披露）**：行政罚款，金额 < 当年净利润5%，且已公告整改完成
>
> 实例：腾讯2023年财付通被央行罚款29.9亿元（占FY2023净利润的1.5%），已整改完成 → 属黄旗，不构成一票否决，但须在前置检查中如实记录；腾讯2021年音乐版权反垄断罚款50万元 → 轻微，不影响分析。
>
> **每次处罚都必须分别记录**，禁止多次不同处罚合并描述（尤其注意金额单位：万元 vs 亿元相差4个数量级）。

若以上均无一票否决项，继续执行分析。

## 维度 A：历史基因与公司 DNA（满分 10 分）

### A1. 公司起源与创始基因

**研究要点：**
- 创始人背景：自然人创业 / 国企改制 / 政府背景 / 外资进入？
- 成立时间节点：是否处于行业萌芽期或政策红利期？（先发 vs 跟随）
- 原始主营业务：技术驱动 / 资源依赖 / 渠道起家 / 政策获取？
- 初始行业地位：领先者 / 跟随者 / 边缘参与者？

**数据来源**：招股说明书（上交所/深交所 → 历史 IPO 文件）

**结论框架**：
> 该公司成立于 \_\_\_\_ 年，由 \_\_\_\_ （背景类型）创立，初始定位为 \_\_\_\_，
> 属于（先发优势型 / 政策红利型 / 追随者型 / 资源型）起源基因。

### A2. 历史控制权稳定性

**研究要点：**
- 实际控制人变更次数（IPO 至今）
- 变更原因：股权争夺 / 家族传承 / 国资接手 / 财务危机被动稀释？
- 是否存在"壳资源"操作痕迹：主业频繁更换 + 无实质经营改善？

**量化信号**：
- 从未变更实控人 → 稳定性强
- 变更 1 次且为主动战略整合 → 中性
- 变更 ≥ 2 次或背景复杂 → 减分

### A3. 资本运作历史

**研究要点：**
- IPO / 增发 / 配股 / 可转债记录：资金实际用途 vs 当时承诺的用途是否一致？
- 并购行为类型：横向整合 / 纵向延伸 / 跨界并购 / 商誉积累？
- "卖资产保利润"行为识别：在业绩压力年份是否有非主营资产出售？

**红旗：**
- 🔴 并购后商誉占净资产 > 30%，且此后发生大额减值
- 🔴 融资频次高但主营业务现金流持续弱（靠融资输血非经营造血）
- 🟡 历次并购跨度大，与主业协同逻辑不清晰

### A4. 历史基因分类

综合以上判断公司历史运营类型（必填一项）：

- [ ] **经营型**：专注主业、靠运营能力驱动增长，管理层稳定
- [ ] **资本运作型**：频繁并购、擅长讲故事、利润来源不稳定
- [ ] **周期型**：业绩随行业周期波动明显，管理层无法控制核心变量
- [ ] **壳资源型**：主业空心化，历史有控制权频繁转移迹象

### A 维度评分

| 子项 | 评分标准 | 分值 | 得分 |
|---|---|---|---|
| A1 起源基因质量 | 先发优势/技术驱动=3；政策红利=2；跟随者=1；资源依赖/壳=0 | 3 | |

**历史商业模式分类结论（必填一项）**：

### B1. 当下业务板块全景

**研究要点：**
- 当前主要业务板块（按营收占比排序）
- 各板块 BCG 矩阵分类：

| 业务名称 | 营收占比 | 毛利率 | 增速 | BCG 定位 |
|---|---|---|---|---|
| | | | | 现金牛 / 明星 / 问题 / 瘦狗 |

- 是否存在单一业务过度集中（一项业务 > 70% 营收）？
  > ⚠️ 若业务高度单一（主业占比 >90%），BCG 矩阵应按**子维度**拆解（按区域/产品线/电站/客户群分别定位），而非给整体打一个标签——单业务公司内部也有"成熟现金牛"与"成长期明星"之分。
- 是否有培育中的成长引擎，还是纯靠历史业务维持？

### B2. 盈利机制解析

**研究要点：**

| 盈利模式 | 判断结论 |
|---|---|
| 收费方式 | 按件 / 订阅制 / 项目制 / 佣金抽成 / 平台撮合 |
| 复购特征 | 高频复购 / 年度续费 / 一次性购买 |
| 需求刚性 | 刚性必需 / 可选消费 / 政策驱动 |
| 成本结构 | 固定成本主导（重资产）/ 变动成本主导 / 人力密集型 |
| 规模效应 | 强（规模越大单位成本越低）/ 弱（线性成本结构）|

**结论一句话**：
> 这是一家「\_\_\_\_\_\_\_\_」模式的公司，（复购率高/低），（刚性需求/可选消费），（有/无）规模效应。

### B3. 定价权深度评估

**第一步：来源判断**（参照普通 PreBuy 的定价权分类表）

## 核心工作原则

1. **原文优先**：每条关键判断必须有管理层原话/原文支撑，禁止仅凭二手信息下结论。
2. **言行对照**：核心方法不是读他说了什么，而是把他说过的和后来发生的对照。
3. **反证驱动**：不只找支持"好管理层"的证据，必须同步找出反例——他说过但没做到的、前后矛盾的地方。
4. **行动 > 话术**：重点研究资本配置**行为**（分红/回购/定增/并购/股权激励），其次才是**表述**。
5. **年份锚定**：每条说法和每条行为都必须标注年份，建立时间线。
6. **不确定就标注**：无法从公开渠道核实的信息，标注"待核实"而非推测。

### 8.1 处罚检索必须同时覆盖「证券监管」与「行业监管」（强制）

> ⚠️ **单一依赖证监会/交易所处罚会遗漏行业主管部门的处罚，导致治理评分虚高。** 管理层廉洁与合规记录检索必须同时拉取两个维度：

| 监管维度 | 适用机构（检索源） | 典型处罚类型 |
|---|---|---|
| **证券监管** | 证监会（measures）、交易所（上交所/深交所问询函）、央行（反洗钱/支付结算） | 信息披露违规、内幕交易、操纵市场、财务造假、问询函 |
| **行业监管** | 国家金融监督管理总局（原银保监会，银行/保险）、证监会（券商）、行业主管部门（如国资委、工信部、生态环境部、药监局、应急管理部等，依公司行业而定） | 业务违规罚单、审慎监管措施、责令整改、行业准入处罚、环保/安全/质量处罚 |

**执行规则**：
- **银行/保险/券商**：行业监管以**国家金融监督管理总局（金监总局）/原银保监会**为主检索源（如银保监罚决字、金监罚决字），与证监会/交易所处罚并列记录。招行、工行等银行的 "监管罚单"（如信贷管理违规、理财业务违规、外汇业务违规）多来自金监总局，**不检索即遗漏**。
- **制造业/资源/消费等**：行业监管以**生态环境部（环保罚单）、应急管理部（安全生产）、药监局（GMP/质量）、市场监管总局（反垄断/质量）** 等为准，依公司行业选择。
- **检索方式**：优先用理杏仁 `cn/company/measures`（含多监管源）+ `cn/company/inquiry`；行业监管罚单若 API 未覆盖，Tavily 兜底搜索 `{公司名} {行业监管关键词} 处罚 罚单`（如银行用"银保监 罚决 信贷"，制造用"环保处罚 生态环境"），且 Tier ≥ T2 才触发。
- **记录要求**：证券监管与行业监管罚单**分列**，不得互相替代；每条仍须独立成行、金额精确、注明处罚机构层级（会/局/分局）。

# 管理层审核内容检查

两位整套审核员均核下表；隔离、输出格式和轮次只依三件套SOP，不在此另开Agent。旧提示词在legacy-context.md留存，不参与执行。

| 检查域 | 验收要点 |
|---|---|
| 言行一致 | 每条承诺对应兑现或未兑现证据；正反案例均考虑；兑现率与结论相符 |
| 评分 | 分项与正文的褒贬、权重相称；独立加总原始分，整数展示不改变门槛 |
| 总结 | 一句话评价、类型、主要优缺点和跟踪项有正文支撑，与评分一致 |
| 时间线 | 言行、资本配置、危机时间线自洽，年份与责任人准确 |
| 措辞 | “长期/持续”有年份锚；强形容词有事实，推测与未知不冒充事实；合理预测并非天然错误 |
| 人物 | 最新披露姓名、职务、任期及持股比例有来源，不凭历史记忆 |
| 金额 | 币种/单位一致；分红、回购、融资、处罚均回到可追溯来源 |
| 处罚诉讼 | 逐事件列年份、机构、金额和状态，不把不同事件合并成一笔 |
| 资本配置 | 融资工具覆盖定增/配股/可转债/H股增发/优先股；公告额度与执行金额区分；分红冲突回官方原件 |
| 摘录 | 会议/年份/发言人准确；直接引语与摘要分开，保留上下文和限定词 |
| 来源缺口 | 关键数据有原件定位；公开可核的事实不滥用“待核实”替代调查 |
