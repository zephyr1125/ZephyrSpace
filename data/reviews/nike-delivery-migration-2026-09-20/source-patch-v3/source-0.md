## 维度 A：历史基因与公司 DNA
- NIKE于1967年在俄勒冈州注册，核心业务是设计、开发、全球营销和销售运动产品。[S005原始页1]
- 起源不是资源、壳或政策套利型；其长期资产主要是品牌、设计、运动营销和渠道。
- Class B在NYSE交易，Class A不公开交易且可一对一转为Class B。[NKE-G-002]
- Swoosh, LLC于2026-06-30实益持有约79% Class A，转换相当于约16% Class B。[NKE-G-002]
- 这带来控制稳定性，也意味着公众Class B持有人治理影响力有限。
- 本包未提供完整IPO以来的控制权变更史，结论限于当前披露。
- FY2026期末股东权益148.65亿美元，是经营积累的可见财务基础。[NKE-F-009]
- 未在本包看到以出售资产维持利润的证据。
- 未在本包看到商誉减值或频繁再融资的证据。
- 但这些未见并不替代对完整并购和融资史的专项核验。
- A1为3分：先发品牌和产品驱动基因明确。
- A2为3分：控制结构长期稳定但有双层股权约束。
- A3为4分：FY2021–26重大融资、回购、借款偿还、滚动额度及shelf用途已核，相邻10-K未见重大并购或卖资产保利润依赖；这不声称不存在未单列小额交易。[NKE-SUP-CAP-001；NKE-SUP-CAP-002；NKE-SUP-CAP-003]

## 维度 B：商业模式质量
- 创立逻辑与当前逻辑都依赖以品牌和创新连接运动消费者，再通过全球渠道销售。
- 主要产品是运动鞋、服装、装备、配件及相关服务。[S005原始页1-2]
- 几乎全部成品由独立合同制造商生产，NIKE并非以自有工厂扩张为核心。[S005原始页10]
- 当下渠道包括NIKE Direct实体店、数字平台和批发客户。[S005原始页1]
- 这是轻制造、重品牌和营销的按件销售模式。
- 消费具有复购属性，但运动鞋服不是刚性必需品。
- 产品、款式、运动潮流和消费者偏好改变会影响需求。
- FY2026 NIKE Brand鞋类收入295.25亿美元，服装134.49亿美元，装备21.99亿美元。[S005原始页31]
- Converse FY2026收入11.74亿美元，较FY2025的16.92亿美元下降。[S005原始页41]
- 鞋类仍是最大品类，因此组合虽多元，却存在主品类集中。
- 直营与批发并存能扩大触点，也会引入渠道库存、折扣和冲突管理。
- 2026年公司把数字平台重定位为全价平台，并重新投资批发渠道。[S005原始页30]
- 此举说明渠道策略在修复，而不是已经完成修复。
- FY2024-26收入为513.62、463.09、463.98亿美元。[NKE-F-001]
- FY2026相对FY2025仅微增，尚不能证明新策略已形成内生增长。
- B0为1分：现有材料能说明外包制造、品牌营销和全球渠道，但未完成创立期与当下九要素逐项对照、建设期判断及全部三个关键问题。

## 定价权与单位经济
- 品牌溢价来自NIKE、Jordan和Converse商标及运动员、赛事和零售连接。
- 研发、设计、营销、数字体验和IP共同支持溢价。[S005原始页15-16]
- 这不同于许可证或政府牌照带来的排他性。
- FY2026多个地区披露较高折扣和更低ASP，表明短期价格实现承压。
- EMEA毛利率同比下降140个基点，原因包括低ASP和折扣。[S005原始页38]
- APLA毛利率下降200个基点，折扣和渠道组合是因素。[S005原始页40]
- Converse毛利率下降490个基点，并有库存过时准备和重置成本。[S005原始页41]
- 因此不能把品牌强度直接等同于任何环境下的强提价权。
- IEEPA关税回收9.86亿美元计入FY2026销售成本收益，不是常态性单价改善。[NKE-F-008]
- 未来毛利率取决于全价销售、库存恢复、产品结构、关税及渠道质量。

## 维度 C：竞争格局与护城河
- 公司披露其为全球最大的运动鞋服销售商，属于市场第一梯队。[S005原始页1]
- 原件列出adidas、Anta、ASICS、Deckers、Li Ning、lululemon、New Balance、On、Puma和Under Armour等竞争者。[S005原始页15]
- 行业仍是高度竞争而非垄断市场。
- 竞争维度包括产品质量、创新、设计、品牌、消费者连接、数字体验和价格价值比。
- 商标、专利、版权、商业秘密及长期营销网络构成进入壁垒。[S005原始页15-16]
- 这些壁垒在消费者心智中有效，但不排除新品牌在细分场景分流需求。
- 供应侧并非完全由NIKE控制。
- FY2026四家鞋类合同制造商合计约占NIKE Brand鞋类产量60%。[S005原始页10]
- 越南、印尼和中国分别占鞋类产量约52%、27%和16%。[S005原始页10]
- 地缘、关税、劳工和单一区域集中会限制纵向话语权。
- 美国前三大客户约占美国销售29%，并非单一客户依赖但仍应跟踪。[S005原始页5]
- 公司对渠道有品牌影响力，但要通过折扣和退货协调恢复市场健康。
- 波特五力中同行竞争强、替代和新进入者为中等、供应商为中等、买方为中等。
- C1为6分：全球龙头地位有原文支持。
- C2为3分：渠道和品牌有力量，但供应链与贸易风险明显。
- C3+C4为5分：综合为3星护城河，不对护城河强度过度外推。
