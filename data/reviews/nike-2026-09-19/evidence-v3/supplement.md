## V3-002：CFO 交接与补偿原件

- 事实：2026-06-23 Form 8-K 披露 David Denton 获任 EVP兼CFO，生效日为 2026-08-16；Matthew Friend 同日停止担任 EVP兼CFO，转任 CEO 顾问至 2026-09-04离职。公司明确披露 Friend 的过渡和离职并非因其与管理层或董事会就经营、政策或做法存在分歧。
- 原件：SEC Form 8-K，accession `0000320187-26-000070`，主文档 `nke-20260616.htm`，HTML L63–73。
- 事实：Denton 年基本薪酬为 145 万美元，目标奖金为基本薪酬的120%，年度目标长期激励为1,150万美元；另有725万美元一次性现金补偿和目标400万美元的绩效现金奖励，后者以FY2027相对FY2026调整后经营利润率增长为核心指标。
- 定位：同一8-K HTML L74–90。
- 事实：Friend 的基本薪酬125万美元及150万美元目标奖金维持至离职日；在满足持续任职及解除要求后，另获200万美元一次性过渡金，并按高管离职计划与竞业协议处理其他离职待遇。
- 定位：同一8-K HTML L96–118；Exhibit 10.1 `nike-mftransitionletter_fi.htm` HTML L24–47。

## V3-003：NEO薪酬与绩效约束

- 事实：FY2026 CEO Elliott Hill 的Summary Compensation Table总额为36,340,876美元；Matthew Friend为15,165,400美元；Venkatesh Alagirisamy为11,514,852美元；Treasure Heinle为11,972,190美元；Robert Leinwand为12,013,121美元。
- 原件：SEC FY2026 DEF 14A，accession `0000320187-26-000089`，HTML L1170–1197。
- 事实：FY2024–FY2026 PSU实际支付率为0%；FY2026年度现金激励按财务指标计算原为101%，薪酬委员会行使负向裁量降至74%；CEO最终年度现金激励支付率74%，其他NEO为78%。
- 定位：DEF 14A HTML L739–760。
- 事实：FY2026 CEO目标年度总薪酬中92%处于风险状态，其他NEO为87%；公司披露CEO两年累计可实现薪酬约为披露薪酬的50%，其他NEO平均约45%。
- 定位：DEF 14A HTML L759–783。

## V3-004：关联交易与内部交易治理披露

- 事实：FY2026关联方披露包括：Philip Knight以Chairman Emeritus身份取得约22.1万美元薪酬及一般员工医疗福利；Mark Parker之子Matthew Parker取得约14.6万美元非高管岗位薪酬；其妹Betsy Parker取得约17.5万美元非高管合同报酬；前NEO Craig Williams之女婿Kenneth Smith取得约12.5万美元非高管岗位薪酬。公司称同类雇员的薪酬福利口径一致，并由独立的公司责任、可持续发展与治理委员会依书面政策审查需按Item 404(a)披露的关联交易。
- 原件：SEC FY2026 DEF 14A HTML L2209–2217；治理委员会职责见 HTML L484。
- 事实：公司披露FY2026期间Section 16(a)报告总体按时，唯一例外是Venkatesh Alagirisamy于2025-12-10获得RSU、PSU及期权的报告因行政处理延误而迟报。
- 定位：DEF 14A HTML L2196–2208。
- 事实：截至2026-06-30，NEO持股包括Friend 460,050股、Alagirisamy 189,634股、Heinle 90,608股、Leinwand 216,591股；董事和高管合计实益持有13,323,115股Class B，占1.1%。其中部分为60日内可行权期权，不能全部视作已实际持有的自由流通股。
- 定位：DEF 14A HTML L2131–2182。
