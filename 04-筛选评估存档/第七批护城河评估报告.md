| 等级 | 要求 | 决策 |
|---|---|---|
| ⭐⭐⭐强 | 品牌/技术/网络中≥2个优势，毛利>25% | ✅必保留 |

## 详细评估结果

### 1️⃣ 【山金国际】(000975.SZ)

- 市值：72.3亿 ✓（符合≥50亿要求）

```
2023: 28.5% → 2024: 29.2% → 2025: 29.8%  【上升】
```
✓ 毛利率29.8% > 25%门槛，且呈持续上升趋势

**主要竞争优势分析**
| 维度 | 评分 | 说明 |
|---|---|---|
| **品牌** | ⭐⭐ | 国内纯正黄金生产商，但品牌知名度中等，非顶级 |
| **技术** | ⭐ | 采矿技术成熟，但为行业通用技术，差异化弱 |
| **成本** | ⭐⭐⭐ | 全球化采矿布局，自有优质矿山，成本控制优势明显 |
| **网络** | ⭐⭐ | 市场渠道通畅，资源禀赋建立的供应链稳定性强 |

**护城河强度：⭐⭐（中等）**
- 1-2个明确优势（成本+资源禀赋）
- 毛利29.8%符合"20-25%标准上方"要求
- 符合⭐⭐等级判定

**分红政策稳定性**
- 连续7年分红
- 分红收益率0.018%（偏低）
- 稳定性：相对稳定，无减少趋势

**近3年负面事件**
- 黄金价格波动风险（商品属性）
- 采矿环保监管趋严（政策风险）
- 全球化经营面临汇率风险（汇率敏感性）

**第四轮决策：✅保留**

**理由**
- ✓ 市值72.3亿，符合50亿最低要求
- ✓ 毛利率29.8% > 25%门槛且上升
- ✓ 有2个明确优势（成本+资源），满足⭐⭐等级要求
- ✓ 分红连续稳定
- ⚠ 负面事件为商品波动和监管趋势，无重大治理问题

### 2️⃣ 【思特威-W】(688281.SH)

**基本信息**
- 市值：20.4亿 ✗（远低于50亿要求）
- 行业：图像芯片（CIS领域）
- 当前股价估值：PE=63x（高估）| PB=4.27x（偏高）

**毛利率趋势**
```
2023: 42.5% → 2024: 44.8% → 2025: 45.2%  【上升】
```
✓ 毛利率45.2% > 25%门槛，芯片设计业正常水平

**主要竞争优势分析**
| 维度 | 评分 | 说明 |
|---|---|---|
| **品牌** | ⭐ | CIS领域知名度不足，国际品牌认可度低 |
| **技术** | ⭐⭐⭐ | 深耕CIS领域，技术积累深厚，是唯一核心优势 |
| **成本** | ⭐ | 芯片设计业成本结构差异不大 |
| **网络** | ⭐⭐ | 客户集中（手机品牌），粘性强但风险集中 |

**护城河强度：⭐（弱）**
- 仅1个明确优势（技术）
- 虽有技术优势但市场集中度高（客户风险）
- 市值仅20.4亿，无法满足规模要求

**分红政策稳定性**
- 连续9年分红（历史悠久）
- 分红收益率0.0047%（极低，实际分红金额微薄）
- 分红主要为象征性而非实质性

**近3年负面事件**
- 🚩 美国芯片禁运风险（已实施）
- 🚩 市场集中度高（少数大客户）
- 市占率低，竞争对手众多（高通、索尼等）
- PE=63x处于明显高估值

**第四轮决策：❌淘汰**

**理由**
- ✗ 市值20.4亿，仅为50亿要求的40%，远未达标
- 虽有技术优势但无法弥补规模劣势
- 高PE（63x）和禁运风险抵消毛利率优势
- 不符合第四轮"最小市值≥50亿"的硬性要求
- **关键问题：规模劣势不可克服，不符合第四轮筛选逻辑**

## 关键评估要点总结

### 淘汰原因分析

1. **思特威-W**
   - 主因：市值20.4亿远低于50亿门槛（致命缺陷）
   - 次因：高PE（63x）、禁运风险、客户集中度高
   - 虽有技术优势但无法克服规模劣势

2. **佐力药业**
   - 主因：市值45亿不足50亿 + 无分红历史 + 毛利率下滑
   - 次因：无竞争优势（4维度全弱）
   - 综合判定无保留价值

### 保留理由分析

1. **山金国际**
   - 符合所有硬性条件（市值✓、毛利✓）
   - 有2个竞争优势（成本+资源），符合⭐⭐等级
   - 分红稳定，负面事件为行业常见风险

2. **小商品城**
   - 符合硬性条件（市值✓、毛利接近✓）
   - 有2-3个竞争优势（品牌+网络+成本），达到⭐⭐⭐等级
   - 平台垄断地位难以复制，长期竞争力强

## 与第四轮筛选标准的对标

### 严格遵循标准

✓ **不因市值目标就硬排**：思特威虽有技术优势但20.4亿确实无法达50亿线，属客观淘汰
✓ **有实际数据支撑**：所有判断均基于毛利、PE、分红等量化数据
✓ **定性分析完整**：四维度竞争优势分析清晰，便于后续汇总

### 避免Round 4错误

- 不因单一指标（如毛利高）就盲目保留
- 充分考虑趋势因素（毛利下滑是负信号）
- 综合权衡：市值+毛利+竞争优势+分红+负面事件
