# 第五批公司护城河强度评估报告

## 评估标准回顾
- **⭐⭐⭐强**：品牌/技术/网络中≥2个优势，毛利>25% → ✅必保留
- **⭐⭐中**：1个明确优势，毛利20-25% → ✅保留
- **⭐弱**：成本优势为主，毛利15-20% → 🟡需评估
- **✗无**：无竞争优势，毛利<15% → ❌淘汰
- **最小市值要求**：≥50亿元

## 【芭田股份】(002170.SZ)
**分类：化肥肥料**

### 基本面数据
- **市值**：133.52亿元 ✓ (>=50亿)
- **毛利率趋势**：2024年 31.17% → 2026年Q1 38.22%（持续上升）
- **营收增长**：2024年33.13亿元，同比+2.15% / 2026年Q1同比+19.42%
- **净利润增长**：2024年4.09亿元，同比+57.67% / 2026年Q1同比+60.26%

### 市场地位与竞争优势

#### 🏆 品牌优势
- **国内磷肥行业龙头**，深耕磷肥、复合肥领域30年
- **品牌认知度高**，全国销售网络覆盖完整

#### 💡 技术优势
- **磷矿采选产能扩张**：2024年实际产量113万吨，同比增长46.9%
- **磷矿二期项目**：90万吨新增产能，总产能规划290万吨/年
- **新能源材料布局**：磷酸铁、磷酸铁锂等新产品线2025年发力

#### 💰 成本优势
- **资源稀缺性**：自有磷矿资源，一体化降成本
- **原材料自给**：磷矿采选+化肥制造垂直整合
- **毛利率提升**：磷矿石业务毛利率高达83.67%，拉升整体毛利

#### 🌐 网络优势
- 国内销售渠道完整，产品覆盖农化、新能源两大终端

### 护城河强度评估
**⭐⭐中强**（接近⭐⭐⭐）

**依据**：
- ✓ 品牌+技术+成本 三维优势明显
- ✓ 毛利率31.17%-38.22%，远超25%门槛
- ✓ 磷矿资源稀缺性强，形成进入壁垒
- ✓ 产能扩张逻辑清晰，新增长点确定

### 分红政策稳定性
- **2024年分红**：派息2.80元/10股，分红率71.1%，经营性现金流5.48亿元同比增长120%
- **分红承诺**：2024-2026年三年累计分红不低于60%，稳定性强

### 负面事件评估
**有负面事件，但风险可控**

| 事件类别 | 具体内容 | 风险评级 |
|---|---|---|
| 安全生产 | 2022-2023年多次因安全生产措施不到位被处罚（30-50万元） | 中 |
| 环保合规 | 子公司因污染物排放控制不力被罚款 | 中 |
| 股东减持 | 2024年9月股东项延灶涉嫌违规减持，被董监会警示 | 低 |

**风险总结**：主要为安全环保合规成本提升，属于化工行业常见风险，不影响主体经营资质。

### 第四轮决策
**✅ 保留**

**理由**：
1. 护城河强度⭐⭐中强（品牌+技术+成本），毛利率31%-38%远超25%门槛
2. 市值133.52亿元满足>=50亿要求
3. 资源稀缺+产能扩张+一体化成本优势逻辑清晰，增长确定性强
4. 虽有安全环保风险但非致命，可持续关注但不成为淘汰理由
