## 筛选方法

| 环节 | 说明 |
|---|---|
| 粗筛（Tiger API） | 港股全市场：股价≥HKD5、流通市值≥100亿港元、PE(TTM) 6-25x |
| 补字段（yfinance） | 52周高点、5年/3年营收与净利CAGR、ROE、毛利率、负债率、现金流等 |
| 跌幅过滤 | 距52周高点跌幅 ≥15% |
| 量化评分（四维） | 增长30% + 现金流质量30% + 资本质量25% + 估值折价15% − 异常惩罚 |
| 下跌归因调研 | 对 A 档候选逐家检索：大跌原因、最新业绩、红旗、错杀/该跌判定 |

> 数据来源：Tiger Open API（行情快照）、yfinance（财务+52周高点）、AASTOCKS/证券之星/东方财富/智通财经等公开报道（下跌归因）。评分为量化辅助，非投资建议。

## 重点跟踪建议

1. **紫金黄金国际 / 高伟电子**：错杀特征最纯粹（业绩强+无红旗），但紫金取决于金价方向、高伟取决于手机行业触底——两者均属「基本面强、贝塔拖累」，适合逢低分批而非一次性重仓。
2. **中烟香港 / 敏实集团**：错杀偏多且基本面确定性较高（垄断平台/订单驱动），若中报验证 H2 改善（中烟 8 月中报、敏实中报）可重点看。
3. **泡泡玛特 / 飞速创新**：错杀成分大但各有待验证项（海外拐点 / 治理整改），建议等中报细节后再定。
4. **规避**：九方智投（监管+盈利崩塌）、比亚迪电子（成本挤压未见拐点）、快手（AI投入期利润难测）、毛戈平（减持潮未止）。

## 风险提示

- 本报告为量化筛选 + 公开信息归因，**不构成投资建议**；所有判断基于 2026-08-20 可得数据。
- 港股整体风险偏好收缩（2026年6月金价大跌、7月手机链重挫）是多数候选的共同背景，需区分「个股错杀」与「市场系统性下行」。
- 紫金黄金国际、飞速创新、中烟香港等存在宏观/治理/关税单一变量集中风险，务必阅读 hk-prebuy 流程做完整尽调后再决策。
- 量化评分中部分公司（腾讯、快手等）财务字段来自 yfinance，可能滞后或口径差异，重要决策前应以公司公告与年报复核。
