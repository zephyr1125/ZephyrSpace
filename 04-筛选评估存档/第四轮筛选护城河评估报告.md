## 评估明细

### 1️⃣ 【万辰集团】(300972.SZ) - 零食零售

| 指标 | 数值 | 评价 |
|---|---|---|
| **市值** | ~200亿元 | ✓ 超50亿门槛 |
| **毛利率趋势** | Q1 2025: 11.02% | ⚠️ 明显偏低（远低于20%底线） |
| **2025Q1 ROE** | 17.74% | 中等偏高 |

#### 竞争优势分析
- **网络优势 ⭐⭐⭐**：18,000+门店，"好想来"品牌已进入万店俱乐部，覆盖全国超过90%地级市以上城市
- **供应链优势 ⭐⭐**：51个常温仓+13个冷链仓，覆盖百万平米，T+1补货效率高，订单满足率99%+
- **品牌与整合优势 ⭐**：多品牌（好想来、来优品、吖嘀吖嘀等）整合初见成效，但知名度不如头部品牌
- **成本优势 ⭐**：大规模直采和议价能力强，产品低于传统渠道20-30%；自有品牌毛利率高但占比仅15%

#### 护城河强度评估
**⭐ 弱** — 理由：
- 虽有强大的渠道网络和供应链体系（2个优势），但**毛利率11%远低于门槛**，核心盈利能力受限
- 零食零售行业进入门槛不高，新玩家持续入局
- 规模经济+网络效应尚未充分转化为护城河（毛利率是主要制约）

#### 负面事件
- 🚨 **2025年3月**：董事长王健坤被国家监察机关留置、立案调查（官方声明与公司业务无关）
- 近年多项安全生产/环保处罚（2019年：安全、环保、海关合规各被罚）
- 2024年底经历巨亏，2025年虽扭亏但仍存现金流压力

#### 分红政策
- 2023年开始参与分红，但鉴于近期亏损和治理风险，分红政策存变数

#### 第四轮决策
**❌ 淘汰** 
- **理由**：毛利率11%远低于15%的"弱"档门槛，跌出第四轮筛选范围；董事长被立案调查为重大治理风险；零售赛道竞争激烈，核心护城河依然薄弱。

### 2️⃣ 【东鹏饮料】(605499.SH) - 功能性饮料

| 指标 | 数值 | 评价 |
|---|---|---|
| **市值** | 1151亿元 | ✓ 远超50亿门槛 |
| **毛利率趋势** | Q1 2025: 44.47% | ✓ 远超25%强度门槛 |
| **2025Q1 ROE** | 11.99% | 中等 |

#### 竞争优势分析
- **品牌优势 ⭐⭐⭐**：功能性饮料龙头，"东鹏特饮"品牌深入人心，年轻消费者认知度极高
- **产品差异化 ⭐⭐⭐**：功能性饮料赛道的先行者，核心产品（维生素饮料）具有独特定位
- **渠道网络 ⭐⭐**：全国渠道覆盖完善，便利店/超市/电商触达率高
- **规模效应 ⭐⭐**：上市公司中成交额最大，成本优势明显

#### 护城河强度评估
**⭐⭐⭐ 强** — 理由：
- 毛利率44.47% 远超25%门槛，显示强大定价权
- 品牌+产品差异 ≥ 2个维度竞争优势
- 功能性饮料赛道高景气，市场地位牢固
- 持续创新能力强（推新速度快）

#### 负面事件
- **未发现重大红旗**：公开资料未见近年重大诉讼、处罚或质量问题

#### 分红政策
- ✓ 连续分红 5 年（2021-2025）
- 分红逐年增加：2023年每10股20元 → 2024年25元 → 2025年拟25元（分两次）
- 累计分红80.12亿元，分红率64.53%（高于行业平均）
- 当前股息率 2.4%（处历史高位区间，显示分红意愿强）

#### 第四轮决策
**✅ 必保留**
- **理由**：毛利率44%+品牌+产品差异形成 ⭐⭐⭐ 强护城河；分红连续稳定增长；无重大负面事件；市值充分。强烈推荐继续保留。

|---|---|---|
| **市值** | 171亿元 | ✓ 超50亿门槛 |
| **毛利率趋势** | Q1 2025: 80.16% | ✓✓ 极高（医药行业典型） |
| **2025Q1 ROE** | 8.75% | 偏低 |

#### 竞争优势分析
- **技术专利 ⭐⭐⭐**：眼科用药专业制造商，拥有多项眼科药物专利
- **品牌专业性 ⭐⭐**：眼科医生和患者认知度高，市场地位稳定
- **产品差异化 ⭐⭐**：眼科用药品类齐全，研发持续投入
- **渠道优势 ⭐**：医院、零售药店全渠道覆盖

#### 护城河强度评估
**⭐⭐⭐ 强** — 理由：
- 毛利率80% 远超25%门槛，医药行业高度数据可信
- 技术专利 + 品牌专业性 ≥ 2个维度竞争优势
- 眼科用药需求稳定，市场竞争相对温和

#### 负面事件
- ✓ **最近5年未被证券监管部门处罚**（官方2025年5月声明）
- 历史上仅有正常的信息披露关注函（非处罚）

#### 分红政策
- ✓ 连续分红 9 年（2017-2025）
- 分红大幅提升：2024年达历史高位（每10股30元+转增4股）、2025年拟每10股10元+转增4.5股
- 累计分红11.66亿元
- 当前股息率 2.49%（处历史高位区间）

#### 第四轮决策
**✅ 必保留**
- **理由**：毛利率80%+专利技术+品牌形成 ⭐⭐⭐ 强护城河；分红连续9年且持续增长；无重大负面事件；市值充分。强烈推荐继续保留。

### 4️⃣ 【盐津铺子】(002847.SZ) - 休闲食品

| 指标 | 数值 | 评价 |
|---|---|---|
| **市值** | ~150亿元 | ✓ 超50亿门槛 |
| **毛利率趋势** | Q1 2025: 28.47% | ✓ 超过20-25%区间 |
| **2025Q1 ROE** | 9.75% | 偏低 |

#### 竞争优势分析
- **品牌知名度 ⭐⭐**：蜜饯、豆干等细分品类领先，消费者认知度较好
- **渠道广度 ⭐⭐**：全国超市、便利店、电商全覆盖，渠道触达率高
- **产品创新 ⭐**：持续推新，但同质化竞争明显
- **成本优势 ⭐**：规模化生产，成本控制一般

#### 护城河强度评估
**⭐⭐ 中** — 理由：
- 毛利率28% 处于 20-25% 中上方，超过中档门槛
- 品牌+渠道 1-2个维度竞争优势，但专业度不如头部
- 竞争环境激烈（三只松鼠、百草味等强势竞争）

#### 负面事件
- 🚨 **食品安全问题**（2025年）：防腐剂超标、产品下架
- **高管违规交易**（2022）：高管未提前15天披露减持计划，被湖南证监局警示函
- **实控人高位减持**（2025）：张学文拟减持4亿+，引发市场质疑
- **消费投诉激增**（2025）：黑猫投诉百余起，主要为"吃出异物"、"食品变质"、"过期产品"
- **毛利率持续下滑**：2020年至今已从40%+降至28%

#### 分红政策
- ✓ 分红稳定，自上市以来11次分红，累计14.28亿元
- 分红频率：近年2-3次/年，分红+转增结合
- 当前静态股息率 2.55%，但TTM 仅 0.67%（处5年低位）
- 派息比率53.52%，历史波动大

#### 第四轮决策
**🟡 待评估** → **倾向淘汰（❌）**

**理由（倾向淘汰）**：
- 虽毛利率28%≥中档门槛，但趋势**持续下滑**（2020年40%+ → 2025年28%），反映竞争力衰退
- **食品安全问题集中爆发**（2025年防腐剂超标+百余投诉），是重大治理和品质风险信号
- **高管及实控人违规交易/高位减持**，表明内部人信心不足
- 与头部品牌（三只松鼠、百草味等）的差距在扩大，护城河被侵蚀

**保留条件**：如3-6个月内食品安全问题得到根本改善、投诉大幅下降、毛利率稳定或反弹，可重新评估。

## 核心结论

### 📊 第四轮筛选结果

| 评分等级 | 公司 | 状态 |
|---|---|---|
| **⭐⭐⭐ 强护城河** | 东鹏饮料、兴齐眼药 | ✅ **必保留** |
| **⭐⭐ 中等护城河** | 盐津铺子 | 🟡 **待评估** → **倾向淘汰** |
| **⭐ 弱护城河** | 万辰集团 | ❌ **淘汰** |

### 🎯 主要发现

1. **强护城河代表**（东鹏、兴齐）：
   - 毛利率显著 ≥ 25%（东鹏44%、兴齐80%）
   - 至少2个维度竞争优势（品牌/技术/网络）
   - 分红连续稳定增长
   - 无重大负面事件
   - **建议长期持有或作为核心配置标的**

2. **风险公司淘汰**（万辰）：
   - 毛利率远低于门槛（11% << 15%），核心竞争力不足
   - 治理风险突出（董事长被查）
   - 零售赛道竞争加剧，护城河难以维系

3. **衰退中的公司**（盐津铺子）：
   - 毛利率持续下滑（4-5年下滑12%+），反映竞争力衰退
   - 食品安全问题集中爆发，品质危机信号
   - 实控人信心不足（高位减持）
   - **建议暂时移出核心关注，待改善后重新评估**

### ✅ 推荐行动

1. **继续重点关注**：东鹏饮料、兴齐眼药 → **确认为一级筛选标的**
2. **移出或降档**：万辰集团（❌）、盐津铺子（🟡→❌）
3. **后续追踪**：盐津铺子——监控食安改善、投诉下降、毛利率止跌等关键指标，6个月后重新评估
