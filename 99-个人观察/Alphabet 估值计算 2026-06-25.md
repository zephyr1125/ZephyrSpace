> 日期：2026-06-25
> 股价参考：**~$360**（2026-06 区间 $345–373）
> 52周区间：$162 – $408.61
> 市值：约 **$4.35 万亿**
> 稀释股数：约 12,200M 股
> 分析师共识：**Strong Buy**，中位目标价 $433（72位分析师）

---

## 方法论选择

Alphabet 是全球最大数字广告平台 + 增速最快的超大规模云厂商之一 + Waymo 等 moonshot 期权。AI Capex 在 FY2026 接近翻倍至 $175-185B——短期 FCF 将被压缩至负值，传统 FCF Yield 估值暂时失效。适用方法：**P/E 框架 > PEG > SOTP > EV/EBITDA**。

---

> **逻辑**：Alphabet 上市 20 年，P/E 区间受市场反复验证。在 Capex 重投入期（FY2026），盈利比 FCF 更能反映真实的经常性盈利能力——折旧要在未来 5-7 年才逐步确认。

## 方法二：增长调整 PEG 框架

> **逻辑**：PEG = P/E ÷ 增长率。对于增速 10-20% 的成熟科技公司，PEG 1.5-2.0x 为合理区间。

| 参数 | 数值 |
|---|---|
| 当前 TTM P/E | **27.5x** |
| FY2025 营收增速 | **+15.1%** |
| FY2025 EPS 增速 | **+34.5%**（含投资收益，不可持续） |
| FY2025 经常性 EPS 增速 | **~18%**（估算） |
| FY2026E 营收增速 | **+21%**（分析共识） |
| FY2026E 经常性 EPS 增速 | **~15%**（剔除投资波动） |

| PEG 计算 | PEG | vs 合理 PEG 1.5-2.0 |
|---|---|---|
| 基于 TTM EPS + 营收增速 | 27.5 / 15.1 = **1.82** | 🟡 合理区间内 |
| 基于 TTM EPS + 经常性 EPS 增速 | 27.5 / 18 = **1.53** | 🟢 合理偏低估 |
| 基于 Forward P/E (~24x) + FY2026E 营收增速 | 24 / 21 = **1.14** | 🟢 低估 |

**PEG 倒推合理股价**（PEG 1.75x 合理中枢）：

- 基于 FY2027E EPS $13.00 × 15% 增速 × 1.75 = $13.00 × 26.25 = **$341**
- 基于 FY2027E EPS $13.50 × 18% 增速 × 1.75 = $13.50 × 31.5 = **$425**（乐观场景）

> **PEG 结论**：PEG 方法指向 **$340–350** 合理中枢。Forward P/E 视角下 Alphabet 甚至略偏低估（PEG 1.14x）。

## 方法三：分部加总（SOTP）

> **逻辑**：Google Cloud 的增速（+48%）和利润率（30%+）与核心广告业务（+10-15%）完全不同——SOTP 分别估值捕捉这种差异。Waymo 的期权价值也应单独考虑。

### 分部拆分

#### 1. Google 核心（搜索 + YouTube + 网络 + 订阅 + 硬件等）

| 参数 | 数值 |
|---|---|
| FY2026E 收入 | ~$414B（总收入 ~$487B - Cloud ~$73B） |
| 营业利润率 | ~40% |
| FY2026E 营业利润 | ~$166B |
| 税后（15%税率） | ~$141B |
| 合理 P/E | **22–26x** |

**可比**：Meta（社交+广告，20x）、腾讯核心（社交+游戏+广告，16x）。Google 核心增速（+10-15%）介于两者之间，但利润率（40%）高于 Meta（~35%）和腾讯（~32%）。

| 情景 | P/E | 核心价值 |
|---|---|---|
| 保守 | 20x | $2.82T |
| **基础** | **24x** | **$3.38T** |
| 乐观 | 28x | $3.95T |

**基础：$3.38T**

#### 2. Google Cloud

## 综合估值结论

### 四种方法交叉验证

| 方法 | 基础情景 | vs 当前 $360 | 权重 |
|---|---|---|---|
| **P/E 框架**（27x FY2027E $13） | **$351** | -3% | 35% |
| **PEG**（1.75x，FY2027E $13 + 15% 增速） | **$341** | -5% | 20% |
| **SOTP**（24x 核心 + 35x Cloud + $130B Bets） | **$339** | -6% | 30% |
| **EV/EBITDA**（20x FY2027E） | **$344** | -4% | 15% |
| **加权合理价值** | **$345** | **-4%** | |

**四法收敛性极好**——全部指向 $339–351，与当前 $360 的差距仅 -4%。这是"**公允定价**"而非"显著低估"的信号。

### 与腾讯估值的本质差异

| | Alphabet ($360) | 腾讯 (HK$421) |
|---|---|---|
| P/E (forward) | ~27x (TTM) / ~25x (FY2027E) | **13.9x** FY2026E |
| 历史分位 | **P50** | **P20 以下** |
| vs 合理价值 | -4%（公允） | **+39%**（显著低估） |
| Capex/营收 | ~38%（FY2026E，极高） | ~15%（FY2026E） |
| 市场叙事 | "AI Capex 恐惧+Cloud 增长对冲" | "AI Capex 恐惧+China discount 双重压制" |
| **结论** | **合理持有，等回调** | **低估区间，逐步建仓** |

> Alphabet 当前约 $360 的价格反映的是"市场充分理解了 Google 的 AI 叙事，并给予了公允定价"。想获得超额收益需要：①Cloud 增速持续超预期（>40%）→ Cloud 估值上调；②Waymo IPO 释放价值（$100B+）→ SOTP 上修；③AI 广告 ROI 超预期→核心增速上移。这些都有可能，但都已经"price-in 了部分预期"——不像腾讯那样被显著低估。

### 价格区间

| 档位 | 价格区间 | 对应 P/E（FY2027E） | 逻辑 |
|---|---|---|---|
| 🚀 乐观 | **>$420** | >32x | Cloud + Waymo 双爆发 |
| 🟢 合理区间 | **$340–$400** | 26–31x | 当前叙事延续 |
| 🟡 **当前位置** | **~$360** | **~28x** | 🟡 合理上沿 |
| 🟢 低估区间 | **$270–$340** | 21–26x | AI Capex 恐慌提供买入窗口 |
| 🔴 深度低估 | **<$250** | <19x | 系统性危机（反垄断拆分/广告崩盘） |

### 当前判断（2026-06-25）

**$360 = 公允定价，安全边际有限。** 四种估值方法收敛于 $345——这意味着 Alphabet 当前被"公平"而非"便宜"地定价。与同属 AI Capex 重投入期的腾讯（14x P/E，+39% 上行空间）形成强烈对比。

> Alphabet 是一笔"**以合理价格持有优质资产**"的交易——你需要对 Google Cloud 增速、Waymo 价值和 AI 广告 ROI 有超越市场共识的判断，才能在 $360 获得超额收益。它不是一笔"**以低估价格买入优质资产**"的交易——腾讯才是。

**催化剂（推动重估至 $400+）**：
1. Q2 2026 财报（2026-07-22）：Cloud 增速 >40% + AI 广告数据超预期
2. Waymo 独立融资/IPO 公告（估值 >$100B）
3. FY2027 Capex 指引回落至 $120-140B（"峰值已过"信号）

**核心风险**：
1. AI Capex $180B 的 ROI 不达预期→2027-2028 年折旧大幅拖累利润
2. 反垄断拆分风险（Google 面临美国司法部拆分搜索/广告业务的诉讼）
3. AI 搜索（ChatGPT/Perplexity）侵蚀 Google 搜索市场份额
