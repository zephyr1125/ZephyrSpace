

适用范围：制造业、设备类公司、项目型公司、技术平台型公司。  
注意：消费垄断、银行、保险、地产、资源周期股需要调整口径，不能完全照搬。

## 1. ROE：股东资本回报率

![[Pasted image 20260525232621.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 加权 ROE | 包含所有利润的股东回报率 |
| 扣非加权 ROE | 扣除非经常性损益后的主业股东回报率 |

### 这个指标回答什么问题

> 股东投入的净资产，公司每年能赚回多少利润？

### 数值标准

| 长期 ROE | 判断 |
|---|---|
| < 8% | 偏弱 |
| 8%–12% | 尚可 |
| 12%–15% | 良好 |
| 15%–20% | 优秀 |
| > 20% | 很强，但要检查是否靠高杠杆或周期高点 |

### 好趋势

- ROE 长期稳定在 12% 以上。
- 更好是长期 15% 以上。
- 加权 ROE 和扣非 ROE 接近。
- 没有连续多年下滑。
- 扣非 ROE 不明显低于普通 ROE。

### 坏趋势

- ROE 连续多年下降。
- 普通 ROE 高，但扣非 ROE 明显低。
- ROE 靠少数年份异常拉高。
- ROE 高但资产负债率也大幅上升。
- ROE 高但经营现金流很差。

### 解释

如果加权 ROE 和扣非 ROE 几乎贴着走，说明：

> 公司利润主要来自主业，非经常性损益影响小，盈利质量较高。

例如：

| 公司 | 判断 |
|---|---|
| 国电南瑞 | 长期约 15%–16%，优秀 |
| 贵州茅台 | 长期 30%+，顶级 |

## 2. 盈利能力：毛利率、营业利润率、净利润率

![[Pasted image 20260525232903.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 毛利率 | 产品 / 服务本身的盈利能力 |
| 营业利润率 | 扣除销售、管理、研发、财务等费用后的经营盈利能力 |
| 净利润率 | 最终留给股东的利润率 |

### 三者关系

```text
营业收入
- 营业成本
= 毛利

毛利 / 营业收入 = 毛利率

毛利
- 销售费用
- 管理费用
- 研发费用
- 财务费用
- 减值损失等
= 营业利润

营业利润 / 营业收入 = 营业利润率

净利润 / 营业收入 = 净利润率
```

### 这个指标回答什么问题

> 公司每一元收入，最终能赚多少钱？

### 数值标准：制造业 / 设备类粗略参考

| 指标 | 偏弱 | 尚可 | 良好 | 优秀 |
|---|---:|---:|---:|---:|
| 毛利率 | < 15% | 15%–25% | 25%–40% | > 40% |
| 营业利润率 | < 5% | 5%–10% | 10%–18% | > 18% |
| 净利润率 | < 5% | 5%–10% | 10%–15% | > 15% |

行业差异很大，所以趋势比绝对值更重要。

### 好趋势

- 毛利率长期稳定。
- 营业利润率长期稳定。
- 净利润率长期稳定。
- 收入增长时，利润率没有明显下降。
- 毛利率下降时，营业利润率仍能稳定，说明费用控制较好。

### 坏趋势

- 毛利率连续多年下降。
- 营业利润率下降幅度大于毛利率。
- 净利润率持续下降。
- 收入增长但利润率越来越低。
- 毛利率和净利润率同时下滑。

### 组合判断

好形态：

```text
营收增长 + 毛利率稳定 + 净利润率稳定
```

说明增长质量较好。

坏形态：

```text
营收增长 + 毛利率下降 + 净利润率下降
```

说明增长可能是低质量增长。

### 国电南瑞示例

国电南瑞毛利率约 26%，净利润率约 13%–15%，整体稳定，但近年略有下行压力。

阶段判断：

> 盈利能力稳定，但需要继续观察毛利率和净利润率是否持续下滑。

## 3. 扣非净利润占比：利润真实性

![[Pasted image 20260525232911.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 扣非净利润占比 | 扣非净利润 / 净利润 |

### 这个指标回答什么问题

> 公司利润是不是主要来自主业？

### 数值标准

| 扣非净利润占比 | 判断 |
|---|---|
| > 90% | 很好，利润主要来自主业 |
| 70%–90% | 可以接受 |
| 50%–70% | 需要警惕 |
| < 50% | 主业利润质量存疑 |
| 长期为负或大幅波动 | 高风险 |

### 好趋势

- 长期高于 90%。
- 多数年份稳定。
- 不依赖政府补助、投资收益、资产处置。
- 和 ROE、净利润率方向一致。

### 坏趋势

- 扣非净利润占比长期偏低。
- 某几年净利润很好，但扣非利润很差。
- 扣非净利润占比大幅波动。
- 普通 ROE 很高，但扣非 ROE 明显低。

### 解释

如果扣非净利润占比长期 95%+，说明：

> 公司利润主要由主业贡献，非经常性损益扰动很小。

例如：

| 公司 | 判断 |
|---|---|
| 国电南瑞 | 近几年约 95%+，很好 |
| 贵州茅台 | 扣非 ROE 和 ROE 几乎贴合，也是极好信号 |

## 4. 利润现金化：经营现金流 vs 净利润

![[Pasted image 20260525232918.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 净利润 | 账面利润 |
| 经营活动现金流量净额 | 主业实际产生的现金 |

### 这个指标回答什么问题

> 账面利润有没有变成真现金？

### 核心指标

```text
经营现金流 / 净利润
```

### 数值标准

| 经营现金流 / 净利润 | 判断 |
|---|---|
| > 1.0 | 很好，现金流覆盖利润 |
| 0.8–1.0 | 可以接受 |
| 0.5–0.8 | 需要警惕 |
| < 0.5 | 利润现金含量较差 |
| 长期为负 | 高风险 |

### 好趋势

- 经营现金流长期接近或高于净利润。
- 多年累计经营现金流接近或高于多年累计净利润。
- 净利润增长时，经营现金流也增长。
- 偶尔波动可以接受，但不能长期背离。

### 坏趋势

- 净利润增长，经营现金流不增长。
- 经营现金流长期低于净利润。
- 经营现金流经常为负。
- 净利润很好看，但现金流很差。

### 解释

如果经营现金流长期高于净利润，说明：

> 公司利润现金化能力强，利润质量较高。

国电南瑞：近几年经营现金流明显高于净利润，是强加分项。  
茅台：长期现金流很强，但单年会受预收款、税费、渠道节奏影响而波动。

## 5. 营运资本占用：收入、应收、合同资产、存货

![[Pasted image 20260525232927.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 营业总收入 | 业务规模 |
| 应收账款 | 已确认收入但还没收回的钱 |
| 合同资产 | 已履约但尚未形成无条件收款权的资产 |
| 存货 | 产品、材料、项目占用 |

### 这个指标回答什么问题

> 公司增长有没有被应收账款、合同资产、存货吃掉现金？

### 好趋势

- 收入增长，应收账款同步增长但不明显跑赢收入。
- 合同资产没有快速膨胀。
- 存货随业务规模增长，但没有明显积压。
- 经营现金流仍能覆盖净利润。

### 坏趋势

- 收入增速放缓，但应收账款继续高增。
- 应收账款增长明显快于收入。
- 合同资产快速增长。
- 存货持续高增。
- 经营现金流同步恶化。

### 判断重点

绝对金额上升不一定坏。公司做大后，应收、存货自然会增加。  
真正要看：

```text
应收账款是否跑赢收入
合同资产是否跑赢收入
存货是否跑赢收入
经营现金流是否变差
```

### 国电南瑞示例

国电南瑞应收账款绝对额较高，但结合周转率和经营现金流看，目前不能直接否定。

阶段判断：

> 应收和存货绝对额上升，但没有证据显示营运资本明显失控。

## 6. 应收账款周转率 / 应收账款周转天数

![[Pasted image 20260525232935.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 应收账款周转率 | 一年内应收账款周转多少次 |
| 应收账款周转天数 | 平均多少天收回账款 |

### 这个指标回答什么问题

> 回款效率有没有恶化？

### 基本原则

```text
周转率越高越好
周转天数越低越好
```

### 粗略标准：B2B / 项目型公司

| 应收账款周转天数 | 判断 |
|---|---|
| < 90 天 | 很好 |
| 90–180 天 | 可以接受 |
| 180–240 天 | 偏重，需要观察 |
| > 240 天 | 回款压力较大 |
| 连续多年上升 | 恶化信号 |

对于项目型、电网、基建、军工、政府客户类公司，账期通常比消费品长，所以不能拿茅台标准比较。

### 好趋势

- 应收账款周转率上升。
- 应收账款周转天数下降。
- 周转天数长期稳定。
- 应收增长但周转效率没有恶化。

### 坏趋势

- 应收账款周转率连续下降。
- 应收账款周转天数连续上升。
- 收入增长放缓，但应收账款周转变慢。
- 经营现金流同步恶化。

### 国电南瑞示例

国电南瑞应收账款周转天数：

| 阶段 | 大致情况 |
|---|---|
| 2016–2019 | 约 200 天以上 |
| 2021–2025 | 大致 165–180 天 |

阶段判断：

> 应收账款绝对额虽然上升，但回款效率相比早年改善，没有明显恶化。

## 7. 存货周转率 / 存货周转天数

![[Pasted image 20260525232941.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 存货周转率 | 一年内存货周转多少次 |
| 存货周转天数 | 平均多少天完成存货周转 |

### 这个指标回答什么问题

> 公司有没有库存积压或项目交付变慢？

### 基本原则

```text
存货周转率越高越好
存货周转天数越低越好
```

### 粗略标准：制造业 / 设备类

| 存货周转天数 | 判断 |
|---|---|
| < 60 天 | 很好 |
| 60–120 天 | 正常 |
| 120–180 天 | 偏重 |
| > 180 天 | 需要警惕 |
| 连续多年上升 | 库存压力可能加大 |

### 好趋势

- 存货周转率稳定或上升。
- 存货周转天数稳定或下降。
- 收入增长时，存货没有明显跑赢收入。
- 存货周转不拖累现金流。

### 坏趋势

- 存货周转率连续下降。
- 存货周转天数连续上升。
- 存货快速增长但收入不增长。
- 毛利率下降同时存货上升。

### 国电南瑞示例

国电南瑞存货周转天数近年大致在 85–91 天附近，比较稳定。

阶段判断：

> 存货没有明显积压，项目交付和库存管理基本正常。

## 8. 资产负债表安全性：负债、现金、商誉、资产质量

### 看什么

| 指标 | 含义 |
|---|---|
| 资产负债率 | 总负债 / 总资产，判断整体杠杆水平 |
| 有息负债率 | 有息负债 / 总资产或相关口径，判断真实债务压力 |
| 货币资金 | 公司账上现金和类现金资产 |
| 有息负债 | 短期借款、长期借款、债券等需要付利息的债务 |
| 商誉 | 并购形成的溢价资产，可能存在减值风险 |
| 商誉占净资产比率 | 判断商誉风险相对股东权益的大小 |
| 固定资产 / 在建工程 / 无形资产 | 判断公司是否重资产扩张、是否存在持续资本投入压力 |

### 这个指标回答什么问题

> 公司有没有隐藏的财务风险？增长是否依赖高负债、重资产、商誉或持续融资？

---

### 8.1 资产负债率与有息负债率

![[Pasted image 20260526102009.png]]

#### 看什么

| 指标 | 含义 |
|---|---|
| 资产负债率 | 整体负债水平 |
| 有息负债率 | 真正需要付利息的债务压力 |

#### 基本原则

资产负债率不是越低越好，但不能持续恶化。  
有息负债率比资产负债率更关键，因为经营性负债和金融性负债风险不同。

```text
资产负债率看整体杠杆
有息负债率看真实偿债压力
```

#### 资产负债率粗略标准

| 资产负债率 | 判断 |
|---|---|
| < 30% | 很稳健 |
| 30%–50% | 正常 |
| 50%–65% | 偏高，需要结合行业 |
| > 65% | 财务压力较大 |
| 连续多年上升 | 需要警惕 |

#### 有息负债率粗略标准

| 有息负债率 | 判断 |
|---|---|
| < 10% | 很安全 |
| 10%–25% | 可以接受 |
| 25%–40% | 偏高 |
| > 40% | 警惕 |
| 持续上升 | 债务风险上升 |

#### 好趋势

- 资产负债率稳定或下降。
- 有息负债率很低。
- 有息负债率没有持续上升。
- 资产负债率不低，但有息负债率很低，说明负债主要是经营性负债。
- 财务费用没有明显侵蚀利润。

#### 坏趋势

- 资产负债率连续多年上升。
- 有息负债率快速上升。
- 短期借款、长期借款、债券明显增加。
- 经营现金流很好但仍需要大量借钱。
- 财务费用占利润比例持续提高。

#### 国电南瑞示例

国电南瑞 2025 年资产负债率约 42.73%，处于正常可控区间；有息负债率约 0.60%，极低。

阶段判断：

> 国电南瑞整体负债率不高，有息负债极低，说明公司几乎不依赖金融负债扩张，财务杠杆风险很低。

### 8.2 货币资金 VS 有息负债

![[Pasted image 20260526102104.png]]

#### 看什么

| 指标 | 含义 |
|---|---|
| 货币资金 | 账上现金和类现金 |
| 有息负债 | 需要付利息的债务 |

#### 这个指标回答什么问题

> 公司账上的钱能不能覆盖债务？有没有短期偿债压力？

#### 基本原则

```text
货币资金 > 有息负债，较好
货币资金远高于有息负债，很好
有息负债远高于货币资金，需要警惕
```

#### 好趋势

- 货币资金长期大于有息负债。
- 货币资金能覆盖短期债务。
- 有息负债不高，且没有快速上升。
- 货币资金下降时，有合理原因，例如分红、回购、资本开支、理财口径变化。

#### 坏趋势

- 有息负债持续上升。
- 货币资金持续下降。
- 货币资金无法覆盖短期债务。
- 经营现金流好，但公司仍持续大量借钱。
- 财务费用明显上升。

#### 国电南瑞示例

国电南瑞 2025 年货币资金约 73.23 亿，有息负债约 5.89 亿，货币资金远高于有息负债。

阶段判断：

> 公司短期偿债压力很低，债务安全性较强。货币资金较前期高点有所下降，但由于有息负债极低，暂不构成主要风险。

### 8.3 资产质量：固定资产、在建工程、无形资产、长期股权投资

![[Pasted image 20260526102407.png]]

#### 看什么

| 指标 | 含义 |
|---|---|
| 固定资产 | 厂房、设备等长期生产资产 |
| 在建工程 | 尚未转固的建设项目 |
| 无形资产 | 软件、土地、技术、专利等资产 |
| 长期股权投资 | 对外长期投资 |

#### 这个指标回答什么问题

> 公司是不是在重资产扩张？未来有没有折旧、摊销、减值或资本开支压力？

#### 好趋势

- 固定资产和在建工程没有持续激进扩张。
- 在建工程没有长期高企。
- 无形资产增长与业务发展匹配。
- 长期股权投资占比不高，且没有持续吞噬现金。
- 资产扩张后，收入、利润、现金流同步增长。

#### 坏趋势

- 固定资产快速上升，但收入利润没有同步增长。
- 在建工程长期高企，迟迟不转固或不贡献利润。
- 无形资产快速膨胀，但利润质量下降。
- 长期股权投资大幅上升，投资收益不稳定。
- 资产扩张导致折旧摊销压力上升。

#### 判断重点

```text
资产扩张必须最终体现为收入、利润、现金流增长
否则可能只是资本沉淀或低效扩张
```

#### 国电南瑞示例

国电南瑞固定资产和在建工程没有出现持续激进扩张迹象，商誉风险极低，有息负债极低。

阶段判断：

> 资产结构整体安全，没有明显重资产失控或商誉减值风险。

---

### 8.4 商誉与商誉占净资产比率

![[Pasted image 20260526102516.png]]

#### 看什么

| 指标 | 含义 |
|---|---|
| 商誉 | 并购形成的溢价资产 |
| 商誉占净资产比率 | 商誉相对于股东权益的比例 |

#### 这个指标回答什么问题

> 公司有没有潜在商誉减值风险？

#### 商誉占净资产比率粗略标准

| 商誉 / 净资产 | 判断 |
|---|---|
| < 5% | 很安全 |
| 5%–15% | 可接受 |
| 15%–30% | 需要关注 |
| > 30% | 高风险 |
| 持续上升 | 需警惕并购扩张和减值风险 |

#### 好趋势

- 商誉占净资产比例很低。
- 商誉没有持续大幅增加。
- 公司利润增长不是靠频繁并购堆出来。
- 没有历史大额商誉减值。

#### 坏趋势

- 商誉占净资产比例高。
- 商誉持续增加。
- 并购标的盈利不达预期。
- 公司利润突然因商誉减值大幅下滑。
- 经营现金流弱，但商誉很高。

#### 国电南瑞示例

国电南瑞商誉金额极低，单位应注意是“万”而不是“亿”；商誉占净资产比率几乎可以忽略。

阶段判断：

> 国电南瑞基本没有明显商誉减值风险。

## 9. FCF vs Capex：自由现金流与资本开支

![[Pasted image 20260526102545.png]]

### 看什么

| 指标 | 含义 |
|---|---|
| 自由现金流量 | 经营现金流扣除必要资本开支后的剩余现金 |
| 购建固定资产、无形资产和其他长期资产支付的现金 | 资本开支，简称 Capex |

### 这个指标回答什么问题

> 公司赚到的经营现金，是否会被持续资本投入吃掉？

### 基本公式

```text
自由现金流 ≈ 经营活动现金流量净额 - 资本开支
```

### 核心判断

| 情况 | 判断 |
|---|---|
| 自由现金流长期为正 | 好 |
| 自由现金流长期增长 | 很好 |
| 资本开支增加，但自由现金流也增加 | 可以接受 |
| 资本开支长期高于经营现金流 | 警惕 |
| 自由现金流长期为负 | 高风险 |
| 收入利润增长，但自由现金流不增长 | 需要警惕 |

### 好趋势

- 自由现金流长期为正。
- 自由现金流随利润增长而增长。
- 资本开支没有持续大幅上升。
- 资本开支占收入比例不高。
- 经营现金流能够轻松覆盖资本开支。
- 公司不需要持续依赖融资维持增长。

### 坏趋势

- 净利润增长，但自由现金流长期为负。
- 资本开支持续大幅增加。
- 资本开支增长快于收入增长。
- 经营现金流覆盖不了资本开支。
- 公司不断融资、借债、扩产。
- 在建工程持续膨胀。
- 折旧摊销未来可能反噬利润。

### 粗略判断标准

| 指标 | 判断 |
|---|---|
| FCF 长期 > 0 | 基础通过 |
| FCF / 净利润 > 80% | 很好 |
| FCF / 净利润 50%–80% | 可以接受 |
| FCF / 净利润 < 50% | 需要警惕 |
| Capex / 营业收入 < 5% | 轻资本开支 |
| Capex / 营业收入 5%–15% | 正常 |
| Capex / 营业收入 > 15% | 偏重，需要看行业 |
| Capex / 营业收入长期上升 | 需要关注 |

### 国电南瑞示例

国电南瑞自由现金流长期为正，且 2022 年后明显上台阶。2025 年自由现金流约 106.61 亿，资本开支约 21.10 亿，资本开支占营业收入比例约 3.2%。

阶段判断：

> 国电南瑞不是重资本开支吞现金的公司，经营现金流能够充分覆盖资本开支，自由现金流表现很好。该项强通过。

## 10. 估值安全边际：PE、PB、股息率

### 这一章回答什么问题

> 好公司，现在是不是好价格？

前面的章节主要判断公司质量。  
估值章节判断当前买入价格是否有安全边际。

 理杏仁操作：基本面 -> 估值
---

### 10.1 PE-TTM 扣非

![[Pasted image 20260526102739.png]]

#### 看什么

| 指标 | 含义 |
|---|---|
| PE-TTM | 当前市值 / 过去 12 个月净利润 |
| PE-TTM 扣非 | 当前市值 / 过去 12 个月扣非净利润 |
| 20% 分位 | 历史偏低估值边界 |
| 50% 分位 | 历史估值中枢 |
| 80% 分位 | 历史偏高估值边界 |

#### 这个指标回答什么问题

> 当前价格相对于公司盈利能力，是便宜、合理还是昂贵？

#### 基本原则

```text
PE 越低，通常越便宜
但 PE 低必须结合基本面是否恶化判断
```

#### PE 分位粗略标准

| PE 分位 | 判断 |
|---|---|
| 0%–20% | 历史偏低，可能有安全边际 |
| 20%–40% | 合理偏低 |
| 40%–60% | 中枢附近 |
| 60%–80% | 偏贵 |
| 80%–100% | 明显偏贵，除非未来增长确定性很强 |

#### 好情况

- PE-TTM 扣非低于 10 年中位数。
- PE-TTM 扣非接近或低于 20%–30% 分位。
- PE 下降不是因为利润恶化，而是因为股价回调或利润增长消化估值。
- ROE、利润率、现金流没有同步恶化。

#### 坏情况

- PE 高于 80% 分位。
- 股价上涨主要来自 PE 扩张，而不是利润增长。
- PE 看似下降，但其实是利润短期异常高。
- PE 低，但 ROE、利润率、现金流同步恶化。
- 扣非 PE 明显高于普通 PE，说明主业利润不足。

#### 国电南瑞示例

国电南瑞当前 PE-TTM 扣非约 26.31 倍，10 年分位约 32.61%，低于历史中位数，但高于 20% 分位。

阶段判断：

> PE 角度当前合理偏低，有一定吸引力，但还不是明显低估区。

---

### 10.2 PB：市净率

![[Pasted image 20260526102759.png]]

#### 看什么

| 指标 | 含义 |
|---|---|
| PB | 当前市值 / 净资产 |
| PB 不含商誉 | 当前市值 / 扣除商誉后的净资产 |
| 20% / 50% / 80% 分位 | 历史估值区间 |

#### 这个指标回答什么问题

> 市场愿意为公司每 1 元净资产支付多少钱？

#### 基本原则

PB 要结合 ROE 看。  
ROE 越高、越稳定，市场可以接受的 PB 越高。

```text
PB 不能脱离 ROE 单独看
```

#### 粗略标准：ROE 15%左右的优质制造 / 设备类公司

| PB | 判断 |
|---|---|
| < 3.0 | 偏便宜，需要确认基本面是否变坏 |
| 3.0–3.5 | 有吸引力 |
| 3.5–4.0 | 合理偏低 |
| 4.0–4.5 | 中枢附近 |
| 4.5–5.0 | 偏贵 |
| > 5.0 | 明显偏贵，需要强增长支撑 |

#### 好情况

- PB 低于历史中位。
- PB 接近 20%–30% 分位。
- ROE 稳定，没有下滑。
- 商誉很低，PB 不含商誉和 PB 差异不大。
- 净资产质量较高。

#### 坏情况

- PB 高于 80% 分位。
- PB 高，但 ROE 没有提升。
- PB 低，但 ROE 持续下降。
- 商誉很高，导致普通 PB 失真。
- 净资产中包含大量低质量资产。

#### 国电南瑞示例

国电南瑞当前 PB 约 3.94，10 年分位约 42.46%，略低于中位，但未进入明显低估区。

阶段判断：

> PB 角度当前中性略低，不贵，但也不是很便宜。

---

### 10.3 股息率

![[Pasted image 20260526102813.png]]

#### 看什么

| 指标 | 含义 |
|---|---|
| 股息率 | 每股分红 / 当前股价 |
| 股息率分位 | 当前股息率在历史中的位置 |
| 分红率 | 分红金额 / 净利润 |

#### 这个指标回答什么问题

> 当前价格下，股东现金回报是否有吸引力？

#### 基本原则

PE、PB 通常越低越便宜。  
股息率通常越高越便宜。

```text
股息率要反着看：分位越高，通常估值越有吸引力
```

#### 股息率分位标准

| 股息率分位 | 判断 |
|---|---|
| 0%–20% | 股息率偏低，估值可能偏贵 |
| 20%–50% | 一般 |
| 50%–80% | 中性偏好 |
| 80%–100% | 股息率历史偏高，可能有估值吸引力 |

#### 好情况

- 股息率处于历史高分位。
- 分红率稳定。
- 利润和现金流能支撑分红。
- 股息率上升不是因为利润恶化，而是因为股价回落或分红提升。
- 自由现金流能覆盖分红。

#### 坏情况

- 股息率高，但利润下滑。
- 股息率高，但自由现金流不足。
- 分红率过高，不可持续。
- 公司通过举债分红。
- 高股息来自股价暴跌，而基本面恶化。

#### 国电南瑞示例

国电南瑞当前股息率约 2.37%，10 年分位约 84.79%，已经处于历史较高位置。

阶段判断：

> 股息率角度是当前估值里比较友好的信号，说明价格相对过去更有吸引力。但国电南瑞不是典型高股息资产，股息率只能作为辅助，不应作为唯一买入理由。

---

### 10.4 PE、PB、股息率合并判断

#### 估值状态划分

| 状态 | 特征 | 动作 |
|---|---|---|
| 明显低估 | PE/PB 低于 20% 分位，股息率高于 80% 分位，基本面未恶化 | 可重点建仓 |
| 合理偏低 | PE/PB 在 20%–40% 分位，股息率较高 | 可观察仓 / 小仓 |
| 中性 | PE/PB 在 40%–60% 分位 | 等待或维持 |
| 偏贵 | PE/PB 在 60%–80% 分位，股息率偏低 | 不追 |
| 昂贵 | PE/PB 高于 80% 分位 | 暂停买入，除非增长显著超预期 |

#### 好的买入组合

```text
PE-TTM 扣非低于历史中位
PB 不高
股息率高于历史中位
ROE 稳定
利润现金流良好
基本面未恶化
```

#### 差的买入组合

```text
PE/PB 高于历史中位
股息率偏低
利润增长放缓
毛利率和净利率下滑
经营现金流变差
```

#### 国电南瑞阶段结论

国电南瑞当前：

| 指标 | 状态 |
|---|---|
| PE-TTM 扣非 | 约 26.31 倍，10 年约 32.61% 分位 |
| PB | 约 3.94，10 年约 42.46% 分位 |
| 股息率 | 约 2.37%，10 年约 84.79% 分位 |

阶段判断：

> 国电南瑞当前估值不贵，处于合理偏低区；但 PE 和 PB 尚未进入 20% 以下低估区，因此安全边际不厚。适合观察仓或小仓试探，不适合因“好公司 + 好赛道”直接重仓。

## 11. 估值分位带：20%—80% 区间怎么理解

### 看什么

| 指标 | 含义 |
|---|---|
| 20% 分位线 | 历史偏便宜边界 |
| 50% 分位线 | 历史估值中枢 |
| 80% 分位线 | 历史偏贵边界 |
| 20%—80% 分位带 | 公司估值的正常波动区间 |

### 这个指标回答什么问题

> 市场过去愿意给这家公司多少估值？这个估值共识是稳定、抬升、下移，还是分歧扩大？

---

### 11.1 分位带整体上移

#### 含义

> 市场愿意给公司更高估值中枢。

#### 可能原因

- ROE 提升。
- 增速提高。
- 商业模式被重新认识。
- 行业景气度上行。
- 利率下降。
- 公司从周期股被重估为成长股。
- 政策或产业逻辑增强。

#### 判断

这未必是泡沫，也可能是基本面改善后的合理重估。  
需要验证：

```text
估值中枢上移是否有利润、ROE、现金流和产业逻辑支撑
```

---

### 11.2 分位带整体下移

#### 含义

> 市场给公司的估值中枢下降。

#### 可能原因

- 增速下降。
- ROE 下降。
- 行业从成长期进入成熟期。
- 市场风险偏好下降。
- 利率上升。
- 公司逻辑变弱。
- 政策预期降温。
- 过去估值过高，正在回归理性。

#### 判断

估值下移可能是机会，也可能是基本面降级。

```text
如果基本面稳定，估值中枢下移可能是机会
如果基本面恶化，估值中枢下移可能是合理重定价
```

---

### 11.3 分位带变宽

#### 含义

> 市场对公司估值的分歧变大，估值波动加大。

#### 可能原因

- 行业预期剧烈变化。
- 公司业绩波动变大。
- 市场对未来增长分歧大。
- 主题炒作明显。
- 盈利周期不稳定。
- 利率或风险偏好剧烈变化。
- 有突发事件、政策催化或产业预期。

#### 投资含义

- 股价和估值波动可能加大。
- 买入需要更强安全边际。
- 仓位应更保守。
- 不宜在估值带上沿追涨。

---

### 11.4 分位带收窄

#### 含义

> 市场对公司估值的共识增强，估值波动变小。

#### 可能原因

- 公司进入成熟稳定期。
- 盈利可预测性增强。
- 市场对商业模式认识稳定。
- 题材热度下降。
- 股价更多由业绩驱动，而不是情绪驱动。

#### 投资含义

- 估值弹性变小。
- 判断难度下降。
- 更适合按估值中枢、股息率和现金流做纪律化建仓。

---

### 11.5 下沿抬升，上沿不动

#### 含义

> 市场不太愿意再给很低估值，估值下限提高。

#### 可能原因

- 公司质量被市场更广泛认可。
- 分红增强。
- 现金流更稳定。
- 机构持仓稳定。
- 下跌时有长期资金承接。

#### 投资含义

> 公司质量可能被重估，但便宜买点会变少。

---

### 11.6 上沿抬升，下沿不动

#### 含义

> 乐观情绪阶段性增强，但悲观时市场仍然会按原来的低估值定价。

#### 可能原因

- 主题催化。
- 周期反转预期。
- 产业叙事升温。
- 短期资金追捧。

#### 投资含义

> 如果上沿抬升很快，但中位线和下沿没跟上，可能主要是情绪推动，需要警惕追高。

---

### 11.7 股息率分位带要反着看

PE、PB 通常越低越便宜。  
股息率通常越高越便宜。

| 股息率分位 | 含义 |
|---|---|
| 高于 80% 分位 | 股息率历史偏高，估值可能偏低 |
| 接近 50% 分位 | 中性 |
| 低于 20% 分位 | 股息率历史偏低，估值可能偏贵 |

#### 注意

股息率高不一定总是好。需要确认：

```text
利润稳定
分红可持续
自由现金流能覆盖分红
不是因为基本面恶化导致股价暴跌
```

---

### 11.8 分位带的陷阱

#### 陷阱一：异常值会污染分位

例如利润极低、扣非为负、并表重组导致 PE 异常高或异常低。  
这种年份不能机械纳入正常估值判断。

#### 陷阱二：公司变了，历史分位会失真

如果公司商业模式、资产结构、盈利能力发生重大变化，历史估值不一定适合今天。

常见情况：

- 并购重组。
- 主业切换。
- ROE 中枢变化。
- 分红政策变化。
- 行业从高增速变成熟。
- 政策环境改变。

#### 陷阱三：低估值可能是基本面降级

估值越来越低有两种可能：

```text
市场错杀
公司真的变差
```

要买第一种，避开第二种。

---

### 11.9 实用判断指标

```text
估值带宽 = 80% 分位值 - 20% 分位值

标准化带宽 =（80% 分位值 - 20% 分位值）/ 50% 分位值
```

| 带宽状态 | 含义 |
|---|---|
| 带宽变窄 | 市场定价稳定，分歧变小 |
| 带宽变宽 | 市场分歧扩大，波动加大 |
| 带整体上移 | 估值中枢抬升 |
| 带整体下移 | 估值中枢下降 |
| 当前值低于 20% 分位 | 可能低估 |
| 当前值高于 80% 分位 | 可能高估 |

---

## 12. 年轻公司与长周期数据

### 核心原则

> 越是准备重仓，越不应该重仓财务历史太短、上市时间太短、没有经历完整周期的公司。

年轻公司不是不能买，而是天然不适合直接大仓。

---

### 为什么要看 10 年数据

#### 1. 看公司是否经历过周期

10 年更可能包含：

- 景气上行。
- 景气下行。
- 估值扩张。
- 估值压缩。
- 利率变化。
- 政策变化。
- 管理层资本配置变化。

#### 2. 看盈利质量是否稳定

长期优秀公司应尽量满足：

```text
10 年 ROE 稳定
10 年扣非利润稳定
10 年现金流稳定
10 年没有大量融资稀释
10 年没有商誉爆雷
10 年没有周期高点幻觉
```

#### 3. 看估值分位是否有意义

估值分位依赖历史样本。  
如果只有 2–3 年数据，所谓“历史低位”可能没有意义。

---

### 年轻公司的主要风险

| 风险 | 说明 |
|---|---|
| 没有跨周期验证 | 可能只经历了顺风期 |
| 财务口径不稳定 | 并表、股权激励、收入确认、募投等扰动大 |
| 上市定价偏乐观 | 新股常常透支成长预期 |
| 商业模式未成熟 | 毛利率、客户留存、现金流尚未稳定 |
| 估值分位样本太短 | 历史低位不等于真的便宜 |

---

### 仓位规则

| 公司类型 | 仓位态度 |
|---|---|
| 10 年以上优秀记录、现金流好、估值合理 | 可以进入核心仓候选 |
| 5–10 年记录、质量较明确 | 可以中等仓位 |
| 3–5 年记录、成长逻辑强但周期未验证 | 小仓观察 |
| 上市不足 3 年 | 原则上不大仓 |
| 亏损或利润波动极大 | 只能主题仓 / 风险仓 |

### 大仓候选最好满足

```text
上市或可验证经营历史 ≥ 10 年
经历过至少一轮逆风期
ROE 长期稳定
扣非利润质量好
经营现金流能覆盖净利润
资产负债表安全
估值处于 10 年中位以下
```

### 判断

> 十年图不是为了看得更远，而是为了降低误判概率。

## 13. 综合判断：从好公司到好价格

### 综合打分维度

| 模块 | 主要问题 |
|---|---|
| ROE | 股东资本回报是否优秀 |
| 盈利能力 | 毛利率、净利率是否稳定 |
| 扣非质量 | 利润是否主要来自主业 |
| 利润现金化 | 净利润是否变成现金 |
| 营运资本 | 应收、合同资产、存货是否失控 |
| 资产负债表 | 债务、商誉、资产质量是否安全 |
| FCF vs Capex | 资本开支是否吞噬现金流 |
| PE / PB / 股息率 | 当前估值是否有安全边际 |
| 估值分位带 | 市场估值中枢和分歧是否变化 |
| 长周期数据 | 公司是否经过足够历史验证 |

---

### 优秀公司形态

```text
ROE 长期 15%+
扣非 ROE 与普通 ROE 接近
毛利率、净利率稳定
扣非净利润占比 90%+
经营现金流长期接近或高于净利润
应收账款周转稳定或改善
存货周转稳定
有息负债率低
商誉风险低
自由现金流长期为正
PE/PB 不高于历史中位
股息率处于历史中高位
```

结论：

> 公司质量较高，可以进入估值和产业逻辑验证。

---

### 警惕公司形态

```text
ROE 下滑
扣非 ROE 明显低于普通 ROE
毛利率和净利率持续下降
扣非净利润占比低或波动大
经营现金流长期低于净利润
应收账款周转天数持续上升
存货周转天数持续上升
资产负债率和有息负债率持续上升
商誉占净资产比例高
资本开支长期吞噬经营现金流
自由现金流长期为负
PE/PB 高于历史中位但增长没有加速
股息率低于历史中位
```

结论：

> 增长质量和估值安全边际存疑，不适合直接大仓。

---

### 国电南瑞阶段结论

根据目前检查，国电南瑞可以暂时归纳为：

```text
ROE：优秀且稳定，长期约 15%–16%
盈利能力：毛利率、净利润率总体稳定，但近年略有下行压力
扣非质量：扣非净利润占比很高，主业利润质量好
利润现金化：近几年经营现金流明显高于净利润，强加分项
营运资本：应收和存货绝对额上升，但周转效率没有恶化
应收账款：周转天数相比早年改善，近年约 165–180 天
存货：周转天数稳定在约 85–91 天
负债：资产负债率约 40%–45%，有息负债率极低
资金安全：货币资金显著高于有息负债
商誉：金额极低，商誉减值风险很小
FCF vs Capex：自由现金流长期为正，资本开支可控
PE：合理偏低，但未进入深度低估
PB：中性略低
股息率：处于历史较高分位
```

阶段判断：

> 国电南瑞已通过公司质量、盈利质量、现金流质量、营运资本质量、资产负债表安全性和自由现金流检查。当前估值不贵，处于合理偏低区，但 PE 和 PB 尚未进入明显低估区，因此更适合观察仓或小仓试探，而不是直接大仓。

## 14. 下一步：产业逻辑与业绩兑现

### 这一章回答什么问题

> 未来 3–5 年，公司凭什么继续增长？

前面的章节主要回答：

```text
过去是不是好公司？
现在是不是好价格？
```

产业逻辑章节回答：

```text
未来还有没有继续变好的条件？
```

---

### 对国电南瑞应重点验证

| 方向 | 需要验证的问题 |
|---|---|
| 电网自动化 | 是否继续受益于新型电力系统和智能调度 |
| 继电保护 | 电网安全稳定运行需求是否继续提升 |
| 电力信息通信 | 电网数字化投资是否持续 |
| 新能源并网 | 新能源消纳是否带来增量需求 |
| 配网升级 | 配电网投资是否成为新周期重点 |
| AI 用电 | 数据中心和算力需求是否提升电网投资 |
| 特高压 | 主网投资是否继续推进 |
| 订单 | 新签订单和在手订单能否支持收入增长 |
| 利润率 | 新订单是否为高质量订单，而非低毛利项目 |
| 竞争格局 | 公司是否仍是核心受益者，而非普通参与者 |

### 好情况

```text
行业投资周期向上
公司核心业务正好受益
订单增长能够兑现收入
收入增长能够兑现扣非利润
利润率没有被低毛利项目拖累
经营现金流继续良好
```

### 坏情况

```text
行业投资增加，但公司核心业务受益有限
收入增长主要来自低毛利项目
订单增长但利润率下降
收入增长但扣非利润增长慢
现金流开始变差
同行竞争导致毛利率下滑
```

### 判断

> 财务图证明过去，产业逻辑决定未来。好公司只有在未来增长逻辑仍成立、且价格合理时，才适合提高仓位。
