## 1. 本期结论摘要

- **🔴 历史性突破——抖音7月潮玩销售额排行榜：四个非 Labubu IP 同时获得 L4 销售验证。** DIMOO×皮克斯联名**登顶#1**、CRYBABY度假系列TOP10、星星人双系列TOP10、SKULLPANDA不想不想系列TOP10。泡泡玛特独占 TOP10 中 5 席。这是本监控启动以来对「多 IP 健康」最有力的证据——从此前的「L3 流量验证+运营动作」升级为「多 IP 多平台 L4 销售验证」。
- **🔴 DIMOO 本周最大赢家——得分跃升 +6 至 ~66–69/B，首次突破 B 线并成为非 Labubu IP 综合分最高。** 三重信号同步出现：皮克斯抖音#1（L4 销售验证）+城市乐园 DIMOO 主题区开放（重资产投入）+菲律宾主题店持续运营。此前困扰三周的「L3→L4 缺口」被抖音#1 数据有力填补——二手市场缺数据不是因为「没人买」，而是因为「官方渠道卖得太好」。
- **🔴 MOLLY 和 CRYBABY 同步首次突破 B 线（~64–67/B）——三个非 Labubu IP 同时进入 B 线。** Molly 靠星巴克亚太扩展（大陆→港→台新分阶段）+六款商品线；CRYBABY 靠特展第二周+度假系列抖音 TOP10+Care Bears 8/13 首发+SK-II 联名五线并行。两种不同的改善路径（跨市场复制 vs 联名矩阵扩展）同时获得正向信号。

## 4. 各 IP 详细分析

### 4.1 THE MONSTERS / Labubu (~35–38/D，持平)

**商业基本盘 85 / 边际趋势 ~35–38**

- **正向**：FIFA 世界杯联名全球持续售罄+补货（独立全球化需求信号）；城市乐园 Labubu 主题区重资产开放（勇士峡湾+精灵部落+飞翔的 LABUBU 海盗船）；段永平最终净增持至 7.70%
- **风险**：4.0 三周稳定在 77.5 元（-51%）无反弹；**Wings of Fantasy 五周无数据→正式降级为「状态未知」**；德银预测 Q2 仅 +1.6%
- **判断**：投机退潮已稳定三周。城市乐园重资产投入证明公司对 Labubu 长期信心未变。但 Wings 降级意味着 Labubu 最后一个「高溢价神话」处于不可知状态。**8/20 H1 中报 Q2 Labubu 收入是终极判断。**

### 4.2 DIMOO (~66–69/B，↑+6，首次突破B线，本周最大赢家)

**商业基本盘 64 / 边际趋势 ~68**

**本周三重突破**：
1. **皮克斯联名抖音7月潮玩销售额#1——L4 销售验证达成！** 这是本监控启动以来非 Labubu IP 获得的最强销售信号。此前困扰三周的「L3→L4 数据缺失」被抖音#1 数据有力填补。
2. **城市乐园 DIMOO 主题区（云之湖+旋转木马）全面开放**——DIMOO 与 LABUBU 并列城市乐园两大头部 IP。公司对 DIMOO 的重资产投入信心达到新高度。
3. **菲律宾主题店持续运营（7/23–9/23）**——海外渠道 IP 独立性验证。

**核心逻辑转变**：此前最大的担忧——「二手数据缺失 2.5 周→可能未形成爆款」——被抖音#1 数据大幅缓解。**二手市场缺数据不是因为没人买，而是因为官方渠道卖得太好+供给充足→消费者无需去二手市场。** 这是对泡泡玛特基本面更健康的解释。

信达消费 8 月跟踪确认的「隐藏款环比下滑」在此背景下应重新解读——不是需求不足，而是供给充足+消费者从官方渠道购买→二手溢价温和是健康的。

**风险**：验证的是「联名运营能力」非「原创 IP 制造能力」（皮克斯是迪士尼 IP）；抖音单月#1≠持续销售领先；皮克斯联名生命周期有限。

### 4.3 MOLLY (~64–67/B，↑+2，首次突破B线)

**商业基本盘 72 / 边际趋势 ~65**

**核心增量——星巴克联名从「中国大陆事件」升级为「亚太多市场商品线」**：
- 大陆（7/8 北京首发）→ 香港（8/3）→ 台湾（8/10-11）→ 新加坡（8/3）分市场分阶段推进
- 六款联名商品（非单一饮品）+限定饮品草莓布蕾星冰乐
- Bearista 小熊首次与 MOLLY 同框
- 香港东堤湾畔 MOLLY 主题店

**与 Labubu FIFA（一次性全球事件）和 DIMOO 菲律宾（单店）不同——Molly×星巴克是系统性的多市场推进。** 这是泡泡玛特能力②（中型 IP 全球化运营）的最直接证据。Molly 的改善路径——「跨界联名的跨市场复制能力」——与 DIMOO（联名爆款单点突破）和 CRYBABY（展览+联名矩阵）不同，三种路径同时获得正向信号是对「多 IP 运营能力」的最强验证。

Crocs 全球持续但无新报道。Ducati 联名预热未在本次搜索中出现（可能已冷却）。

- 🆕 **度假系列抖音7月 TOP10——L4 销售验证达成！** 补充了此前仅靠特展 L3+隐藏款溢价支撑的 CRYBABY 叙事

**风险**：特展热度温和（非爆款级）；Care Bears 新品需看首发表现；心动系列二手数据仍空白（5周）。

### 4.5 SKULLPANDA (~58–61/C，↑+6)

## 7. 本期核心判断

**本期泡泡玛特 IP 侧面数据呈现为：【历史性突破——多 IP L4 初步验证。从连续 6 期的「接力候选信号」升级为「四个非 Labubu IP 同时获得抖音 L4 销售验证」。DIMOO/MOLLY/CRYBABY 三个 IP 首次突破 B 线（65+），多 IP 健康指数从 0% 跃升至 43%。】**

核心理由：

1. **抖音 7 月排行榜是监控启动以来最重要的第三方数据突破。** DIMOO 皮克斯#1+CRYBABY 度假+星星人双系列+SKULLPANDA 不想不想——四个非 Labubu IP 同时获得 L4 销售验证。这证明的不是「某个 IP 突然变强了」，而是「多个 IP 一直在卖，只是我们之前没有可见的销售数据」。从方法论角度，本周的评分上调包含「信息质量改善」的成分。
2. **三种不同的改善路径同时获得正向信号。** DIMOO（联名爆款单点突破#1）、Molly（跨界联名跨市场复制）、CRYBABY（展览品牌升级+多系列销售+高端联名矩阵）。三种路径的同时验证是对「泡泡玛特多 IP 运营能力」的最强证据。
3. **城市乐园重资产开放将 IP 投入从「轻资产联名」升级为「重资产乐园」。** DIMOO 与 LABUBU 并列两大头部 IP——公司对 DIMOO 的战略信心已达新高度。
4. **段永平持仓过山车暴露了市场信心的极度脆弱。** 但 8/20 H1 中报——如果分 IP 收入数据与抖音排名指向的「多 IP 消费需求不差」一致，可能成为情绪反转的催化剂。
