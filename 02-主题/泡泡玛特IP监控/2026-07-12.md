## 7. 本期核心判断

**本期泡泡玛特 IP 侧面数据呈现为：【Labubu 边际走弱，其他 IP 边际改善——多 IP 接力信号出现，但尚不能替代 THE MONSTERS 收入贡献】**

四态区分：
- **投机退潮【已验证】**：4.0 破发加深、黄牛离场、泡沫特征减弱。
- **消费需求退潮【未验证】**：缺官方售罄/零售量/退货率数据；破发可由补货与黄牛退出解释。
- **多 IP 接力信号【已出现】**：DIMOO×皮克斯官宣、Twinkle Twinkle 出圈、Crybaby 溢价+特展、Skullpanda 2026 多系列。
- **多 IP 接力成功【未验证】**：五个 IP 仍零个达 A/B 线；DIMOO 改善主要靠单 SKU+官宣预期，皮克斯实际发售待验证。

理由：
1. Labubu 4.0 单盒破发加深至 ~108（官方 159），确认结构性投机退潮；THE MONSTERS 边际分 40/D，本期综合排名末位——但**基本盘 85 仍第一**，边际弱 ≠ 商业价值崩。
2. 其他四 IP 边际全部改善（DIMOO 63 因皮克斯、Skullpanda 52 因空窗期修正、Crybaby 52 因溢价/特展），多 IP 共热在社媒侧获印证。
3. 段永平举牌 7.65%、股价 ~153/PE~14x、德银沽售 vs 大摩建设性——资本市场信号分化，独立成章，不影响 IP 评分。

**对"泡泡玛特是否具备持续制造全球 IP 的组织能力"的验证程度：【边际增强——但仅验证"全球 IP 运营/联名能力"，未验证"原创 IP 制造能力"】**
- DIMOO×皮克斯验证的是**全球 IP 运营、外部授权商业化、供应链与渠道能力**；不能直接证明泡泡玛特能持续创造原创全球 IP，或 DIMOO 脱离皮克斯后仍有同等需求。
- Twinkle Twinkle（大摩：中国销售或达 Labubu 一半）才是更接近"原创 IP 制造能力"的证据，但仍偏定性、未系统跟踪。
