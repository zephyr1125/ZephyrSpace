# 泡泡玛特 IP 监控报告 - 2026-07-19

> **第4期报告 | 上期：2026-07-12 | 完整数据快照：`popmart-ip-monitor/data/snapshots/2026-07-19.json`**

## 1. 本期结论摘要

- **多个非 Labubu IP 的全球运营动作本周密集落地，但需区分"公司资源投入"与"消费者需求验证"。** MOLLY 20 周年联名潮三箭齐发（星巴克 7/8 + Crocs + Ducati 预热）、SKULLPANDA 登上巴黎高定周（× Robert Wun 7/8）、CRYBABY 全球多点开花（芭提雅巨型装置 + 新加坡 S.E.A. 海洋馆 + 北京特展预热 8/1）——证明泡泡玛特正主动将运营资源扩散至多个非 Labubu IP。但它们目前主要兑现的是**运营动作**，而非**销售或财务结果**。
- **DIMOO×皮克斯已于 7/16（线上）和 7/17（线下）正式发售**，但首发 2–3 天内的数据尚未进入公开报道。催化已从"官宣预期"转为"实绩验证期"。
- **Labubu 4.0 二手价格显著走弱。** 多款低于官方 159 元交易，隐藏款从峰值 1378 元回落。短线套利活动明显退潮，投机退潮已获**较强验证**。
- 段永平持股 7.65% 维持不变；股价 ~163.6 港元（周 +7%）；汇丰 7/17 降级至持有/TP 168.9，德银维持沽售/140——资本市场信号持续分化，**不计入任何 IP 健康度**。
