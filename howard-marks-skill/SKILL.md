# Howard Marks 风格 A股低估错杀股二筛

## 目标

对同花顺股票筛选器导出的 A 股候选池进行二次筛选，找出可能存在"市场过度悲观定价"的股票。

本 skill **不追求**寻找短期上涨股或纯粹低 PE 股。核心目标：

> 识别公司没有明显恶化，但市场因结构性行情/资金偏好/短期恐慌/行业冷落而给予过低定价，
> 当前价格已充分反映坏情景，如果未来只是"没那么差"就存在较好修复空间，
> 下行风险可理解、可承受、可分散。

最终输出不是"买入名单"，而是**"研究优先级名单"**。

---

## 输入格式

同花顺导出的 xlsx 或 csv 文件。使用 xlsx skill 读取表格，若为 csv 则直接读取。

### 核心字段（必须）

| 字段 | 说明 |
|---|---|
| 股票代码 | 6位代码 |
| 股票名称 | 公司简称 |
| 总市值 | 注意单位（元/万元/亿元），统一为亿元 |
| 市盈率 | 静态PE；0或负数为异常 |
| 市净率 | PB |
| 净资产收益率 | ROE；注意小数 vs 百分数 |
| 营业收入增长率 | 同比% |
| 资产负债比率 | % |
| 26周价格涨跌幅 | %；负数为下跌 |
| 净利润率/主营利润率 | % |

### 辅助字段（有则读取）

13周涨跌幅、50/150/200日均价、每股收益、每股净资产、毛利率、净利润增长率、
3年收入/净利润增长率、应收账款周转率、流动/速动/现金比率。

---

## 核心原则（贯穿全流程）

1. **不因便宜而买** — 低PE低PB只是起点，必须解释便宜原因；无法解释则降优先级
2. **重视价格隐含预期** — 每家公司追问：当前估值隐含了多悲观的未来？
3. **赔率优先于胜率** — 判断乐观/中性/悲观情景期望收益，悲观情景不得永久毁灭资本
4. **逆向但不接飞刀** — 以下情况优先排除：利润大幅恶化无周期解释、资产负债率过高、
   应收/存货异常上升、主业丧失竞争力、行业长期收缩、大股东频繁减持质押、
   依赖一次性投资收益、高ROE明显下台阶、股价跌幅巨大且基本面同步恶化

---

## 执行流程

### 第一步：数据清洗

读取表格后进行单位检查和标准化：

- ROE：若以小数表示（如 0.08），乘以 100 转为百分数
- 涨跌幅：通常已是百分数（-30 = -30%）
- 利润率：字段名带"%"通常已是百分数
- 市值：统一转为亿元
- PE ≤ 0：单独标注，不简单排除，需检查原因

**输出**：字段解释表，说明每个字段的单位判断。

---

### 第二步：硬性排除

以下公司进入**排除池**：

**财务危险**
- 资产负债率 > 75%（非金融行业）
- ROE < 5%
- 净利润率 < 3%
- 营业收入增长率 < -30%
- 市盈率为负（且无合理周期解释）
- PB < 0.4 且 ROE < 5%

**价格异常**
- 26周跌幅 < -60%（无明确周期或行业解释）
- 26周涨幅 > 30%（不再符合"被冷落资产"目标）
- 近期连续暴跌且伴随业绩预告预警/监管处罚/重大诉讼/债务问题

**商业质量问题**
- 主营业务不清晰
- 利润主要来自投资收益/公允价值变动/资产处置
- 长期收入停滞且利润率持续下滑
- 行业处于明确长期衰退且公司无份额提升能力

---

### 第三步：便宜原因归因

对通过排除的每家公司标注一个原因类别：

| 类别 | 说明 | 信号 |
|---|---|---|
| 行业被冷落 | 行业未恶化，资金偏好离开 | AI抱团吸血、消费疲弱、周期低位、政策预期压制 |
| 周期底部 | 盈利处周期低点，估值看似不低或利润承压 | 需判断资产负债表能否熬过周期 |
| 短期业绩扰动 | 单季度扰动可逆 | 费用前置、汇率、原材料、一次性计提 |
| 治理/信披折价 | 质量尚可但被折价 | 减持、信披问题、历史治理瑕疵 → **谨慎** |
| 真实恶化 | 商业模式变差 | 竞争加剧、需求萎缩、利润率长期下台阶 → **通常排除** |
| 无法判断 | 信息不足 | 不进入优先名单 |

---

### 第四步：评分框架（100分制）

#### A. 估值分（25分）

| 指标 | 区间 | 得分 |
|---|---|---|
| PE | 0–12 | 10 |
| PE | 12–18 | 7 |
| PE | 18–25 | 4 |
| PB | 0.6–1.2 | 10 |
| PB | 1.2–2.0 | 7 |
| PB | 2.0–2.5 | 3 |
| PE 与 PB 同时合理 | — | +5 |

> 强周期行业：降低 PE 权重，提高 PB 和资产负债表权重。

#### B. 质量分（25分）

| 指标 | 区间 | 得分 |
|---|---|---|
| ROE | ≥ 15% | 10 |
| ROE | 10%–15% | 7 |
| ROE | 8%–10% | 4 |
| 净利润率 | ≥ 10% | 8 |
| 净利润率 | 5%–10% | 5 |
| 营收增长率 | ≥ 0 | 4 |
| 资产负债率 | ≤ 50% | 3 |
| 资产负债率 | 50%–60% | 2 |

#### C. 错杀/冷落分（20分）

| 指标 | 区间 | 得分 |
|---|---|---|
| 26周涨跌幅 | -40% 到 -10% | 10 |
| 26周涨跌幅 | -10% 到 0% | 7 |
| 26周涨跌幅 | 0% 到 5% | 4 |
| 估值低但半年未涨 | — | +5 |
| 行业明显被AI/科技抱团挤压 | — | +5 |

> 半年涨幅较大者，即使估值不高也降低该项得分。

#### D. 风险补偿分（20分）— 三情景判断

**悲观情景**：利润继续下降 + 估值继续压缩 + 行业恢复慢 → 计算潜在亏损
**中性情景**：利润不明显增长 + 估值回到合理偏低 → 计算合理回报
**乐观情景**：利润温和恢复 + 估值修复到历史中位 → 计算潜在收益

| 条件 | 得分 |
|---|---|
| 上行/下行比 ≥ 3 | 10 |
| 上行/下行比 2–3 | 7 |
| 上行/下行比 1.5–2 | 4 |
| 中性情景不亏或小赚 | +5 |
| 悲观情景不造成永久性资本损失 | +5 |

#### E. 可研究性分（10分）

| 条件 | 得分 |
|---|---|
| 业务简单、能理解 | 3 |
| 财报口径清晰 | 2 |
| 行业有公开可跟踪数据 | 2 |
| 公司有历史分红或回购 | 2 |
| 无明显治理瑕疵 | 1 |

---

### 第五步：最终分层

| 层级 | 总分 | 条件 | 动作 |
|---|---|---|---|
| **S 优先研究** | ≥ 75 | 无硬性排除 + 低估原因清晰 + 悲观可承受 + 中性正收益 + 乐观有弹性 | 深入研究 |
| **A 观察池** | 65–75 | 基本面尚可 + 1–2个关键不确定性 | 等待财报/价格回落/行业数据确认 |
| **B 低优先级** | 55–65 | 估值不贵但缺少明确赔率 + 质量普通 + 便宜原因不清晰 | 暂不研究，保留大池 |
| **C 排除** | < 55 | 或触发硬性排除，或便宜原因属真实恶化 | 排除，除非价格/基本面明显变化 |

### 第七步：S类研究问题模板

对每只 S 类公司必须回答以下 10 个问题：

1. 市场为什么不喜欢它？
2. 这个悲观预期是否已反映在价格里？
3. 它是真的变差了，还是只是短期被冷落？
4. 未来 1–3 年，利润不增长时能不能赚钱？
5. 如果利润继续下滑，最大亏损可能是多少？
6. 资产负债表是否足够安全？
7. 现金流是否支持利润质量？
8. 行业有没有永久性衰退风险？
9. 它是否适合进入卫星仓（而非核心仓）？
10. 如果买入，什么条件下必须卖出？

## 仓位建议规则

| 层级 | 单只仓位 | 备注 |
|---|---|---|
| S类高确定性 | 总资产 1%–2% | |
| S类有周期风险 | 总资产 0.5%–1% | |
| A类观察 | 暂不买或 0.2%–0.5% 试探 | |
| B/C类 | 不买 | |

**硬约束**：
- 单一卫星股 ≤ 总资产 3%
- 所有低估错杀策略持仓合计 ≤ 总资产 10%
- 用户已有相关行业/个股暴露时，应降低建议仓位

---

## 输出语气规范

保持审慎，**禁止使用**"必涨""确定低估""稳赚"等表达。

**优先使用**：赔率较好 / 可能被过度定价 / 值得进一步研究 / 需要验证 /
暂不构成买入理由 / 风险补偿不足 / 更像价值陷阱 / 可进入观察池

---

## 核心判断标准（最终筛选目标）

> 市场已经因为短期恐慌、行业冷落或资金偏好偏移而给出较低价格，但公司的长期竞争力、
> 资产负债表和现金流没有同步恶化。即使未来只是"不那么差"，当前价格也可能提供足够的
> 风险补偿。这就是本 skill 的最终筛选目标。
