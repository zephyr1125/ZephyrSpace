### 第 4 步：输出终稿并关联

1. 输出终稿到 `管理层档案/[公司简称] 管理层档案 [评分] YYYY-MM-DD.md`
2. 在关联的公司页（`01-公司/[公司简称].md`）末尾添加管理层档案引用：

```markdown
## 管理层档案

- [[管理层档案/[公司简称] 管理层档案 [评分] YYYY-MM-DD|[公司简称] 管理层档案]]
  - 评分：XX / 100
  - 评级：⭐⭐⭐⭐⭐
  - 一句话：[管理层类型定位]
```

3. 如果公司存在深度分析报告，在深度分析页面的"关联页面"或末尾追加管理层档案引用：

```markdown
- 管理层档案：[[管理层档案/[公司简称] 管理层档案 [评分] YYYY-MM-DD|[公司简称] 管理层档案]]（XX/100）
```

4. 确保深度分析的 F 维度评分与本档案不矛盾。若深度分析 F 维度得分与本档案管理层总分差距 > 5 分，必须在档案中注明差异原因。

> ⚠️ **交叉链接规范（强制）**：
> - 管理层档案写完后，主 Agent 必须同时更新：①公司页（01-公司/）②深度分析页（深度分析/）
> - 公司页引用块放在"## 深度分析报告"章节之后、"## 返回入口"之前
> - 深度分析引用放在"## 关联页面"章节内或末尾
> - 子 Agent 不得直接修改公司页或深度分析页——由主 Agent 统一执行
