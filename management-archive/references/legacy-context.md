# 管理层档案 · Management Archive

## 定位

弥补普通投资者与专业投资机构之间最大的信息差距——不是"能不能见到老板"，而是**是否有系统框架从公开记录中判断管理层质量**。

核心理念：

> 管理层其实已经在公开材料里暴露了很多东西。核心不是看他说得多好，而是看：**他说过什么，后来做到了没有；他遇到诱惑时有没有克制；遇到困难时有没有诚实。**

本技能输出的档案页面独立于公司 PreBuy 页面，但两者互相引用：
- 公司页 `01-公司/` 引用管理层评分和关键结论
- 深度分析 `深度分析/` 引用管理层档案作为 F 维度（治理结构与管理层）的核心支撑

---

## 与深度分析的关系

| 维度 | 深度分析 (deep-prebuy-skill) | 管理层档案 (本技能) |
|---|---|---|
| 分析对象 | 公司全部 8 个维度 | 仅聚焦管理层这一个维度 |
| 深度 | F 维度占 15/100 分 | 穿透到言行一致性、每笔资本动作、每条公开表述的兑现 |
| 评分 | 管理层是 15 分的子项 | 独立 100 分制管理层评分 |
| 引用关系 | F 维度结论引用本档案 | 为深度分析提供 F 维度完整证据链 |

> **推荐使用顺序**：先建管理层档案 → 再做深度分析 → 深度分析 F 维度直接引用本档案结论。

### 第 2 步：双 Agent 并行审核（强制步骤）

单独管理层任务按本节启动两个独立审核员；若属于完整三件套，由主对话按统一SOP安排整套一次双审核，本节仅提供检查项，不再另开两个Agent。

#### Agent A：逻辑一致性审核

**提示词模板**：

```
你是管理层尽调审核专家。请审核以下管理层档案的逻辑一致性：

[粘贴完整档案 Markdown]

审核要点（逐项检查）：

1. **言行一致性追踪的自洽性**：
   - 每条"关键表述"是否都能找到对应的"兑现/未兑现"证据？
   - 正面案例和失信案例的权重是否平衡？（如果只有正面没有负面，是否遗漏了反证？）
   - 一致性评估的结论是否与表格中的兑现率一致？

2. **评分内在一致性**：
   - 各维度得分是否与正文中的证据匹配？
   - 如果正文大量笔墨描述"资本配置纪律优秀"但资本配置仅得 15/25，是否存在自相矛盾？
   - 如果正面信号远多于负面信号，总分却偏低，是否合理？
   - Σ(各维度得分) == 汇总表总分？逐项加总校验。

3. **结论与证据的匹配度**：
   - "一句话评价"是否与评分和正文一致？
   - "最突出的优点"和"最需要警惕的问题"是否在正文中有充分展开？
   - 管理层类型定位（托付重仓/中性/跟踪/减分项）是否与实际评分匹配？

4. **时间线自洽性**：
   - 言行一致性追踪表中的年份顺序是否准确？
   - 资本配置时间线是否与言行时间线前后一致？
   - 危机处理时间线是否与其他表中的事件年份一致？

5. **过渡词与模糊表述检测**：
   - 是否存在"近年来""长期""持续""一贯"等无锚定年份的模糊表述？
   - 是否存在"极好""极强""卓越"等形容词但缺乏对应的具体证据支撑？
   - 是否存在"似乎""可能""应该"等推测性表述替代确定性判断？

请给出：
- 每条审核要点的通过/不通过状态
- 不通过项的具体位置（引用原文）+ 问题描述
- 综合判断：是否需要进入 P1 修复
```

#### Agent B：数据与事实准确性审核

**提示词模板**：

```
你是管理层尽调数据审核专家。请审核以下管理层档案的数据和事实准确性：

[粘贴完整档案 Markdown]

审核要点（逐项检查）：

1. **人物信息准确性**：
   - 董事长/总经理/实控人姓名是否与最新年报一致？（不得依赖历史记忆）
   - 任期起始年份是否正确？
   - 持股比例是否为最新披露数据？来源是否标注？

2. **数字与金额准确性**：
   - 所有金额数字是否有明确来源？（年报/CNINFO/理杏仁/智堡）
   - 金额单位是否统一且正确？（元/万元/亿元不得混淆）
   - 分红/回购/融资/处罚金额是否已溯源核实？

3. **处罚记录准确性（高频错误点）**：
   - 每次监管处罚/诉讼是否独立记录、未合并？
   - 处罚金额是否精确到正确单位？
   - 处罚年份是否准确？
   - 处罚机构名称是否正确？

4. **资本配置记录准确性**：
   - 融资金额是否包含所有工具（定增/配股/可转债/H股增发/优先股）？
   - 回购金额是否区分了"公告金额"和"实际执行金额"？
   - 分红数据是否与理杏仁/CNINFO一致？

5. **关键原文摘录准确性**：
   - 每条原文摘录的出处（会议/年份/发言人）是否准确？
   - 标注"摘要"的条目是否确实为摘要（而非直接引语）？
   - 摘录内容是否断章取义？（对比完整上下文确认）

6. **数据来源完整性**：
   - 每条关键数据是否标注了来源？
   - "待核实"标记是否合理使用（不应滥用于本可核实的数据）？

请给出：
- 每条审核要点的通过/不通过状态
- 不通过项的具体位置（引用原文）+ 问题描述 + 正确数据（如有）
- 综合判断：是否需要进入 P1 修复
```
