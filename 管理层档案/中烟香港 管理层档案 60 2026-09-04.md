# 中烟香港 管理层档案

> 财年口径：自然年（12 月底止）。最新已发布 = **2026 中期业绩**（止 2026-06-30，2026-08-21 公告）；年度基准 = **FY2025**（止 2025-12-31，2026-03-05 公告）。金额币种 = 港元（HK$）。
> ⚠️ **央企档案定位**：本档案评估的是**中国烟草总公司的境外上市平台——国资委全资央企体系内的"通道型平台"管理层**。央企管理层分析重点不是"老板个人能力"，而是**代理问题**：①向母公司体系的关联交易是否公允、有无对少数股东利益输送；②分红是否真实回馈少数股东；③有无过度扩张/不作为；④经营自主性边界。据此调整各维度评分权重（资本配置"自主权"有限，故按其授权范围内审慎度+代理问题评估）。

### 控制权结构

- 实际控制人类型：**国有（国务院）**。控制链：国务院 → 中国烟草总公司（CNTC）→ 中烟国际集团（CTIG，2020-09 起 CNTC 直接全资）→ 中烟香港 **72.29%**（总股本 691,680,000 股）。
- 实控人持股路径：全资子公司上市后稀释——母公司上市前 100%，2019-06 IPO（基础发行+超额配售）后摊薄至 72.29%（对应公众盘约 1.92 亿股/27.71%；IPO 精确新增股数含超额配售口径，未单独核实）；**上市后无增发、无控股股东减持、无质押、股本无变动**。
- 公众流通盘：~27.71%，高度分散（Vanguard ~1%、贝莱德 ~0.5% 等），无第二名单一大股东；南向持股（港股通）比例未核实。
- 控制权稳定性评估：**股权层面极稳定**（国家控制不变）；但**治理程序层面有瑕疵**——2026-07-02 主席邵岩退休后主席空缺近 2 个月（代佳辉暂代），提名委员会一度缺主席、薪酬委员会人数降至 2 人（低于职规，上市规则 3.27A），公告承诺 3 个月内补齐（截至 2026-09-04 未见新主席任命）。
- **央企代理结构**：控股股东同时是公司最大的交易对手方（见三、关联交易）——"裁判与运动员"一体，少数股东保护依赖母公司自觉 + 港交所关连交易制度。

### 管理层背景评估

- **央企干部高度一体化**：全体执行董事均为中烟国际/中烟体系派任的中层以上干部，非市场化高管。上市 7 年 1 位主席（邵岩）+ 3 任总经理（张宏实→杨雪梅→代佳辉）全部由体系中层干部空降轮换，无外部市场化背景。董事长/总经理的任命权在母公司党组，上市公司董事会实质是"执行上级决策的治理外壳"。
- **履历特征**：以财务/烟草体系内流转为主（如代佳辉：审计→财务→HR→空降总经理），说明干部培养在"体系内通才"逻辑而非"上市公司市场化经营者"逻辑；对少数股东而言，管理层激励主要靠央企行政晋升而非股权绑定（无股权激励计划）。

### 典型兑现案例（正面）

1. **"每股派息稳中有增"连续兑现**：DPS 从 FY2023 的 0.32 一路增至 FY2025 的 0.52（2026H1 中期息 0.19 持平），派息率稳定 ~37%——对少数股东是真实现金承诺的兑现（来源：etnet 派息记录 + 年报）。
2. **"内生+外延"双轮兑现**：内生（卷烟出口自营化使毛利率 17.6%→36.1%、烟叶出口/雪茄扩区）+ 外延（2021 巴西收购、2025 长城雪茄全球独家经销陆续落地）——体系授权内的经营扩张基本说到做到（来源：年报/公告序列）。
3. **2026H1 盈警预判准确**：6/18 盈警区间（收入 -25~-30%、归母 -10~-15%）与实际（-26.9%/-11.2%）高度吻合，说明管理层对自己受母公司分货影响的业务节奏有真实掌握，不做粉饰（来源：盈警公告 vs 中报）。

### 典型失信/夸大案例（负面）

1. **未见明显的"说到没做到"**——央企管理层极少给市场承诺，规避了失信风险，但也意味着"不作为/信息不足"的风险（见警惕 2：无量化经营指引，投资者难以跟踪）。
2. **待核实/需跟踪**：公司 2026-08 中报称关注行业"十五五"机遇、无重大收购/出售/回购——**"十五五"外延叙事的实际落地（母公司是否注入更多海外资产）无法由公司单方决定**，市场若据此给溢价需自行承担"注入落空"风险（散户/财富号流传"管理层称 12 个月内无注入计划"，未经公司/权威渠道证实，标注未核实）。

### 一致性评估

- 战略方向是否连贯：**连贯**（"国际拓展主体+投融资平台"定位自 IPO 未变，战略由上级/母公司赋予、执行稳定）。无主题漂移，但也谈不上战略"企业家精神"。
- 业绩指引达成率：**无正式量价指引**；唯一次"类指引"（2026 盈警）区间兑现准确。
- 对行业周期/外部变量归因是否诚实：**诚实且有据**——2026H1 下滑归因"国际贸易关系（对美烟叶进口）+ 发运节奏 + 境内免税流程调整"，与可核实的量价数据一致（烟叶进口量 -29.1%、卷烟出口量 -35.6%），无甩锅、无把外部因素当自身功绩。

### 资本配置纪律评估

- **代理问题视角（央企重点）**：无"上市公司向母公司输血"证据——母公司未减持/质押、未高额抽取异常分红（72.29% 按股比分走属按比例非侵占）、注入巴西资产按 ~3.5x PE 且经独立股东批准（公允）。**未发现利益输送或过度扩张**。
- **资本配置自主权有限（结构性）**：公司留存资金与扩张方向基本由母公司体系主导（分货量、注入节奏、业务授权均由上级决定），管理层在授权内的资本动作（巴西收购、自营化投入、扩区）均审慎且围绕主业。
- **无乱并购、无跨界**：唯一重大并购为母公司注入的巴西资产（围绕主业且公允），此后无新并购。

## 十一、综合结论

### 一句话评价

> 这是一支"**干净但受限**"的央企通道平台管理层：无个体腐败、审计干净、分红真实逐年递增、战略定位稳定、2026H1 下滑处理规范（提前盈警+透明归因+有效对冲）——在母公司授予的通道与授权范围内，他们是一群诚实、审慎、执行到位的央企干部；但**他们的天花板由母公司决定**：关联交易占收入 ~94%、烟叶进口量价的分货开关在母公司体系、主席退休后治理程序出现瑕疵、所处中烟系统反腐风暴无法切割。评价为"**可以信任其不偷钱，但不可高估其能为你创造超额价值**"——少数股东买的是"母公司愿意让渡多少"而非"管理层能争取多少"。

### 最突出的优点（不超过 3 条）

1. **财务干净、无代理冲突证据**：KPMG 无保留、无审计师更换、无个体腐败通报、无减持/质押/摊薄、无关联方资金占用（来源：年报 + 监管检索）。
2. **分红真实且逐年递增**：派息率稳定 ~37%、DPS 0.32→0.46→0.52、2026H1 末现金+定存 38.2 亿支撑（来源：etnet 派息记录 + 中报）。
3. **授权范围内执行出色 + 外延公允**：卷烟出口毛利率 17.6%→36.1%（去通道化）、巴西收购 ~3.5x PE 公允注入并成新引擎（2026H1 +81.3%）（来源：年报/收购公告）。

### 最需要警惕的问题（不超过 3 条）

1. **经营自主性极弱 + 关联交易 ~94%**：盈利的"分货开关"在母公司（2026H1 烟叶进口量 -29% 直接击穿利润，归母 -11.2%）；进口 +6%/出口留成 1-4% 的固定点数定价使公司无定价权——少数股东承担母公司决策的全部波动（来源：招股书 + 中报）。
2. **治理程序瑕疵**：2026-07-02 主席退休后主席空缺 2 个月、提名委员会缺主席/薪酬委员会人数不足（违反上市规则 3.27A），承诺 3 个月补齐至今未任命新主席（来源：董事名单公告/etnet）。
3. **体系反腐与人事风险无法切割**：国家烟草专卖局/中烟系统 2023-2026 反腐（凌成兴判 16 年、张建民 2026-03 被免）——虽无证据指向上市公司，但作为母公司全资体系平台，治理文化风险属系统性折价（来源：最高检/媒体）。

### 适合的管理层类型定位

- [ ] 可以托付重仓（管理层质量加分）
- [ ] 中性（管理层不拖后腿，但也不是加分项）
- [x] **需要持续跟踪（有具体隐忧）**——自主权稀缺 + 关联交易依赖 + 治理程序瑕疵 + 体系反腐背景
- [ ] 管理层本身就是减分项（不适合重仓）

> 补充：60 分落在"⭐⭐⭐ 良好"（55-69 带中位附近）。**不落入"减分项"档（<40）**，因其无代理冲突、财务干净、分红真实、执行到位；但也**远未到"加分项"档（≥70）**——扣分核心不是"管理层人品或能力"，而是**结构：央企通道平台的自主权稀缺 + 关联交易 ~94% + 治理程序瑕疵 + 体系风险**，这些是管理层作为个体无法解决、只能承受的结构性限制。**若未来出现母公司向上市公司注入高溢价资产、或分货量被明显压减用于他处、或分红率下降，本评分应下调并触发对代理问题的红旗审查。**

### 关键跟踪指标

1. **新主席/新执行董事任命 + 提名/薪酬委员会补齐**（承诺 2026-10 前；2026-09 股东大会后观察）。
2. **母公司"分货开关"**：烟叶进口量（2026H2 发运回补节奏）、境内免税新政落地后卷烟出口恢复——FY2026 全年归母能否回到 8.9-9.4 亿共识。
3. **关联交易上限持续扩大（2026-01 烟叶出口至新地区上限升至 466M 港元）下的定价公允性**与母公司是否有向体系内其他主体输送的迹象。
4. **派息率是否继续维持 ~37% 并递增**（若分红率下调 = 红旗信号）。
5. **HNB 国标（2027）落地后新型烟草出口是否成为实质收入**、以及"十五五"外延（母公司注入海外资产）是否有实质进展。
