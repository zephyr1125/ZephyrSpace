# 周度卫星仓复盘（价值投资版）

## 定位与核心理念

每周六与用户互动进行的卫星仓组合管理。**这是一个价值投资者的组合管理流程,不是技术交易系统。**

### 投资纪律（贯穿全流程的硬约束）

1. **不做频繁的止盈止损。** 价格波动本身不构成买卖理由。
2. **卖出/减仓只在以下四种情况发生**（适用于**全部持仓，包括巴菲特仓**）：
   - 公司基本面发生实质性变化（持有逻辑被证伪）
   - 标的进入极端高估区间（A 股尤其容易出现泡沫，即使巴菲特仓的长期持有标的，估值过于夸张时也要减仓甚至清仓）
   - 组合层面必须再平衡
   - 出现更优的公司，且其价位更具吸引力（调仓）
3. **技术分析只在"执行层"使用。** 当已经基于基本面决定要建仓或清仓某标的时，才用 K 线划线来平滑买卖节奏、寻找更好的进出场点。它不产生"买/卖"的决策，只优化"已决定的买/卖"如何分批执行。
4. **现金是机会储备，不是日历指标。** 维持约 10% 现金应对机会，但被动归位——绝不为了凑现金比例去卖基本面良好的标的。
5. **两个仓的资金池可混用。** 卫星仓和巴菲特仓的现金合并计算，作为统一子弹池进行加仓分配。

### 流程对应的五步法

来自投资组合五步法:① 预留约 10% 现金作为机会储备 → ② 基于风险偏好选择估值合适的公司 → ③ 建仓/清仓时用技术分析平滑节奏 → ④ 周末审视持仓,提前规划而非临时起意 → ⑤ 长期跟踪公司内在价值变化。

本 skill 覆盖第 1、3、4 步的组合管理层面。第 2 步选股由 PreBuy 流程负责,但**第 5 步(内在价值跟踪)在本复盘中也要轻量检查**——每只持仓本周/本期是否出现任何改变持有逻辑的信息。

运行频率:**每周六一次**(持仓精简可降频到月度/季度)。

## 前置：获取持仓数据（卫星仓 + 巴菲特仓）

每周复盘开始时，向用户索要**两张券商截图**：

1. **卫星仓截图** → 提取持仓表（对应 Sheet "主题卫星"板块）
2. **巴菲特仓截图** → 提取持仓表（对应 Sheet "巴菲特仓"板块）

> 巴菲特仓纳入加仓判断和极端估值减仓判断，但**永不因质量问题淘汰**。

然后拉取 Google Sheets 核算 tab 进行交叉校验：

### 数据拉取

**主数据源：Google Sheets 核算 tab**（优先，结构化数据，含成本价和市值）

### 筛选规则

**Step 1 — 筛选持仓中个股**：
```python
# 排除条件（任一命中即排除）
# 1. 持仓状态 != "持仓中"
# 2. 剩余份额 = 0 或空
# 3. 代码以 5 开头且长度为 6（ETF/LOF 基金：510300, 513500, 159915 等）
# 4. 代码非纯数字（如 AU9999）
# 5. 代码长度 < 4 或 > 6
# 6. 资产板块为"固定收益"或"大宗商品"
# 7. 名称含 "ETF" / "基金" / "黄金" / "国债" / "转债" / "债券"

# 保留条件（A股 + 港股个股）
# - A股：6位纯数字，以 0/3/6 开头（包括 688xxx 科创板）
# - 港股：5位纯数字，以 0 开头（如 00700 腾讯、02097 蜜雪集团、09992 泡泡玛特）
```

**Step 2 — 识别卫星仓标的**：

筛选后的个股分属两个含个股的资产板块：
- **主题卫星** — 卫星仓标的，本 skill 的复盘对象
- **巴菲特仓** — 稳定长期持有、通常不需频繁审视的标的（如腾讯、茅台、美的、泡泡玛特等）

默认仅拉取"主题卫星"板块的个股。如果用户明确表示某只巴菲特仓标的也需要纳入本周复盘（如出现了需要关注的新信息），可以临时加入。

券商账户中可能同时持有两个板块的标的——以 Sheet 的资产板块分类为准区分。

**Step 3 — 与券商截图交叉校验**：

Google Sheet 是手动维护的，可能滞后于实际持仓。如果用户同时提供了券商截图：
- 以券商截图的**持仓列表**为准（实际在账户里的股票）
- 以 Google Sheet 的**成本价和累计数据**为准（更准确的历史记录）
- 标出两者不一致的项（截图有但 Sheet 没有，或反之），向用户确认

### 汇总计算

从 Sheet 数据提取每只卫星仓标的：

| 字段 | 来源 | 说明 |
|------|------|------|
| 证券代码 | 列 B | 如 600406、02097 |
| 证券名称 | 列 C | 公司简称 |
| 持股数量 | 列 D | 股数 |
| 成本价 | 列 J | 加权平均成本 |
| 当前市价 | 列 E | 最新价 |
| 市值 | 列 F | 单位万元，需 ×10000 转为元 |

计算：
- **股票总市值** = Σ(每只市值 × 10000)
- **可用现金** = 券商截图中的可取金额（Sheet 不直接含现金数据，需从券商截图补充或用户提供）
- **总资产** = 可用现金 + 股票总市值
- **现金比例** = 可用现金 / 总资产 × 100%
- **持股数量** = 筛选后标的数

> ⚠️ 如果本次复盘用户只提供了 Sheet、没提供券商截图，则现金数据需用户手动补充（Sheet 核算 tab 不跟踪账户现金余额）。

提取完成后，用表格展示当前卫星仓概览，标注现金比例和持股数量 vs 参考值（约 10%、8 家）的偏离——**仅作为观察项，不触发强制操作**。

## 第 1 步：现金管理（机会储备，不强制拉回）

### 目标

现金作为**机会储备**,参考水平约 **10%**。这是软性目标,不是必须每周达成的硬指标。

### 关键原则

> **现金只被动归位,绝不主动割肉凑现金。**
> 现金的补充只能来自三个**本来就该做的**动作:
> 1. 止盈极端高估的标的
> 2. 清仓基本面恶化的标的
> 3. 组合再平衡
>
> **不存在"现金太低 → 强制卖出"这条规则。** 现金偏低本身只是一个观察结果,不是卖出信号。

### 决策矩阵（观察 + 讨论，非强制）

| 现金比例 | 状态 | 处理方式 |
|----------|------|----------|
| < 5% | 偏低 | **仅观察**。如果第 2 步本来就要淘汰/止盈某标的,顺势让现金回升;若所有标的都健康且不贵,则维持低现金,无需任何操作。 |
| 5% ~ 8% | 略低 | 观察,等待自然归位(分红、止盈、再平衡时补充)。 |
| 8% ~ 12% | 目标区间 | 通过。 |
| 12% ~ 15% | 略高 | 可讨论是否有值得建仓的机会(见下);没有合适标的就继续持币等待。 |
| > 15% | 偏高 | 讨论现有持仓或 watchlist 中是否有处于吸引人价位的标的。**没有就继续等,持币不是错误。** |

### 现金偏高时的讨论要点（找机会,不是为花钱而花钱）

1. 从现有持仓中找加仓机会:基本面仍然优秀、当前价位有吸引力的标的。
2. 从 growth/radar watchlist 中找新标的:基本面通过 PreBuy、估值进入合理或低估区间。
3. **若市场整体不便宜、找不到有吸引力的标的 → 保留高现金,等待机会。** 这是价值投资者的正常状态,不需要"修正"。

### 输出

```
💰 现金管理结论
- 当前现金：X%（参考：约 10% 机会储备）
- 状态：[目标区间 / 偏低观察 / 偏高待机]
- 是否有动作：[无,仅观察 / 因止盈YYY自然回升 / 因加仓ZZZ动用现金]
- 原因：[简述。若维持异常现金比例,记录逻辑]
```

## 第 2 步：精简持仓（基本面驱动，月度/季度深度审视）

### 目标

持股数量 **6 ~ 10 家**（目标 **8 家**）。无需每周强制精简——只在持股数漂出 6~10 区间,或某标的持有逻辑出现裂痕时,才进入深度淘汰讨论。

### AI 职责

对每只持仓，基于已有深度分析报告 + 当前基本面信息，输出评估摘要：

| 维度 | 评估内容 |
|------|----------|
| 基本面 | PreBuy 评分是否仍然成立？本期有无改变持有逻辑的新信息？ |
| 估值 | 当前 PE/PB 处于历史什么分位？是否进入**极端高估**区间?（定性判断即可） |
| 仓位 | 单只占比是否 > 15%（过重,需关注集中度风险）或 < 3%（过轻/浪费注意力）？ |
| 持有逻辑 | 当初买入的理由现在是否依然成立? |

按**淘汰建议优先级**排序：

| 优先级 | 类型 | 说明 |
|--------|------|------|
| P0 | 持有逻辑被证伪 | PreBuy 结论不再成立(基本面实质恶化),应清仓 |
| P1 | 进入极端高估 | 基本面虽好但估值已严重透支,可止盈减仓 |
| P2 | 仓位过轻（< 3%） | 占用注意力但不贡献收益,可合并或清掉 |
| P3 | 有更优替代 | 同行业/同风格出现基本面更好、价位更吸引人的标的,可调仓 |

> ⚠️ **注意 P0/P1 的依据是"基本面被证伪"或"极端高估",不是"浮亏扩大"。** 一只基本面没变、只是价格下跌的标的,不在淘汰之列——对价值投资者而言那是机会,不是问题。

### 用户职责

- 对每只被建议淘汰的标的，给出保留原因或同意淘汰
- 最终决定淘汰名单和保留名单

### 精简策略

- 先从 P0(逻辑被证伪)下手,这是必须处理的。
- P1(极端高估)讨论是否止盈,以及止盈多少。
- 再审视 P2/P3,合并小微仓位、必要时调仓。
- 如果持股已在 6~10 家且无 P0/P1,**不强制进一步精简**。

### 输出

```
📋 精简结论
- 当前：N 家（参考目标 8 家,6~10 可接受）
- 淘汰：[标的列表 + 原因（逻辑证伪 / 极端高估 / 过轻合并 / 调仓换更优）]
- 保留：[标的列表]
- 下一步：对"决定建仓/加仓/清仓/减仓"的标的进入第 3 步执行划线
```

## 第 3 步：执行辅助技术划线（仅建仓/清仓时使用）

### 角色定位（务必理解）

> **这一步不做任何买卖决策。** 它只处理第 1、2 步中**已经基于基本面决定要建仓/加仓/清仓/减仓**的标的,用 K 线划线来回答一个问题:**"既然我决定要买(卖)了,怎么分批、在什么价位执行更划算?"**
>
> - 对**已决定不动**的持仓:跳过,不划线、不设触发价。
> - 没有任何已决定的执行动作:本步直接输出"本周无执行计划"。
> - **绝不**根据技术信号反过来产生买卖决策,**绝不**设止损线。

### 适用对象

只对以下标的执行:
- 第 1 步中决定要动用现金**加仓/建仓**的标的
- 第 2 步中决定要**止盈/清仓/调仓减仓**的标的

### 数据拉取

使用理杏仁 API 的 candlestick 端点:

- **A 股**:`POST /cn/company/candlestick`,参数 `stockCode`(6 位)、`startDate`、`endDate`、`type: "day"`、`adjustmentType: "1"`(前复权)
- **港股**:`POST /hk/company/candlestick`,参数 `stockCode`(5 位)

**时间窗口**:近 3 个月(短期进出场点)+ 近 12 个月(MA120 及重要高低点)。仅对需要执行的标的拉取。

### 技术指标计算

#### 1. 均线系统
```
MA20  = 最近 20 个交易日收盘价均值
MA60  = 最近 60 个交易日收盘价均值
MA120 = 最近 120 个交易日收盘价均值
```

#### 2. 支撑位（用于优化"买入"分批点）
**S1（强支撑）**:近 6 个月内被 ≥ 2 次触及但未有效跌破的低点。
- 算法:找出 6 个月内所有局部极小值(左右各 10 个交易日内最低),按价格聚类(差距 < 3% 视为同一水平),按触及次数排序,取最密集的 2 个水平。

**S2（趋势支撑）**:MA60 和 MA120 中更接近当前价的那条(差距 < 5% 时合并为一个支撑区)。

#### 3. 压力位（用于优化"卖出"分批点）
**R1（弱压力）**:若当前价 < MA20,则 MA20 为第一压力;若当前价 > MA20,取近 3 个月最高点。

**R2（强压力）**:近 12 个月最高点 或整数关口,取较高者。

### 执行划线逻辑（替代原"触发交易"逻辑）

**当决定要建仓/加仓某标的时** —— 目的是分批买在更低/更稳的位置:

| 区域 | 价位 | 执行建议 |
|------|------|----------|
| 首批 | 当前价附近 | 既然已决定买,可先建底仓(如目标仓位 1/3~1/2) |
| 加码区 | 接近 S1 / S2(回踩) | 若价格回踩到支撑区,分批补足剩余仓位——平滑成本 |

> 若价格不回踩、直接上行也没关系——底仓已建,不必追高,剩余资金等下一次机会。技术划线只是帮你**在已决定买入的前提下买得更从容**,不是要你等到某个价位才肯买。

**当决定要止盈/清仓/减仓某标的时** —— 目的是分批卖在更好的位置:

| 区域 | 价位 | 执行建议 |
|------|------|----------|
| 首批 | 当前价附近 | 既然已决定卖(因极端高估/逻辑证伪),可先减一部分 |
| 优化区 | 接近 R1 / R2(冲高) | 若价格冲高到压力区,分批卖出剩余——卖得更好 |

> 若是因**基本面被证伪(P0)**而清仓,优先尽快了结,不必为等一个好价位而拖延——基本面坏了,价格优化是次要的。技术划线主要服务于**止盈型(因极端高估)**的从容退出。

### 输出格式

仅对有执行动作的标的输出卡片:

```
### [股票代码] [公司简称]  —— 执行动作：[建仓/加仓 / 止盈减仓/清仓]
> 决策依据(基本面)：[一句话,例：估值进入历史90分位以上,极端高估,决定止盈]

| 项目 | 数值 |
|------|------|
| 当前价 | ¥XX |
| S1 强支撑 | ¥XX（触及 X 次,最近 YYYY-MM-DD） |
| S2 趋势支撑 | ¥XX（MA60/MA120） |
| R1 弱压力 | ¥XX（MA20 / 前高） |
| R2 强压力 | ¥XX（12月高点 / 整数关口） |

| 分批执行计划 | 价位参考 | 动作 |
|-------------|----------|------|
| 首批 | ¥XX（当前价附近） | [先建1/3仓 / 先减1/3仓] |
| 后续批次 | ¥XX（S1或R1附近） | [回踩补仓 / 冲高续减] |
```

无执行动作时:
```
📈 第 3 步：本周无已决定的建仓/清仓动作,跳过技术划线。
现有持仓维持不动,继续长期跟踪基本面。
```

## 执行原则

1. **基本面优先,技术辅助。** 所有买卖决策来自基本面(逻辑证伪/极端高估/再平衡/更优替代);技术只在执行层平滑节奏。
2. **现金不强制。** 现金被动归位,持币等待是价值投资者的正常状态,不为达标割肉。
3. **无止盈止损线。** 不存在因价格下跌而止损、因触及压力位而机械止盈的规则。
4. **不临时起意。** 决策在周末完成,盘中只执行;但"决策"指的是基本面层面的判断,不是看图下单。
5. **轻量跟踪内在价值。** 每期复盘对每只持仓快速检查:本期有无改变持有逻辑的信息?这是价值投资的核心,不可省略。
6. **连续追踪。** 下期复盘回顾上期的执行计划是否完成、基本面判断是否准确。
7. **与 watchlist 联动。** 淘汰标的若在 watchlist,确认是否降级(core → growth → radar → 剔除)。
8. **复盘文件独立归档,每周一份,不覆盖历史。**
