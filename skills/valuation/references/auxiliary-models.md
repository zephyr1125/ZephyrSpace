### PVGO 方法详解

以下为可选辅助诊断，不作为凑数主模型。历史研究基准须能取得原始出处才可引用；无来源时标为未核，不为使用本辅助方法反复检索。示例年份/折现率不是当前输入，须按本次资料截止日和可持续盈利假设确定。

PVGO（Present Value of Growth Opportunities）将股价拆解为两部分：

$$
P = \text{Steady-State Value} + PVGO
$$

- **稳态价值（SSV）**：假设当前盈利永续不变的价值，SSV/股 = Normalized EPS ÷ Ke
- **PVGO**：市场赋予未来价值创造（ROIC > WACC 的新投资）的期权价值
- **PVGO% = (P - SSV) / P**：股价中有多少比例来自"对未来价值创造的预期"

**对标基准**（来自 Counterpoint Global / Morgan Stanley 2026.6 研究）：
- S&P 500 历史 PVGO% 均值 ≈ 35%，2025 年末远高于均值
- 低 PVGO% 组合 5 年年化跑赢高 PVGO% 组合约 260bp（1990-2024 美国市场）
- 低 PVGO% 后 10 年 S&P 500 CAGR ≈ 11.6%，高 PVGO% 后 ≈ 7.6%

**计算步骤**：

```
1. 确定 Normalized EPS（选择本次适用的正常化盈利或有来源的预测，明确期间；周期企业覆盖完整周期）
2. Ke = 权益成本（A 股 9%，港股 10-11%，美股 8.5-9%）
3. SSV/股 = Normalized EPS / Ke（等价于 PE_ssv ≈ 1/Ke，如 A 股 11.1x）
4. PVGO/股 = 当前股价 - SSV/股
5. PVGO% = PVGO / 当前股价
6. 判定"合理 PVGO%"：
   - ROIC 持续 > WACC 且护城河深 → 合理 PVGO% 30-50%（价值创造确定性强）
   - ROIC ≈ WACC 或护城河一般 → 合理 PVGO% 15-30%
   - ROIC < WACC 或竞争激烈 → 合理 PVGO% < 15%
   - 亏损/微利 → 方法不适用（PVGO% > 100% 无意义）
7. 合理价 = SSV / (1 - 合理 PVGO%)
```

**输出格式**：

```
### 方法 N：PVGO（增长机会现值）

| 参数 | 值 |
|---|---|
| Normalized EPS | X.XX 元 |
| Ke（权益成本） | X.X% |
| SSV/股 | XX.XX 元 |
| 当前股价 | XX.XX 元 |
| 实际 PVGO% | XX% |
| 合理 PVGO% 判断 | XX%（依据：ROIC=XX% vs WACC=XX%，护城河…） |
| 合理价 | XX.XX 元 |
| vs 现价 | +/-XX% |
```

**PVGO vs 逆向 DCF 的互补关系**：

| | PVGO | 逆向 DCF |
|---|---|---|
| 回答的问题 | "股价中多少是预期，多少是确定的？" | "当前价格隐含多少增速？" |
| 计算复杂度 | 低（3 步） | 中（需建模） |
| 主要输入 | EPS + Ke | EPS + Ke + 成长期 + 终值PE |
| 长处 | 直观分解预期结构；极端值信号强 | 精确量化隐含增速 |
| 短板 | 不区分增速高低 | 参数多、对终值假设敏感 |
| 最佳用途 | 快速判断预期高低 + 跨公司可比 | 验证隐含增速是否合理 |

两者结合使用：PVGO% 告诉你"市场有/没有预期"，逆向 DCF 告诉你"这个预期对应的增速是多少"。

**不适用场景**：
- 亏损公司（SSV 为负，PVGO% > 100% 无意义）
- 强周期股在盈利低谷（Normalized EPS 应改用 5Y 平均）
- 金融公司（资产负债表驱动，book value 更相关，用 P/B-ROE 替代）

### PEG 的增速选取
- 使用与本次预测期一致、可核验的前瞻增速，注明实际基期与预测期
- 若增速 >30%，同时用 **3Y 历史 CAGR**（去基数效应）做交叉校验
- 终端增长率 g = ROE × (1-payout)，用于 DDM 和逆向 DCF
