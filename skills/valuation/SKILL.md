# 估值分析（多方法 + Watchlist 联动）

## 概览

这个技能执行「公司估值分析 → watchlist 更新 → Finance 项目同步」的完整闭环。

核心原则：
- **多方法交叉验证**：至少使用 4-7 种估值方法，加权得出合理价中枢，不依赖单一方法
- **方法选择按公司特征定**：成长型用 PEG + 逆向 DCF，成熟型用 PE 分位 + DDM，制造型用 EV/EBITDA + FCF Yield，预期分歧大时加 PVGO
- **分析完成后自动联动 watchlist**：检索所有 watchlist JSON，命中则更新 price_bands

## 第 0 步：数据拉取

执行估值前必须获取以下数据：

### 必须数据
1. **行情**：最新收盘价、市值、总股本（tushare `daily` + `daily_basic`）
2. **财务**：近 5 年收入/净利/毛利率/ROE/EPS/OCF/FCFF/EBITDA（tushare `fina_indicator` + `income` + `cashflow`）
3. **一致预期**：2026E/2027E EPS 和净利润（web_search 券商一致预期）
4. **历史估值区间**：3Y PE 分位 P20/P50/P80（理杏仁 API 或已有分析文件）

### 可选数据（用于交叉验证）
5. **分红**：近 5 年 DPS + 分红率（tushare `dividend`）
6. **资产负债表**：有息负债/净现金/商誉（已有深度分析或 tushare `balancesheet`）

### 已有资料利用
- 先 `Glob **/*公司名*` 检查 vault 中是否有深度分析、公司页、管理层档案
- 深度分析中的财务数据可直接复用，但行情和估值分位必须拉最新
- 公司页中如有 PE 分位锚点数据，优先使用

## 第 0.5 步：数据日期与真实性标注（强制）

> ⚠️ **本步骤为硬性前置，未执行不得进入估值。** 估值失真的最大来源是"数据日期混乱 + 实际值与预测值混用"。

### 0.5.1 财务数据必须优先采用最新年报/季报官方值

- **优先顺序**：最新已发布**年报** > 最新已发布**季报（一季报/三季报/中报）> 业绩快报 > 一致预期推算。
- 估值所引用的每一个财务数字（营收、净利、EPS、BVPS、ROE、NIM、赔付率等），**必须来自最近一期已正式披露的定期报告**，而非记忆、旧分析或过期研报。
- 若分析日处于年报密集披露期（4–5 月），且目标公司年报尚未发布，必须**显式标注所用数据仍来自上一年报/三季报**，不得擅用未发布的预测值冒充"实际值"。
- 审计意见与审计报告签发日期（如"2025 年报 2026-04-15 标准无保留"）应在数据来源中注明；非标意见须触发复核。

### 0.5.2 必须列明"数据日期"与"实际值/预测值"

**每条财务与估值数据必须带两个标签**：

1. **数据日期**：该数字对应的报告期或提取日（如 `2025-12-31` / `2026Q1` / `2026-07-10 行情`）。
2. **性质标签**：`（实际值，已发布）` 或 `（预测/推算，来源：xxx）`。

**强制格式示例**（估值快照与核心财务表必须如此列示）：

| 指标 | 数值 | 数据日期 | 性质 |
|---|---|---|---|
| 营业收入 | 3,375 亿元 | 2025-12-31 | 实际值，已发布（2025 年报） |
| 归母净利润 | 1,502 亿元 | 2025-12-31 | 实际值，已发布 |
| 2026E EPS | 6.46 元 | 2026-07-12 | 预测/推算（来源：高盛一致预期 + 内生模型） |
| 当前 PE_TTM | 6.17x | 2026-07-10 行情 | 实际值（行情） |

> 任何未标注数据日期或性质标签的数字，审核 Agent 应判定为 **P1（数据不完整）**，必须退回补标。

## 第 1 步：方法选择矩阵

根据公司特征，从以下方法中选择最合适的 4-6 种：

| 方法 | 最适用 | 需要数据 | 权重建议 |
|---|---|---|---|
| **PE 历史分位** | 盈利稳定、有 3Y+ 交易历史的公司 | EPS + 3Y PE P20/P50/P80 | 20-30% |
| **PEG** | 增速 10%+ 的成长型公司 | 2026E EPS + 增速 | 10-20% |
| **EV/EBITDA** | 有息负债显著的制造/工业公司 | EBITDA + 净债务 | 10-15% |
| **标准化 FCF Yield** | 现金流强且稳定的**非金融**公司（制造/消费/公用事业） | OCF - 维护性 capex | 20-25% |
| **DDM（股利折现）** | 高分红成熟公司（分红率>40%） | DPS + g + r | 10-15% |
| **逆向 DCF** | 所有公司，用于验证隐含预期 | EPS + 折现率 | 15-20% |
| **SOTP 分部估值** | 多元化/跨行业/有期权价值的公司 | 分部收入/利润 | 10-15% |
| **P/B-ROE** | 金融/高杠杆/周期性公司 | ROE + PB + 权益成本 | 底线验证 |
| **PVGO（增长机会现值）** | 盈利可预测、存在预期分歧的**非金融**公司；与逆向DCF互补验证 | Normalized EPS + 权益成本Ke | 10-15% |

> 🚫 **银行/保险/券商 禁用规则（强制）**：
> - **禁止对银行使用普通企业的「标准化 FCF Yield」**——银行的"经营现金流"受存贷款净变动剧烈扰动（如招行 2019 年净利含金量仅 4.7%、其他年份 >150%），OCF 不是可分配给股东的自由现金流，用 OCF−Capex 算 FCF Yield 会严重失真。银行若需现金流视角，应使用 **股息率（DPS/价格）** 或 **（净利润−资本补充需求）/市值** 替代，并明确标注口径。
> - **禁止对银行/保险使用 EPS/Ke 式 PVGO**（即 `SSV = EPS/Ke`）——金融机构盈利需留存资本支撑资产扩张，EPS/Ke 会把稳态价值人为抬高到远超 BVPS，PVGO 几乎必然为负且无解，对银行无指示意义。银行/保险的价值锚应是其 **BVPS（账面净值）与 P/B-ROE**，PVGO 框架不适用。
> - 保险、券商同理：保险禁用普通 FCF Yield（保单现金流结构特殊），改用 **P/EV（内含价值倍数）** 或 **P/B + 新业务价值**；券商估值以 **P/B + ROE** 为主、辅以 **P/E**，禁用 DDM（分红不稳定）与 PVGO。

### PVGO 方法详解

PVGO（Present Value of Growth Opportunities）将股价拆解为两部分：

$$
P = \text{Steady-State Value} + PVGO
$$

- **稳态价值（SSV）**：假设当前盈利永续不变的价值，SSV/股 = Normalized EPS ÷ Ke
- **PVGO**：市场赋予未来价值创造（ROIC > WACC 的新投资）的期权价值
- **PVGO% = (P - SSV) / P**：股价中有多少比例来自"对未来价值创造的预期"

**对标基准**（来自 Counterpoint Global / Morgan Stanley 2026.6 研究）：
- S&P 500 历史 PVGO% 均值 ≈ 35%，2025 年末远高于均值
- 低 PVGO% 组合 5 年年化跑赢高 PVGO% 组合约 260bp（1990-2024 美国市场）
- 低 PVGO% 后 10 年 S&P 500 CAGR ≈ 11.6%，高 PVGO% 后 ≈ 7.6%

**计算步骤**：

```
1. 确定 Normalized EPS（优先用 2026E 一致预期 EPS；若处于周期低谷则用 3Y 平均 EPS）
2. Ke = 权益成本（A 股 9%，港股 10-11%，美股 8.5-9%）
3. SSV/股 = Normalized EPS / Ke（等价于 PE_ssv ≈ 1/Ke，如 A 股 11.1x）
4. PVGO/股 = 当前股价 - SSV/股
5. PVGO% = PVGO / 当前股价
6. 判定"合理 PVGO%"：
   - ROIC 持续 > WACC 且护城河深 → 合理 PVGO% 30-50%（价值创造确定性强）
   - ROIC ≈ WACC 或护城河一般 → 合理 PVGO% 15-30%
   - ROIC < WACC 或竞争激烈 → 合理 PVGO% < 15%
   - 亏损/微利 → 方法不适用（PVGO% > 100% 无意义）
7. 合理价 = SSV / (1 - 合理 PVGO%)
```

**输出格式**：

```
### 方法 N：PVGO（增长机会现值）

| 参数 | 值 |
|---|---|
| Normalized EPS | X.XX 元 |
| Ke（权益成本） | X.X% |
| SSV/股 | XX.XX 元 |
| 当前股价 | XX.XX 元 |
| 实际 PVGO% | XX% |
| 合理 PVGO% 判断 | XX%（依据：ROIC=XX% vs WACC=XX%，护城河…） |
| 合理价 | XX.XX 元 |
| vs 现价 | +/-XX% |
```

**PVGO vs 逆向 DCF 的互补关系**：

| | PVGO | 逆向 DCF |
|---|---|---|
| 回答的问题 | "股价中多少是预期，多少是确定的？" | "当前价格隐含多少增速？" |
| 计算复杂度 | 低（3 步） | 中（需建模） |
| 主要输入 | EPS + Ke | EPS + Ke + 成长期 + 终值PE |
| 长处 | 直观分解预期结构；极端值信号强 | 精确量化隐含增速 |
| 短板 | 不区分增速高低 | 参数多、对终值假设敏感 |
| 最佳用途 | 快速判断预期高低 + 跨公司可比 | 验证隐含增速是否合理 |

两者结合使用：PVGO% 告诉你"市场有/没有预期"，逆向 DCF 告诉你"这个预期对应的增速是多少"。

**不适用场景**：
- 亏损公司（SSV 为负，PVGO% > 100% 无意义）
- 强周期股在盈利低谷（Normalized EPS 应改用 5Y 平均）
- 金融公司（资产负债表驱动，book value 更相关，用 P/B-ROE 替代）

### PEG 的增速选取
- 优先使用 **2025A→2026E 一致预期增速**
- 若增速 >30%，同时用 **3Y 历史 CAGR**（去基数效应）做交叉校验
- 终端增长率 g = ROE × (1-payout)，用于 DDM 和逆向 DCF

### 逆向 DCF 标准参数
- 折现率：A 股 9-10%，港股 10-11%，美股 9-10%
- 成长期：10 年
- 终值 PE：15x（一般制造业）、18x（品牌/龙头）、20x（顶级护城河）
- 输出：「当前价格隐含 10 年 EPS CAGR ≈ X%」

## 第 1.5 步：行业专属估值框架（强制按行业选用）

> ⚠️ **估值方法必须与公司行业匹配。除通用成长/成熟框架外，以下四类行业必须使用专属框架；误用通用企业方法（尤其银行的 FCF Yield / PVGO）属 P1 错误。**

### A. 银行业（商业银行）

- **主框架**：`P/B-ROE`（核心）+ `DDM` + `PE 分位` + `逆向 DCF` + `股息率视角`。
- **合理 PB 锚定**：`理论 PB 区间 = ROE/(Ke)（零增长）至 (ROE−g)/(Ke−g)（有增长）`，再以当前 PB 与历史分位对照。
- **禁用**：普通企业 **FCF Yield**（OCF 受存贷款扰动非股东可分配现金流）、**EPS/Ke 式 PVGO**（SSV 人为抬高、对银行无解）。若需现金流视角，用 **股息率（DPS/价）** 或 **（归母净利 − 当年资本补充需求）/市值**，并标注口径。
- **关键行业指标**：NIM（净息差）、不良贷款率、拨备覆盖率、资本充足率（CET1）、房地产/零售不良生成率、AUM（财富管理）。估值须引用这些银行专属指标，而非仅看 PE。
- **H/A 溢价**：若同时上市，须拉取 H 股行情，A/H 溢价纳入估值参考。

### B. 保险业

- **主框架**：`P/EV（内含价值倍数）` + `P/B-ROE` + `新业务价值（NBV）倍数`。
- **禁用**：普通 **FCF Yield**（保单现金流结构特殊）、**DDM**（分红政策不稳定）、**EPS/Ke 式 PVGO**。
- **关键行业指标**：内含价值（EV）、新业务价值增长率、营运利润（OPAT，非会计利润）、投资收益率、偿付能力充足率。优先用 **营运利润** 而非净利润做盈利基数。

### C. 券商业

- **主框架**：`P/B-ROE`（核心，重资本业务驱动）+ `P/E`（轻资本业务如财富管理）+ `PB 分位`。
- **禁用**：**DDM**（分红不稳定）、**PVGO**、**FCF Yield**（资本密集型、现金流波动大）。
- **关键行业指标**：净资产、ROE（尤其加权）、经纪/投行/资管/自营收入结构、杠杆率、市场成交额β。估值高度随市场贝塔波动，须标注所处境（牛市/熊市/震荡）。

### D. 资源股（油气/煤炭/金属/矿业）

- **主框架**：`EV/EBITDAX（矿企用 EBITDAX 含特许权使用费与勘探）` + `P/B`（资源储量法辅助）+ `重置成本/NAV（净现值，按储量与商品价格）` + `股息率`。
- **关键行业指标**：**储量（Reserves）、资源量（Resources）、现金成本（AISC/C1）、商品价格假设、折耗率**。估值必须对**商品价格假设**做敏感性分析（如油价 ±20$、铜价 ±1000 美元）。
- **禁用**：纯 PE 估值（周期底部 PE 极高、顶部极低，严重误导）；PEG 仅可用于穿越周期的成长型矿企。
- **NAV 法**：`NAV = Σ(储量×价格×回收率 − 成本 − 税费)/折现`，是资源股最贴近基本面的锚，须列明商品价格与折现率假设。

## 第 3 步：综合加权 + 价格区间

### 加权合理价
对每个方法赋权重（按方法选择矩阵），计算加权合理价。

### 方法独立性声明（强制）

> ⚠️ **加权前必须逐项声明所选方法是否相互独立**，否则加权结果可能重复计入同一驱动因素导致虚高/虚低。

在加权表中增加一列「独立性」，逐对说明方法关系：

| 方法 | 权重 | 独立性说明 |
|---|---|---|
| PE 分位 | 20% | 与 DDM 共享 EPS/盈利预期，但切入角度不同（市场相对历史 vs 股利折现），**弱相关** |
| PB-ROE | 20% | 与 PE 分位共享 ROE/盈利，但锚定账面值而非盈利倍数，**弱相关** |
| DDM | 15% | 与 PE 分位共享 DPS/盈利预期，**弱相关** |
| 逆向 DCF | 15% | 与 PE/DDM 共享 EPS 但验证隐含增速，**部分重叠** |
| 股息率视角 | 15% | 与 DDM 同源（均基于 DPS），**强相关，权重合计须克制** |
| FCF Yield | 15% | 与盈利类方法同源（基于净利润/现金流），**弱相关** |

**判定与处理规则**：
- **强相关方法（如 DDM 与股息率、PE 与 PEG）**：若同时选用，权重合计不应超过单类上限（如 DDM+股息率合计 ≤ 25%），避免同一信号被双重加权。
- **弱/部分相关**：可并行加权，但须在敏感性分析中交叉验证（如 PE 合理价与 PB-ROE 合理价偏差过大时，须解释原因而非简单平均）。
- **完全独立**：如 SOTP 与相对估值、NAV（资源股）与 EV/EBITDAX，可正常加权。
- 声明结论示例："本次 6 法可归为 3 类信号（相对估值 / 股利折现 / 现金流），已控制同源权重，加权中枢可信。"

若未附独立性声明即输出加权价，审核 Agent 应判定为 **P1（方法学不完整）**。

### 价格区间锚定
输出四级价格区间（格式参考）：

```
🔴 追高区    >XXX 元    (PE >XXx / 触发条件)
🟡 中性区    XXX-XXX    (PE XX-XXx)
🟢 较好区    XXX-XXX    (PE XX-XXx，推荐建仓)
🟢🟢 低估区  <XXX       (PE <XXx，安全边际充足)
```

### 敏感性分析
以 2027E EPS 为基准，输出 PE × EPS 矩阵。

## 第 4 步：Watchlist 联动（强制步骤）

估值报告输出完成后，**立即执行**以下步骤：

### 4.1 检索标的

```bash
# 用 grep 在所有 watchlist JSON 中检索股票代码或名称
grep -l "代码\|公司名" data/watchlist_*.json
```

检索范围：
- `data/watchlist_core.json`
- `data/watchlist_growth.json`
- `data/watchlist_index.json`

检索关键词：股票代码（如 `600406.SH`）和公司简称（如 `国电南瑞`）。

### 4.2 更新 price_bands

若命中，用 Read 工具定位到该条目，然后 Edit 更新以下字段：

```json
"current_price": <最新收盘价>,
"price_date": "<YYYY-MM-DD>",
"price_bands": [
  <追高区边界>,
  <中性区上界>,
  <低估区下界>
],
"valuation_anchor": "<PE TTM XXx（3Y P50≈XXx），2026E EPS≈XX→Fwd PE XXx。PEG=XX，FCF Yield XX%，逆向DCF隐含g≈XX%。多方法加权合理价≈XX元(±XX%)。[估值更新YYYY-MM-DD]>"
```

**price_bands 格式约定**：
- `[0]`：追高区下界（PE >此值不宜追高）
- `[1]`：中性区上界（合理偏贵 vs 合理偏低的分界）


### 4.4 告知用户

总结更新了哪些标的、在哪个 watchlist 中、新的 price_bands 是什么。

---

## 第 5 步：输出格式模板

最终输出应包含以下板块（顺序可调整）：

1. **估值快照**：一张表（PE/PB/PS/FCF Yield/股息率 + vs 历史分位）
2. **核心财务**：近 5 年收入/净利/ROE/毛利率/OCF 趋势
3. **多方法估值**：每种方法独立成段
4. **综合加权 + 价格区间**
5. **敏感性分析**：PE × EPS 矩阵
6. **风险与催化剂**
7. **一句话结论**
8. **Watchlist 更新确认**：更新了哪个文件、新的 price_bands

## 注意事项

- EPS 单位：tushare `total_mv` 是万元，EPS 是元，注意换算一致性
- H 股标的：额外拉取 H 股行情，A/H 溢价纳入估值参考
- 新股/次新股：若 PE 历史不足 3 年，用可比公司 + PEG + 逆向 DCF 为主，PE 分位法降权
- 亏损公司：跳过 PE/PEG/DDM/PVGO，主用 EV/Sales + 逆向 DCF + SOTP
- 强周期股：PE 分位法失效，用正常化盈利（5Y 平均 EPS）替代 TTM EPS
- 深度分析未覆盖的标的：先执行完整估值，估值完成后提示用户可后续补做深度分析
