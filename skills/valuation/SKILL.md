# 估值：通用约束与计算核心规则

仅作为 `skills/company-triplet/SKILL.md` 的仓库内部模块，不单独安装或启动。完整流程以 `docs/three-report-economy-routing.md` 为唯一调度真源，数据源以 `docs/three-report-evidence-contract.md` 为准；旧段落中的独立审核、全源拉取、提交及回写指令不执行。评分标准、研究内容、行业约束及原件核验要求不变。

总分展示遵守 `docs/three-report-closeout.md` 的整数规则；分项、原始总分与门槛不变。

## 按需读取

- 作者及两位审核员必读本文件：方法选择、行业禁用、三情景、双变量敏感性、确定性和机械买入价规则均完整保留。
- 银行必读 [银行框架](references/bank.md)，保险必读 [保险框架](references/insurance.md)，券商必读 [券商框架](references/broker.md)，资源企业必读 [资源框架](references/resources.md)。经济本质不明确或业务混合时加载所有可能适用的框架，记录最终取舍；不能按股票行业标签机械选择。
- 只有实际采用 PVGO/PEG 辅助诊断时读取 [辅助模型](references/auxiliary-models.md)，不为使用附件增加模型数量。
- 主 Agent 收尾必读 [Watchlist字段与财报清场](references/watchlist-closeout.md)；子 Agent 不执行回写。作者不必为写估值读同步命令。
- [流程示例](references/examples.md)仅在理解格式时读取；示例数值不是本次假设。[旧定位](references/legacy-context.md)不参与执行。
- 各行业估值必须与经济本质相符，缺证则未完成；[行业说明](references/industry-intro.md)保留原条款。金融企业的核心财务表使用行业适用指标，不机械套用普通企业 OCF。
- 下文自动联动均由主 Agent 在完整验收后执行。

## 概览

这个技能执行「公司估值分析 → watchlist 更新 → Finance 项目同步」的完整闭环。

核心原则：
- **多方法交叉验证**：默认两个有不同估值依据的主模型，加一个行业适用的反向验证；只对有效主模型赋权，不为满足数量堆砌同源方法。完整三件套保留三情景、敏感性、机械买入价及100行全文底线。
- **方法选择按公司特征定**：先选两个有不同依据的适用主模型，再以行业适用的隐含变量做反向验证；PEG、PVGO等同源变换只作辅助，具体按下文矩阵选择。
- **分析完成后自动联动 watchlist**：检索 core/growth，命中则把最终加权合理估值写入 `target_price`

## 第 0 步：数据拉取

执行估值前必须获取以下数据：

### 必须数据

1. **行情**：共同截止日的最新可得收盘价、市值、股数及其日期/类别、币种与复权口径。
2. **财务**：近5年或可得完整周期的官方披露基础；最新中期/季报及必要TTM桥，按行业选择收入、利润、净资产、资本充足率或现金流等适用指标。
3. **预测**：模型需要时获取带来源/日期/预测期的一致预期；不可得时用有完整假设的自主预测并标记，不强制寻找固定年份的卖方数字。
4. **交叉验证输入**：按选定主模型获取历史分位、可比公司、分红/资本补充需求、净债务/受限现金、储量/成本等，不全量拉取不适用指标。

### A/H双重上市自动选择（强制）

同一公司A/H双重上市时，读取 `docs/ah-share-selection.md`，综合同币种折价、税后股息、税后费后总回报及交易条件，自动选定A或H。估值报告主结论与Watchlist使用选定股份的代码、币种及估值；保留双边比较和切换条件，不能只列两套价格让用户选择。仅影响市场选择，不给公司/管理层评分加减分。

### 共享与数据源

在ZephyrSpace先读取项目 `docs/three-report-evidence-contract.md` 和本run证据包；深度分析已有数字须能回到原件，旧报告判断不能替代新一期披露。行情统一刷新一次，后续角色复用快照。

法定披露优先；结构化数据以理杏仁适用端点为主，东方财富校验A股期别/延迟，CNINFO接口按缺口补充，Tavily搜索治理事件后回到原公告。港美股无主源覆盖时使用SEC/披露易/公司IR及可核验的补充数据源。冲突最终回到官方原件；不再要求Tushare。智堡与卖方材料只作补充，预测与实际严格分列。

## 第 0.5 步：数据日期与真实性标注（强制）

> ⚠️ **本步骤为硬性前置，未执行不得进入估值。** 估值失真的最大来源是"数据日期混乱 + 实际值与预测值混用"。

### 0.5.1 财务数据必须优先采用最新年报/季报官方值

- **信息截止**：最新年报提供年度基础，更新的中报/季报必须纳入；业绩快报及预测分列，不能替代已披露实际值。
- 当前财务事实取最新适用的正式披露；历史数字用于完整周期分析，预测数字用于估值假设，分别注明报告期和来源，禁止把记忆、旧分析或预测冒充当前事实。
- 若分析日处于年报密集披露期（4–5 月），且目标公司年报尚未发布，必须**显式标注所用数据仍来自上一年报/三季报**，不得擅用未发布的预测值冒充"实际值"。
- 审计意见与审计报告签发日期（如"2025 年报 2026-04-15 标准无保留"）应在数据来源中注明；非标意见须触发复核。

### 0.5.2 必须列明"数据日期"与"实际值/预测值"

**每条财务与估值数据必须带两个标签**：

1. **数据日期**：该数字对应的报告期或提取日（如 `2025-12-31` / `2026Q1` / `2026-07-10 行情`）。
2. **性质标签**：`（实际值，已发布）` 或 `（预测/推算，来源：xxx）`。

**强制格式示例**（估值快照与核心财务表必须如此列示）：

| 指标 | 数值 | 数据日期 | 性质 |
|---|---|---|---|
| 营业收入 | 3,375 亿元 | 2025-12-31 | 实际值，已发布（2025 年报） |
| 归母净利润 | 1,502 亿元 | 2025-12-31 | 实际值，已发布 |
| 2026E EPS | 6.46 元 | 2026-07-12 | 预测/推算（来源：高盛一致预期 + 内生模型） |
| 当前 PE_TTM | 6.17x | 2026-07-10 行情 | 实际值（行情） |

> 任何未标注数据日期或性质标签的数字，审核 Agent 应判定为 **P1（数据不完整）**，必须退回补标。

## 第 1 步：方法选择矩阵

默认选两个主模型，再做一个反向验证。选择依据是经济本质、数据可得性和新增信息；下表是可选工具箱，不是全部必做清单。

| 工具 | 适用依据 | 使用限制 |
|---|---|---|
| 正向DCF / 标准化FCF估值 | 非金融公司可持续现金流 | FCFF配WACC并桥接净债务，FCFE配Ke；增长与再投资匹配 |
| PE / PEG | 稳定盈利或可验证成长 | PE与PEG属于同一盈利倍数类，不能充作两个独立主模型 |
| EV/EBITDA | 可比工业企业、经正常化的资本结构 | 与DCF共享经营预测；说明可比倍数提供的独立市场依据 |
| DDM | 可持续分红及明确资本约束 | 与股息率同源；不得重复赋权 |
| SOTP | 经济本质不同的分部 | 独立性取决于分部底层模型，名称不保证独立 |
| PB-ROE / RI | 银行、部分金融等净资产驱动公司 | 与DDM可能是同一经济模型的等价表达，须查共享假设 |
| NAV / P/EV | 储量资产或保险内含价值等适用行业 | 按行业专属模型及公开数据，不用不完整储量数字硬算NAV |
| PVGO | 满足条件的非金融公司预期分解 | 同源EPS变换是辅助诊断，不凑主模型数量 |
| 反向验证 | 在市场价格下求隐含增速、ROE、商品价格或利润率 | 权重为0；反向DCF只是其中一种，输出隐含变量而非合理价 |

- 每个主模型说明：输入证据、独立估值依据、与另一模型共享的变量、适用限制。目标是两个不同依据，并非宣称统计独立。
- 只有一个可靠模型时，不虚构第二个；集中补证或寻找适用的交叉锚。仍不可得则标注“估值未完成，单模型试算”，不输出可入库的最终价格，不能以降低确定性替代缺失验收。
- 确有新增经济信息才增加主模型，并记录原因；两个主模型冲突时先查口径/假设，不用第三个同源模型凑平均。
- 两个主模型各保留保守/基准/乐观情景；反向验证输出当前价格隐含假设及敏感性。无可解反向DCF时用行业适用的隐含ROE/商品价/利润率等验证；无可靠替代则记未完成。

> 🚫 **银行/保险/券商 禁用规则（强制）**：
> - **禁止对银行使用普通企业的「标准化 FCF Yield」**——银行的"经营现金流"受存贷款净变动剧烈扰动（如招行 2019 年净利含金量仅 4.7%、其他年份 >150%），OCF 不是可分配给股东的自由现金流，用 OCF−Capex 算 FCF Yield 会严重失真。银行若需现金流视角，应使用 **股息率（DPS/价格）** 或 **（净利润−资本补充需求）/市值** 替代，并明确标注口径。
> - **禁止对银行/保险使用 EPS/Ke 式 PVGO**（即 `SSV = EPS/Ke`）——金融机构盈利需留存资本支撑资产扩张，EPS/Ke 会把稳态价值人为抬高到远超 BVPS，PVGO 几乎必然为负且无解，对银行无指示意义。银行/保险的价值锚应是其 **BVPS（账面净值）与 P/B-ROE**，PVGO 框架不适用。
> - 保险、券商同理：保险禁用普通 FCF Yield（保单现金流结构特殊），改用 **P/EV（内含价值倍数）** 或 **P/B + 新业务价值**；券商估值以 **P/B + ROE** 为主、辅以 **P/E**，禁用 DDM（分红不稳定）与 PVGO。

### 反向验证参数

- 复用正向模型的口径与约束，仅对选择的关键变量反向求解；注明市场价日期、其余固定假设及解的适用范围。
- 现金流模型明确FCFF/WACC或FCFE/Ke、显式期、再投资与终值；不能把EPS直接当作自由现金流。采用终值PE时应称“盈利倍数反推”，与现金流DCF区分。
- 银行可求隐含可持续ROE，资源股可求隐含商品价；选择与主模型匹配的反向检验。
- 输出“本组假设下，当前价格隐含X”；无解或极端解列为反证，不将市场价格倒算结果重新赋权到合理价。

## 第 2 步：执行多方法估值

对两个主模型分别输出以下完整输入和三情景表；反向验证单列隐含变量、求解假设和敏感性，不将求解得到的市场价当作独立合理价：

```
### 方法 N：XXX

| 输入参数 | 值 |
|---|---|
| ... | ... |

| 情景 | 合理价 |
|---|---|
| 保守 | XXX |
| 基准 | XXX |
| 乐观 | XXX |

**结论：合理价 ≈ XXX（+/- XX% vs 现价）**
```

关键纪律：
- **所有计算参数必须显式列出**（EPS、PE、g、r、FCF 等），方便审核
- **逆向 DCF 的 g 是"市场在定价什么"，不是你预期的 g**——要把两者分开
- PE估值选择匹配的实际/正常化/预测EPS，明确预测期与来源；历史PE分位与前瞻EPS口径不同须解释，不强制固定2026E。
- FCF区分报表口径与标准化口径，给出Capex/营运资金调整桥；保留增长所需再投资，不能剔除全部扩张Capex后仍保留对应增长。

## 第 3 步：综合加权 + 价格区间

### 加权合理价
对两个有效主模型赋权，权重合计100%，说明权重与证据质量的关系；同一组权重计算保守/基准/乐观三种综合价值。新增有效主模型时重新解释权重。反向验证与辅助指标权重为0，不参与合理价。

### 方法独立性声明（强制）

列明每个主模型的来源、独立估值依据、共享参数及权重。以下情况均不能充作额外独立信号：PE与PEG；DDM与股息率；同一利润/现金流乘除不同常数；SOTP与其底层模型的再加权；同一假设下等价的PB-ROE与DDM。

现金流估值与有独立可比依据的相对估值可提供不同视角，但仍共享盈利预测，不能宣称完全独立。NAV与EV/EBITDA同样可能共享商品价假设。若两个主模型仅同源变换，替换其中一个；无可靠替代则按单模型试算处理。

模型差异较大时，解释输入口径、资本结构、增长与再投资、期限/终值及市场可比性，报告敏感性和误差范围。不能通过平均数掩盖未解决的模型不适用。缺少独立性说明或给反向验证非零权重，视为P1。

### 价格区间锚定
输出四级价格区间（格式参考）：

```
🔴 追高区    >XXX 元    (PE >XXx / 触发条件)
🟡 中性区    XXX-XXX    (PE XX-XXx)
🟢 较好区    XXX-XXX    (PE XX-XXx，推荐建仓)
🟢🟢 低估区  <XXX       (PE <XXx，安全边际充足)
```

### 敏感性分析
按主模型输出关键双变量矩阵：如DCF的折现率×终值增长、PE的倍数×EPS、银行的ROE×Ke、资源股的商品价格×成本；标明对应预测期，不套用固定2027E。

#### Valuation Certainty 认定

`valuation_certainty` 只衡量当前 `target_price` 作为合理价值中枢的可靠程度，不评价公司质量或管理层质量，不得与 `cScore`、`mScore` 重复计分。

必须逐项评估：

1. 盈利和现金流是否可预测；
2. 商业模式与资本强度是否稳定；
3. 资产负债表和融资需求是否清晰；
4. 不同估值方法是否收敛；
5. 是否存在周期、单一客户、监管、技术迭代、商品价格、临床结果或重大资本开支等尾部风险。

参考区间：

- `0.80–0.90`：极高确定性，现金流稳定、估值区间窄、主要假设较少；
- `0.70–0.79`：较高确定性，基本面稳定，但仍受行业、监管或中期增长假设影响；
- `0.60–0.69`：中等确定性，需要一定增长、订单或行业景气判断；
- `0.50–0.59`：中低确定性，盈利波动、技术迭代或周期因素明显；
- `0.40–0.49`：较低确定性，高度依赖远期增长、客户集中或资本开支回报；
- `<0.40`：很低确定性，存在商品、临床、转型、单一客户或二元事件等高不确定性。

认定时优先估计目标价误差范围。高质量公司也可能确定性较低，低增长但现金流稳定的公司反而可能较高。不得因偏好公司而上调；财报、商业模式、资本结构或主要估值假设变化时必须重评。

买入价自动计算，但不写入 Watchlist：

```text
buy_price = target_price × (0.68 + 0.14 × valuation_certainty)
```

## 第 5 步：输出格式模板

最终输出应包含以下板块（顺序可调整）：

1. **估值快照**：一张表（PE/PB/PS/FCF Yield/股息率 + vs 历史分位）
2. **核心财务**：近 5 年收入/净利/ROE/毛利率/OCF 趋势
3. **多方法估值**：每种方法独立成段
4. **综合加权 + 价格区间**
5. **敏感性分析**：按行业/主模型选择双变量矩阵；反向验证隐含假设
6. **风险与催化剂**
7. **一句话结论**
8. **Watchlist 更新确认**：更新了哪个文件、新的 `target_price`、`valuation_certainty` 和自动计算的 `buy_price`

## 注意事项

- 单位：保存数据源原始单位再规范化，理杏仁市值mc按合法字段说明换算；每股值、股数、币种与ADR比例须一致。
- H 股标的：额外拉取 H 股行情，A/H 溢价纳入估值参考
- 新股/次新股：若 PE 历史不足 3 年，用可比公司 + PEG + 逆向 DCF 为主，PE 分位法降权
- 亏损公司：跳过 PE/PEG/DDM/PVGO，主用 EV/Sales + 逆向 DCF + SOTP
- 强周期股：PE 分位法失效，用正常化盈利（5Y 平均 EPS）替代 TTM EPS
- 深度分析未覆盖的标的：先执行完整估值，估值完成后提示用户可后续补做深度分析
