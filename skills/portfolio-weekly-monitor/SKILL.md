# 持仓公司新闻周报

## 定位

仅覆盖 **Google Sheet 核算 tab 中实际持有的 A 股标的**（过滤 ETF/基金/港股/美股）。
与全量 watchlist 周报的核心差异：

| 维度 | 全量周报 | 持仓周报 |
|------|---------|---------|
| 覆盖范围 | core + growth + radar 全部 | 仅实际持仓 |
| 分析视角 | 全覆盖扫描 | "对我的持仓有何影响" |
| 输出特色 | 行业信号、跨公司对比 | 持仓健康度速览、信心变化、历史跟踪闭环 |
| 行动导向 | 发现新机会/风险 | 现有仓位是否要调整 |

运行频率建议：**每周一次**（周末或周一），覆盖最近 7 天。

## 流程

### 第 1 步：数据拉取

```powershell
python scripts/weekly_watchlist_scan.py --tier portfolio
```

输出：`scripts/_weekly_scan/YYYY-MM-DD.json`

脚本自动从 Google Sheet 核算 tab 读取持仓 → 过滤非 A 股标的 → 拉取 CNINFO 数据：
- 公告标题（最近 N 天）
- 高管持股变动
- 公司处罚记录
- 业绩预告/快报
- 股东质押（最新状态）

脚本已做**预分级**（基于关键词匹配）：
- `CRITICAL`：业绩预告/处罚/诉讼/减持/并购重组/冻结/退市
- `WATCH`：增持/回购/质押/解禁/评级/分红/股权激励
- `IGNORE`：董事会/监事会/募集资金/章程制度
- `UNKNOWN`：无法自动判断，**需要 AI 分析**

### 第 1.5 步：WebSearch 补充（对 CRITICAL/WATCH 标的强制执行）

CNINFO 覆盖公告，但不覆盖市场解读。对每只标记为 CRITICAL 或 WATCH 的标的，用 WebSearch 补充：

- 业绩预告/快报 → 搜索卖方点评、市场反应
- 减持/质押 → 搜索减持原因、股东背景
- 重大合同/并购 → 搜索交易细节、市场解读
- 行业政策 → 搜索政策影响分析

### 第 2 步：AI 分析

读取 `scripts/_weekly_scan/YYYY-MM-DD.json`，按以下规则逐条分析：

**① UNKNOWN 类公告逐条判断**

AI 直接阅读每条 UNKNOWN 标题，判断属于：
- 🔴 **CRITICAL**：可能实质影响基本面的公告（重大合同/资产收购/控制权变更/立案调查/退市风险/业绩预告）
- 🟡 **WATCH**：需关注但不紧急（经营范围变更/会计师事务所变更/对外投资/新项目/政府补贴/子公司变动）
- ⚫ **IGNORE**：纯流程性公告（独立董事述职/募集资金使用报告/内部控制自我评价/审计委员会履职/年度股东大会资料）

**② CRITICAL/WATCH 类公告深度评估**

已标记的公告需要 AI 逐条判断是否**真正重要**。

常见**关键词误匹配**场景（标记为 CRITICAL 实则不重要）：
- "关于公司减持已回购股份的公告" → 减持的是**库存股**，不是大股东减持 → 降为 IGNORE
- "关于持股 5% 以上股东减持计划期限届满的公告" → 减持**已结束**，不是新动作 → 降为 WATCH
- "关于使用闲置募集资金进行现金管理的公告" → 纯现金管理 → IGNORE
- "关于募集资金投资项目结项并将节余募集资金永久补充流动资金的公告" → 已完成项目结尾 → WATCH

常见**真正重要但可能被低估**的公告：
- "关于对外投资设立子公司的公告" → 新业务布局 → 升为 WATCH 或 CRITICAL
- "关于获得政府补助的公告" → 金额大（> 净利润 10%）→ 🔴 CRITICAL，金额小 → IGNORE
- "关于公司产品中标/取得认证的公告" → 业务里程碑 → 🟡 WATCH
- "关于会计政策变更/会计差错更正的公告" → 利润大幅修正 → 🔴 CRITICAL

**③ 持仓视角评估**

对每条非 IGNORE 事件，回答三个问题：
1. 是否改变对公司核心投资逻辑的判断？
2. 是否需要调整仓位（加仓/减仓/清仓）？
3. 是否需要更新深度分析中的某项评分？

**④ 动态跟踪**

如果上期报告中有待跟踪项，本期逐一检查是否有新进展。连续两期出现的同类事件应升级关注级别。

## AI 分析原则

1. **持仓视角优先**：每条判断都要回答"对我的持仓意味着什么"
2. **宁可多报不可漏报**：边界模糊的事项标 WATCH 而非直接丢弃
3. **解释 WHY 而非 WHAT**：不仅要列事件，还要解释为什么重要/不重要
4. **联系深度分析结论**：如果深度分析中已有定论（如"毛利率持续下滑"），新事件要关联到这个框架
5. **标注置信度**：如果无法确定重要性（如标题信息不足），标注「需查看公告全文」
6. **信心变化显式化**：持仓健康度速览中必须标注信心方向（↑/↓/→），迫使自己判断
7. **历史闭环**：每期必须回顾上期待跟踪项，不允许"沉没"
8. **跨公司关联**：同一行业/产业链的多只持仓，信号要关联分析
