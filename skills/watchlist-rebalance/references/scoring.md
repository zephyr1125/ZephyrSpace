# 统一评分：质量与价格共同决定替换优先级

用户于 2026-09-16 补充：更好的标的是双评分与低估程度加权后的结果；高分公司进入低估一档、一般公司接近低估三档，都可考虑替代高估持仓。不能设“买方至少低估二档”的额外门槛。

## 初始模型

参数真源为上一级 `rules.json`。初始建议质量与价格各占 50%，质量内部公司分与管理层分各占一半；是否已获用户确认以配置状态为准。价格刻度是本技能提出的透明启发式，并非经过回测的最优参数，不冒充用户既有规则。

`质量分 Q = 公司分 × 公司权重 + 管理层分 × 管理层权重`

`统一总分 S = Q × 质量权重 + V × 价格权重`

公司分及管理层分各须为 0—100 的有效最新报告分数，同一证券不能混用旧单分与新双分。缺失分数标记不能比较，不填零、不按剩余分项重新分配权重。评级只决定资金档位，不再额外加分。

价格吸引力 V 为 0—100，以 `T` 和 `B` 为锚点线性插值：

| 价格锚点 | 价格分 |
|---|---:|
| ≥ 1.2T | 0 |
| 1.1T | 10 |
| T | 20 |
| B | 50 |
| 0.9B | 65 |
| 0.8B | 80 |
| ≤ 0.6B | 100 |

锚点之间线性插值，越便宜分越高，区间外封顶/封底。比如刚低于 0.9B 与刚高于它的价格分几乎相同，避免档位跳变主导选股。`0.6B` 是深折价封顶锚点，不是第四档或新的资金上限。

金额仍由 Finance 的离散档位决定：总分用于比较吸引力，不能擅自按高总分突破当档累计目标。高估三档价格分都为零，但卖方之间仍可用溢价程度及风险重叠作同分取舍。

示例（非实时标的）：T=100、C=0.5，B=75。质量 95、P=74 的低估一档公司，价格分为 52，总分 73.5；质量 65、P=61 的低估二档公司（接近三档），价格分为 78，总分 71.5。两者都进入比较，高质量一档可以排在更便宜的普通公司之前。

## 替换条件与敏感性

卖方有真实可卖持仓且高估三档，买方在有效池且至少低估一档、缺口大于零、数据有效，且 `S买 > S卖`。同分不替换。必须展示分差，不将总分或分差解读为预期收益率，也不将交易费率直接减去“评分点”。交易成本在真实货币预算与经济判断中处理。

对最终配对以质量/价格权重 40/60、50/50、60/40 做敏感性展示，质量内部比例不变。使用用户选定权重生成主方案，其他权重只作对照。若候选排序或配对关系反转，说明方案对偏好敏感，不宣称唯一最优。不自动覆盖用户选定配置。

重大新事实、估值过时、市场口径不一致和不可转移资金是有效性问题，不靠高总分抵消。只为数据足够的配对分配资金，且每笔买入只能占用一次可用卖出预算。
