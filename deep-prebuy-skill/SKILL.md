# 深度公司基本面分析（大仓位尽调版）

## 定位说明

本技能与普通 `stock-prebuy-review` 形成互补而非替代关系：

| 维度 | 普通 PreBuy | 深度公司分析（本技能）|
|---|---|---|
| 使用场景 | 准备买入前快速排雷 | 重大仓位前系统性尽调 |
| 核心问题 | 现在能不能买 | 这家公司是否值得长期重仓 |
| 价格 / 估值 | ✅ 包含 | ❌ 不涉及（专注公司本体）|
| 深度 | 14 模块快速覆盖 | 8 大维度深度穿透 |
| 历史 DNA 分析 | ❌ | ✅ 从公司起源切入 |
| 战略体系分析 | ❌ | ✅ PESTEL + SWOT + 战略执行验证 |
| 量化评分 | ❌ | ✅ 100 分制多维评分 |
| 输出结论 | 买入逻辑验证 + 红旗 | 公司质量评级 + 长期持有适配度 |

> **推荐组合使用**：先用本技能判断"这家公司值不值得长期持有"，再用普通 PreBuy 判断"现在的价格时机是否合适"。

### 评级标准

| 总分 | 评级 | 含义 | 仓位建议 |
|---|---|---|---|
| 85–100 | ⭐⭐⭐⭐⭐ 卓越 | 极少数真正优质公司，长期持有首选 | 可做核心仓位（>10%）|
| 70–84 | ⭐⭐⭐⭐ 优质 | 基本面扎实，长期持有理由充分 | 可建重仓（5–10%）|
| 55–69 | ⭐⭐⭐ 良好 | 有明确优势，但存在需要持续跟踪的隐忧 | 标准仓位（2–5%）|
| 40–54 | ⭐⭐ 一般 | 有价值，但短板明显，需等待基本面改善 | 轻仓观察（<2%）|
| <40 | ⭐ 不达标 | 存在结构性问题，不建议重仓 | 放入 radar 观察，不建仓 |

> ⚠️ 任何单项维度得分 ≤ 该维度满分的 40%（即出现"严重缺陷"），**自动触发重大警告**，
> 无论总分多高，都不建议重仓——单点致命风险不能被其他维度平均化。

## 核心工作原则

1. **事实 / 推断 / 未知三分法**：每条结论必须明确标注来源；无法核实的标为「待补证据」并降低置信度。
2. **数据源优先级**：证监会/交易所官方披露 → 理杏仁 API → 东方财富/Tavily 验证 → 媒体/卖方报告。
3. **反证驱动**：不只找支持结论的证据，必须同步列出使这个公司"变差"的条件和证据。
4. **历史先于预测**：先弄清楚公司过去 5–10 年实际发生了什么，再判断未来。
5. **AI 不编造**：没有可靠来源的字段一律留空并标注「未核实」，禁止推测填充。

## 维度 A：历史基因与公司 DNA（满分 10 分）

### A1. 公司起源与创始基因

**研究要点：**
- 创始人背景：自然人创业 / 国企改制 / 政府背景 / 外资进入？
- 成立时间节点：是否处于行业萌芽期或政策红利期？（先发 vs 跟随）
- 原始主营业务：技术驱动 / 资源依赖 / 渠道起家 / 政策获取？
- 初始行业地位：领先者 / 跟随者 / 边缘参与者？

**数据来源**：招股说明书（上交所/深交所 → 历史 IPO 文件）

**结论框架**：
> 该公司成立于 \_\_\_\_ 年，由 \_\_\_\_ （背景类型）创立，初始定位为 \_\_\_\_，
> 属于（先发优势型 / 政策红利型 / 追随者型 / 资源型）起源基因。

### A2. 历史控制权稳定性

**研究要点：**
- 实际控制人变更次数（IPO 至今）
- 变更原因：股权争夺 / 家族传承 / 国资接手 / 财务危机被动稀释？
- 是否存在"壳资源"操作痕迹：主业频繁更换 + 无实质经营改善？

**量化信号**：
- 从未变更实控人 → 稳定性强
- 变更 1 次且为主动战略整合 → 中性
- 变更 ≥ 2 次或背景复杂 → 减分

### A3. 资本运作历史

**研究要点：**
- IPO / 增发 / 配股 / 可转债记录：资金实际用途 vs 当时承诺的用途是否一致？
- 并购行为类型：横向整合 / 纵向延伸 / 跨界并购 / 商誉积累？
- "卖资产保利润"行为识别：在业绩压力年份是否有非主营资产出售？

**红旗：**
- 🔴 并购后商誉占净资产 > 30%，且此后发生大额减值
- 🔴 融资频次高但主营业务现金流持续弱（靠融资输血非经营造血）
- 🟡 历次并购跨度大，与主业协同逻辑不清晰

### A4. 历史基因分类

综合以上判断公司历史运营类型（必填一项）：

- [ ] **经营型**：专注主业、靠运营能力驱动增长，管理层稳定
- [ ] **资本运作型**：频繁并购、擅长讲故事、利润来源不稳定
- [ ] **周期型**：业绩随行业周期波动明显，管理层无法控制核心变量
- [ ] **壳资源型**：主业空心化，历史有控制权频繁转移迹象

## 维度 B：商业模式质量（满分 20 分）

### B1. 当下业务板块全景

**研究要点：**
- 当前主要业务板块（按营收占比排序）
- 各板块 BCG 矩阵分类：

| 业务名称 | 营收占比 | 毛利率 | 增速 | BCG 定位 |
|---|---|---|---|---|
| | | | | 现金牛 / 明星 / 问题 / 瘦狗 |

- 是否存在单一业务过度集中（一项业务 > 70% 营收）？
- 是否有培育中的成长引擎，还是纯靠历史业务维持？

### B2. 盈利机制解析

**研究要点：**

| 盈利模式 | 判断结论 |
|---|---|
| 收费方式 | 按件 / 订阅制 / 项目制 / 佣金抽成 / 平台撮合 |
| 复购特征 | 高频复购 / 年度续费 / 一次性购买 |
| 需求刚性 | 刚性必需 / 可选消费 / 政策驱动 |
| 成本结构 | 固定成本主导（重资产）/ 变动成本主导 / 人力密集型 |
| 规模效应 | 强（规模越大单位成本越低）/ 弱（线性成本结构）|

**结论一句话**：
> 这是一家「\_\_\_\_\_\_\_\_」模式的公司，（复购率高/低），（刚性需求/可选消费），（有/无）规模效应。

## 维度 D：战略清晰度与执行力（满分 15 分）

### D1. 战略一致性分析

**研究要点（查近 3–5 年年报）：**
- 公司宣称的使命 / 愿景：是否长期一致还是频繁变换？
- 总体战略方向（发展/扩张 / 稳定维持 / 收缩聚焦）是否始终清晰？
- 业务竞争战略（成本领先 / 差异化 / 集中化）是否与实际资源投入一致？

**红旗：**
- 🔴 每年年报战略描述大幅变动，主题漂移明显

## 维度 E：财务质量（非估值）（满分 20 分）

### E1. ROE 质量与杜邦分析

**必做**（ROE ≥ 10% 时必须拆解，<10% 直接扣分）：

ROE = 净利率 × 资产周转率 × 权益乘数

| 年份 | 净利率 | 资产周转率 | 权益乘数 | ROE |
|---|---|---|---|---|
| 20XX | | | | |
| 20XX | | | | |
| 20XX | | | | |

**驱动因素判断**：
- ✅ 净利率驱动：运营效率提升，最健康
- ✅ 资产周转率驱动：轻资产模式红利
- ⚠️ 权益乘数驱动（加杠杆）：需结合负债率判断
- 🔴 权益乘数 > 3x 主导高 ROE → 标注"高杠杆伪装高ROE"

**数据来源**：理杏仁 `cn/company/fs/non_financial`，metricsList 含 ROE 相关字段

### E2. 现金流质量

**必查指标**：
- 经营现金流净额 / 归母净利润（近 3 年均值）：\_\_\_\_（健康标准：> 80%）
- 经营现金流净额 / 归母净利润趋势：改善/稳定/恶化
- 自由现金流（经营现金流 - 资本性支出）：是否持续为正？

**财务造假预警信号（量化）**：
- 营收增速 vs 应收账款增速：如应收增速持续 > 营收增速 2 年以上 → 🔴
- 净利润增速 vs 经营现金流增速：如净利润持续远高于现金流 → 🔴
- 存货增速 vs 营收增速：如存货积压持续扩大 → 🔴

**数据来源**：理杏仁 `cn/company/fs/non_financial`

```python
        f"&filter=(SECURITY_CODE%3D%22{code_6}%22)"
        "&pageNumber=1&pageSize=8"
    )
    r = requests.get(url, timeout=10)
    return r.json()["result"]["data"]

# 关键字段说明：
# WEIGHTAVG_ROE      → 加权平均ROE（%）
# MGJYXJJE           → 每股经营活动现金流量（元）← OCF核心字段
# PARENT_NETPROFIT   → 归母净利润（元）
# TOTAL_OPERATE_INCOME → 总营收（元）
# XSMLL              → 销售毛利率（%）
# QDATE              → 报告期（如 "2024Q4" = 年报）
# DATATYPE           → 报告类型文字（如 "2024年 年报"）
# BASIC_EPS          → 每股收益（元）

# OCF计算：总OCF ≈ MGJYXJJE × 总股本（需另行获取股本数）
# OCF质量 = 总OCF / PARENT_NETPROFIT（健康标准 > 1.0；水电/公用事业通常 > 1.5）
```

> ⚠️ **分红单位**：理杏仁 `cn/company/dividend` 的 `dividend` 字段单位是**元/股**（不是"分"）。
> 0.79 = 0.79元/股。`dividendAmount` 是总派现金额（元），需除以1亿换算成亿元。

## 常见执行顺序

1. **前置排除检查** → 若一票否决则终止

## 数据采坑手册（执行经验汇总）

> 以下为实际执行中踩过的坑，每次执行前必读。

### 坑 1：理杏仁 gzip 解码偶发失败

**现象**：`json.loads(gzip.decompress(resp.content))` 抛 `OSError: Not a gzip file`。
**原因**：API 有时即使请求了 `Accept-Encoding: gzip`，仍直接返回明文 JSON。
**修复**：`lx_post` 函数必须用 try/except 双路解码（见上方代码模板）。

---

### 坑 2：fs/non_financial 响应字段不是扁平 key

**现象**：`d.get("y.ps.toi.t")` 返回 `None`。
**原因**：`metricsList` 的点号路径是**请求语法**，响应体是嵌套 dict，不是扁平 key。
**修复**：必须按嵌套层级访问：

```python
y = d.get("y", {})
toi = y.get("ps", {}).get("toi", {}).get("t", "N/A")
```

---

### 坑 3：fs/non_financial 无效字段静默返回 None

**现象**：`metricsList` 中写了 `y.ps.ocf.t`（经营现金流）或 `y.bs.se.t`（净资产），API 不报错，但数据返回 None。
**有效字段**（已实测）：`y.ps.toi.t` / `y.ps.np.t` / `y.bs.ta.t` / `y.bs.tl.t`
**OCF 获取**：改用东方财富 `MGJYXJJE`（每股经营现金流）字段计算。
**净资产**：必须手算 = `ta - tl`。

---

### 坑 4：fundamental/non_financial 用年末日期历史 ROE 全为 None

**现象**：传入 `date: "2020-12-31"` 等年末日，所有 ROE/PE/PB 字段返回 None。
**原因**：`fundamental/*` 必须传**最近交易日**（非周末/节假日/年末）才能返回数据。
**修复**：
- 当前估值 → 用 `last_trading_day()` 计算最近交易日
- 历史年度 ROE → 改用东方财富 API 的 `WEIGHTAVG_ROE` 字段

---

### 坑 5：Python 脚本必须写成 .py 文件

**现象**：将多行 Python 代码嵌入 PowerShell `-c "..."` 或 heredoc，语法报错（f-string内引号转义、缩进等问题）。
**原因**：PowerShell 不支持 Unix-style `<< 'EOF'`；多行 `-c` 字符串中的内嵌引号极易冲突。
**修复**：用 `Set-Content` 将 Python 代码写入 `_tmp_xxx.py`，再用 `python _tmp_xxx.py` 执行，分析结束后 `Remove-Item` 清理。
